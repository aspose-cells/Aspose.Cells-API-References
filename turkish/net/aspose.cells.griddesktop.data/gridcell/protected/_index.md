## GridCell.Protected property

Hücrenin korumalı olup olmadığını gösterir. Değer "true" ise, kullanıcı kullanıcı arayüzü üzerinden hücreyi değiştiremez. Bu öznitelik Style.CellLocked özelliğiyle hiçbir ilişkisi yoktur ve ızgara verileri dışa aktarıldığında dosyaya kaydedilmez. Varsayılan değer "false"dır.

```csharp
public bool Protected { get; set; }
```
