Bu **Aspose.Cells.ExternalConnections** ad alanı, veritabanları ve web gibi dış kaynaklardan veri almak için dış bağlantılar sağlayan sınıflar sunar.

## Sınıflar

| Sınıf | Açıklama |
| --- | --- |
| [ConnectionParameter](./connectionparameter/) | Harici veri bağlantılarıyla kullanılan parametrelerle ilgili özellikleri belirtir; parametreler ODBC ve web sorguları için geçerlidir. |
| [ConnectionParameterCollection](./connectionparametercollection/) | [`ConnectionParameter`](../aspose.cells.externalconnections/connectionparameter/) koleksiyonunu belirtir |
| [DataModelConnection](./datamodelconnection/) | Bir veri modeli bağlantısını belirtir |
| [DBConnection](./dbconnection/) | ODBC veya OLE DB harici veri bağlantısıyla ilişkili tüm özellikleri belirtir. |
| [ExternalConnection](./externalconnection/) | Harici bir veri bağlantısını belirtir |
| [ExternalConnectionCollection](./externalconnectioncollection/) | [`ExternalConnection`](../aspose.cells.externalconnections/externalconnection/) koleksiyonunu belirtir |
| [WebQueryConnection](./webqueryconnection/) | Web sorgu kaynağı için özellikleri belirtir. Bir web sorgusu, HTML tablolarından veri alır ve ayrıca parametreleri ve parametre öğelerini dahil ederek HTML oluşturulurken web sunucusu tarafından işlenmek üzere HTTP \"Get\" parametreleri sağlayabilir. |
