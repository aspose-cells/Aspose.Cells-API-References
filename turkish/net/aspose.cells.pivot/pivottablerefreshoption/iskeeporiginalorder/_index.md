## PivotTableRefreshOption.IsKeepOriginalOrder property

Pivot öğelerinin orijinal sırasının eski veri kaynağı gibi korunup korunmayacağını gösterir.

```csharp
public bool IsKeepOriginalOrder { get; set; }
```

### Açıklamalar

Sıralanmamış pivot alanı için yalnızca geçerlidir. Böyle bir pivot alanı yenilendiğinde, Ms Excel eski veri kaynağının orijinal sırasını korur. Bu özelliğin varsayılan değeri true'tır ve Ms Excel ile aynı davranışı temsil eder. Kullanıcı, pivot alanının yeni veri kaynağındaki veriler gibi tamamen yenilenmesini istiyorsa, bu özellik false olarak ayarlanmalıdır.
