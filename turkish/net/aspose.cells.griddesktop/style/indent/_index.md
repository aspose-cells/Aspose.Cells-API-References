## Style.Indent property

Hücre veya aralık için m_IndentLevel seviyesini temsil eder. Yalnızca 0 ile 15 arasında bir tam sayı olabilir.

```csharp
public int Indent { get; set; }
```

### Açıklamalar

Metin yatay hizalama tipi sol veya sağ dışında bir değere ayarlanırsa, m_IndentLevel seviyesi sıfıra sıfırlanır.
