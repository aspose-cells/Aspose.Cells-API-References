## GridDesktop.EnableClipboardCopyPaste property

Panoya dayalı kopyalama/yapıştırmayı gösterir, böylece MS-EXCEL ile kopyala/yapıştır yapılabilir. Yalnızca hücre değerini kopyalar/yapıştırır, hücrenin formatı, kenarlık stili vb. gibi diğer ayarları kopyalamaz. Varsayılan değer false'tur.

public bool EnableClipboardCopyPaste { get; set; }
