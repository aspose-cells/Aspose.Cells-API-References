## GridTxtLoadOptions.TreatQuotePrefixAsValue property

Başlangıçtaki tek tırnak işaretinin bir hücrenin değerinin bir parçası olarak alınması gerekip gerekmediğini gösterir. Varsayılan true'dur. False ise, ilgili hücrenin değerinden başlangıçtaki tek tırnak kaldırılır ve [`QuotePrefix`](../../../aspose.cells.gridweb/gridtableitemstyle/quoteprefix/) hücre için true olarak ayarlanır.

```csharp
public bool TreatQuotePrefixAsValue { get; set; }
```
