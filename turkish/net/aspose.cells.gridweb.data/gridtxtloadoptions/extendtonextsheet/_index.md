## GridTxtLoadOptions.ExtendToNextSheet property

Veri satırları veya sütunları sınırı aştığında verinin bir sonraki sayfaya genişletilip genişletilmeyeceği. Bu özellik true ise, fazla veri mevcut sayfanın arkasındaki bir sonraki sayfaya genişletilir (eğer mevcut sayfa son sayfa ise, yeni sayfa mevcut çalışma kitabına eklenir). Bu özellik false ise, sınırı aşan veri yok sayılır. Varsayılan değer false;

```csharp
public bool ExtendToNextSheet { get; set; }
```
