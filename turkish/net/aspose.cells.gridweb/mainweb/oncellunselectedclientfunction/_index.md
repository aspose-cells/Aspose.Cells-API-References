## MainWeb.OnCellUnselectedClientFunction property

İstemci fonksiyonu şu şekilde tanımlanmalıdır: function MyOnUnselectCell(cell) { this.setCellValueByCell(cell, \"test\"); } Not: Olayı tetikleyen ızgara denetimini işaret etmek için istemci fonksiyonunda \"this\" işaretçisini kullanabilirsiniz.
