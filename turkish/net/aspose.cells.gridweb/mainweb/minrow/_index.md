## MainWeb.MinRow property

Web sayfasının minimum görüntüleme satır indeksini (sıfır tabanlı) alır veya ayarlar. Denetim, MinRow ve sayfa verisinin minimum satır değerinden daha küçük olanı kullanır.

```csharp
public int MinRow { get; set; }
```

### Örnekler

```csharp
[C#]
	// 4x4 "görüntü penceresi" oluşturur.
	GridWeb1.MinRow = 2;
	GridWeb1.MaxRow = 5;
	GridWeb1.MinColumn = 3;
	GridWeb1.MaxColumn = 6;

[Visual Basic]
```
