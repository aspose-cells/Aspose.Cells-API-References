## MainWeb.OnPageChangeClientFunction property

Sayfa indeksi değiştikten sonra çağrılacak istemci tarafı işlevi alır veya ayarlar. Yalnızca EnablePaging true olduğunda etkili olur. İstemci işlevi şu şekilde tanımlanmalıdır: function MyOnPageChange(index) { console.log("current page is:"+index); }Not: İstemci işlevinde "this" işaretçisini, olayı tetikleyen ızgara kontrolüne işaret etmek için kullanabilirsiniz.

public string OnPageChangeClientFunction { get; set; }
