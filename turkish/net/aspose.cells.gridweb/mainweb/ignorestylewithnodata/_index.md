## MainWeb.IgnoreStyleWithNoData property

GridWeb'in hücre değeri içermeyen ancak stillendirilmiş satırları veya sütunları göstermeyi göz ardı edip etmeyeceğini alır veya ayarlar. true olarak ayarlanırsa performans daha iyi olur. Varsayılan değer false'tur; bu, son ardışık satır/sütunun hücre değeri olmaması ancak stillendirilmiş olması durumunda yine de görüntüleneceği anlamına gelir. Bu seçenek yalnızca EnableAsync false olduğunda geçerlidir. EnableAsync true olduğunda bu seçeneğin etkisi yoktur; bu, GridWeb'in stil uygulanmış tüm satırları/sütunları göstereceği anlamına gelir.

public bool IgnoreStyleWithNoData { get; set; }
