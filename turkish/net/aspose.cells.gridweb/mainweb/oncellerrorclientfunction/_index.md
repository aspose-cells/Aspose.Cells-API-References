## MainWeb.OnCellErrorClientFunction property

İstemci fonksiyonu şu şekilde tanımlanmalıdır: function MyOnCellError(cell) { alert(this.getCellValueByCell(cell)); } Not: Olayı tetikleyen ızgara denetimini işaret etmek için istemci fonksiyonunda \"this\" işaretçisini kullanabilirsiniz.
