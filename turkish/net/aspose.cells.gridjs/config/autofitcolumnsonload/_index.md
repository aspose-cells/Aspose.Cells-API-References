## Config.AutoFitColumnsOnLoad property

Dosya yüklenirken sütun genişliklerinin otomatik ayarlanıp ayarlanmayacağını belirtir. Varsayılan değer `false`'dur. Uyarı: Bunu `true` olarak ayarlamak, yükleme sonrasında tüm sütunların otomatik ayarlanmasını gerçekleştirir ve bu, performans üzerinde belirgin bir etki yaratabilir.

public static bool AutoFitColumnsOnLoad { get; set; }
