## Config.MaxShapeOrImageWidthOrHeight property

Alır/Ayarlar bir şekil veya görüntünün maksimum genişlik veya yüksekliğini, GridJs bu genişlik veya yüksekliği aşan şekil veya görüntüyü yok sayar, IslimitShapeOrImage=true olduğunda etkili olur. Varsayılan değer 10000'dir.

public static int MaxShapeOrImageWidthOrHeight { get; set; }
