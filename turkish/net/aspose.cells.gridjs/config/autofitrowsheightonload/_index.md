## Config.AutoFitRowsHeightOnLoad property

Dosya yüklenirken satır yüksekliklerinin otomatik ayarlanıp ayarlanmayacağını belirtir. Varsayılan değer `false`'dur. Uyarı: Bunu `true` olarak ayarlamak, yükleme sonrasında tüm satırların otomatik ayarlanmasını gerçekleştirir ve bu, performans üzerinde belirgin bir etki yaratabilir.

public static bool AutoFitRowsHeightOnLoad { get; set; }
