## Config.EnableChartClientRendering property

İstemci tarafı grafik render'ını etkinleştirip etkinleştirmeyeceğini alır/ayarlar. false olarak ayarlanırsa, GridJs yalnızca sunucu tarafından oluşturulan grafik görüntüleri/şekilleri kullanır. Varsayılan değer true'tir.

```csharp
public static bool EnableChartClientRendering { get; set; }
```
