## JsonCacheOptions.Enable property

Alır/Ayarlar JSON önbelleklemesini daha hızlı yanıt için etkinleştirip etkinleştirmeyeceğini. Etkinleştirildiğinde, GridJs oluşturulan JSON'ı önbelleğe alır ve sonraki isteklerde yeniden kullanır. Varsayılan değer false'tur. Not: Özel önbellek depolama kullanmak için Implementation'ı ayarlamanız gerekir.

```csharp
public bool Enable { get; set; }
```
