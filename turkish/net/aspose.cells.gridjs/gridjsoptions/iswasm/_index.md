## GridJsOptions.IsWasm property

Alır/Ayarlar GridJs'in bir sunucu süreci yerine tarayıcı WebAssembly ana bilgisayarında çalışıp çalışmayacağını. True olduğunda, FileCacheDirectory / disk / interrupt-thread yolu kullanılmaz ve dosya önbelleği CacheImp'ten gelmelidir, çünkü tarayıcı ana bilgisayarında yerel disk yoktur. Çalışma zamanında kod yolları seçilir, böylece tek bir Aspose.Cells.GridJs.dll her iki ana bilgisayarı da hizmet verir. Varsayılan değer false'tur.

```csharp
public bool IsWasm { get; set; }
```
