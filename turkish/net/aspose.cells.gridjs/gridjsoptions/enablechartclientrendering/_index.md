## GridJsOptions.EnableChartClientRendering property

İstemci tarafı grafik renderlamasını etkinleştirip etkinleştirmeyeceğini alır/ayarlar. False olarak ayarlanırsa, GridJs yalnızca grafik resimleri/şekilleri üretir ve istemci tarafı grafik renderlaması gerektirmez. Varsayılan değer true'tur.

```csharp
public bool EnableChartClientRendering { get; set; }
```
