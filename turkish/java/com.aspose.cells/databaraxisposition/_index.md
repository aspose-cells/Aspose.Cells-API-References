### AUTOMATIC {#AUTOMATIC}
```
public static final int AUTOMATIC
```


Eksen, aralıktaki minimum negatif değer ile maksimum pozitif değer oranına göre değişken bir konumda gösterilir. Pozitif değerler soldan sağa yönünde gösterilir. Negatif değerler sağdan sola yönünde gösterilir. Tüm değerler pozitif ya da tüm değerler negatif olduğunda, eksen gösterilmez.

### MIDPOINT {#MIDPOINT}
```
public static final int MIDPOINT
```


Eksen, aralıktaki değer kümesinden bağımsız olarak hücrenin orta noktasında gösterilir. Pozitif değerler soldan sağa yönünde gösterilir. Negatif değerler sağdan sola yönünde gösterilir.

### NONE {#NONE}
```
public static final int NONE
```


Eksen görüntülenmez ve pozitif ile negatif değerler soldan sağa doğru yönlendirilir.
