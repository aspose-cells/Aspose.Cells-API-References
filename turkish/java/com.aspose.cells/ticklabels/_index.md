```
public int getOffset()
```


Etiketlerin kategori ekseninden olan mesafesini alır. Bu yalnızca kategori (x) ekseni için geçerlidir.

**Remarks**

Varsayılan mesafe %100'dür ve bu, eksen etiketleri ile eksen çizgisi arasındaki varsayılan boşluğu temsil eder. Değer, eksen etiket''nin yazı tipi boyutuna göre 0 ile 1000 arasında bir tam sayı yüzde olarak olabilir.
