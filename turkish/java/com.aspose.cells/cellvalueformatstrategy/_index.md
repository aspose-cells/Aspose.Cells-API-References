### DISPLAY_STRING {#DISPLAY-STRING}
```
public static final int DISPLAY_STRING
```


MS Excel'de gösterilen görüntülenen dizeyi alır. [DISPLAY\\_STYLE](../../com.aspose.cells/cellvalueformatstrategy\\#DISPLAY-STYLE) ile olan temel fark, bu seçeneğin ayrıca sütun genişliğinin etkisini de dikkate almasıdır. Eğer sütun genişliği biçimlendirilmiş dizeyi tamamen gösterecek kadar küçükse, \"\\#\" gösterilebilir, tıpkı MS Excel'in yaptığı gibi.
