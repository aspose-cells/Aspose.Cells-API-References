### MERGE_FORCELY {#MERGE-FORCELY}
```
public static final int MERGE_FORCELY
```


HTML'ye dosya dışa aktarılırken boş TD öğesinin zorunlu birleştirilmesi. Değeri true olarak ayarladıktan sonra HTML dosyasının boyutu önemli ölçüde azalacaktır. HTML dosyasını Excel'e içe aktarmak veya dosyayı HTML olarak kaydederken mükemmel ızgara çizgileri dışa aktarmak istiyorsanız, lütfen varsayılan değeri koruyun.

### NONE {#NONE}
```
public static final int NONE
```


HTML'ye dosya dışa aktarılırken boş TD öğeleri birleştirilmeyecek. Bu, önemli ölçüde daha büyük bir HTML dosyası oluşturacaktır.
