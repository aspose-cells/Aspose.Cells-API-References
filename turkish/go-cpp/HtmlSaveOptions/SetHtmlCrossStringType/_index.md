## SetHtmlCrossStringType function

Excel dosyasını html formatında kaydederken çapraz hücre dizesinin MS Excel'de olduğu gibi görüntülenip görüntülenmeyeceğini gösterir. Varsayılan değer Default'tır, bu nedenle çapraz hücre dizeleri için Aspose.Cells tarafından oluşturulan html dosyaları ile MS Excel arasında çok az fark vardır. Ancak büyük html dosyaları oluştururken değeri Cross olarak ayarlamak, Default veya Fit2Cell'e göre birkaç kat daha hızlı olur.
