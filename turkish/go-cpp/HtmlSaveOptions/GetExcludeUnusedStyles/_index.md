## GetExcludeUnusedStyles function

Kullanılmayan stillerin dışlanıp dışlanmayacağını gösterir. Oluşturulan HTML dosyalarında, kullanılmayan stillerin dışlanması dosya boyutunu görsel etkilere zarar vermeden küçültebilir. Bu nedenle bu özelliğin varsayılan değeri true'dur. Kullanıcı, oluşturulan HTML'de (örneğin, daha sonra HTML'den çalışma kitabını geri yükleme senaryosu gibi) çalışma kitabındaki tüm stilleri tutması gerekiyorsa, lütfen bu özelliği false olarak ayarlasın.
