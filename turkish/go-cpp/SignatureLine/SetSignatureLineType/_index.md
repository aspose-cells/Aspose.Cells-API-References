## SetSignatureLineType function

İmza türünü alır veya ayarlar. Default - Varsayılan değer ayarlandığında, ilgili ProviderId değeri {0000000000-0000-0000-0000-0000000000} olarak sabitlenir. Stamp - Değer Stamp olduğunda, ilgili ProviderId değeri genellikle {000CD6A4-0000-0000-C000-000000000046} olur. Custom - Değer Custom olduğunda, ilgili ProviderId değerinin genellikle kullanıcı tarafından ayarlanması gerekir. Bu değer, sağlayıcıyla birlikte gelen belgelerden elde edilmelidir.

```go

func (instance *SignatureLine) SetSignatureLineType(value SignatureType)  error
```
