## SetExportCellName function

Excel2007 .xlsx (.xlsm, .xltx, .xltm) dosyasına hücre adının dışa aktarılıp aktarılmayacağını gösterir. Çıktı dosyasına SQL Server DTS tarafından erişilebilecekse, bu değer true olmalıdır. Değeri false olarak ayarlamak, büyük dosya oluştururken performansı önemli ölçüde artıracak ve dosya boyutunu azaltacaktır. Varsayılan değer true'tir.
