## ExcelRenderingBehavior Enum

Bir çalışma kitabı render edilirken uygulanacak Excel'e özgü render davranışlarını belirtir.

```go

type ExcelRenderingBehavior int32


```

## Alanlar

| Alan | Açıklama |
| --- | --- |
| [None](./none/) | Excel'e özgü renderleme davranışlarını uygulamaz. |
| [CellTextLengthLimit](./celltextlengthlimit/) | Excel'in hücre metni çıktı uzunluğu limitini uygular. Örneğin, Excel sarılmamış bir hücrede yalnızca ilk 1024 karakteri çıktılar. |
| [All](./all/) | Desteklenen tüm Excel'e özgü renderleme davranışlarını uygular. |
