## ShapeCollection.Find method

Найти фигуру по тексту

```csharp
public int Find(string what, int previous, FindOptions findOptions)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| что | String | Текст для поиска. |
| предыдущий | Int32 | Индекс предыдущей фигуры, содержащей тот же текст. -1, если поиск начинается с начала. |
| findOptions | FindOptions | Параметры поиска |

### Возвращаемое значение

Индекс найденной фигуры, -1 если фигура не найдена.
