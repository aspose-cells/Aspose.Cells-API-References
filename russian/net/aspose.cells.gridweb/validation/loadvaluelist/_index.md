## Validation.LoadValueList method

Загружает список значений из объекта DataView. Вы можете указать поле значения и поле текста объекта DataView. Каждая пара значения и текста будет объединена в одну строку, разделённую запятой.

```csharp
public void LoadValueList(DataView view, string valueField, string textField, bool valuePrefixText)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| вид | DataView | Объект DataView. |
| valueField | String | Имя поля значения. |
| textField | String | Имя текстового поля. |
| valuePrefixText | Boolean | Указывает, следует ли добавлять префикс значения к каждому отображаемому тексту. |
