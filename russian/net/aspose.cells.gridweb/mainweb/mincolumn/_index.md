## MainWeb.MinColumn property

Получает или задает минимальный индекс отображаемого столбца (нумерация с нуля) веб‑листа. Элемент управления использует меньшее значение из MinColumn и минимального столбца данных листа.

```csharp
public int MinColumn { get; set; }
```

### Примеры

```csharp
[C#]
	// Создаёт 4×4 «окно отображения».
	GridWeb1.MinRow = 2;
	GridWeb1.MaxRow = 5;
	GridWeb1.MinColumn = 3;
	GridWeb1.MaxColumn = 6;

[Visual Basic]
	' Creates a 4x4 "display window".
	GridWeb1.MinRow = 2
	GridWeb1.MaxRow = 5
	GridWeb1.MinColumn = 3
	GridWeb1.MaxColumn = 6
```
