## MainWeb.OnSubmitClientFunction property

Получает или задает клиентскую функцию, вызываемую перед отправкой управления на клиенте. Клиентская функция должна быть объявлена так: function MyOnSubmit(arg, cancelEdit) { return true;} Параметр arg – аргумент отправки, содержит команду, которая будет передана на сервер. Параметр cancelEdit – логическое значение, указывающее, отменил ли контроль ввод пользователя перед отправкой. Управление продолжит отправку, если функция вернёт true. Примечание: Вы можете использовать указатель \"this\" в клиентской функции, чтобы указать на элемент управления сеткой, который генерирует событие.

```csharp
public string OnSubmitClientFunction { get; set; }
```
