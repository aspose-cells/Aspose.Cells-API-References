## MainWeb.EnablePaging property

Получает или задает, включать ли режим постраничного отображения элемента управления.

```csharp
public bool EnablePaging { get; set; }
```

### Примечания

Когда установлено в true, элемент управления отобразит PageSize строк данных за раз и покажет элемент выбора страницы на вкладке.
