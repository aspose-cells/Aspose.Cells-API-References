## MainWeb.ShowCellEditBox property

Отображает ли Gridweb панель инструментов редактирования, как в MS‑EXCEL. Если включено, для текущей ячейки будет отображаться поле редактирования в Gridweb. При включении этой функции необходимо импортировать библиотеку jquery js в ваши файлы aspx для поддержки новой возможности; подходит любая актуальная версия jquery и т.п.

```csharp
public bool ShowCellEditBox { get; set; }
```
