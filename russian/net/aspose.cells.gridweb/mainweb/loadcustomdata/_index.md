## MainWeb.LoadCustomData event

Срабатывает, когда свойство SessionMode элемента управления установлено в Custom и требуется загрузить данные листа. Вы можете обработать это событие в режиме Custom Session для загрузки данных листа из файла или базы данных.

```csharp
public event WorkbookEventHandler LoadCustomData;
```
