## MainWeb.ShowLoadingPosition property

Указывает левую и верхнюю позицию (в пикселях) для отображения диалогового окна загрузки во время обратного вызова на сервер и т.д. 100,200 означает, что левая и верхняя позиция диалогового окна загрузки находятся на 100 px и 200 px.

```csharp
public string ShowLoadingPosition { get; set; }
```
