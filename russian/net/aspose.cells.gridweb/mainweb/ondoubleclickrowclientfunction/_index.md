## MainWeb.OnDoubleClickRowClientFunction property

Получает или задает клиентскую функцию, которая будет вызываться при двойном щелчке по строке. Клиентская функция должна быть объявлена так: function MyOnRowDoubleClick(row) { alert(row); }Примечание: Вы можете использовать указатель \"this\" в клиентской функции, чтобы указать на элемент управления сеткой, который генерирует событие.

```csharp
public string OnDoubleClickRowClientFunction { get; set; }
```
