## MainWeb.OnAjaxCallFinishedClientFunction property

Получает или задает имя клиентской функции, вызываемой после завершения ajaxcall. Клиентская функция должна быть объявлена так: function GridAjaxcallFinished() { alert(this.id+\" ajaxcall finished \"); } Примечание: вы можете использовать указатель \"this\" в клиентской функции, чтобы ссылаться на элемент управления сеткой, который генерирует событие.

```csharp
public string OnAjaxCallFinishedClientFunction { get; set; }
```
