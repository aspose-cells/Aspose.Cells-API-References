## MainWeb.SessionStorePath property

Получает или задает путь к хранилищу кэша сеанса, когда режим сеанса установлен в File или ViewState и т.д.: gridweb.SessionStorePath=\"c:/mytempdir/session\"; тогда данные сеанса будут сохраняться в c:/mytempdir/session.

public string SessionStorePath { get; set; }
