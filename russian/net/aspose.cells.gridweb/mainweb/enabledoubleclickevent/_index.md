## MainWeb.EnableDoubleClickEvent property

Получает или задает, включать ли событие двойного щелчка на клиентской стороне.

```csharp
public bool EnableDoubleClickEvent { get; set; }
```

### Примечания

Когда установлено в true, элемент управления будет получать события двойного щелчка на стороне клиента, и вы можете обрабатывать эти события на стороне сервера. В противном случае элемент управления будет игнорировать любые события двойного щелчка.
