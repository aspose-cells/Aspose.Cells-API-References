## MainWeb.ColumnDeleting event

Происходит, когда пользователь пытается удалить столбец из контекстного меню на клиенте. Вы можете обработать это событие и установить параметр cancel в значение True, чтобы отменить операцию удаления.

```csharp
public event RowColumnEventHandler ColumnDeleting;
```
