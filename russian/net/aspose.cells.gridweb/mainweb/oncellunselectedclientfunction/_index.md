## MainWeb.OnCellUnselectedClientFunction property

Получает или задает клиентскую функцию, вызываемую при снятии выделения с ячейки. Клиентская функция должна быть объявлена так: function MyOnUnselectCell(cell) { this.setCellValueByCell(cell, \"test\"); } Примечание: вы можете использовать указатель \"this\" в клиентской функции, чтобы ссылаться на элемент управления сеткой, который генерирует событие.

```csharp
public string OnCellUnselectedClientFunction { get; set; }
```
