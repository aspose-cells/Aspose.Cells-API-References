## MainWeb.OnGridInitClientFunction property

Получает или задает имя клиентской функции, которая будет вызываться при инициализации сетки. Клиентская функция должна быть объявлена так: function MyOnGridInit(grid) { alert(\"The grid is initialized: \" + grid.id); }Примечание: Вы можете использовать указатель \"this\" в клиентской функции, чтобы указать на элемент управления сеткой, который генерирует событие.

```csharp
public string OnGridInitClientFunction { get; set; }
```
