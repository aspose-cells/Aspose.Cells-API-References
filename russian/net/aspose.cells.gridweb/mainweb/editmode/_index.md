## MainWeb.EditMode property

Получает или задает режим редактирования элемента управления.

```csharp
public bool EditMode { get; set; }
```

### Примечания

Когда установлено в true, ячейки элемента управления редактируемы, и отображаются значки "save" и "undo". Когда установлено в false, ячейки элемента управления только для чтения, и значки "save" и "undo" не отображаются.
