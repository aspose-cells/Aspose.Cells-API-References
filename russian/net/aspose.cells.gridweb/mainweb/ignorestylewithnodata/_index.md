## MainWeb.IgnoreStyleWithNoData property

Получает или задает, игнорирует ли GridWeb отображение строк или столбцов, которые не содержат значений ячеек, но имеют стиль. Если установить значение true, производительность будет лучше. Значение по умолчанию — false, что означает, что если последняя последовательная строка/столбец не содержит значений ячеек, но имеет стиль, они всё равно будут отображаться. Эта опция действительна только когда EnableAsync равно false. Эта опция не влияет, когда EnableAsync равно true, что означает, что GridWeb будет показывать все строки/столбцы со стилем.

```csharp
public bool IgnoreStyleWithNoData { get; set; }
```
