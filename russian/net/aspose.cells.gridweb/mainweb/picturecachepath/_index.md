## MainWeb.PictureCachePath property

Получает или задает путь хранения изображений для рабочей книги; все фигуры и изображения будут сохраняться в этом каталоге, путь по умолчанию — acwcache в базовом каталоге текущего приложения. Пользователи должны реализовать плановый сервис для очистки файлов, срок действия которых истёк.

```csharp
public static string PictureCachePath { get; set; }
```
