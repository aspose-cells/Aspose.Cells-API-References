## MainWeb.OnDoubleClickCellClientFunction property

Получает или задает клиентскую функцию, которая будет вызываться при двойном щелчке по ячейке. Клиентская функция должна быть объявлена так: function MyOnDoubleClickCell(cell) { this.setCellValueByCell(cell, \"test\"); }Примечание: Вы можете использовать указатель \"this\" в клиентской функции, чтобы указать на элемент управления сеткой, который генерирует событие.

```csharp
public string OnDoubleClickCellClientFunction { get; set; }
```
