## MainWeb.OnCellSelectedAjaxCallBackClientFunction property

Получает или задает клиентскую функцию, вызываемую при выборе ячейки. Клиентская функция должна быть объявлена так: function MyOnSelectCellAjaxCallBack(cell,customerdata) { } Примечание: вы можете использовать указатель \"this\" в клиентской функции, чтобы ссылаться на элемент управления сеткой, который генерирует событие.

```csharp
public string OnCellSelectedAjaxCallBackClientFunction { get; set; }
```
