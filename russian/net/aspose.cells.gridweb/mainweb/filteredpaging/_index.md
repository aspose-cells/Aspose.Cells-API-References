## MainWeb.FilteredPaging property

Получает или задает, включать ли постраничный вывод после фильтрации данных, будет применяться, когда EnablePaging равно true.

```csharp
public bool FilteredPaging { get; set; }
```

### Примечания

Когда установлено в true, элемент управления будет выполнять постраничный вывод на основе отфильтрованных данных; значение по умолчанию — false.
