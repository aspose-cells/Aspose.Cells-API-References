## MainWeb.EnableStyleDialogbox property

Получает или задает, включать ли диалоговое окно стилей на клиентской стороне.

```csharp
public bool EnableStyleDialogbox { get; set; }
```

### Примечания

Когда установлено в true, пользователь может использовать style dialogbox для установки стиля ячейки, выбрав "Format Cell..." в всплывающем меню.
