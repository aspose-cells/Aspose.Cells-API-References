## MainWeb.UseClientPageHeight property

Получает или задает, использовать ли GridWeb высоту клиентской страницы в качестве высоты элемента управления; подходит, когда установлено Height="100%", значение по умолчанию — false.

```csharp
public bool UseClientPageHeight { get; set; }
```
