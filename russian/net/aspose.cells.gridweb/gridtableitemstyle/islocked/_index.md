## GridTableItemStyle.IsLocked property

Получает или задаёт значение, указывающее, может ли ячейка быть изменена, когда лист защищён. Когда лист защищён и IsLocked равно true, ячейка не может быть отредактирована. Когда лист защищён и IsLocked равно false, ячейка может быть отредактирована.

```csharp
public bool IsLocked { get; set; }
```
