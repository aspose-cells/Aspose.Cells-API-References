## Worksheet.SetProtected method

Устанавливает, защищён ли cellRange. Это расширенный метод, используемый только в Grid. Этот метод не связан со свойством cell.Style.CellLocked и не будет влиять после сохранения в файл Excel.

```csharp
public void SetProtected(CellRange range, bool isProtected)
```

| --- | --- | --- |
| диапазон | CellRange | Объект CellRange. |
| isProtected | Boolean | Булево значение для установки. |
