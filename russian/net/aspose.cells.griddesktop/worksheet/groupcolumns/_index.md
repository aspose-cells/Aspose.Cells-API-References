## GroupColumns(int, int, bool, bool) {#groupcolumns_1}

Группирует столбцы.

```csharp
public void GroupColumns(int firstColumn, int lastColumn, bool isHidden, bool addToUndo)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| firstColumn | Int32 | Индекс первого столбца для группировки. |
| lastColumn | Int32 | Индекс последнего столбца для группировки. |
| isHidden | Boolean | Указывает, скрыты ли сгруппированные столбцы |
| addToUndo | Boolean | Указывает, будет ли эта операция добавлена в менеджер отмены. Кроме того, свойство EnableUndo объекта GridDesktop должно быть установлено в true. |
