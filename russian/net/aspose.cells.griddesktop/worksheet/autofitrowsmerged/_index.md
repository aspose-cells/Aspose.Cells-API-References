## Worksheet.AutoFitRowsMerged method

Автоматически подгоняет высоту всех строк в этом листе. Также будет автоматически подгонять высоту строки, когда ячейки объединены в строке.

```csharp
public void AutoFitRowsMerged()
```

### Примечания

Если ячейки объединены в строке и автоматически подгоняется высота строк в MS Excel, MS Excel не расширяет высоту строки. Aspose.Cells расширит высоту строки, чтобы вместить данные ячеек.
