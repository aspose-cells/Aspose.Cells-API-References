## FormatConditionType enumeration

Тип правила условного форматирования.

```csharp
public enum FormatConditionType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| CellValue | `0` | Это правило условного форматирования сравнивает значение ячейки с результатом вычисленной формулы, используя оператор. |
| Expression | `1` | Это правило условного форматирования содержит формулу для вычисления. Когда результат формулы истинный, ячейка выделяется. |
| ColorScale | `2` | Это правило условного форматирования создает градуированную цветовую шкалу в ячейках. |
| DataBar | `3` | Это правило условного форматирования отображает градуированную полоску данных в диапазоне ячеек. |
| IconSet | `4` | Это правило условного форматирования применяет значки к ячейкам в соответствии с их значениями. |
| Top10 | `5` | Это правило условного форматирования выделяет ячейки, значения которых попадают в верхний N или нижний N диапазон, как указано. |
| UniqueValues | `6` | Это правило условного форматирования выделяет уникальные значения в диапазоне. |
| DuplicateValues | `7` | Это правило условного форматирования выделяет дублированные значения. |
| ContainsText | `8` | Это правило условного форматирования выделяет ячейки, содержащие заданный текст. Эквивалентно использованию функции листа SEARCH() для определения, содержит ли ячейка текст. |
| NotContainsText | `9` | Это правило условного форматирования выделяет ячейки, которые не пусты. Эквивалентно использованию LEN(TRIM()). Это означает, что если ячейка содержит только символы, которые удалит TRIM(), она считается пустой. Пустая ячейка также считается пустой. |
| BeginsWith | `10` | Это правило условного форматирования выделяет ячейки в диапазоне, которые начинаются с заданного текста. Эквивалентно использованию функции листа LEFT() и сравнению значений. |
| EndsWith | `11` | Это правило условного форматирования выделяет ячейки, заканчивающиеся заданным текстом. Эквивалентно использованию функции листа RIGHT() и сравнению значений. |
| ContainsBlanks | `12` | Это правило условного форматирования выделяет ячейки, которые полностью пусты. Эквивалентно использованию LEN(TRIM()). Это означает, что если ячейка содержит только символы, которые удалит TRIM(), она считается пустой. Пустая ячейка также считается пустой. |
| NotContainsBlanks | `13` | Это правило условного форматирования выделяет ячейки, которые не пусты. Эквивалентно использованию LEN(TRIM()). Это означает, что если ячейка содержит только символы, которые удалит TRIM(), она считается пустой. Пустая ячейка также считается пустой. |
| ContainsErrors | `14` | Это правило условного форматирования выделяет ячейки с ошибками формулы. Эквивалентно использованию функции листа ISERROR() для определения наличия ошибки формулы. |
| NotContainsErrors | `15` | Это правило условного форматирования выделяет ячейки без ошибок формулы. Эквивалентно использованию функции листа ISERROR() для определения наличия ошибки формулы. |
| TimePeriod | `16` | Это правило условного форматирования выделяет ячейки, содержащие даты в указанном периоде времени. Оценивается базовое значение ячейки, поэтому ячейка не обязана быть отформатирована как дата для оценки. Например, при ячейке со значением 38913 условный формат будет применён, если правило требует значение 14.07.2006. |
| AboveAverage | `17` | Это правило условного форматирования выделяет ячейки, значения которых выше или ниже среднего для всех значений в диапазоне. |
