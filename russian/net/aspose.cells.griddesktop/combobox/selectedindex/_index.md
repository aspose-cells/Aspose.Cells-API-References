## ComboBox.SelectedIndex property

Получает или задает индекс, указывающий текущий выбранный элемент. При установке индекса будет автоматически вызываться метод GridDesktop.RunAllFormulas, если свойство GridDesktop.RecalculateFormulas равно true.

```csharp
public int SelectedIndex { get; set; }
```
