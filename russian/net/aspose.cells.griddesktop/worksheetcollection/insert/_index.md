## Insert(int) {#insert_1}

Вставляет лист в WorksheetCollection по указанному индексу. Количество строк этого листа — 256, количество столбцов — 32. Имя листа будет сгенерировано методом Add().

```csharp
public void Insert(int index)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| индекс | Int32 | Индекс, начинающийся с нуля, по которому должен быть вставлен лист. |

### Возвращаемое значение

Возвращаемый объект Worksheet добавлен.
