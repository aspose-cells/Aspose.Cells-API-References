## WorksheetCollection.Remove method

Удаляет лист по указанному индексу в WorksheetCollection. Если конкретный лист является последним, после его удаления будет добавлен новый лист в WorksheetCollection.

```csharp
public void Remove(int index)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| индекс | Int32 | Нулевой индекс листа, который нужно удалить. |
