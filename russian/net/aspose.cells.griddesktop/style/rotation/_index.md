## Style.Rotation property

Представляет угол поворота текста.

```csharp
public int Rotation { get; set; }
```

### Примечания

0: Не повернут.

255: Сверху вниз.

-90: Downward.

90: Вверх.

Вы можете установить 255 или значение в диапазоне от -90 до 90.
