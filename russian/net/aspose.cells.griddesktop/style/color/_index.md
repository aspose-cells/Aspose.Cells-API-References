## Style.Color property

Получает или задает цвет затенения ячейки. Когда шаблон равен none, возвращается Color.Empty; когда шаблон BackgroundType.Solid, возвращается ForegroundColor; в остальных случаях возвращается BackgroundColor.

public Color Color { get; set; }
