## Style.Indent property

Представляет уровень m_IndentLevel для ячейки или диапазона. Может быть только целым числом от 0 до 15.

```csharp
public int Indent { get; set; }
```

### Примечания

Если тип горизонтального выравнивания текста установлен в значение, отличное от left или right, уровень m_IndentLevel будет сброшен до нуля.
