## Style.Clone method

Создаёт и возвращает копию этого объекта. **NOTE:** Если вы клонируете именованный стиль, имя не копируется, потому что имя стиля должно быть уникальным. Поэтому клонированный стиль не будет "равен" оригинальному стилю.

```csharp
public Style Clone()
```

### Возвращаемое значение

Возвращает новый объект Style.
