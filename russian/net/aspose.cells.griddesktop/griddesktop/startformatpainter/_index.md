## GridDesktop.StartFormatPainter method

Уведомляет GridDesktop о запуске FormatPainter.

```csharp
public void StartFormatPainter(bool formatOnce)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| formatOnce | Boolean | Если formatOnce равно true, FormatPainter можно использовать один раз; если formatOnce равно false, FormatPainter можно использовать многократно, пока не будет вызвано EndFormatPainter(). |

### Примеры

```csharp
[C#]
gridDesktop1.StartFormatPainter(true);

[Visual Basic]
gridDesktop1.StartFormatPainter(True)

```
