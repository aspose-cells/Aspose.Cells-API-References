## GridDesktop.EnableClipboardCopyPaste property

Указывает, следует ли копировать/вставлять на основе буфера обмена, чтобы обеспечить совместимость с MS-EXCEL. Копируются/вставляются только значения ячеек, другие настройки ячеек, такие как формат, стиль границы и т.д., не копируются. Значение по умолчанию — false.

```csharp
public bool EnableClipboardCopyPaste { get; set; }
```
