## HorizontalAlignmentType enumeration

Указывает, как ячейка сетки выравнивается по горизонтали.

```csharp
public enum HorizontalAlignmentType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| General | `0` | Если тип объекта — число, объект выравнивается по правому краю ячейки сетки. Если тип объекта — строка, объект выравнивается по левому краю ячейки сетки. |
| Left | `1` | Объект или текст выравнивается по левому краю ячейки сетки. |
| Centred | `2` | Объект или текст выравнивается по центру ячейки сетки. |
| Right | `3` | Объект или текст выравнивается по правому краю ячейки сетки. |
| Filled | `4` | Объект или текст заполнен в gridcell. |
| Justified | `5` |  |
| CentredAcross | `6` |  |
| Distributed | `7` |  |
