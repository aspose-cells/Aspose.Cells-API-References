## PivotTableRefreshOption.IsKeepOriginalOrder property

Указывает, следует ли сохранять исходный порядок элементов сводной таблицы как в старом источнике данных.

```csharp
public bool IsKeepOriginalOrder { get; set; }
```

### Примечания

Применяется только к полю сводной таблицы, которое не отсортировано. При обновлении такого поля Ms Excel сохраняет оригинальный порядок старого источника данных. Значение по умолчанию этого свойства — true, представляющее то же поведение, что и у Ms Excel. Если пользователю необходимо полностью обновить поле сводной таблицы в соответствии с данными нового источника, это свойство следует установить в false.
