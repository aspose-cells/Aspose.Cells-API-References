## PivotTableRefreshOption.KeepCachedLocalGroupData property

Указывает, следует ли сохранять кэшированные локальные данные групп, если максимальные и минимальные значения не изменились. Значение по умолчанию — false, что означает обновление группы с локальными настройками.

```csharp
public bool KeepCachedLocalGroupData { get; set; }
```
