## PivotTableCreateOptions.IsXlsClassic property

Получает или задает значение, указывающее, следует ли создавать PivotTable в классическом стиле Excel 97-2003.

```csharp
public bool IsXlsClassic { get; set; }
```

### Примечания

Классическая сводная таблица использует устаревшее расположение и форматирование из Excel 97‑2003. Если значение не задано явно, значение по умолчанию определяется форматом целевой книги.
