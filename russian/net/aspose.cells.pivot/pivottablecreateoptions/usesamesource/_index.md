## PivotTableCreateOptions.UseSameSource property

Получает или задает значение, указывающее, следует ли использовать тот же источник данных, что и у существующих сводных таблиц. Значение по умолчанию — true.

```csharp
public bool UseSameSource { get; set; }
```

### Примечания

Если установить значение true, несколько сводных таблиц могут использовать один кэш сводных таблиц для снижения потребления памяти.
