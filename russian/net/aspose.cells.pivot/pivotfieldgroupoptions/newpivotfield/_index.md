## PivotFieldGroupOptions.NewPivotField property

Получает или задает значение, указывающее, должны ли создаваться новые поля сводной таблицы после группировки.

```csharp
public bool NewPivotField { get; set; }
```

### Примечания

Если явно не задано, значение по умолчанию — false для числовой группировки и true для группировки по дате и времени, true для дискретной группы. Работает только для первого нового группового поля сводной таблицы базового поля.
