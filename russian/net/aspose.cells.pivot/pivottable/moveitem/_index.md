## PivotTable.MoveItem method

Переместить один элемент вверх или вниз.

```csharp
public void MoveItem(PivotFieldType region, string[] nodes, bool absolute, int offset)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| регион | PivotFieldType | Регион. Только для строки или столбца. |
| узлы | String[] | Элемент. |
| абсолютный | Boolean | Указывает, является ли смещение абсолютной позицией. |
| смещение | Int32 | Если absolute истинно: 0 перемещает в начало, -1 перемещает в конец, остальные означают абсолютную позицию; иначе offset является относительной позицией. |
