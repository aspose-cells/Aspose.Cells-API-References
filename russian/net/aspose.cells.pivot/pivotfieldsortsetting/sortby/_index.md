## PivotFieldSortSetting.SortBy property

Представляет индекс поля, по которому выполнена сортировка. Значение -1 указывает на сортировку по собственным значениям элемента сводной таблицы. При значении, большем или равном нулю, представляет индекс поля данных в области данных.

public int SortBy { get; set; }
