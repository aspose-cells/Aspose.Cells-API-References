## PivotField.ShowInCompactForm property

Получает или задает значение, указывающее, использует ли это поле строки компактный макет. Применяется только к полям строк.

```csharp
public bool ShowInCompactForm { get; set; }
```

### Примечания

Компактный режим — это подрежим контурного макета. Эта настройка действует только когда [`ShowInOutlineForm`](../showinoutlineform/) равно true.
