Пространство имен **Aspose.Cells.Timelines** содержит классы, позволяющие получать доступ и рисовать временные шкалы в файлах Excel Spreadsheet.

## Классы

| Класс | Описание |
| --- | --- |
| [Timeline](./timeline/) | Краткое описание представления Timeline. Из‑за MS Excel, Excel 2003 не поддерживает Timeline. |
| [TimelineCollection](./timelinecollection/) | Указывает коллекцию всех объектов [`Timeline`](../aspose.cells.timelines/timeline/) на листе. Поддерживается, начиная с Excel 2013. |
## Перечисление

| Перечисление | Описание |
| --- | --- |
| [TimelineLevelType](./timelineleveltype/) | Представляет тип уровня [`Timeline`](../aspose.cells.timelines/timeline/) |
