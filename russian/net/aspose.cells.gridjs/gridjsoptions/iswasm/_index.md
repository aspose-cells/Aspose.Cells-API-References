## GridJsOptions.IsWasm property

Получает/Устанавливает, работает ли GridJs внутри браузерного WebAssembly‑хоста вместо серверного процесса. При значении true не используется FileCacheDirectory / диск / путь interrupt‑thread, и кэш файлов должен поступать из CacheImp, поскольку у браузерного хоста нет локального диска. Выбираются пути кода во время выполнения, поэтому один Aspose.Cells.GridJs.dll обслуживает оба хоста. Значение по умолчанию — false.

```csharp
public bool IsWasm { get; set; }
```
