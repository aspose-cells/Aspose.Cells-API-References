## GridJsOptions.MaxShapeOrImageWidthOrHeight property

Получает/Устанавливает максимальную ширину или высоту для формы или изображения, GridJs будет игнорировать форму или изображение с шириной или высотой, превышающей это значение, действует при IslimitShapeOrImage=true. Значение по умолчанию — 10000.

```csharp
public int MaxShapeOrImageWidthOrHeight { get; set; }
```
