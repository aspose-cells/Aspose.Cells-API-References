## GridJsOptions.EnableChartClientRendering property

Получает/устанавливает, следует ли включить рендеринг диаграмм на клиенте. Если установить false, GridJs будет выводить только изображения/формы диаграмм и не потребует рендеринг на клиенте. Значение по умолчанию — true.

```csharp
public bool EnableChartClientRendering { get; set; }
```
