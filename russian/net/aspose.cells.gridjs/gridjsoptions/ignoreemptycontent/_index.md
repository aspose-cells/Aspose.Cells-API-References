## GridJsOptions.IgnoreEmptyContent property

Получает/Устанавливает, показывать ли максимальный диапазон, который включает данные, стиль, объединённые ячейки и формы. Если последняя строка или столбец содержит ячейки без значения и формулы, но с пользовательским стилем, то при истинном значении мы не будем показывать эту строку/столбец. Значение по умолчанию — true.

```csharp
public bool IgnoreEmptyContent { get; set; }
```
