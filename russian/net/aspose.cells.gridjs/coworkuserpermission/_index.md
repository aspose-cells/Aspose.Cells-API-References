## CoWorkUserPermission enumeration

представляет разрешения пользователя в режиме совместной работы. Доступно только в версии Java, будет доступно в версиях .NET/Python в будущем.

```csharp
public enum CoWorkUserPermission
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| READ_ONLY | `0` | Разрешение только для чтения, Пользователь может только просматривать содержимое, но не может вносить изменения |
| EDITABLE | `1` | Разрешение на редактирование, Пользователь может просматривать и редактировать содержимое |
| DOWNLOAD | `2` | Разрешение на загрузку, Пользователь может просматривать, редактировать и загружать содержимое в локальное хранилище |
| ADMIN | `3` | Разрешение администратора, Пользователь имеет полный доступ, включая операции управления |
