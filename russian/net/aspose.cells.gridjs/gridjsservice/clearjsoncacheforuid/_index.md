## GridJsService.ClearJsonCacheForUid method

Очищает все записи кэша JSON, принадлежащие указанному уникальному идентификатору. Вызовите это после изменения исходного файла вне обычного потока, чтобы следующий запрос сгенерировал JSON заново.

```csharp
public void ClearJsonCacheForUid(string uid)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| uid | String | Уникальный идентификатор для кэша файла. |
