Пространство имен **Aspose.Cells.GridJs** инкапсулирует все классы GridJs, предоставляя простые API для просмотра или редактирования файлов электронных таблиц через операции JSON.

| Класс | Описание |
| --- | --- |
| [Config](./config/) | Представляет все статические настройки для GridJs |
| [DefaultGridJsJsonCache](./defaultgridjsjsoncache/) | Стандартная реализация JSON‑кэша (L1 память + L2 диск) |
| [GridAbstractCalculationEngine](./gridabstractcalculationengine/) | Представляет пользовательский движок вычислений, расширяющий движок вычислений по умолчанию в Aspose.Cells. |
| [GridCacheForStream](./gridcacheforstream/) | Этот класс содержит операции кэширования для GridJs. Пользователь должен реализовать свою бизнес‑логику хранения на его основе.. |
| [GridCalculationData](./gridcalculationdata/) | Представляет необходимые данные при вычислении функции, такие как имя функции, параметры, ...etc. |
| [GridCellException](./gridcellexception/) | Исключение, которое выбрасывается при возникновении указанной ошибки GridJs. |

Уровень по умолчанию — None. В сборке DEBUG уровень по умолчанию — Debug (выводит все сообщения). Поддерживает ротацию файлов журнала по дню/неделе/месяцу. |
| [GridJsOptions](./gridjsoptions/) | Представляет все параметры загрузки для GridJs. |

| [JsonCacheOptions](./jsoncacheoptions/) | Параметры конфигурации кэширования JSON в GridJs. Управляет поведением кэша в памяти (L1) и на диске (L2). |
| [OprMessageService](./oprmessageservice/) | Этот класс предоставляет все операции синхронизации сообщений в режиме совместной работы. |
