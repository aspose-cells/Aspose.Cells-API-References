## GridWorkbookSettings.CheckExcelRestriction property

Проверять ли ограничения файла Excel, когда пользователь изменяет связанные с ячейками объекты. Например, Excel не позволяет вводить строковое значение длиной более 32 КБ. Когда вы вводите значение длиной более 32 КБ, например с помощью Cell.PutValue(string), если это свойство истинно, вы получите Exception. Если это свойство ложно, мы примем введённую строку как значение ячейки, чтобы позже вы могли вывести полное строковое значение в другие форматы файлов, такие как CSV. Однако, если вы задали значение, которое недопустимо для формата файла Excel, не следует сохранять рабочую книгу в формате Excel позже. Иначе может возникнуть неожиданная ошибка в сгенерированном файле Excel. по умолчанию false.

```csharp
public bool CheckExcelRestriction { get; set; }
```
