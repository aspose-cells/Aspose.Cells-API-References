## GridJsWorkbook.SetTransParentView method

Устанавливает прозрачность форм редактирования в рабочей книге.

```csharp
public void SetTransParentView(string excelFilePath, string uid, bool isTransparent)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| excelFilePath | String | Путь к Excel‑файлу. |
| uid | String | Уникальный идентификатор книги. Если null или пустой, новый uid будет сгенерирован на основе пути к файлу. |
| isTransparent | Boolean | Если true, устанавливает прозрачность 0.89 (полупрозрачная); если false, устанавливает прозрачность 1 (полностью непрозрачная/невидимая). |
