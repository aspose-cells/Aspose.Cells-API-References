## GridJsWorkbook.JsonToStream method

Генерирует JSON из находящегося в памяти Workbook и записывает его в указанный поток. При необходимости кэширует сгенерированный JSON для более быстрого последующего получения. Ключевые отличия от JsonToStreamByUid: - Этот метод использует текущее состояние Workbook в памяти (поле wb) - JsonToStreamByUid загружает Workbook из файлов кэша .cells на диске - Используйте этот метод, когда нужно экспортировать текущее состояние книги после изменений - Используйте JsonToStreamByUid, когда необходимо восстановить JSON из ранее кэшированного состояния файла. Поведение кэширования (при указании uid): - Проверяет кэш JSON перед генерацией (L1 память + L2 диск) - При промахе кэша генерирует JSON из Workbook в памяти - Сохраняет сгенерированный JSON в кэш для будущих запросов.

```csharp
public void JsonToStream(Stream stream, string filename, string uid = null)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| поток | Stream | Выходной поток, в который записываются данные JSON. |
| имя файла | String | Указывает имя файла в JSON. Если установлено в null, имя файла по умолчанию: book1. |
| uid | String | Необязательный уникальный идентификатор для кэширования JSON. При указании он включает поиск и сохранение в кэше. |
