## GridJsWorkbook.SaveToCacheWithFileName method

Сохраняет данные из памяти в файл кэша с указанным именем файла и также задает пароль открытия; формат сохранения определяется расширением имени файла.

```csharp
public void SaveToCacheWithFileName(string uid, string filename, string password)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| uid | String | Уникальный идентификатор для кэша файла. |
| имя файла | String | Имя файла для сохранения. |
| пароль | String | Пароль открытия Excel‑файла. Значение может быть null, если пароль не установлен. |
