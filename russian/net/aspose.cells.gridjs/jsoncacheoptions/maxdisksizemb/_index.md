## JsonCacheOptions.MaxDiskSizeMB property

Получает/Устанавливает максимальный размер кэша диска в МБ (по умолчанию: 500 МБ). Влияет, когда Enable = true и используется кэш по умолчанию.

public long MaxDiskSizeMB { get; set; }
