## JsonCacheOptions.Enable property

Получает/Устанавливает, следует ли включить кэширование JSON для более быстрого отклика. При включении GridJs будет кэшировать сгенерированный JSON и повторно использовать его для последующих запросов. Значение по умолчанию — false. Примечание: необходимо установить Implementation для использования пользовательского хранилища кэша.

```csharp
public bool Enable { get; set; }
```
