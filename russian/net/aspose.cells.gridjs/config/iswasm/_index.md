## Config.IsWasm property

Получает/устанавливает, работает ли GridJs внутри WebAssembly‑хоста в браузере вместо серверного процесса. При значении true не используется путь FileCacheDirectory / диск / прерывающий поток, и кэш файлов должен поступать из GridJsOptions.CacheImp. GridJsOptions.IsWasm задаёт это при построении сервиса GridJs, поэтому один Aspose.Cells.GridJs.dll обслуживает оба хоста. Значение по умолчанию — false.

```csharp
public static bool IsWasm { get; set; }
```
