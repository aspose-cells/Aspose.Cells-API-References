## Config.AutoFitColumnsOnLoad property

Указывает, следует ли автоматически подгонять ширину столбцов при загрузке файла. Значение по умолчанию — `false`. Предупреждение: установка значения `true` выполнит автоматическую подгонку всех столбцов после загрузки, что может заметно повлиять на производительность.

```csharp
public static bool AutoFitColumnsOnLoad { get; set; }
```
