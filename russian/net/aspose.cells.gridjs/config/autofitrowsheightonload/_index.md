## Config.AutoFitRowsHeightOnLoad property

Указывает, следует ли автоматически подгонять высоту строк при загрузке файла. Значение по умолчанию — `false`. Предупреждение: установка значения `true` выполнит автоматическую подгонку всех строк после загрузки, что может заметно повлиять на производительность.

```csharp
public static bool AutoFitRowsHeightOnLoad { get; set; }
```
