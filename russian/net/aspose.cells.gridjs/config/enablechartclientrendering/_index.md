## Config.EnableChartClientRendering property

Получает/устанавливает, включена ли отрисовка диаграмм на клиенте. Если установить значение false, GridJs будет использовать только серверно‑созданные изображения/формы диаграмм. Значение по умолчанию — true.

```csharp
public static bool EnableChartClientRendering { get; set; }
```
