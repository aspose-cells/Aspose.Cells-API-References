## Config.IslimitShapeOrImage property

Получает/Устанавливает, ограничивать ли общее количество отображаемых форм/изображений в одном листе; если установлено в true, GridJs ограничит общее количество отображаемых форм или изображений в одном листе значением MaxShapeOrImageCount. Значение по умолчанию — true.

```csharp
public static bool IslimitShapeOrImage { get; set; }
```
