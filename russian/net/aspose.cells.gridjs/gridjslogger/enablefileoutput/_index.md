## GridJsLogger.EnableFileOutput property

Получает или задает, следует ли выводить сообщения журнала в файл. По умолчанию false. Необходимо вызвать [`SetLogFile`](../setlogfile/) или [`SetLogDirectory`](../setlogdirectory/) перед включением.

```csharp
public static bool EnableFileOutput { get; set; }
```
