## GridJsLogger.MaxFileSize property

Получает или устанавливает максимальный размер (в байтах) одного файла журнала перед ротацией. Действует только когда ротация включена. 0 означает отсутствие ограничения размера. По умолчанию — 0.

```csharp
public static long MaxFileSize { get; set; }
```
