Пространство имен **Aspose.Cells.WebExtensions** содержит классы для доступа к надстройкам Office в файлах Excel.

## Классы

| Класс | Описание |
| --- | --- |
| [WebExtension](./webextension/) | Представляет экземпляр Office Add-in. |
| [WebExtensionBinding](./webextensionbinding/) | Представляет связь привязки между надстройкой Office и данными в документе. |
| [WebExtensionBindingCollection](./webextensionbindingcollection/) | Представляет список связей привязки между надстройкой Office и данными в документе. |
| [WebExtensionCollection](./webextensioncollection/) | Представляет список веб‑расширений. |
| [WebExtensionProperty](./webextensionproperty/) | Представляет пользовательское свойство надстройки Office. |
| [WebExtensionPropertyCollection](./webextensionpropertycollection/) | Представляет список свойств веб‑расширения. |
| [WebExtensionReference](./webextensionreference/) | Представляет идентификацию местоположения поставщика и версии расширения. |
| [WebExtensionReferenceCollection](./webextensionreferencecollection/) | Представляет список ссылок на веб‑расширения. |
| [WebExtensionTaskPane](./webextensiontaskpane/) | Представляет сохранённый объект области задач. |
| [WebExtensionTaskPaneCollection](./webextensiontaskpanecollection/) | Представляет список областей задач. |
## Перечисление
