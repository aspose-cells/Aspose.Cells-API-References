Пространство имён **Aspose.Cells.DataModels** предоставляет классы для доступа к моделям данных книги и их обновления.

## Классы

| Класс | Описание |
| --- | --- |
| [DataModel](./datamodel/) | Представляет модель данных. |
| [DataModelRelationship](./datamodelrelationship/) | Представляет отдельную связь в модели данных электронной таблицы. |
| [DataModelRelationshipCollection](./datamodelrelationshipcollection/) | Представляет связи. |
| [DataModelTable](./datamodeltable/) | Представляет свойства отдельной таблицы в модели данных электронной таблицы. |
| [DataModelTableCollection](./datamodeltablecollection/) | Представляет список таблицы модели данных. |
