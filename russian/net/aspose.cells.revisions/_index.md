Пространство имен **Aspose.Cells.Revisions** предоставляет классы для доступа к ревизиям файлов Excel Spreadsheet.

## Классы

| Класс | Описание |
| --- | --- |
| [HighlightChangesOptions](./highlightchangesoptions/) | Представляет параметры выделения ревизий или изменений в совместных файлах Excel. |
| [Revision](./revision/) | Представляет ревизию. |
| [RevisionAutoFormat](./revisionautoformat/) | Представляет запись ревизии с информацией об изменении форматирования. |
| [RevisionCellChange](./revisioncellchange/) | Представляет ревизию, изменяющую ячейки. |
| [RevisionCellComment](./revisioncellcomment/) | Представляет запись ревизии изменения комментария ячейки. |
| [RevisionCellMove](./revisioncellmove/) | Представляет запись ревизии о перемещении ячейки(й). |
| [RevisionCollection](./revisioncollection/) | Представляет все журналы ревизий. |
| [RevisionCustomView](./revisioncustomview/) | Представляет запись ревизии добавления или удаления пользовательского представления в книгу. |
| [RevisionDefinedName](./revisiondefinedname/) | Представляет запись ревизии изменения определённого имени. |
| [RevisionFormat](./revisionformat/) | Представляет запись ревизии с информацией об изменении форматирования. |
| [RevisionHeader](./revisionheader/) | Представляет список конкретных изменений, которые произошли в этой рабочей книге. |
| [RevisionInsertDelete](./revisioninsertdelete/) | Представляет запись ревизии действия вставки/удаления строки/столбца. |
| [RevisionInsertSheet](./revisioninsertsheet/) | Представляет запись ревизии листа, который был вставлен. |
| [RevisionLog](./revisionlog/) | Представляет журнал ревизий. |
| [RevisionLogCollection](./revisionlogcollection/) | Представляет все журналы ревизий. |
| [RevisionMergeConflict](./revisionmergeconflict/) | Представляет запись ревизии, указывающую на конфликт слияния. |
| [RevisionQueryTable](./revisionquerytable/) | Представляет ревизию изменения поля запросной таблицы. |
| [RevisionRenameSheet](./revisionrenamesheet/) | Представляет ревизию переименования листа. |
