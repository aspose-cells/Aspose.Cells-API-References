Пространство имен **Aspose.Cells.Vba** содержит классы для доступа к проектам и модулям Visual Basic Analysis в файлах Excel Spreadsheet.

## Классы

| Класс | Описание |
| --- | --- |
| [VbaModule](./vbamodule/) | Представляет модуль в проекте VBA. |
| [VbaModuleCollection](./vbamodulecollection/) | Представляет список [`VbaModule`](../aspose.cells.vba/vbamodule/) |
| [VbaProject](./vbaproject/) | Представляет проект VBA. |
| [VbaProjectReference](./vbaprojectreference/) | Представляет ссылку проекта VBA. |
| [VbaProjectReferenceCollection](./vbaprojectreferencecollection/) | Представляет все ссылки проекта VBA. |
## Перечисление

| Перечисление | Описание |
| --- | --- |

| [VbaProjectReferenceType](./vbaprojectreferencetype/) | Представляет тип ссылки проекта VBA. |
