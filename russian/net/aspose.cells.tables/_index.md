Пространство имен **Aspose.Cells.Tables** содержит классы, представляющие таблицы, строки, ячейки и их форматирование для файлов Excel Spreadsheet.

## Классы

| Класс | Описание |
| --- | --- |
| [ListColumn](./listcolumn/) | Представляет столбец в таблице. |
| [ListColumnCollection](./listcolumncollection/) | Представляет список всех объектов [`ListColumn`](../aspose.cells.tables/listcolumn/) в таблице. |
| [ListObject](./listobject/) | Представляет таблицу в листе. |
| [ListObjectCollection](./listobjectcollection/) | Представляет коллекцию объектов [`ListObject`](../aspose.cells.tables/listobject/) в листе. |
| [TableStyle](./tablestyle/) | Представляет стиль таблицы. |
| [TableStyleCollection](./tablestylecollection/) | Представляет все пользовательские стили таблиц. |
| [TableStyleElement](./tablestyleelement/) | Представляет элемент стиля таблицы. |
| [TableStyleElementCollection](./tablestyleelementcollection/) | Представляет все элементы стиля таблицы. |
| [TableToRangeOptions](./tabletorangeoptions/) | Представляет параметры при преобразовании таблицы в диапазон. |
## Перечисление

| Перечисление | Описание |
| --- | --- |
| [TableDataSourceType](./tabledatasourcetype/) | Представляет тип источника данных таблицы. |
| [TableStyleElementType](./tablestyleelementtype/) | Представляет тип элемента стиля таблицы или сводной таблицы. |
| [TableStyleType](./tablestyletype/) | Представляет тип встроенного стиля таблицы. |
| [TotalsCalculation](./totalscalculation/) | Определяет тип вычисления в строке Totals списка столбцов. |
