Пространство имен **Aspose.Cells.Utility** содержит вспомогательные классы для обработки форматов JSON в файлах Excel Spreadsheet.

## Классы

| Класс | Описание |
| --- | --- |
| [ConversionUtility](./conversionutility/) | Представляет утилиту для преобразования файлов в другие форматы. |
| [ExportRangeToJsonOptions](./exportrangetojsonoptions/) | Указывает параметры экспорта диапазона в JSON. |
| [JsonLayoutOptions](./jsonlayoutoptions/) | Представляет параметры типа макета JSON. |
| [JsonUtility](./jsonutility/) | Представляет вспомогательный класс для обработки JSON. |
