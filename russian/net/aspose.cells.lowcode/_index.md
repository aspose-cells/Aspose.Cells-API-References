Пространство имён **Aspose.Cells.LowCode** предоставляет набор простых и удобных API для наиболее часто используемых операций в режиме low‑code.

## Классы

| Класс | Описание |
| --- | --- |
| [AbstractLowCodeLoadOptionsProvider](./abstractlowcodeloadoptionsprovider/) | Реализация, предоставляющая несколько вариантов загрузки для процессов, использующих несколько входных данных (например, файлов шаблонов). |
| [AbstractLowCodeProtectionProvider](./abstractlowcodeprotectionprovider/) | Реализация, предоставляющая настройки защиты |
| [AbstractLowCodeSaveOptionsProvider](./abstractlowcodesaveoptionsprovider/) | Реализация, предоставляющая несколько вариантов сохранения для процессов, требующих несколько выходных данных. Например, функция [`SpreadsheetSplitter`](../aspose.cells.lowcode/spreadsheetsplitter/) требует нескольких назначений для сохранения разделённых файлов. |
| [HtmlConverter](./htmlconverter/) | Конвертер для преобразования HTML‑файлов (html или mht) в другие форматы файлов электронных таблиц. |
| [ImageConverter](./imageconverter/) | Конвертер для преобразования файла шаблона в изображения. |
| [JsonConverter](./jsonconverter/) | Конвертер для преобразования JSON‑структуры данных в другие форматы файлов электронных таблиц. |
| [LowCodeHtmlSaveOptions](./lowcodehtmlsaveoptions/) | Параметры сохранения HTML в режиме low code. |
| [LowCodeImageSaveOptions](./lowcodeimagesaveoptions/) | Параметры сохранения изображения в режиме low code. |
| [LowCodeLoadOptions](./lowcodeloadoptions/) | Параметры загрузки файла шаблона. |
| [LowCodeMergeOptions](./lowcodemergeoptions/) | Параметры объединения нескольких файлов шаблонов в один. |
| [LowCodePdfSaveOptions](./lowcodepdfsaveoptions/) | Параметры сохранения PDF в режиме low code. |
| [LowCodeSaveOptions](./lowcodesaveoptions/) | Параметры сохранения сгенерированных результатов в режиме low code. |
| [LowCodeSaveOptionsProviderOfAssembling](./lowcodesaveoptionsproviderofassembling/) | Реализация, предоставляющая параметры сохранения, которые сохраняют разделённые части в файлы, а путь результирующего файла именуется как (может содержать каталоги): [`PathHeader`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/pathheader/)+[`SheetPrefix`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/sheetprefix/)+SheetIndex(или SheetName)+[`SplitPartPrefix`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/splitpartprefix/)+SplitPartIndex+[`PathTail`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/pathtail/). |
| [LowCodeSaveOptionsProviderOfPlaceHolders](./lowcodesaveoptionsproviderofplaceholders/) | Реализация, предоставляющая параметры сохранения, которые сохраняют разделённые части в файлы, а путь результирующего файла определяется с помощью заполнителей. |
| [LowCodeSplitOptions](./lowcodesplitoptions/) | Параметры разделения электронной таблицы. |
| [PdfConverter](./pdfconverter/) | Конвертер для преобразования шаблонного файла в PDF. |
| [SplitPartInfo](./splitpartinfo/) | Представляет информацию одного входа/выхода для нескольких входов/выходов, например текущей страницы, которая будет отрисована при преобразовании электронной таблицы в изображение. |
| [SpreadsheetConverter](./spreadsheetconverter/) | Конвертер для преобразования между различными форматами файлов электронных таблиц, такими как xls, xlsx, xlsb, SpreadsheetML... |
| [SpreadsheetLocker](./spreadsheetlocker/) | API с низким кодом для блокировки файла электронной таблицы. |
| [SpreadsheetMerger](./spreadsheetmerger/) | Объединяет несколько шаблонных файлов в один. |
| [SpreadsheetSplitter](./spreadsheetsplitter/) | Разделяет файл электронной таблицы на несколько частей. |
| [TextConverter](./textconverter/) | Конвертер для преобразования между текстовыми форматами (csv, tsv, dif...) и другими форматами файлов электронных таблиц. |
