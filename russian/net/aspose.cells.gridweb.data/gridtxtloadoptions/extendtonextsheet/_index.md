## GridTxtLoadOptions.ExtendToNextSheet property

Указывает, расширять ли данные на следующий лист, когда строки или столбцы данных превышают ограничение. Если это свойство истинно, дополнительные данные будут перенесены на следующий лист позади текущего (если текущий лист последний, будет добавлен новый лист в текущую книгу). Если свойство ложно, данные, превышающие ограничение, будут игнорироваться. По умолчанию — false;

```csharp
public bool ExtendToNextSheet { get; set; }
```
