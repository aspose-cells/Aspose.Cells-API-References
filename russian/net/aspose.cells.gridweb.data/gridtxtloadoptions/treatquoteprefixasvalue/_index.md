## GridTxtLoadOptions.TreatQuotePrefixAsValue property

Указывает, следует ли учитывать начальный одинарный апостроф как часть значения ячейки. По умолчанию true. Если false, начальный одинарный апостроф будет удалён из значения соответствующей ячейки, и [`QuotePrefix`](../../../aspose.cells.gridweb/gridtableitemstyle/quoteprefix/) будет установлен в true для ячейки.

```csharp
public bool TreatQuotePrefixAsValue { get; set; }
```
