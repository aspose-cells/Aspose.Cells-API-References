## GridCellErrorType enumeration

Используется в WebCellException. Представляет тип ошибки ячейки.

```csharp
public enum GridCellErrorType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| ValidationError | `0` | Проверка ячейки не прошла. |
| DataSourceInsertError | `1` | При вставке связанной строки листа в источник данных произошла ошибка. |
| DataSourceUpdateError | `2` | При обновлении связанной строки листа или поля объекта произошла ошибка. |
| DataSourceDeleteError | `3` | При удалении привязанной строки листа к источнику данных произошла ошибка. |
