## GridWorksheet.GetColumnReadonly method

Получает, является ли столбец только для чтения. Это расширенный метод GridWeb, который не сохраняется и не влияет на реальный файл Excel.

```csharp
public bool GetColumnReadonly(int columnIndex)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| columnIndex | Int32 | индекс столбца. |

### Возвращаемое значение

Если только для чтения, возвращает true.
