## GridWorksheet.SetRowReadonly method

Устанавливает строку только для чтения, чтобы пользователь не мог удалить её на клиенте. Это расширенный метод GridWeb, он не сохраняется и не влияет на реальный файл Excel.

```csharp
public void SetRowReadonly(int rowIndex, bool isReadonly)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| rowIndex | Int32 | индекс строки. |
| isReadonly | Boolean | true или false. |
