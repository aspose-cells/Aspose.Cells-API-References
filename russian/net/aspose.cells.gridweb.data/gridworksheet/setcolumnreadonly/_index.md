## GridWorksheet.SetColumnReadonly method

Устанавливает столбец только для чтения, чтобы пользователь не мог удалить его на клиенте. Это расширенный метод GridWeb, он не сохраняется и не влияет на реальный файл Excel.

```csharp
public void SetColumnReadonly(int columnIndex, bool isReadonly)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| columnIndex | Int32 | индекс столбца. |
| isReadonly | Boolean | true или false. |
