## WebCells.SetRowHeight method

Устанавливает высоту указанной строки. Принимаемый тип ширины: Point, Pixel и Inch.

```csharp
public void SetRowHeight(int row, Unit height)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| строка | Int32 | Индекс строки. |
| высота | Единица | Высота строки. В единицах точек. Должна быть между 0 и 409,5. |

### Примечания

Чтобы скрыть строку, устанавливает её высоту в ноль.
