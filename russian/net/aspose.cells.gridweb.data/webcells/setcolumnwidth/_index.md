## WebCells.SetColumnWidth method

Устанавливает ширину указанного столбца. Принимаемый тип ширины: Point, Pixel или Inch.

```csharp
public void SetColumnWidth(int column, Unit width)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| column | Int32 | Индекс столбца. |
| ширина | Единица | Ширина столбца. |

### Примечания
