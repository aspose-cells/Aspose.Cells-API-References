## WebCells.GetRowReadonly method

Получает, является ли строка только для чтения. Это расширенный метод GridWeb, он не сохраняется и не влияет на реальный файл Excel.

```csharp
public bool GetRowReadonly(int rowIndex)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| rowIndex | Int32 | индекс строки. |

### Возвращаемое значение

Если только для чтения, возвращает true.
