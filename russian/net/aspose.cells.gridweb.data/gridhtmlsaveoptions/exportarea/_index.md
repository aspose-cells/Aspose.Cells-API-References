## GridHtmlSaveOptions.ExportArea property

Получает или задаёт экспортируемую CellArea текущего активного листа Worksheet. Если задать этот атрибут, область печати текущего активного листа Worksheet будет опущена. При сохранении файла в html будет экспортирована только указанная область.

public GridCellArea ExportArea { get; set; }
