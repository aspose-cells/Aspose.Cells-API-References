## HyperlinkActionType enumeration

Гиперссылка имеет два типа действия: UrlLink и CellCommand. Гиперссылка типа UrlLink представляет собой якорь в ячейке; при щелчке она переходит на другую страницу или открывает новое окно браузера. Гиперссылка типа CellCommand представляет собой кнопку команды в ячейке; при щелчке она генерирует событие на стороне сервера.

```csharp
public enum HyperlinkActionType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| UrlLink | `0` | Url‑ссылка. Якорь в ячейке. |
| CellCommand | `1` | Кнопка команды ячейки. |
| SimpleImage | `2` | просто простое изображение |
