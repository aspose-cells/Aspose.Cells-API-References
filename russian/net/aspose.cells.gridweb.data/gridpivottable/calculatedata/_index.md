## GridPivotTable.CalculateData method

Вычисляет данные pivottable в ячейки.

```csharp
public void CalculateData()
```

### Примечания

Cell.Value в диапазоне сводной таблицы может не вернуть правильный результат, если метод не был вызван. Этот метод вычисляет данные с внутренним кэшем сводных таблиц, а не из оригинального источника данных. Поэтому, если источник данных изменён, пожалуйста, сначала вызовите метод RefreshData().
