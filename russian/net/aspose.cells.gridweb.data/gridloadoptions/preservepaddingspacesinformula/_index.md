## GridLoadOptions.PreservePaddingSpacesInFormula property

Указывает, следует ли сохранять пробелы и переносы строк, добавленные между токенами формулы при получении и установке формул. Значение по умолчанию — false.

```csharp
public bool PreservePaddingSpacesInFormula { get; set; }
```

### Примечания

После загрузки книги из шаблона с этой опцией, [`PreservePaddingSpaces`](../../gridworkbooksettings/preservepaddingspaces/) будет установлена в то же значение, что и это свойство.
