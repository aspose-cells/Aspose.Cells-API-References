## AutoFitColumn(int, int, int) {#autofitcolumn_1}

Автоматически подгоняет ширину столбца. Этот метод подгоняет столбец по содержимому в диапазоне ячеек столбца от startRow до endRow. AutoFitColumn — неточная функция.

```csharp
public void AutoFitColumn(int columnIndex, int startRow, int endRow)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| columnIndex | Int32 | индекс столбца, нумерация с нуля |
| startRow | Int32 | индекс начальной строки, нумерация с нуля |
| endRow | Int32 | индекс конечной строки, нумерация с нуля |
