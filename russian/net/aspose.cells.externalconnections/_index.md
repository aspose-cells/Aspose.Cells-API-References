Пространство имён **Aspose.Cells.ExternalConnections** предоставляет классы для внешних соединений, позволяющих получать данные из внешних источников, таких как базы данных и веб.

## Классы

| Класс | Описание |
| --- | --- |
| [ConnectionParameter](./connectionparameter/) | Указывает свойства любых параметров, используемых во внешних соединениях данных. Параметры действительны для ODBC и веб‑запросов. |
| [ConnectionParameterCollection](./connectionparametercollection/) | Указывает коллекцию [`ConnectionParameter`](../aspose.cells.externalconnections/connectionparameter/) |
| [DataModelConnection](./datamodelconnection/) | Указывает соединение модели данных |
| [DBConnection](./dbconnection/) | Указывает все свойства, связанные с внешним соединением данных ODBC или OLE DB. |
| [ExternalConnection](./externalconnection/) | Указывает внешнее соединение данных |
| [ExternalConnectionCollection](./externalconnectioncollection/) | Указывает коллекцию [`ExternalConnection`](../aspose.cells.externalconnections/externalconnection/) |
| [WebQueryConnection](./webqueryconnection/) | Указывает свойства источника веб‑запроса. Веб‑запрос получает данные из HTML‑таблиц и может также передавать параметры HTTP "Get", которые обрабатываются веб‑сервером при генерации HTML, включая параметры и элементы параметров. |
## Перечисление

| Перечисление | Описание |
| --- | --- |
| [ConnectionDataSourceType](./connectiondatasourcetype/) | Указывает тип внешнего источника базы данных |
| [ConnectionParameterType](./connectionparametertype/) | Указывает тип параметра внешнего соединения |
| [CredentialsMethodType](./credentialsmethodtype/) | Указывает метод учётных данных, используемый для доступа к серверу. |
| [ExternalConnectionClassType](./externalconnectionclasstype/) | Представляет тип соединения |
| [HtmlFormatHandlingType](./htmlformathandlingtype/) | Указывает, как обрабатывать форматирование из HTML‑источника |
| [OLEDBCommandType](./oledbcommandtype/) | Указывает тип команды OLE DB. |
| [ReConnectionMethodType](./reconnectionmethodtype/) | Указывает, что должно делать приложение таблиц, когда соединение не удаётся. |
| [SqlDataType](./sqldatatype/) | Указывает тип данных SQL параметра. Действительно только для источников ODBC. |
