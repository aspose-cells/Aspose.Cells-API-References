## ExcelRenderingBehavior enumeration

Указывает специфические для Excel поведения рендеринга, применяемые при рендеринге книги.

```csharp
[Flags]
public enum ExcelRenderingBehavior
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Не применяет специфические для Excel поведения рендеринга. |
| CellTextLengthLimit | `1` | Применяет ограничение длины вывода текста ячейки Excel. Например, Excel выводит только первые 1024 символа в ячейке без переноса. |
| All | `FFFFFFFFFFFFFFFF` | Применяет все поддерживаемые специфические для Excel поведения рендеринга. |
