Пространство имен **Aspose.Cells.Rendering** предоставляет классы для рендеринга изображений и PDF.

## Классы

| Класс | Описание |
| --- | --- |
| [CustomRenderSettings](./customrendersettings/) | Представляет пользовательские настройки во время рендеринга. |
| [DrawObject](./drawobject/) | DrawObject будет инициализирован и возвращён при рендеринге. |
| [DrawObjectEventHandler](./drawobjecteventhandler/) | Интерфейс для получения DrawObject и Bound при рендеринге. |
| [ImageOrPrintOptions](./imageorprintoptions/) | Позволяет задавать параметры при рендеринге листа в изображения, печати листа или рендеринге диаграммы в изображение. |
| [PageEndSavingArgs](./pageendsavingargs/) | Информация о странице завершает процесс сохранения. |
| [PageSavingArgs](./pagesavingargs/) | Информация о процессе сохранения страницы. |
| [PageStartSavingArgs](./pagestartsavingargs/) | Информация о начале процесса сохранения страницы. |
| [PdfBookmarkEntry](./pdfbookmarkentry/) | PdfBookmarkEntry является записью в закладках PDF. Если свойство Text текущего экземпляра равно null или "", текущий экземпляр будет скрыт, а дочерние элементы будут вставлены на текущем уровне. |
| [RenderingFont](./renderingfont/) | Шрифт для рендеринга. |
| [RenderingWatermark](./renderingwatermark/) | Водяной знак для рендеринга. |
| [SheetPrintingPreview](./sheetprintingpreview/) | Предпросмотр печати листа. |
| [SheetRender](./sheetrender/) | Представляет рендер листа, который может выводить лист в различные изображения, такие как (BMP, PNG, JPEG, TIFF...). Конструктор этого класса должен использоваться после изменения параметров страницы и стиля ячеек. |
| [SheetSet](./sheetset/) | Описывает набор листов. |
| [SvgImageOptions](./svgimageoptions/) | Параметры генерации изображения SVG. |
| [WorkbookPrintingPreview](./workbookprintingpreview/) | Предпросмотр печати книги. |
| [WorkbookRender](./workbookrender/) | Представляет рендер книги. Конструктор этого класса должен использоваться после изменения параметров страницы и стиля ячеек. |
