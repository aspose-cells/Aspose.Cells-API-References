## PdfZoomBehavior enumeration

Указывает режим начального просмотра при открытии сгенерированного PDF‑документа.

```csharp
public enum PdfZoomBehavior
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Использует поведение по умолчанию PDF‑просмотрщика. |
| ZoomFactor | `1` | Открывает документ с определённым процентом масштабирования. |
| FitPage | `2` | Вмещает всю страницу в окно просмотрщика. |
| FitWidth | `3` | Вмещает ширину страницы в окно просмотрщика. |
| FitHeight | `4` | Вписывает высоту страницы в окно просмотра. |
