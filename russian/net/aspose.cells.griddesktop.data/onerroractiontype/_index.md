## OnErrorActionType enumeration

Используется в событии CellError элемента GridWeb. Пользователь задает OnErrorActionQuery.OnErrorAction, чтобы указать элементу управления остановить обработку или игнорировать ошибку.

```csharp
public enum OnErrorActionType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Throw | `0` | Выбрасывает текущее исключение. |
| Stop | `1` | Останавливает текущую обработку. |
| Ignore | `2` | Игнорирует ошибку и продолжает обработку. |
