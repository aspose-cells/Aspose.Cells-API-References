## GridHyperlink.ImageURL property

Получить или задать URL изображения для ссылки, в гиперссылке нет свойства imageurl, поэтому фактически используется TextToDisplay для записи этого значения, TextToDisplay будет установлен в &lt;img src=value &gt;, что изменит значение TextToDisplay.

```csharp
public string ImageURL { get; set; }
```
