## GridComment.Width property

Получить или установить ширину комментария. Значение по умолчанию — 140. Вводимое значение должно быть от 20 до 1000. Если введено значение меньше 20, будет установлено 20. Если введено значение больше 1000, будет установлено 1000.

public int Width { get; set; }
