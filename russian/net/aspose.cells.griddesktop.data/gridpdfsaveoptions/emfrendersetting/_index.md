## GridPdfSaveOptions.EmfRenderSetting property

Настройка рендеринга метафайла Emf.

```csharp
public GridEmfRenderSetting EmfRenderSetting { get; set; }
```

### Примечания

EMF-метафайлы, идентифицированные как "EMF+ Dual", могут содержать как записи EMF+, так и записи EMF. Любой тип записей может использоваться для рендеринга изображения, только записи EMF+, или только записи EMF.
