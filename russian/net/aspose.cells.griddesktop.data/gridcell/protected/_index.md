## GridCell.Protected property

Указывает, защищена ли ячейка. Если значение "true", пользователь не может изменить ячейку через пользовательский интерфейс. Этот атрибут не связан со свойством Style.CellLocked и не будет сохранён в файл при экспорте данных сетки. Значение по умолчанию — "false".

```csharp
public bool Protected { get; set; }
```
