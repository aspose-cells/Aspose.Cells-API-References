## GridCellValueFormatStrategy enumeration

Указывает, как применять стиль к значению ячейки.

```csharp
public enum GridCellValueFormatStrategy
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Не отформатировано. |
| CellStyle | `1` | Отформатировано только оригинальным стилем ячейки. |
| DisplayStyle | `2` | Отформатировано отображаемым стилем ячейки. |
| DisplayString | `3` | Получает отображаемую строку, показываемую в ms excel. Основное отличие от DisplayStyle заключается в том, что эта опция также учитывает влияние ширины столбца. Если ширина столбца слишком мала, чтобы полностью отобразить отформатированную строку, может отображаться "#", как в ms excel. |
