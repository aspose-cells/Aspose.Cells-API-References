Пространство имён **Aspose.Cells.Markup** содержит классы, представляющие пользовательскую семантику в документе: смарт‑теги, пользовательский XML и другие теги разметки.

## Классы

| Класс | Описание |
| --- | --- |
| [CustomXmlPart](./customxmlpart/) | Представляет часть хранилища пользовательского XML-данных (пользовательские XML‑данные внутри пакета). |
| [CustomXmlPartCollection](./customxmlpartcollection/) | Представляет часть хранилища пользовательского XML-данных (пользовательские XML‑данные внутри пакета). |
| [SmartTag](./smarttag/) | Представляет смарт‑тег. |
| [SmartTagCollection](./smarttagcollection/) | Представляет все смарт‑теги в ячейке. |
| [SmartTagOptions](./smarttagoptions/) | Представляет параметры смарт‑тега. |
| [SmartTagProperty](./smarttagproperty/) | Представляет свойство смарт‑тега ячейки. |
| [SmartTagPropertyCollection](./smarttagpropertycollection/) | Представляет все свойства смарт‑тега ячейки. |
| [SmartTagSetting](./smarttagsetting/) | Представляет все объекты [`SmartTagCollection`](../aspose.cells.markup/smarttagcollection/) в листе. |
