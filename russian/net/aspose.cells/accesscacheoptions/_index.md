## AccessCacheOptions enumeration

Параметры кэширования доступа к данным. Несколько параметров можно комбинировать с помощью оператора "&#x7C;".

```csharp
[Flags]
public enum AccessCacheOptions
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Отсутствие кэширования для любого доступа к данным. |
| All | `FFFFFFFFFFFFFFFF` | Примените все возможные оптимизации для всех видов доступа к данным в книге. Все настройки и данные не должны изменяться во время оптимизированного доступа. |
| PositionAndSize | `3` | Примените возможную оптимизацию получения позиции и размера объекта (например, Shape). Настройки высоты строки и ширины столбца не должны изменяться во время оптимизированного доступа. |
| CellsData | `9` | Примените возможную оптимизацию получения значений ячеек. Данные ячеек (данные и настройки Cell, Row) не должны изменяться во время оптимизированного доступа, также не должно создаваться новых объектов Cell/Row (например, с помощью [`Item`](../cells/item/)). |
| CellDisplay | `100086` | Примените возможную оптимизацию получения отображаемых результатов ячеек ([`DisplayStringValue`](../cell/displaystringvalue/), [`GetStyle`](../cell/getstyle/), [`GetDisplayStyle`](../cell/getdisplaystyle/), и др.). Данные ячеек и связанные со стилем объекты (стили Cell/Row/Column, ширина столбца и т.д.) не должны изменяться во время оптимизированного доступа. |
| GetFormula | `200000` | Примените возможную оптимизацию получения формул. Все данные и настройки, которые могут влиять на выражение формулы (имя Worksheet, текст Name, столбец таблицы и т.д.), не должны изменяться во время оптимизированного доступа. |
| SetFormula | `400000` | Примените возможную оптимизацию установки формул. Все данные и настройки, которые могут влиять на выражение формулы (имя Worksheet, текст Name, столбец таблицы и т.д.), не должны изменяться во время оптимизированного доступа. |
| CalculateFormula | `800009` | Примените возможную оптимизацию вычисления формул. Данные ячеек не должны изменяться во время оптимизированного доступа, также не должно создаваться новых объектов (Cell, Row и т.д.) (например, с помощью [`Item`](../cells/item/)). |
| ConditionalFormatting | `1000009` | Примените возможную оптимизацию получения результатов условного форматирования. Все данные и настройки, которые могут влиять на результат условного форматирования (настройки условного форматирования, значения зависимых ячеек и т.д.), не должны изменяться во время оптимизированного доступа. |
| Validation | `2000009` | Примените возможную оптимизацию получения результата проверки. Все данные и настройки, которые могут влиять на результат проверки (настройки проверки, значения зависимых ячеек и т.д.), не должны изменяться во время оптимизированного доступа. |

### Примечания

Для некоторых функций доступ к большому набору данных требует множества повторяющихся и сложных операций, таких как поиск, вычисления и т.д., и эти операции занимают значительное дополнительное время. В обычных ситуациях все зависимые данные остаются неизменными во время доступа, поэтому можно создать и использовать кэши для повышения производительности доступа. С этой целью мы предоставляем данный API, позволяющий пользователю указать, какой тип доступа к данным следует оптимизировать с помощью возможного механизма кэширования. Обратите внимание, что для разных вариантов может потребоваться, чтобы соответствующий набор данных был "read-only". Производительность доступа к данным зависит от многих факторов, и использование кэша не гарантирует её улучшения. В некоторых случаях, например когда набор данных небольшой, использование кэша может даже увеличить время, так как кэширование также требует дополнительных затрат.

### Примеры

```csharp
namespace AsposeCellsExamples
{
    using Aspose.Cells;
    using System;

    public class AccessCacheOptionsDemo
    {
        public static void AccessCacheOptionsExample()
        {
            // Создать новую книгу
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // Запустить кэш доступа с конкретными параметрами
            workbook.StartAccessCache(AccessCacheOptions.PositionAndSize | AccessCacheOptions.CellsData);

            // Выполнить некоторые операции, выигрывающие от кэширования
            for (int i = 0; i < 10; i++)
            {
                for (int j = 0; j < 10; j++)
                {
                    worksheet.Cells[i, j].PutValue(i + j);
                }
            }

            // Закрыть кэш доступа
            workbook.CloseAccessCache(AccessCacheOptions.PositionAndSize | AccessCacheOptions.CellsData);

            // Сохраните книгу
            workbook.Save("AccessCacheOptionsExample.xlsx");
        }
    }
}
```
