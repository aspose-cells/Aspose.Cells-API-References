## BorderCollection.IsOutline property

Указывает, следует ли применять границы слева, справа, сверху и снизу только к внешним границам диапазона ячеек. Значение по умолчанию — true.

```csharp
public bool IsOutline { get; set; }
```

### Примечания

Работает только при применении к диапазону для условного форматирования, сводных таблиц. Если false, границы слева, справа, сверху и снизу будут применяться к каждой ячейке, иначе только к внешним границам диапазона ячеек. Если true, пожалуйста, задайте горизонтальные и вертикальные границы внутренних границ диапазона для условного форматирования, сводных таблиц.
