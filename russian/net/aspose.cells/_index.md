Пространство имён **Aspose.Cells** предоставляет фундаментальные и базовые классы для создания, конвертации, изменения, визуализации и печати электронных таблиц без использования Microsoft Excel. Например, класс [`Workbook`](aspose.cells/workbook/) является основной точкой входа для создания или загрузки, а затем манипулирования файлом таблицы, класс [`Cells`](aspose.cells/cells/) — основной класс для работы со всеми данными и свойствами листа, ... и т.д.
