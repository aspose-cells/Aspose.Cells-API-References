Пространство имён **Aspose.Cells.Properties** предоставляет классы для работы с пользовательскими и встроенными свойствами электронных таблиц, такими как заголовок, ключевые слова, компания и т.д.

## Классы

| Класс | Описание |
| --- | --- |
| [BuiltInDocumentPropertyCollection](./builtindocumentpropertycollection/) | Коллекция встроенных свойств документа. |
| [ContentTypeProperty](./contenttypeproperty/) | Представляет информацию об идентификаторе. |
| [ContentTypePropertyCollection](./contenttypepropertycollection/) | Коллекция объектов [`ContentTypeProperty`](../aspose.cells.properties/contenttypeproperty/), представляющих дополнительную информацию. |
| [CustomDocumentPropertyCollection](./customdocumentpropertycollection/) | Коллекция пользовательских свойств документа. |
| [CustomProperty](./customproperty/) | Представляет пользовательское свойство, которое хранит пары имя‑значение произвольных пользовательских данных для листа. |
| [CustomPropertyCollection](./custompropertycollection/) | Коллекция объектов [`CustomProperty`](../aspose.cells.properties/customproperty/), представляющих дополнительную информацию. |
| [DocumentProperty](./documentproperty/) | Представляет пользовательское или встроенное свойство документа. |
| [DocumentPropertyCollection](./documentpropertycollection/) | Базовый класс для коллекций [`BuiltInDocumentPropertyCollection`](../aspose.cells.properties/builtindocumentpropertycollection/) и [`CustomDocumentPropertyCollection`](../aspose.cells.properties/customdocumentpropertycollection/). |
