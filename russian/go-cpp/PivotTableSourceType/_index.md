## PivotTableSourceType Enum

Представляет тип источника данных сводной таблицы.

```go

type PivotTableSourceType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Sheet](./sheet/) | Указывает, что исходные данные представляют собой диапазон. |
| [External](./external/) | Указывает, что используются внешние исходные данные. |
| [Consolidation](./consolidation/) | Указывает, что в качестве исходных данных используются несколько диапазонов консолидации. |
| [Scenario](./scenario/) | Исходные данные заполняются из временной внутренней структуры. |
| [Unknown](./unknown/) | Неизвестный источник данных. |
