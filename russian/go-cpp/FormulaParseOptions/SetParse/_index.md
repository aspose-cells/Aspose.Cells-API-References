## SetParse function

Разбирать ли заданную формулу. По умолчанию true. Если false, то строка формулы будет оставаться без изменений для ячейки, пока пользователь не вызовет другие методы для её разбора, или пока данные разобранной формулы не потребуются другим операциям, например вычислению формул.

```go

func (instance *FormulaParseOptions) SetParse(value bool)  error
```
