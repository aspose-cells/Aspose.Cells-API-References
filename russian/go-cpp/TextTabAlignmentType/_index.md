## TextTabAlignmentType Enum

Представляет типы выравнивания табуляции текста.

```go

type TextTabAlignmentType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Center](./center/) | Текст на этой табуляции выровнен по центру. |
| [Decimal](./decimal/) | На этой табуляции десятичные знаки выровнены. |
| [Left](./left/) | Текст на этой табуляции выровнен по левому краю. |
| [Right](./right/) | Текст на этой табуляции выровнен по правому краю. |
