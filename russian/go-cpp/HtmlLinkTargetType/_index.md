## HtmlLinkTargetType Enum

Представляет тип атрибута target в теге HTML <a/>.

```go

type HtmlLinkTargetType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Blank](./blank/) | Открывает связанный документ в новом окне или вкладке |
| [Parent](./parent/) | Открывает связанный документ в родительском фрейме |
| [Self](./self/) | Открывает связанный документ в том же фрейме, в котором был щелкнут (по умолчанию) |
| [Top](./top/) | Открывает связанный документ во всей области окна |
