## GetAccentCharacter function

Этот атрибут указывает тип комбинирующего диакритического знака, присоединяемого к основе функции акцента. Символ акцента по умолчанию — U+0302. Настоятельно рекомендуется использовать атрибут AccentType для установки символа акцента. Используйте эту настройку свойства, если вы не можете найти нужный символ в известном типе.
