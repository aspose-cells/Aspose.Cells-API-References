## AccessCacheOptions Enum

Опции кэширования для доступа к данным. Несколько опций можно комбинировать с помощью оператора "|".

```go

type AccessCacheOptions int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [None](./none/) | Без кэширования для любого доступа к данным. |
| [All](./all/) | Применить все возможные оптимизации для всех видов доступа к данным в рабочей книге. Все настройки и данные не должны изменяться во время оптимизированного доступа. |
| [PositionAndSize](./positionandsize/) | Применить возможные оптимизации для получения позиции и размера объекта (например, Shape). Настройки высоты строк и ширины столбцов не должны изменяться во время оптимизированного доступа. |
| [CellsData](./cellsdata/) | Применить возможные оптимизации для получения значений ячеек. Данные ячеек (данные и настройки Cell, Row) не должны изменяться во время оптимизированного доступа, также не должно создаваться новых объектов Cell/Row (например, с помощью <see cref="Cells.this[int, int]"/>). |
| [CellDisplay](./celldisplay/) | Применить возможные оптимизации для получения результатов, связанных с отображением ячеек (<see cref="Cell.DisplayStringValue"/>, <see cref="Cell.GetStyle()"/>, <see cref="Cell.GetDisplayStyle()"/>, и т.д.). Данные ячеек и объекты, связанные со стилем (стили Cell/Row/Column, ширина столбца и т.п.) не должны изменяться во время оптимизированного доступа. |
| [GetFormula](./getformula/) | Применить возможные оптимизации для получения формул. Все данные и настройки, которые могут влиять на выражение формулы (имя листа, текст имени, столбец таблицы и т.д.), не должны изменяться во время оптимизированного доступа. |
| [SetFormula](./setformula/) | Применить возможные оптимизации для установки формул. Все данные и настройки, которые могут влиять на выражение формулы (имя листа, текст имени, столбец таблицы и т.д.), не должны изменяться во время оптимизированного доступа. |
| [CalculateFormula](./calculateformula/) | Применить возможные оптимизации для вычисления формул. Данные ячеек не должны изменяться во время оптимизированного доступа, также не должно создаваться новых объектов (Cell, Row и т.п.) (например, с помощью <see cref="Cells.this[int, int]"/>). |
| [ConditionalFormatting](./conditionalformatting/) | Применить возможные оптимизации для получения результатов форматирования условных форматов. Все данные и настройки, которые могут влиять на результат условного форматирования (настройки условных форматов, значения зависимых ячеек и т.д.), не должны изменяться во время оптимизированного доступа. |
| [Validation](./validation/) | Применить возможные оптимизации для получения результата проверки. Все данные и настройки, которые могут влиять на результат проверки (настройки проверки, значения зависимых ячеек и т.д.), не должны изменяться во время оптимизированного доступа. |
