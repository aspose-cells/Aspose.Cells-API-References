## ChartSplitType Enum

Представляет способ разделения двух секций диаграммы «pie of pie» или «bar of pie».

```go

type ChartSplitType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Position](./position/) | Представляет точки данных. Точки данных должны быть разделены между круговой диаграммой и второй диаграммой, помещая последнюю позицию разбиения точек данных во вторую диаграмму. |
| [Value](./value/) | Представляет точки данных, которые должны быть разделены между pieand и второй диаграммой, помещая точки данных withvalue меньше Split Position во вторую диаграмму. |
| [PercentValue](./percentvalue/) | Представляет точки данных, которые должны быть разделены между круговой диаграммой и второй диаграммой, помещая точки с процентом меньше Split Position percent во вторую диаграмму. |
| [Custom](./custom/) | Представляет точки данных, которые должны быть разделены между pieand и второй диаграммой согласно Custom Splitvalues. |
| [Auto](./auto/) | Представляет точки данных, которые должны быть разделены с использованием механизма по умолчанию для этого типа диаграммы. |
