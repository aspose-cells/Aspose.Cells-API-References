## DataBarAxisPosition Enum

Указывает положение оси для диапазона ячеек с условным форматированием в виде гистограмм.

```go

type DataBarAxisPosition int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Automatic](./automatic/) | Отображать ось в переменной позиции в зависимости от отношения минимального отрицательного значения к максимальному положительному значению в диапазоне.Положительные значения отображаются слева направо.Отрицательные значения отображаются справа налево.Когда все значения положительные или все значения отрицательные, ось не отображается. |
| [Midpoint](./midpoint/) | Отображать ось в средней точке ячейки независимо от набора значений в диапазоне.Положительные значения отображаются слева направо.Отрицательные значения отображаются справа налево. |
| [None](./none/) | Ось не отображается, а положительные и отрицательные значения отображаются слева направо. |
