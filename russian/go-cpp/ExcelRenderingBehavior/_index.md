## ExcelRenderingBehavior Enum

Указывает специфичные для Excel поведения рендеринга, применяемые при рендеринге книги.

```go

type ExcelRenderingBehavior int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [None](./none/) | Не применяет специфические для Excel поведения рендеринга. |
| [CellTextLengthLimit](./celltextlengthlimit/) | Применяет ограничение длины вывода текста ячейки Excel. Например, Excel выводит только первые 1024 символа в ячейке без переноса. |
| [All](./all/) | Применяет все поддерживаемые специфические для Excel поведения рендеринга. |
