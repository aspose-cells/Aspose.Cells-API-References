## FontConfigs_GetPreferSystemFontSubstitutes function

Указывает, использовать ли системные заменители шрифтов в первую очередь, когда шрифт не представлен и заменитель этого шрифта не установлен. Например, в Ubuntu шрифт "Arial" обычно заменяется на "Liberation Sans". Значение по умолчанию — false.
