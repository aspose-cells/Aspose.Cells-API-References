## PlacementType Enum

Представляет способ, которым объект рисования прикреплен к ячейкам под ним.

```go

type PlacementType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [FreeFloating](./freefloating/) | Не перемещать и не изменять размер вместе с ячейками. |
| [Move](./move/) | Перемещать, но не изменять размер вместе с ячейками. |
| [MoveAndSize](./moveandsize/) | Перемещать и изменять размер вместе с ячейками. |
