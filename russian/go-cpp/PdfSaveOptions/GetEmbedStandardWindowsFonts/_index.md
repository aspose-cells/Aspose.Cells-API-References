## GetEmbedStandardWindowsFonts function

True, чтобы встраивать шрифты TrueType. Влияет только на ASCII‑символы 32‑127. Шрифты для кодов символов выше 127 всегда встраиваются. Шрифты всегда встраиваются для стандарта PDF/A-1a, PDF/A-1b. По умолчанию — true.
