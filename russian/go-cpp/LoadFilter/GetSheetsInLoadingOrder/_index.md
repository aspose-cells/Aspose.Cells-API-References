## GetSheetsInLoadingOrder function

Указывает листы (индексы) и порядок их загрузки. По умолчанию значение null, что означает загрузку всех листов в порядке по умолчанию из шаблонного файла. Если не null и индекс какого‑то листа отсутствует в возвращённом массиве, то этот лист не будет загружен.
