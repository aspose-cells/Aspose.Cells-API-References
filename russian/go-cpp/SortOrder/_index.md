## SortOrder Enum

Представляет порядок сортировки для диапазона данных.

```go

type SortOrder int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Ascending](./ascending/) | Сортирует данные по возрастанию |
| [Descending](./descending/) | Сортирует данные по убыванию |
| [Natural](./natural/) | Сохраняет исходный порядок данных без сортировки. Применяется только в некоторых специальных сценариях, таких как PivotTable. |
