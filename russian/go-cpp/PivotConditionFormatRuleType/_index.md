## PivotConditionFormatRuleType Enum

Представляет тип правила условного форматирования сводной таблицы.

```go

type PivotConditionFormatRuleType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [None](./none/) | Указывает, что условное форматирование Top N не оценивается |

| [Row](./row/) | Указывает, что условное форматирование Top N оценивается для каждой строки. |
| [Column](./column/) | Указывает, что условное форматирование Top N оценивается для каждого столбца. |
