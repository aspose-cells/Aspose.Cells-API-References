## Top10 class

Опишите правило условного форматирования Top10. Это правило условного форматирования выделяет ячейки, значения которых попадают в верхний N или нижний N диапазон, как указано.

```go

type Top10 struct  {
	ptr unsafe.Pointer
}

```
