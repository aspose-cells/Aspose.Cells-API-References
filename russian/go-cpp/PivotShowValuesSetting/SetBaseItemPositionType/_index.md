## SetBaseItemPositionType function

Представляет тип базового элемента сводки в базовом поле, когда вычисление ShowDataAs используется. Действительно только для полей данных. Поскольку PivotItemPosition.Custom доступен только для чтения, если необходимо установить PivotItemPosition.Custom, пожалуйста, установите атрибут PivotField.BaseItemIndex.

func (instance *PivotShowValuesSetting) SetBaseItemPositionType(value PivotItemPositionType)  error
