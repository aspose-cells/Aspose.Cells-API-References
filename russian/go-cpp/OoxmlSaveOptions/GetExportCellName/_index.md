## GetExportCellName function

Указывает, экспортировать ли имя ячейки в файл Excel2007 .xlsx (.xlsm, .xltx, .xltm). Если файл может быть доступен SQL Server DTS, это значение должно быть true. Установка значения в false значительно повышает производительность и уменьшает размер файла при создании больших файлов. Значение по умолчанию — true.
