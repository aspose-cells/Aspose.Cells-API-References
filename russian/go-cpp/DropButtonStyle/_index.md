## DropButtonStyle Enum

Представляет символ, отображаемый на кнопке раскрытия.

```go

type DropButtonStyle int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Plain](./plain/) | Отображает кнопку без символа. |
| [Arrow](./arrow/) | Отображает кнопку со стрелкой вниз. |
| [Ellipsis](./ellipsis/) | Отображает кнопку с многоточием (...). |
| [Reduce](./reduce/) | Отображает кнопку с горизонтальной линией, похожей на символ подчёркивания. |
