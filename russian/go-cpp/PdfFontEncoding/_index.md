## PdfFontEncoding Enum

Представляет кодировку встроенного шрифта PDF.

```go

type PdfFontEncoding int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Identity](./identity/) | Представляет использование кодировки Identity-H для всех встроенных шрифтов в pdf. |
| [AnsiPrefer](./ansiprefer/) | Представляет предпочтение использовать WinAnsiEncoding для TrueType шрифтов с символами 32‑127, иначе будет использована кодировка Identity-H для встроенных шрифтов в pdf. |
