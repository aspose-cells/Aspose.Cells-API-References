## SetBackward function

Получает или задает количество периодов (или единиц на точечной диаграмме), на которое линия тренда продолжается назад. Количество периодов должно быть больше или равно нулю. Если тип диаграммы — столбчатая, количество периодов должно быть от 0 до 0,5.

```go

func (instance *Trendline) SetBackward(value float64)  error

```
