## ShapeDisplayType Enum

Представляет, как приложение отображает фигуры в этой книге. Фигуры могут включать диаграммы, изображения и другие данные объектов, поддерживаемые приложением.

```go

type ShapeDisplayType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [All](./all/) | Указывает, что все фигуры отображаются в книге. |
| [Placeholders](./placeholders/) | Указывает, что приложение показывает заполнители для фигур в книге. |
| [None](./none/) | Указывает, что все фигуры скрыты в книге. |
