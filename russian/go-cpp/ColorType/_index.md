## ColorType Enum

Представляет все типы цветов.

```go

type ColorType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Automatic](./automatic/) | Автоматический цвет. |
| [AutomaticIndex](./automaticindex/) | Это автоматический цвет, но отображаемый цвет зависит от настройки ОС. |
| [RGB](./rgb/) | RGB‑цвет. |
| [IndexedColor](./indexedcolor/) | Индекс цвета в палитре. |
| [Theme](./theme/) | Цвет темы. |
