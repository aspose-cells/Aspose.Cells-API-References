## Date Struct

Представляет дату и время.

```go

type Date int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [year](./year/) | Компонент года (1-9999). |
| [month](./month/) | Компонент месяца (1-12). |
| [day](./day/) | Компонент дня (1-31). |
| [hour](./hour/) | Компонент часа (0-23). |
| [minute](./minute/) | Компонент минуты (0-59). |
| [second](./second/) | Компонент секунды (0-59). |
| [millisecond](./millisecond/) | Компонент миллисекунды (0-999). |
| [dateKind](./datekind/) | Указывает, является ли время локальным, UTC или неустановленным. Значение по умолчанию — Unspecified. |
