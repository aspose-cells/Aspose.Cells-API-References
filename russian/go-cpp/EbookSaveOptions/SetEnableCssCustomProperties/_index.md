## SetEnableCssCustomProperties function

Оптимизирует вывод HTML с помощью пользовательских CSS‑свойств. Например, если один base64‑изображение используется несколько раз, с пользовательским свойством данные изображения сохраняются один раз, что улучшает производительность получаемого HTML. Значение по умолчанию — false.
