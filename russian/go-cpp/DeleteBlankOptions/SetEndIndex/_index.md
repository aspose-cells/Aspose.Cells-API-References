## SetEndIndex function

Указывает конечный индекс строки/столбца (включительно) диапазона, который следует проверить и удалить пустые строки/столбцы. Значение по умолчанию — -1, а -1 означает максимальный диапазон всех объектов (ячейки, рисунки, ...) которые необходимо проверить.
