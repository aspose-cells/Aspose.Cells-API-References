## GetUpdateAllPoints function

Обновлять ли все точки данных при выполнении расчёта диаграммы. По умолчанию: False. Когда нужно получить значение каждой отдельной точки данных в диаграмме, установите значение true. Если этот параметр установлен в True, новые точки данных могут быть созданы при расчёте диаграммы. Это может увеличить размер файла Excel.
