## PrintingPageType Enum

Указывает, какие страницы не будут печататься.

```go

type PrintingPageType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Default](./default/) | Печатает все страницы. |
| [IgnoreBlank](./ignoreblank/) | Не печатать страницы, где ячейки пусты. |
| [IgnoreStyle](./ignorestyle/) | Не печатать страницы, где ячейки содержат только стили. |
