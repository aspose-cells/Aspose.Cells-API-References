## ControlListStyle Enum

Представляет визуальный вид списка в ListBox или ComboBox.

```go

type ControlListStyle int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Plain](./plain/) | Отображает список, в котором фон элемента выделяется при его выборе. |
| [Option](./option/) | Отображает список, в котором рядом с каждой записью находится переключатель или флажок, показывающий состояние выбора данного элемента. |
