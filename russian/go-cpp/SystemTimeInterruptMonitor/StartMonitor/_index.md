## StartMonitor function

Запускает монитор с указанным ограничением времени. Время начала для расчёта затраченного времени фиксируется в момент вызова этого метода, поэтому процедура, которую необходимо мониторить, должна быть запущена сразу после этого вызова.

func (instance *SystemTimeInterruptMonitor) StartMonitor(mslimit int32)  error
