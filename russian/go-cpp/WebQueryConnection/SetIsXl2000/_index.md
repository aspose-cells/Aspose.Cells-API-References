## SetIsXl2000 function

Этот флаг существует для обратной совместимости со старыми существующими файлами таблиц и устанавливается в true, если этот веб‑запрос был обновлён в приложении для таблиц, версии не ниже Microsoft Excel 2000. Это необязательный атрибут, который можно игнорировать.
