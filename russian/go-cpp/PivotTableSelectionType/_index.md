## PivotTableSelectionType Enum

Указывает, что можно выбрать в PivotTable во время структурированного выбора. Эти константы можно комбинировать для выбора нескольких типов.

```go

type PivotTableSelectionType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [DataAndLabel](./dataandlabel/) | Данные и метки |
| [DataOnly](./dataonly/) | Выбирает только данные |
| [LabelOnly](./labelonly/) | Выбирает только метки |
