## SetTreatQuotePrefixAsValue function

Указывает, следует ли учитывать начальный одинарный апостроф как часть значения ячейки. По умолчанию true. Если false, начальный одинарный апостроф будет удалён из соответствующего значения ячейки, и для ячейки будет установлен Style.QuotePrefix в значение true.
