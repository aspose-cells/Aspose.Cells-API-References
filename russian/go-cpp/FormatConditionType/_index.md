## FormatConditionType Enum

Тип правила условного форматирования.

```go

type FormatConditionType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [CellValue](./cellvalue/) | Это правило условного форматирования сравнивает значение ячейки с результатом, вычисленным формулой, используя оператор. |
| [Expression](./expression/) | Это правило условного форматирования содержит формулу для вычисления. Когда результат формулы истинный, ячейка выделяется. |
| [Top10](./top10/) | Это правило условного форматирования выделяет ячейки, значения которых находятся в верхнем N или нижнем N диапазоне, как указано. |
| [UniqueValues](./uniquevalues/) | Это правило условного форматирования выделяет уникальные значения в диапазоне. |
| [DuplicateValues](./duplicatevalues/) | Это правило условного форматирования выделяет дублированные значения. |
| [ContainsText](./containstext/) | Это правило условного форматирования выделяет ячейки, содержащие заданный текст. Эквивалентно использованию функции листа SEARCH() для определения, содержит ли ячейка этот текст. |
| [NotContainsText](./notcontainstext/) | Это правило условного форматирования выделяет ячейки, которые не содержат заданный текст. Эквивалентно использованию функции листа SEARCH() для определения, содержит ли ячейка этот текст или нет. |
| [BeginsWith](./beginswith/) | Это правило условного форматирования выделяет ячейки в диапазоне, которые начинаются с заданного текста. Эквивалентно использованию функции листа LEFT() и сравнению значений. |
| [EndsWith](./endswith/) | Это правило условного форматирования выделяет ячейки, заканчивающиеся заданным текстом. Эквивалентно использованию функции листа RIGHT() и сравнению значений. |
| [ContainsBlanks](./containsblanks/) | Это правило условного форматирования выделяет ячейки, которые полностью пусты. Эквивалентно использованию LEN(TRIM()). Это означает, что если ячейка содержит только символы, которые удалит TRIM(), она считается пустой. Пустая ячейка также считается пустой. |
| [NotContainsBlanks](./notcontainsblanks/) | Это правило условного форматирования выделяет ячейки, которые не пусты. Эквивалентно использованию LEN(TRIM()). Это означает, что если ячейка содержит только символы, которые удалит TRIM(), она считается пустой. Пустая ячейка также считается пустой. |
| [ContainsErrors](./containserrors/) | Это правило условного форматирования выделяет ячейки с ошибками формулы. Эквивалентно использованию функции листа ISERROR() для определения наличия ошибки формулы. |
| [NotContainsErrors](./notcontainserrors/) | Это правило условного форматирования выделяет ячейки без ошибок формулы. Эквивалентно использованию функции листа ISERROR() для определения наличия ошибки формулы. |
| [TimePeriod](./timeperiod/) | Это правило условного форматирования выделяет ячейки, содержащие даты в указанном временном периоде. Оценка производится по базовому значению ячейки, поэтому ячейка не обязана быть отформатирована как дата для оценки. Например, если ячейка содержит значение 38913, условное форматирование будет применено, если правило требует значение 7/14/2006. |
| [AboveAverage](./aboveaverage/) | Это правило условного форматирования выделяет ячейки, которые находятся выше или ниже среднего значения всех ячеек в диапазоне. |
| [ColorScale](./colorscale/) | Это правило условного форматирования создает градиентную шкалу цвета в ячейках. |
| [DataBar](./databar/) | Это правило условного форматирования отображает градиентную полосу данных в диапазоне ячеек. |
| [IconSet](./iconset/) | Это правило условного форматирования применяет значки к ячейкам в соответствии с их значениями. |
