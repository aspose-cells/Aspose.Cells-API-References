## MemorySetting Enum

Режимы использования памяти для модели данных ячеек.

```go

type MemorySetting int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Normal](./normal/) | Режим по умолчанию для модели ячеек. |
| [MemoryPreference](./memorypreference/) | Предпочтительно использование памяти для производительности. |
| [FileCache](./filecache/) | Предпочтительно использование памяти для производительности и использование файла вместо памяти для хранения данных ячеек. |
