## TxtValueQuoteType Enum

Указывает тип использования кавычек для значений в текстовых файлах.

```go

type TxtValueQuoteType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Normal](./normal/) | Все значения, содержащие специальные символы, такие как кавычка или разделитель, будут заключены в кавычки. Такое же поведение, как в MS Excel при экспорте текстового файла. |
| [Always](./always/) | Все значения всегда будут заключены в кавычки. |
| [Minimum](./minimum/) | Кавычки ставятся только при необходимости. Например, если значение содержит кавычку, но кавычка не находится в начале этого значения, это значение не будет заключено в кавычки. |
| [Never](./never/) | Все значения не будут заключены в кавычки. Экспортированный текстовый файл этого типа может быть прочитан некорректно, потому что необходимые кавычки отсутствуют. |
