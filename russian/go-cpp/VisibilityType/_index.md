## VisibilityType Enum

Представляет состояния видимости листа.

```go

type VisibilityType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Visible](./visible/) | Указывает, что лист видим. |
| [Hidden](./hidden/) | Указывает, что лист скрыт, но может быть отображён пользователем через пользовательский интерфейс. |
| [VeryHidden](./veryhidden/) | Указывает, что лист скрыт и не может быть отображён в пользовательском интерфейсе (UI). Это состояние доступно только программно. |
