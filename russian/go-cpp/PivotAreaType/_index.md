## PivotAreaType Enum

Указывает тип правила, используемого для описания области или аспекта сводной таблицы.

```go

type PivotAreaType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [None](./none/) | Нет области Pivot. |
| [Normal](./normal/) | Представляет заголовок или элемент. |
| [Data](./data/) | Представляет что‑то в области данных. |
| [All](./all/) | Представляет всю сводную таблицу. |
| [Origin](./origin/) | Представляет пустые ячейки в левом верхнем углу сводной таблицы (в правом верхнем углу для листов с RTL). |
| [Button](./button/) | Представляет кнопку поля. |
| [TopRight](./topright/) | Представляет пустые ячейки в правом верхнем углу сводной таблицы (в левом верхнем углу для листов с RTL). |
