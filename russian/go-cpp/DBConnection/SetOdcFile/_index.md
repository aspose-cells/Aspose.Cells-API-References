## SetOdcFile function

Указывает полный путь к внешнему файлу соединения, из которого было создано это соединение. Если соединение не удаётся во время попытки обновить данные, и reconnectionMethod=1, приложение таблиц попытается снова, используя информацию из внешнего файла соединения вместо объекта соединения, встроенного в рабочую книгу.
