## GradientStyleType Enum

Представляет стиль градиентного затенения.

```go

type GradientStyleType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [DiagonalDown](./diagonaldown/) | Стиль затенения по диагонали вниз |
| [DiagonalUp](./diagonalup/) | Стиль затенения по диагонали вверх |
| [FromCenter](./fromcenter/) | Стиль затенения от центра |
| [FromCorner](./fromcorner/) | Стиль затенения от угла |
| [Horizontal](./horizontal/) | Горизонтальный стиль затенения |
| [Vertical](./vertical/) | Вертикальный стиль затенения |
| [Unknown](./unknown/) | Неизвестный стиль затенения. Только для стиля затенения (который не относится ни к одному члену GradientStyleType) в файле шаблона. |
