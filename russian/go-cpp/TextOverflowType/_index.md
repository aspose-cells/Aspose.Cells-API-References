## TextOverflowType Enum

Представляет способ вертикального или горизонтального переполнения текста.

```go

type TextOverflowType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Clip](./clip/) | Обратите внимание на верхние и нижние границы. Не указывайте, что есть невидимый текст. |
| [Ellipsis](./ellipsis/) | Обратите внимание на верхние и нижние границы. Используйте многоточие, чтобы обозначить, что есть невидимый текст. Только для вертикального переполнения. |
| [Overflow](./overflow/) | Переполняйте текст и не обращайте внимания на верхние и нижние границы. |
