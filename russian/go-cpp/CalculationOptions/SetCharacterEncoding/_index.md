## SetCharacterEncoding function

Указывает кодировку, используемую для кодирования/декодирования символов при вычислении формул. Для функций, таких как CHAR, CODE, вычисленный результат зависит от региональных настроек и кодировки по умолчанию среды. С помощью этого свойства пользователь может указать правильную кодировку, используемую этими функциями, чтобы получить ожидаемый результат.

```go

func (instance *CalculationOptions) SetCharacterEncoding(value EncodingType)  error

```
