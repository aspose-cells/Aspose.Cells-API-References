## CalculationPrecisionStrategy Enum

Перечисляет стратегии обработки точности вычислений. Из‑за проблемы точности арифметики с плавающей запятой IEEE 754 некоторые \"на вид простые\" формулы могут не давать ожидаемый результат. Например формула \"=-0.45+0.43+0.02\", при вычислении операндов оператором '+' напрямую, результат не равен нулю. Для подобных проблем точности некоторые специальные стратегии могут дать ожидаемый результат.

```go

type CalculationPrecisionStrategy int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [None](./none/) | Нет стратегии, применяемой к вычислению. При вычислении просто используйте оригинальное значение double в качестве операнда и возвращайте результат напрямую. Наиболее эффективна по производительности и применима в большинстве случаев. |
| [Round](./round/) | Округляет результат вычисления в соответствии со значимыми цифрами. |
| [Decimal](./decimal/) | Использует decimal в качестве операндов, когда это возможно. Наименее эффективна по производительности. |
