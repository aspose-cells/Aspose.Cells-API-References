## TextOrientationType Enum

Перечисляет типы ориентации текста.

```go

type TextOrientationType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [ClockWise](./clockwise/) | Поворачивает текст на 90 градусов по часовой стрелке. |
| [CounterClockWise](./counterclockwise/) | Поворачивает текст на 90 градусов против часовой стрелки. |
| [NoRotation](./norotation/) | Представляет значение по умолчанию. |
| [TopToBottom](./toptobottom/) | Отображает текст сверху вниз ячейки. Сложенный текст. |
