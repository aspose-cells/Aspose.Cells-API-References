## SetSignatureLineType function

Получает или задает тип подписи. Default - Когда установлено значение по умолчанию, соответствующее значение ProviderId фиксируется как {0000000000-0000-0000-0000-0000000000}. Stamp - Когда значение равно Stamp, соответствующее значение ProviderId обычно равно {000CD6A4-0000-0000-C000-000000000046}. Custom - Когда значение равно Custom, соответствующее значение ProviderId обычно должно быть задано пользователем. Оно должно быть получено из документации, поставляемой с провайдером.

func (instance *SignatureLine) SetSignatureLineType(value SignatureType)  error
