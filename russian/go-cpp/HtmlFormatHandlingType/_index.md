## HtmlFormatHandlingType Enum

Указывает, как обрабатывать форматирование из HTML‑источника

```go

type HtmlFormatHandlingType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [All](./all/) | Перенести всё форматирование HTML в лист вместе с данными. |
| [None](./none/) | Импортировать данные как неформатированный текст (установка типов данных всё равно происходит). |
| [Rtf](./rtf/) | Преобразовать форматирование HTML в форматирование Rich Text для данных, импортированных в лист. |
