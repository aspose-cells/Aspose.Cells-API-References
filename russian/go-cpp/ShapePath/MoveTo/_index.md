## MoveTo function

Начинает новую фигуру из указанной точки без закрытия текущей фигуры. Все последующие точки, добавляемые к пути, добавляются к этой новой фигуре. Единица измерения: пиксель.

```go

func (instance *ShapePath) MoveTo(x float32, y float32)  error
```
