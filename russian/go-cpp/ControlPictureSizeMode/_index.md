## ControlPictureSizeMode Enum

Представляет способ отображения изображения.

```go

type ControlPictureSizeMode int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Clip](./clip/) | Обрезает любую часть изображения, превышающую границы элемента управления. |
| [Stretch](./stretch/) | Растягивает изображение, чтобы заполнить область элемента управления. Эта настройка искажает изображение по горизонтали или вертикали. |
| [Zoom](./zoom/) | Увеличивает изображение, но не искажает его ни по горизонтали, ни по вертикали. |
