## SetType function

Получить или установить тип набора значков для отображения. Установка типа автоматически проверит, соответствует ли текущий счетчик Cfvos новому типу. Если не соответствует, старые Cfvos будут очищены, а значения Cfvos по умолчанию будут добавлены.
