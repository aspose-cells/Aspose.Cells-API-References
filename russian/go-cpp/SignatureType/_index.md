## SignatureType Enum

Указывает тип подписи.

```go

type SignatureType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Default](./default/) | Значение по умолчанию, соответствующее значение ProviderId фиксировано как {0000000000-0000-0000-0000-0000000000}. |
| [Stamp](./stamp/) | Соответствующее значение ProviderId обычно равно {000CD6A4-0000-0000-C000-000000000046}. |
| [Custom](./custom/) | Обычно соответствующее значение ProviderId должно устанавливаться пользователем. Оно должно быть получено из документации, поставляемой с провайдером. |
