## ShapePathPoint class

Укажите координаты положения или маркеры углов. Координаты положения представляют координаты пути в координатном пространстве (например, X/Y). Маркеры углов указывают изменения угла в пути (например, начальный и конечный углы дуги).

```go

type ShapePathPoint struct  {
	ptr unsafe.Pointer
}
```
