## SetBuildPathWithSheetAlways function

Определяет, добавлять ли индекс листа или его имя к пути файла всегда. Значение по умолчанию — false, то есть когда существует только один лист, индекс листа и имя, а также соответствующий префикс (SheetNamePrefix), не будут добавляться к пути файла.
