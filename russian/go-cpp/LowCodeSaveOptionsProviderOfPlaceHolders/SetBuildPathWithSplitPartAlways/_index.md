## SetBuildPathWithSplitPartAlways function

Определяет, добавлять ли индекс части разбиения к пути файла всегда. Значение по умолчанию — false, то есть когда существует только одна часть разбиения, индекс части разбиения и соответствующий префикс (SplitPartPrefix) не будут добавляться к пути файла.
