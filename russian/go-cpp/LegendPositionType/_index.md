## LegendPositionType Enum

Перечисляет типы положения легенды.

```go

```

## Поля

| Поле | Описание |
| --- | --- |
| [Bottom](./bottom/) | Отображает легенду внизу области построения графика. |
| [Corner](./corner/) | Отображает легенду в углу области построения графика. |
| [Left](./left/) | Отображает легенду слева от области построения графика. |
| [NotDocked](./notdocked/) | Указывает, что легенда не закреплена. |
| [Right](./right/) | Отображает легенду справа от области построения графика. |
| [Top](./top/) | Отображает легенду вверху области построения графика. |
