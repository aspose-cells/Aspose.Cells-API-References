## DateKind Enum

Указывает, представляет ли объект Date локальное время, координированное всемирное время (UTC) или не указано ни локальное время, ни UTC.

```go

type DateKind int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Unspecified](./unspecified/) | Представленное время не указано ни как локальное, ни как всемирное координированное время (UTC). |
| [Utc](./utc/) | Представленное время — UTC. |
