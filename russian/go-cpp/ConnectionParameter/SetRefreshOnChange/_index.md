## SetRefreshOnChange function

Флаг, указывающий, должна ли запрос автоматически обновляться, когда содержимое ячейки, предоставляющей значение параметра, изменяется. Если true, то внешние данные обновляются с использованием нового значения параметра каждый раз при изменении. Если false, то внешние данные обновляются только по запросу пользователя или при срабатывании другого события (например, при открытии книги).

```go

func (instance *ConnectionParameter) SetRefreshOnChange(value bool)  error
```
