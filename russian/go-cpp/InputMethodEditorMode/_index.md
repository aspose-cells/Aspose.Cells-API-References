## InputMethodEditorMode Enum

Представляет режим выполнения по умолчанию для редактора ввода (IME).

```go

type InputMethodEditorMode int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [NoControl](./nocontrol/) | Не управляет IME. |
| [On](./on/) | IME включён. |
| [Off](./off/) | IME выключен. Английский режим. |
| [Disable](./disable/) | IME выключен. Пользователь не может включить IME с клавиатуры. |
| [Hiragana](./hiragana/) | IME включён в режиме полноширинных хирагана. |
| [Katakana](./katakana/) | IME включён в режиме полноширинных катакана. |
| [KatakanaHalf](./katakanahalf/) | IME включён в режиме полуширинных катакана. |
| [AlphaFull](./alphafull/) | IME включён в режиме полноширинных буквенно-цифровых символов. |
| [Alpha](./alpha/) | IME включён в режиме полуширинных буквенно-цифровых символов. |
| [HangulFull](./hangulfull/) | IME включён в режиме полноширинных хангыль. |
| [Hangul](./hangul/) | IME включён в режиме полуширинных хангыль. |
| [HanziFull](./hanzifull/) | IME включён в режиме полноширинных хандзи. |
| [Hanzi](./hanzi/) | IME включён в режиме полуширинных хандзи. |
