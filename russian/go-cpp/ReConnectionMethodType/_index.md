## ReConnectionMethodType Enum

Указывает, что приложение таблиц должно делать при сбое соединения.

```go

type ReConnectionMethodType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Required](./required/) | При обновлении используйте существующую информацию о соединении, и если она окажется недействительной, получите обновлённую информацию о соединении, если она доступна во внешнем файле соединения. |
| [Always](./always/) | При каждом обновлении получайте обновлённую информацию о соединении из внешнего файла соединения, если она доступна, и используйте её вместо существующей информации о соединении. В этом случае обновление данных завершится неудачей, если внешний файл соединения недоступен. |
| [Never](./never/) | Никогда не получайте обновлённую информацию о соединении из внешнего файла соединения, даже если он доступен и даже если существующая информация о соединении недействительна. |
