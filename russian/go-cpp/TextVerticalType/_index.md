## TextVerticalType Enum

Представляет тип направления текста.

```go

type TextVerticalType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Vertical](./vertical/) | Восточноазиатское вертикальное отображение. |
| [Horizontal](./horizontal/) | Горизонтальный текст. |
| [VerticalLeftToRight](./verticallefttoright/) | Отображается вертикально, и текст течёт сверху вниз, затем СЛЕВА направо |
| [Vertical90](./vertical90/) | Каждая строка повернута на 90 градусов по часовой стрелке. |
| [Vertical270](./vertical270/) | Каждая строка повернута на 270 градусов по часовой стрелке. |
| [Stacked](./stacked/) | Определяет, является ли весь текст вертикальным. |
| [StackedRightToLeft](./stackedrighttoleft/) | Указывает, что вертикальный WordArt должен отображаться справа налево, а не слева направо. |
