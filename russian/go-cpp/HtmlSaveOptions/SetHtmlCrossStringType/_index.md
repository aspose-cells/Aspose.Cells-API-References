## SetHtmlCrossStringType function

Указывает, будет ли строка, охватывающая несколько ячеек, отображаться так же, как в MS Excel при сохранении файла Excel в формате HTML. По умолчанию значение — Default, поэтому для строк, охватывающих несколько ячеек, разница между HTML‑файлами, созданными Aspose.Cells и MS Excel, небольшая. Однако при создании больших HTML‑файлов установка значения в Cross ускорит процесс в несколько раз по сравнению с Default или Fit2Cell.
