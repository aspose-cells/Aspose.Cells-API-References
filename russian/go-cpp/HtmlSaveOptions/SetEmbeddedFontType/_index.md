## SetEmbeddedFontType function

Получает или задает тип встраивания файлов шрифтов в HTML‑файл. Значение по умолчанию — HtmlEmbeddedFontType.None, что означает, что шрифты в HTML не будут встраиваться.

func (instance *HtmlSaveOptions) SetEmbeddedFontType(value HtmlEmbeddedFontType)  error
