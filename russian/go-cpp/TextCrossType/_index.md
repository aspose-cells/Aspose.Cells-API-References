## TextCrossType Enum

Перечисляет типы отображения текста, когда ширина текста превышает ширину ячейки.

```go

type TextCrossType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [Default](./default/) | Отображать текст как в Microsoft Excel. |
| [CrossKeep](./crosskeep/) | Отображать весь текст, пересекающий другие ячейки, и сохранять текст пересечённых ячеек. |
| [CrossOverride](./crossoverride/) | Отображать весь текст, пересекающий другие ячейки, и переопределять текст пересечённых ячеек. |
| [StrictInCell](./strictincell/) | Отображать только текст в пределах ширины ячейки. |
