## GetDataFields function

Получает объект PivotField, представляющий все поля данных в PivotTable. Только для чтения. Инициализируется только когда в DataPiovtFiels присутствует два или более поля данных. Используется исключительно для добавления DataPivotField в область строк/столбцов PivotTable. По умолчанию находится в области строк.

```go

func (instance *PivotTable) GetDataFields()  (*PivotFieldCollection,  error) 

```
