## GetValuesField function

Получает объект PivotField, представляющий все поля данных в PivotTable. Только для чтения. Создаётся только когда в регионе Data присутствует два или более полей данных. По умолчанию находится в строковой области. Вы можете перетащить его в область строк/столбцов с помощью метода PivotTable.AddFieldToArea().
