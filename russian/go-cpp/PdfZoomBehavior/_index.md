## PdfZoomBehavior Enum

Указывает начальный режим просмотра при открытии сгенерированного PDF-документа.

```go

type PdfZoomBehavior int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [None](./none/) | Использует поведение по умолчанию PDF‑просмотрщика. |
| [ZoomFactor](./zoomfactor/) | Открывает документ с определённым процентом масштабирования. |
| [FitPage](./fitpage/) | Вмещает всю страницу в окно просмотрщика. |
| [FitWidth](./fitwidth/) | Вмещает ширину страницы в окно просмотрщика. |
| [FitHeight](./fitheight/) | Вмещает высоту страницы в окно просмотрщика. |
