## ProtectionType Enum

Представляет тип защиты книги/листа.

```go

type ProtectionType int32


```

## Поля

| Поле | Описание |
| --- | --- |
| [All](./all/) | Представляет защиту всех. |
| [Contents](./contents/) | Представляет защиту содержимого, используется в защите листа. |
| [Objects](./objects/) | Представляет защиту объектов, используется в защите листа. |
| [Scenarios](./scenarios/) | Представляет защиту сценариев, используется в защите листа. |
| [Structure](./structure/) | Представляет защиту структуры, используется в защите книги. |
| [Windows](./windows/) | Представляет защиту окна, используется в защите книги. |
| [None](./none/) | Представляет отсутствие защиты. Только для свойства Reading. |
