## SetStdDev function

Получить или установить количество стандартных отклонений, включаемых выше или ниже среднего в правиле условного форматирования. Входное значение должно быть от 0 до 3 (включительно). Установка значения 0 означает, что stdDev не задан. Значение по умолчанию — 0.
