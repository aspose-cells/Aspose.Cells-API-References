Представляет предустановленный стиль для элемента управления GridWeb. На данный момент мы предоставляем 7 предустановленных стилей.

| --- | --- |
| [COLORFUL_1](#COLORFUL-1) | Rose |
| [COLORFUL_2](#COLORFUL-2) | Синий |
| [CUSTOM](#CUSTOM) | Используйте ваш пользовательский стиль |
| [PROFESSIONAL_1](#PROFESSIONAL-1) | Голубой |
| [PROFESSIONAL_2](#PROFESSIONAL-2) | Циан снова |
| [STANDARD](#STANDARD) | Стандартный стиль, серебряный |
| [TRADITIONAL_1](#TRADITIONAL-1) | Тёмный |
| [TRADITIONAL_2](#TRADITIONAL-2) | Серый |
