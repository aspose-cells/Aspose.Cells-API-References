```
public final class HyperlinkActionType
```

Гиперссылка имеет два типа действий: UrlLink и CellCommand. Гиперссылка типа UrlLink представляет собой якорь в ячейке; при щелчке она переходит на другую страницу или открывает новое окно браузера. Гиперссылка типа CellCommand представляет собой кнопку команды в ячейке; при щелчке она генерирует событие на стороне сервера.

**Remarks**

ПРИМЕЧАНИЕ: Этот класс теперь устарел. пожалуйста, используйте вместо него GridHyperlink. Этот класс будет удалён через 6 месяцев после августа 2014 г. Aspose извиняется за любые неудобства, которые вы могли испытать.
