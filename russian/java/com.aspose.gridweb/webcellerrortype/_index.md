Используется в WebCellException. Представляет тип ошибки ячейки.
## Поля

| Поле | Описание |
| --- | --- |
| [DATA_SOURCE_DELETE_ERROR](#DATA-SOURCE-DELETE-ERROR) | При удалении связанной строки листа в источник данных произошла ошибка. |
| [DATA_SOURCE_INSERT_ERROR](#DATA-SOURCE-INSERT-ERROR) | При вставке связанной строки листа в источник данных произошла ошибка. |
| [DATA_SOURCE_UPDATE_ERROR](#DATA-SOURCE-UPDATE-ERROR) | При обновлении связанной строки листа или поля объекта произошла ошибка. |
| [VALIDATION_ERROR](#VALIDATION-ERROR) | Проверка ячейки не прошла. |
