Тип узла уравнения. Примечание: (1)[1-99] В настоящее время в области видимости присутствует только один узел, его значение перечисления равно 1. Указанный узел используется для хранения математического текста. (2)[100-199] Указывает, что узел является компонентом некоторых специальных функций. (3)[200-] Указывает, что у узла есть некоторые специальные функции.
