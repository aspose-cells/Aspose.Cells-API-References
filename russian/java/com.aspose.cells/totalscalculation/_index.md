## Поля

| Поле | Описание |
| --- | --- |
| [AVERAGE](#AVERAGE) | Представляет вычисление средних итогов. |
| [COUNT](#COUNT) | Представляет вычисление подсчёта итогов. |
| [COUNT_NUMS](#COUNT-NUMS) | Представляет вычисление подсчёта чисел итогов. |
| [CUSTOM](#CUSTOM) | Представляет пользовательское вычисление. |
| [MAX](#MAX) | Представляет вычисление максимальных итогов. |
| [MIN](#MIN) | Представляет вычисление минимальных итогов. |
| [NONE](#NONE) | Представляет отсутствие вычисления итогов. |
| [STD_DEV](#STD-DEV) | Представляет вычисление стандартного отклонения итогов. |
| [SUM](#SUM) | Представляет вычисление суммы итогов. |
| [VAR](#VAR) | Представляет вычисление дисперсии итогов. |
