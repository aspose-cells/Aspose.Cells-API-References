Указывает, как обрабатываются гиперссылки при загрузке HTML.
## Поля

| Поле | Описание |
| --- | --- |
| [ALLOW_MULTIPLE](#ALLOW-MULTIPLE) | Все гиперссылки в ячейке добавляются в [Worksheet.getHyperlinks()](../../com.aspose.cells/worksheet\#getHyperlinks--). |
| [NORMAL](#NORMAL) | Загружается только первая гиперссылка в ячейке, последующие игнорируются. |

### ALLOW_MULTIPLE {#ALLOW-MULTIPLE}
```
public static final int ALLOW_MULTIPLE
```


Все гиперссылки в ячейке добавляются в [Worksheet.getHyperlinks()](../../com.aspose.cells/worksheet\#getHyperlinks--). Обратите внимание, что MS Excel поддерживает только одну гиперссылку на ячейку, поэтому эта опция может создавать файлы, которые Excel не сможет полностью отобразить.

### NORMAL {#NORMAL}
```
public static final int NORMAL
```


Загружается только первая гиперссылка в ячейке, последующие игнорируются.
