Представляет режим выполнения по умолчанию редактора ввода (Input Method Editor).
## Поля

| Поле | Описание |
| --- | --- |
| [ALPHA](#ALPHA) | IME включён в режиме полуширинных буквенно-цифровых символов. |
| [ALPHA_FULL](#ALPHA-FULL) | IME включён в режиме полноширинных буквенно-цифровых символов. |
| [DISABLE](#DISABLE) | IME выключен. Пользователь не может включить IME с клавиатуры. |
| [HANGUL](#HANGUL) | IME включён в режиме полуширинного хангуль. |
| [HANGUL_FULL](#HANGUL-FULL) | IME включён в режиме полноширинного хангуль. |
| [HANZI](#HANZI) | IME включён в режиме полуширинных хандзи. |
| [HANZI_FULL](#HANZI-FULL) | IME включён в режиме полноширинных хандзи. |
| [HIRAGANA](#HIRAGANA) | IME включён в режиме полноширинных хирагана. |
| [KATAKANA](#KATAKANA) | IME включён в режиме полноширинных катакана. |
| [KATAKANA_HALF](#KATAKANA-HALF) | IME включён в режиме полуширинных катакана. |
| [NO_CONTROL](#NO-CONTROL) | Не управляет IME. |
| [OFF](#OFF) | IME выключен. |
| [ON](#ON) | IME включен. |
