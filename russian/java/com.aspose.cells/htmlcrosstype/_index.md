Представляет пять типов html‑cross‑string.
## Поля

| Поле | Описание |
| --- | --- |
| [CROSS](#CROSS) | Отображать строку HTML cross, эта производительность при создании больших HTML‑файлов будет более чем в десять раз быстрее, чем установка значения Default или FitToCell. |
| [CROSS_HIDE_RIGHT](#CROSS-HIDE-RIGHT) | Отображать строку HTML cross и скрывать правую строку, когда тексты перекрываются. |
| [DEFAULT](#DEFAULT) | Отображать как в MS Excel, зависит от следующей ячейки. |
| [FIT_TO_CELL](#FIT-TO-CELL) | Отображать строку только в пределах ширины ячейки. |
| [MS_EXPORT](#MS-EXPORT) | Отображать строку как в MS Excel при экспорте в html. |
