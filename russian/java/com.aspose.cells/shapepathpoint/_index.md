java.lang.Object
```
public class ShapePathPoint
```

Укажите координаты позиции или маркеры угла. Координаты позиции представляют координаты пути в координатном пространстве (например, X/Y). Маркеры угла указывают угловые изменения в пути (например, начальный и конечный углы дуги).

### getXAngle() {#getXAngle--}
```
public int getXAngle()
```


Когда объект является маркером угла, получайте или задавайте первый угол в градусах.

**Remarks**

Если этот угол является начальным углом дуги. Этот угол укажет, какой угол вдоль предполагаемого пути круга будет использоваться в качестве начальной позиции для рисования дуги. Этот начальный угол будет зафиксирован на последней известной позиции пера в пути фигуры. Таким образом гарантируется непрерывный путь фигуры.

**Returns:**
int
