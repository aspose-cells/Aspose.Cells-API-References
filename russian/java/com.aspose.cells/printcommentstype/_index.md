Представляет способ печати комментариев вместе с листом.
## Поля

| Поле | Описание |
| --- | --- |
| [PRINT_IN_PLACE](#PRINT-IN-PLACE) | Представляет печать комментариев так, как они отображаются на листе. |
| [PRINT_NO_COMMENTS](#PRINT-NO-COMMENTS) | Представляет отсутствие печати комментариев. |
| [PRINT_SHEET_END](#PRINT-SHEET-END) | Представляет печать комментариев в конце листа. |
| [PRINT_WITH_THREADED_COMMENTS](#PRINT-WITH-THREADED-COMMENTS) | Представляет печать комментариев в виде, отображаемом на листе, включая ветвящиеся комментарии. |
