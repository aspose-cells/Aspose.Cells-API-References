## Поля

| Поле | Описание |
| --- | --- |
| [BOTTOM](#BOTTOM) | Представляет выравнивание текста по нижнему краю. |
| [CENTER](#CENTER) | Представляет выравнивание текста по центру. |
| [CENTER_ACROSS](#CENTER-ACROSS) | Представляет выравнивание текста по центру по ширине. |
| [DISTRIBUTED](#DISTRIBUTED) | Представляет распределённое выравнивание текста. |
| [FILL](#FILL) | Представляет выравнивание текста заполнением. |
| [GENERAL](#GENERAL) | Представляет общее выравнивание текста. |
| [JUSTIFIED_LOW](#JUSTIFIED-LOW) | Выравнивает текст с изменённой длиной кашиды для арабского текста. |
| [JUSTIFY](#JUSTIFY) | Представляет выравнивание текста по ширине. |
| [LEFT](#LEFT) | Представляет выравнивание текста по левому краю. |
| [RIGHT](#RIGHT) | Представляет выравнивание текста по правому краю. |
| [THAI_DISTRIBUTED](#THAI-DISTRIBUTED) | Особым образом распределяет тайский текст, поскольку каждый символ рассматривается как слово. |
| [TOP](#TOP) | Представляет выравнивание текста по верхнему краю. |
