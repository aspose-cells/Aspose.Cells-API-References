### FILE_CACHE {#FILE-CACHE}
```
public static final int FILE_CACHE
```


Предпочтительна производительность памяти и использование файла вместо памяти для хранения данных ячеек.

**Remarks**

В этом режиме данные ячеек будут храниться в компактном формате, а основная часть данных будет сохраняться во временном файле вместо памяти. Поэтому при сравнении с режимом [MEMORY\_PREFERENCE](../../com.aspose.cells/memorysetting\#MEMORY-PREFERENCE) этот режим может более сильно уменьшить расход памяти, но операции ввода‑вывода при доступе к данным ячеек также приведут к большему затрату времени.

Эта опция доступна, начиная с версии v25.7.0.

| Некоторые заметные ограничения и рекомендуемые операции при использовании этого режима: |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Когда этот режим используется для любого листа в рабочей книге, следует вызвать [Workbook.dispose()](../../com.aspose.cells/workbook\#dispose--) в конце работы, чтобы освободить все ресурсы, такие как временные файлы. |
| Случайный доступ к ячейкам приводит к плохой производительности, поскольку данные необходимо считывать случайным и повторяющимся образом (указатель в файле будет перемещаться соответственно, и операции ввода‑вывода потребуются многократно). По возможности, пожалуйста, всегда обращайтесь к данным последовательно (строка за строкой). |
| Когда данные одной строки/ячейки изменяются, данные других ячеек/строк также могут быть затронуты (например, данные могут быть смещены/перемещены в другие места, чтобы выделить достаточно места для изменённых данных). Поэтому каждое изменение любых данных требует синхронизации с другими существующими объектами (например, объектами Row или Cell). Чтобы достичь лучшей производительности, пожалуйста, не храните одновременно несколько Row/Cell. Обработка их по одной уменьшит синхронизацию данных и позволит улучшить производительность. |

### MEMORY_PREFERENCE {#MEMORY-PREFERENCE}
```
public static final int MEMORY_PREFERENCE
```


Предпочтительна производительность памяти.

**Remarks**

В этом режиме данные ячеек будут храниться в компактном формате для снижения расхода памяти. С другой стороны, компактные данные могут увеличить затраты времени, особенно при обновлении данных ячеек или случайном доступе к ним.

Эта опция доступна, начиная с версии v8.0.0.

### NORMAL {#NORMAL}
```
public static final int NORMAL
```


Режим по умолчанию для модели ячеек.

**Remarks**

Этот режим применяется ко всем версиям.
