```
public interface LightCellsDataHandler
```

Представляет обработчик данных ячеек для чтения больших файлов электронных таблиц в легковесном режиме.

**Remarks**

При чтении книги в этом режиме, [startSheet(Worksheet)](../../com.aspose.cells/lightcellsdatahandler\#startSheet-Worksheet-) будет проверяться при чтении каждой листа книги. Для одного листа, если [startSheet(Worksheet)](../../com.aspose.cells/lightcellsdatahandler\#startSheet-Worksheet-) возвращает true, то все данные и свойства строк/ячеек этого листа будут проверяться и обрабатываться реализацией этого интерфейса. Для каждой строки будет вызываться [startRow(int)](../../com.aspose.cells/lightcellsdatahandler\#startRow-int-) для проверки, нужно ли её обрабатывать. Если строка требует обработки, её свойства будут сначала считаны, и пользователь может получить к ним доступ через [processRow(Row)](../../com.aspose.cells/lightcellsdatahandler\#processRow-Row-). Если также необходимо обработать ячейки строки, тогда [processRow(Row)](../../com.aspose.cells/lightcellsdatahandler\#processRow-Row-) должен вернуть true, после чего для каждой существующей ячейки в этой строке будет вызываться [startCell(int)](../../com.aspose.cells/lightcellsdatahandler\#startCell-int-) для проверки, нужна ли обработка ячейки. Если ячейка требует обработки, будет вызван [processCell(Cell)](../../com.aspose.cells/lightcellsdatahandler\#processCell-Cell-) для обработки ячейки реализацией этого интерфейса.

Обратите внимание, пользователь должен работать только со значениями и свойствами текущего объекта Row/Cell, предоставленного соответствующим методом. Поскольку данные ячеек читаются из шаблонного файла потоковым способом, большинство остальных объектов могут быть сброшены/обновлены позже после загрузки данных ячеек. Поэтому при работе с другими объектами в этой реализации такие операции могут не влиять на объекты, существующие в книге. И даже хуже, эти операции могут вызвать несогласованные данные в книге и привести к неожиданным проблемам или исключениям позже. Таким образом, для всех остальных объектов, таких как фигуры, ширина столбцов и стили, условное форматирование и т.д., пожалуйста, не изменяйте их в каких-либо методах этой реализации. Вместо этого управляйте ими после того, как книга будет построена.

### processCell(Cell cell) {#processCell-com.aspose.cells.Cell-}
```
public abstract boolean processCell(Cell cell)
```


Начинает обработку одной ячейки.

**Remarks**

Будет вызвано после чтения данных одной ячейки.

**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
| cell | [Cell](../../com.aspose.cells/cell) | Объект ячейки, который в данный момент обрабатывается |

**Returns:**
boolean — указывает, нужно ли сохранять эту ячейку в модели ячеек текущего листа. Обычно должно быть false, чтобы все ячейки не удерживались в памяти после обработки и тем самым экономилась память. Для некоторых специальных целей, например когда пользователю необходимо позже получить доступ к некоторым ячейкам после полной обработки книги, пользователь может вернуть true, чтобы сохранить эти специальные ячейки в модели Cells и получить к ним доступ позже через API, такие как Cells[row, column]. Однако сохранение данных ячеек в модели Cells требует больше памяти, и если сохраняются все ячейки, чтение шаблонного файла в режиме LightCells становится аналогичным обычному чтению.
### processRow(Row row) {#processRow-com.aspose.cells.Row-}
```
public abstract boolean processRow(Row row)
```


Начинает обработку одной строки.

**Remarks**

Будет вызвано после чтения свойств строки, таких как высота, стиль и т.д. Однако ячейки в этой строке еще не прочитаны.

**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
| row | [Row](../../com.aspose.cells/row) | Объект строки, который в данный момент обрабатывается. |

**Returns:**
boolean — указывает, нужно ли обрабатывать ячейки этой строки. false — игнорировать все ячейки в этой строке.
### startCell(int columnIndex) {#startCell-int-}
```
public abstract boolean startCell(int columnIndex)
```


Готовится обработать ячейку.

**Remarks**

Он будет вызван при достижении существующей ячейки в текущей строке. Текущая строка — это строка последнего вызова [processRow(Row)](../../com.aspose.cells/lightcellsdatahandler\#processRow-Row-).

**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
| columnIndex | int | индекс столбца ячейки, которую нужно обработать |

**Returns:**
логический тип — требуется ли обработка этой ячейки. false — игнорировать ячейку и проверять следующую, пока не будет достигнут конец данных ячеек текущей строки
### startRow(int rowIndex) {#startRow-int-}
```
public abstract boolean startRow(int rowIndex)
```


Готовится обработать строку.

**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
| rowIndex | int | индекс следующей строки для обработки |

**Returns:**
логический тип — требуется ли обработка этой строки (свойств или данных ячеек). false — игнорировать эту строку и её ячейки и проверять следующую строку.
### startSheet(Worksheet sheet) {#startSheet-com.aspose.cells.Worksheet-}
```
public abstract boolean startSheet(Worksheet sheet)
```


Начинает обработку листа.

**Remarks**

Он будет вызван перед чтением данных ячеек листа.

**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
| sheet | [Worksheet](../../com.aspose.cells/worksheet) | лист, из которого читаются данные ячеек. |

**Returns:**
логический тип — требуется ли обработка данных ячеек этого листа. false — игнорировать этот лист.
