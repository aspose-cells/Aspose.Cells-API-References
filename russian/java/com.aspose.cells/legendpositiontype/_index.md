## Поля

| Поле | Описание |
| --- | --- |
| [BOTTOM](#BOTTOM) | Отображает легенду в нижней части области построения диаграммы. |
| [CORNER](#CORNER) | Отображает легенду в углу области построения диаграммы. |
| [LEFT](#LEFT) | Отображает легенду слева от области построения диаграммы. |
| [NOT_DOCKED](#NOT-DOCKED) | Указывает, что легенда не закреплена. |
| [RIGHT](#RIGHT) | Отображает легенду справа от области построения диаграммы. |
| [TOP](#TOP) | Отображает легенду в верхней части области построения диаграммы. |
