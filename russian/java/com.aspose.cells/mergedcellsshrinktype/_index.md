Представляет стратегию сжатия объединённых ячеек для операций, таких как удаление пустых строк/столбцов.
## Поля

| Поле | Описание |
| --- | --- |
| [KEEP_HEADER_ONLY](#KEEP-HEADER-ONLY) | Сохраняет только строки/столбцы заголовка объединённой области, когда верхняя‑левая ячейка объединённой области не пустая. |
| [NONE](#NONE) | Оставляет объединённые ячейки без каких‑либо изменений. |
| [SHRINK_TO_FIT](#SHRINK-TO-FIT) | Уменьшает объединённую область при необходимости, удаляя строки снизу или столбцы справа, при этом гарантируя, что всё содержимое остаётся видимым. |
