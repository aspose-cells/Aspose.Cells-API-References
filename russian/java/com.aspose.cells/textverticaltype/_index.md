```

```

Представляет тип направления текста.
## Поля

| Поле | Описание |
| --- | --- |
| [HORIZONTAL](#HORIZONTAL) | Горизонтальный текст. |
| [STACKED](#STACKED) | Определяет, является ли весь текст вертикальным |
| [STACKED_RIGHT_TO_LEFT](#STACKED-RIGHT-TO-LEFT) | Указывает, что вертикальный WordArt должен отображаться справа налево, а не слева направо. |
| [VERTICAL](#VERTICAL) | Отображение вертикального текста восточноазиатских языков. |
| [VERTICAL_270](#VERTICAL-270) | Каждая строка вращена на 270 градусов по часовой стрелке |
| [VERTICAL_90](#VERTICAL-90) | Каждая строка вращена на 90 градусов по часовой стрелке |
| [VERTICAL_LEFT_TO_RIGHT](#VERTICAL-LEFT-TO-RIGHT) | Отображается вертикально, и текст течет сверху вниз, затем LEFT to RIGHT |
