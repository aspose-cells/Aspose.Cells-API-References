Представляет, как приложение отображает фигуры в этой рабочей книге. Фигуры могут включать диаграммы, изображения и другие данные объектов, поддерживаемые приложением.
## Поля

| Поле | Описание |
| --- | --- |
| [ALL](#ALL) | Указывает, что все фигуры должны отображаться в рабочей книге. |
| [NONE](#NONE) | Указывает, что все фигуры должны быть скрыты в рабочей книге. |
| [PLACEHOLDERS](#PLACEHOLDERS) | Указывает, что приложение должно показывать заполнители для фигур в рабочей книге. |
