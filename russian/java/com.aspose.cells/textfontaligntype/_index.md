Представляет различные типы выравнивания шрифта.
## Поля

| Поле | Описание |
| --- | --- |
| [AUTOMATIC](#AUTOMATIC) | Когда поток текста горизонтальный или простой вертикальный, он такой же, как fontBaseline, но для других вертикальных режимов — такой же, как fontCenter. |
| [BASELINE](#BASELINE) | Буквы привязаны к нижней базовой линии одной строки. |
| [BOTTOM](#BOTTOM) | Буквы привязаны к самому низу одной строки. |
| [CENTER](#CENTER) | Буквы привязаны между двумя базовыми линиями одной строки. |
| [TOP](#TOP) | Буквы привязаны к верхней базовой линии одной строки. |
