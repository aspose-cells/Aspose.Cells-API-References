### getOffset() {#getOffset--}
```
public int getOffset()
```


Получает расстояние меток от категориальной оси. Применяется только к категориальной (x) оси.

**Remarks**

Расстояние по умолчанию составляет 100 процентов, что представляет собой стандартный интервал между метками оси и линией оси. Значение может быть целым процентом от 0 до 1000, относительно размера шрифта метки оси''.

**Returns:**
int
