Указывает тип правила, используемого для описания области или аспекта сводной таблицы.
## Поля

| Поле | Описание |
| --- | --- |
| [ALL](#ALL) | Представляет всю сводную таблицу. |
| [BUTTON](#BUTTON) | Представляет кнопку поля. |
| [DATA](#DATA) | Представляет элемент в области данных. |
| [NONE](#NONE) | Нет области сводной таблицы. |
| [NORMAL](#NORMAL) | Представляет заголовок или элемент. |
| [ORIGIN](#ORIGIN) | Представляет пустые ячейки в левом верхнем углу сводной таблицы (правый верхний угол для листов RTL). |
| [TOP_RIGHT](#TOP-RIGHT) | Представляет пустые ячейки в правом верхнем углу сводной таблицы (левый верхний угол для листов RTL). |
