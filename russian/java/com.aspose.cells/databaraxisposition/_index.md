Указывает позицию оси для диапазона ячеек с условным форматированием в виде полос данных.
## Поля

| Поле | Описание |
| --- | --- |
| [AUTOMATIC](#AUTOMATIC) | Отображать ось в переменной позиции, основанной на отношении минимального отрицательного значения к максимальному положительному значению в диапазоне. |
| [MIDPOINT](#MIDPOINT) | Отображать ось в середине ячейки независимо от набора значений в диапазоне. |
| [NONE](#NONE) | Ось не отображается, а положительные и отрицательные значения выводятся слева направо. |

### AUTOMATIC {#AUTOMATIC}
```
public static final int AUTOMATIC
```


Отобразите ось в переменной позиции на основе отношения минимального отрицательного значения к максимальному положительному значению в диапазоне. Положительные значения отображаются слева направо. Отрицательные значения отображаются справа налево. Когда все значения положительные или все значения отрицательные, ось не отображается.

### MIDPOINT {#MIDPOINT}
```
public static final int MIDPOINT
```


Отобразите ось в средней точке ячейки независимо от набора значений в диапазоне. Положительные значения отображаются слева направо. Отрицательные значения отображаются справа налево.

### NONE {#NONE}
```
public static final int NONE
```


Ось не отображается, а положительные и отрицательные значения выводятся слева направо.
