Указывает начальный режим просмотра при открытии сгенерированного PDF‑документа.
## Поля

| Поле | Описание |
| --- | --- |
| [FIT_HEIGHT](#FIT-HEIGHT) | Подгоняет высоту страницы под окно просмотра. |
| [FIT_PAGE](#FIT-PAGE) | Подгоняет всю страницу под окно просмотра. |
| [FIT_WIDTH](#FIT-WIDTH) | Подгоняет ширину страницы под окно просмотра. |
| [NONE](#NONE) | Использует поведение по умолчанию PDF‑просмотрщика. |
| [ZOOM_FACTOR](#ZOOM-FACTOR) | Открывает документ с определённым процентом масштабирования. |
