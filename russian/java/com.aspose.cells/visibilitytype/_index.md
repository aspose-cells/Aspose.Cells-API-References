Представляет состояния видимости листа.
## Поля

| Поле | Описание |
| --- | --- |
| [HIDDEN](#HIDDEN) | Указывает, что лист скрыт, но может быть отображён пользователем через пользовательский интерфейс. |
| [VERY_HIDDEN](#VERY-HIDDEN) | Указывает, что лист скрыт и не может быть отображён в пользовательском интерфейсе (UI). |
| [VISIBLE](#VISIBLE) | Указывает, что лист видим. |
