```
public interface LightCellsDataProvider
```

Представляет поставщика данных для сохранения больших файлов электронных таблиц в легковесном режиме.

**Remarks**

При сохранении книги в этом режиме, [startSheet(int)](../../com.aspose.cells/lightcellsdataprovider\#startSheet-int-) будет проверяться при сохранении каждого листа в книге. Для одного листа, если [startSheet(int)](../../com.aspose.cells/lightcellsdataprovider\#startSheet-int-) возвращает true, тогда все данные и свойства, которые должны быть сохранены для строк/ячеек этого листа, будут предоставлены реализацией этого интерфейса. Сначала будет вызвано [nextRow()](../../com.aspose.cells/lightcellsdataprovider\#nextRow--) чтобы получить индекс следующей строки для сохранения. Если возвращён корректный индекс строки (индекс строки должен быть в возрастающем порядке для сохраняемых строк), тогда объект Row, представляющий эту строку, будет предоставлен через [startRow(Row)](../../com.aspose.cells/lightcellsdataprovider\#startRow-Row-) для установки его свойств. Для одной строки будет проверяться [nextCell()](../../com.aspose.cells/lightcellsdataprovider\#nextCell--) сначала. Если возвращён корректный индекс столбца (индекс столбца должен быть в возрастающем порядке для всех ячеек текущей строки), тогда объект Cell, представляющий эту ячейку, будет предоставлен через [startCell(Cell)](../../com.aspose.cells/lightcellsdataprovider\#startCell-Cell-) для установки его данных и свойств. После [startCell(Cell)](../../com.aspose.cells/lightcellsdataprovider\#startCell-Cell-) ячейка будет сохранена напрямую в результирующий файл электронной таблицы. Затем будет проверена и обработана следующая ячейка.

Обратите внимание, пользователь должен обновлять только значения и свойства текущего объекта Row/Cell, предоставленного соответствующим методом. Поскольку данные ячеек записываются в результирующий файл потоковым способом, большинство других объектов уже могли быть записаны в результирующий файл или собраны и записаны некоторые глобальные данные для них. Поэтому, когда пользователь обновляет другие объекты во время сохранения данных ячеек, эти операции могут не повлиять на сохранённые данные. И даже хуже, такие операции могут привести к сохранению несогласованных данных в результирующий файл и в конечном итоге испортить файл. Поэтому для всех остальных объектов, таких как фигуры, ширина столбцов и стили, условное форматирование и т.д., пожалуйста, не оперируйте ими в каких-либо методах этой реализации. Вместо этого управляйте ими и приводите к окончательному состоянию перед вызовом метода \"Save\" книги.

### isGatherString() {#isGatherString--}
```
public abstract boolean isGatherString()
```


Проверяет, нужно ли текущему строковому значению ячейки собирать в глобальный пул.

**Remarks**

Сбор строковых значений будет полезен только тогда, когда существует множество дублирующихся строковых значений для ячеек, предоставляемых этой реализацией. В такой ситуации сбор строк экономит память и создаёт более маленький результирующий файл. Если для ячеек, предоставляемых LightCellsDataProvider, существует много строковых значений, но лишь несколько из них одинаковы, сбор строк потребует больше памяти и времени и не даст преимущества для результирующего файла.

**Returns:**
boolean — true, если строковое значение должно быть собрано в глобальный пул для результирующего файла.
### nextCell() {#nextCell--}
```
public abstract int nextCell()
```


Получает следующую ячейку для сохранения.

**Remarks**

Будет вызвано в начале сохранения одной ячейки.

**Returns:**
int — индекс столбца следующей ячейки для сохранения. -1 означает, что достигнут конец данных текущей строки и дальнейших ячеек текущей строки для сохранения нет.
### nextRow() {#nextRow--}
```
public abstract int nextRow()
```


Получает следующую строку для сохранения.

**Remarks**

Будет вызвано в начале сохранения строки и её данных ячеек (перед [startRow(Row)](../../com.aspose.cells/lightcellsdataprovider\#startRow-Row-)).

**Returns:**
int — индекс следующей строки для сохранения. -1 означает, что достигнут конец данных текущего листа и дальнейших строк текущего листа для сохранения нет.
### startCell(Cell cell) {#startCell-com.aspose.cells.Cell-}
```
public abstract void startCell(Cell cell)
```


Начинает сохранять данные одной ячейки.

**Remarks**

**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
| cell | [Cell](../../com.aspose.cells/cell) | Объект Cell для реализации заполнения данных. Его индекс столбца — значение, возвращённое последним вызовом [nextCell()](../../com.aspose.cells/lightcellsdataprovider\#nextCell--). Если ячейка была инициализирована во внутренней модели ячеек, будет использован существующий объект Cell. ### startRow(Row row) {#startRow-com.aspose.cells.Row-}
```
public abstract void startRow(Row row)
```


Начинает сохранять данные одной строки.

**Remarks**

Будет вызвано в начале сохранения строки и её данных ячеек. Если у текущей строки есть пользовательские свойства, такие как высота, стиль и т.д., реализация должна установить эти свойства в переданный объект Row здесь.

**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
| row | [Row](../../com.aspose.cells/row) | Объект Row для реализации заполнения данных. Его индекс строки — значение, возвращённое последним вызовом [nextRow()](../../com.aspose.cells/lightcellsdataprovider\#nextRow--). Если строка была инициализирована во внутренней модели ячеек, будет использован существующий объект Row. В противном случае будет использован временный объект Row для реализации заполнения данных. |

### startSheet(int sheetIndex) {#startSheet-int-}
```
public abstract boolean startSheet(int sheetIndex)
```


Начинает сохранять лист.

**Remarks**

Будет вызвано в начале сохранения листа во время сохранения книги. Если провайдеру необходимо позже обратиться к *`sheetIndex`* в методах startRow(Row) или startCell(Cell), то есть если процессу нужно знать, какой лист обрабатывается, реализация должна сохранить значение *`sheetIndex`* здесь.

**Parameters:**
| Параметр | Тип | Описание |
| --- | --- | --- |
| sheetIndex | int | индекс текущего листа для сохранения. |

**Returns:**
boolean — true, если этот провайдер будет предоставлять данные для указанного листа; false, если указанный лист должен использовать свою обычную модель данных (Cells).
