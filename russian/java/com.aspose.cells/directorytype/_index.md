Представляет тип каталога имени файла.
## Поля

| Поле | Описание |
| --- | --- |
| [DOWN_DIRECTORY](#DOWN-DIRECTORY) | Указывает, что исходная рабочая книга находится в подкаталоге текущего каталога. |
| [SAME_VOLUME](#SAME-VOLUME) | Указывает, что исходная рабочая книга находится на том же диске, что и зависимая рабочая книга (буква диска опущена). |
| [UP_DIRECTORY](#UP-DIRECTORY) | Указывает, что исходная рабочая книга находится в родительском каталоге текущего каталога. |
| [VOLUME](#VOLUME) | Представляет букву диска MS-DOS. |
