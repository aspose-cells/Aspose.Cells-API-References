Перечисляет тип отображения текста, когда ширина текста превышает ширину ячейки.
## Поля

| Поле | Описание |
| --- | --- |
| [CROSS_KEEP](#CROSS-KEEP) | Отображать весь текст, пересекающий другие ячейки, и сохранять текст пересечённых ячеек. |
| [CROSS_OVERRIDE](#CROSS-OVERRIDE) | Отображать весь текст, пересекающий другие ячейки, и заменять текст пересечённых ячеек. |
| [DEFAULT](#DEFAULT) | Отображать текст так же, как в Microsoft Excel. |
| [STRICT_IN_CELL](#STRICT-IN-CELL) | Отображать только текст в пределах ширины ячейки. |
