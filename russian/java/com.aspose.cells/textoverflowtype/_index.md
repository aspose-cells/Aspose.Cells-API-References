| [OVERFLOW](#OVERFLOW) | Переполнять текст, игнорируя верхние и нижние границы. |

### CLIP {#CLIP}
```
public static final int CLIP
```


Учитывать верхние и нижние границы. Не указывать, что есть невидимый текст.

### ELLIPSIS {#ELLIPSIS}
```
public static final int ELLIPSIS
```


Учитывать верхние и нижние границы. Использовать многоточие, чтобы обозначить наличие невидимого текста. Только для вертикального переполнения.

### OVERFLOW {#OVERFLOW}
```
public static final int OVERFLOW
```


Переполнять текст, игнорируя верхние и нижние границы.
