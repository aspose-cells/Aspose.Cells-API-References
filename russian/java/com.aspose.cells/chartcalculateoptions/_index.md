### getUpdateAllPoints() {#getUpdateAllPoints--}
```
public boolean getUpdateAllPoints()
```


Обновлять ли все точки данных при выполнении расчёта диаграммы. По умолчанию: False. Когда вы хотите получить значение каждой точки данных в диаграмме отдельно, установите значение true. Если этот параметр установлен в True, новые точки данных могут быть созданы при расчёте диаграммы. Это может увеличить размер файла Excel.
