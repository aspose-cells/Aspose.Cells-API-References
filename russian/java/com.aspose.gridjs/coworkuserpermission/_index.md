Представляет разрешения пользователя в режиме совместной работы. Доступно только в версии Java сейчас, будет доступно в версиях .net/python в будущем.
## Поля

| Поле | Описание |
| --- | --- |
| [ADMIN](#ADMIN) | Разрешение администратора, пользователь имеет полный доступ, включая операции управления |
| [DOWNLOAD](#DOWNLOAD) | Разрешение на загрузку, пользователь может просматривать, редактировать и загружать содержимое в локальное хранилище |
| [EDITABLE](#EDITABLE) | Разрешение на редактирование, пользователь может просматривать и редактировать содержимое |
| [READ_ONLY](#READ-ONLY) | Разрешение только для чтения, пользователь может только просматривать содержимое, но не может вносить изменения |
