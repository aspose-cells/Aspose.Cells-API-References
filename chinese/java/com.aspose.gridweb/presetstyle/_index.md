```
public final class PresetStyle
```

表示 GridWeb 控件的预设样式。迄今为止，我们提供了 7 种预设样式。
## 字段

| 字段 | 描述 |
| --- | --- |
| [COLORFUL_1](#COLORFUL-1) | Rose |
| [COLORFUL_2](#COLORFUL-2) | 蓝色 |
| [CUSTOM](#CUSTOM) | 使用您自定义的样式 |
| [PROFESSIONAL_1](#PROFESSIONAL-1) | 青色 |
| [PROFESSIONAL_2](#PROFESSIONAL-2) | 再次使用青色 |
| [STANDARD](#STANDARD) | 标准样式，银色 |
| [TRADITIONAL_1](#TRADITIONAL-1) | 暗色 |
| [TRADITIONAL_2](#TRADITIONAL-2) | 灰色 |
