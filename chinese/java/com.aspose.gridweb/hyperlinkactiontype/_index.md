```
public final class HyperlinkActionType
```

超链接有两种操作类型：UrlLink 和 CellCommand。UrlLink 类型的超链接是单元格中的锚点，点击后会导航到另一个页面或打开新的浏览器窗口。CellCommand 类型的超链接是单元格中的命令按钮，点击后会生成服务器端事件。

**Remarks**

注意：此类已过时，请改用 GridHyperlink。该类将在自 2014 年 8 月起 6 个月后移除。Aspose 对您可能遇到的不便表示歉意。
