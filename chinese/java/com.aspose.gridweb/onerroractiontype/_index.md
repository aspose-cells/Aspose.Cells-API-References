java.lang.Object
```
public final class OnErrorActionType
```

在 GridWeb 的 CellError 事件中使用。用户设置 OnErrorActionQuery.OnErrorAction 来指示控件停止处理或忽略错误。
## 字段

| 字段 | 描述 |
| --- | --- |
| [IGNORE](#IGNORE) | 忽略错误并继续处理。 |
| [STOP](#STOP) | 停止当前处理。 |
| [THROW](#THROW) | 抛出当前异常。 |
