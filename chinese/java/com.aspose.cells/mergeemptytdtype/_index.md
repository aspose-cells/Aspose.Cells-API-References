### MERGE_FORCELY {#MERGE-FORCELY}
```
public static final int MERGE_FORCELY
```


在导出文件为 html 时强制合并空的 TD 元素。将该值设为 true 后，html 文件的大小将显著减小。如果您想将 html 文件导入 Excel，或在保存为 html 时导出完美的网格线，请保持默认值。

### NONE {#NONE}
```
public static final int NONE
```


导出文件为 html 时空的 TD 元素将不会被合并。这将生成显著更大的 html 文件。
