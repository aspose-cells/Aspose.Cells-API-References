## 字段

| 字段 | 描述 |
| --- | --- |
| [DOWN_DIRECTORY](#DOWN-DIRECTORY) | 指示源工作簿位于当前目录的子目录中。 |
| [SAME_VOLUME](#SAME-VOLUME) | 指示源工作簿与依赖工作簿位于同一驱动器上（省略驱动器字母）。 |
| [UP_DIRECTORY](#UP-DIRECTORY) | 指示源工作簿位于当前目录的父目录中。 |
| [VOLUME](#VOLUME) | 表示 MS-DOS 驱动器字母。 |
