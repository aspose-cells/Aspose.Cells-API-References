## 字段

| 字段 | 描述 |
| --- | --- |
| [HORIZONTAL](#HORIZONTAL) | 水平文本。 |
| [STACKED](#STACKED) | 确定所有文本是否垂直。 |
| [STACKED_RIGHT_TO_LEFT](#STACKED-RIGHT-TO-LEFT) | 指定垂直 WordArt 应从右向左而不是从左向右显示。 |
| [VERTICAL](#VERTICAL) | 东亚垂直显示。 |
| [VERTICAL_270](#VERTICAL-270) | 每行顺时针旋转 270 度。 |
| [VERTICAL_90](#VERTICAL-90) | 每行顺时针旋转 90 度。 |
| [VERTICAL_LEFT_TO_RIGHT](#VERTICAL-LEFT-TO-RIGHT) | 垂直显示，文本从上到下流动，然后从左到右。 |
