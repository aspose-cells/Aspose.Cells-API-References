表示 HTML 标记中 target 属性的类型。
## 字段

| 字段 | 描述 |
| --- | --- |
| [BLANK](#BLANK) | 在新窗口或标签页中打开链接文档 |
| [PARENT](#PARENT) | 在父框架中打开链接文档 |
| [SELF](#SELF) | 在点击时所在的同一框架中打开链接文档（这是默认设置） |
| [TOP](#TOP) | 在窗口的完整主体中打开链接文档 |
