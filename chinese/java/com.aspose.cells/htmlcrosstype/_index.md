表示五种 HTML 交叉字符串类型。
## 字段

| 字段 | 描述 |
| --- | --- |
| [CROSS](#CROSS) | 显示 HTML 交叉字符串，此在创建大型 HTML 文件时的性能将比将值设置为 Default 或 FitToCell 快十倍以上。 |
| [CROSS_HIDE_RIGHT](#CROSS-HIDE-RIGHT) | 显示 HTML 交叉字符串，并在文本重叠时隐藏右侧字符串。 |
| [DEFAULT](#DEFAULT) | 显示类似 MS Excel，取决于下一个单元格。 |
| [FIT_TO_CELL](#FIT-TO-CELL) | 仅在单元格宽度范围内显示字符串。 |
| [MS_EXPORT](#MS-EXPORT) | 显示字符串类似 MS Excel 导出 HTML。 |
