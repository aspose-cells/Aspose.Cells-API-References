表示应用程序在此工作簿中显示形状的方式。形状可能包括图表、图像以及应用程序支持的其他对象数据。
## 字段

| 字段 | 描述 |
| --- | --- |
| [ALL](#ALL) | 指示在工作簿中显示所有形状。 |
| [NONE](#NONE) | 指示在工作簿中隐藏所有形状。 |
| [PLACEHOLDERS](#PLACEHOLDERS) | 指示应用程序在工作簿中显示形状的占位符。 |
