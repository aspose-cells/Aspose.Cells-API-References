枚举当文本宽度大于单元格宽度时的显示文本类型。
## 字段

| 字段 | 描述 |
| --- | --- |
| [CROSS_KEEP](#CROSS-KEEP) | 显示跨越其他单元格的所有文本，并保留被跨越单元格的文本。 |
| [CROSS_OVERRIDE](#CROSS-OVERRIDE) | 显示跨越其他单元格的所有文本，并覆盖被跨越单元格的文本。 |
| [DEFAULT](#DEFAULT) | 显示类似于 Microsoft Excel 的文本。 |
| [STRICT_IN_CELL](#STRICT-IN-CELL) | 仅在单元格宽度范围内显示文本。 |
