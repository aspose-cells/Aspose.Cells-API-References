```
public final class HtmlFormatHandlingType
```

指定如何处理来自 HTML 源的格式。
## 字段

| 字段 | 描述 |
| --- | --- |
| [ALL](#ALL) | 将所有 HTML 格式连同数据一起转移到工作表中。 |
| [NONE](#NONE) | 将数据作为未格式化的文本导入（仍会设置数据类型）。 |
| [RTF](#RTF) | 将导入工作表的数据的 HTML 格式转换为富文本格式。 |
