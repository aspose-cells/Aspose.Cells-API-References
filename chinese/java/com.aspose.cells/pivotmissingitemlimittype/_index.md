表示每个字段要保留的项数。

**Remarks**

注意：此属性已过时。请改用 PivotCache.MissingItemsLimit 属性。该方法将在自 2026 年 9 月起的 12 个月后被移除。Aspose 对您可能遇到的不便表示歉意。
## 字段

| 字段 | 描述 |
| --- | --- |
| [AUTOMATIC](#AUTOMATIC) | 每个 PivotField 允许的默认唯一项数。 |
| [MAX](#MAX) | 每个 PivotField 允许的最大唯一项数（>32,500）。 |
| [NONE](#NONE) | 不允许每个 PivotField 有唯一项。 |
