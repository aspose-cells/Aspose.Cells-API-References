### AUTOMATIC {#AUTOMATIC}
```
public static final int AUTOMATIC
```


根据范围内最小负值与最大正值的比例，在可变位置显示坐标轴。正值从左向右显示，负值从右向左显示。当所有值均为正或均为负时，不显示坐标轴。

### MIDPOINT {#MIDPOINT}
```
public static final int MIDPOINT
```


不论范围内的值集合如何，都在单元格的中点显示坐标轴。正值从左向右显示，负值从右向左显示。

### NONE {#NONE}
```
public static final int NONE
```


不显示坐标轴，正负值均从左向右显示。
