java.lang.Object
```
public final class CoWorkUserPermission
```

表示协作模式下的用户权限。目前仅在 Java 版本中可用，未来将在 .net/python 版本中提供。
## 字段

| 字段 | 描述 |
| --- | --- |
| [ADMIN](#ADMIN) | 管理员权限，用户拥有包括管理操作在内的全部访问权限 |
| [DOWNLOAD](#DOWNLOAD) | 下载权限，用户可以查看、编辑并将内容下载到本地存储 |
| [EDITABLE](#EDITABLE) | 可编辑权限，用户可以查看并编辑内容 |
| [READ_ONLY](#READ-ONLY) | 只读权限，用户只能查看内容，不能进行任何修改 |
