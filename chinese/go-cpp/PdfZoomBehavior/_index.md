## PdfZoomBehavior Enum

指定打开生成的 PDF 文档时的初始视图模式。

```go

type PdfZoomBehavior int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [None](./none/) | 使用 PDF 查看器的默认行为。 |
| [ZoomFactor](./zoomfactor/) | 在特定的缩放百分比下打开文档。 |
| [FitPage](./fitpage/) | 将整页适配到查看器窗口内。 |
| [FitWidth](./fitwidth/) | 将页面宽度适配到查看器窗口内。 |
| [FitHeight](./fitheight/) | 将页面高度适配到查看器窗口内。 |
