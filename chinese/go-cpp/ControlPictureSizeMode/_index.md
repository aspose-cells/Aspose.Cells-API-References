## ControlPictureSizeMode Enum

表示图片的显示方式。

```go

type ControlPictureSizeMode int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Clip](./clip/) | 裁剪超出控件边界的图片部分。 |
| [Stretch](./stretch/) | 拉伸图片以填满控件区域。此设置会在水平或垂直方向上扭曲图片。 |
| [Zoom](./zoom/) | 放大图片，但不会在水平或垂直方向上扭曲图片。 |
