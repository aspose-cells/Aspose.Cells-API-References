## PaneStateType Enum

表示工作表窗格的状态。

```go

type PaneStateType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Frozen](./frozen/) | 窗格已冻结，但在冻结之前未冻结。 |
| [FrozenSplit](./frozensplit/) | 窗格已冻结，并且在冻结之前已拆分。 |
| [Split](./split/) | 窗格已拆分，但未冻结。 |
| [Normal](./normal/) | 窗格未冻结且未拆分。 |
