## HtmlVersion Enum

指示在保存为 HTML 格式时使用的 HTML 版本。

```go

type HtmlVersion int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Default](./default/) | 将文档保存为符合 MS Excel 导出 HTML 的格式。 |
| [XHtml](./xhtml/) | 将文档保存为符合 XHTML 1.0 Transitional 标准的格式。 |
| [Html5](./html5/) | 将文档保存为符合 HTML 5 标准的格式。 |
