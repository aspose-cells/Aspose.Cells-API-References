## VisibilityType Enum

表示工作表可见性的状态。

```go

type VisibilityType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Visible](./visible/) | 指示工作表是可见的。 |
| [Hidden](./hidden/) | 指示工作表已隐藏，但用户可以通过用户界面显示它。 |
| [VeryHidden](./veryhidden/) | 指示工作表已隐藏，且无法在用户界面（UI）中显示。此状态仅可通过编程方式获得。 |
