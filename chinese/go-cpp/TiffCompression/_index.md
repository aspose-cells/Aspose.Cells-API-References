## TiffCompression Enum

指定在将图像保存为 TIFF 格式文件时要应用的压缩类型。

```go

type TiffCompression int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [CompressionNone](./compressionnone/) | 指定无压缩。 |
| [CompressionRle](./compressionrle/) | 指定 RLE 压缩方案。 |
| [CompressionLZW](./compressionlzw/) | 指定 LZW 压缩方案。 |
| [CompressionCCITT3](./compressionccitt3/) | 指定 CCITT3 压缩方案。 |
| [CompressionCCITT4](./compressionccitt4/) | 指定 CCITT4 压缩方案。 |
