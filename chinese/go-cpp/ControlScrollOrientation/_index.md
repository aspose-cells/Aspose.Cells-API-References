## ControlScrollOrientation Enum

表示滚动方向的类型

```go

type ControlScrollOrientation int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Auto](./auto/) | 当控件的宽度大于高度时，控件水平渲染；否则垂直渲染。 |
| [Vertical](./vertical/) | 控件垂直渲染。 |
| [Horizontal](./horizontal/) | 控件水平渲染。 |
