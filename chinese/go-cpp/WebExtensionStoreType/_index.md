## WebExtensionStoreType Enum

表示 Web 扩展的存储类型。

```go

type WebExtensionStoreType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [OMEX](./omex/) | 指定存储类型为 Office.com。 |
| [SPCatalog](./spcatalog/) | 指定存储类型为 SharePoint 企业目录。 |
| [SPApp](./spapp/) | 指定存储类型为 SharePoint Web 应用程序。 |
| [Exchange](./exchange/) | 指定存储类型为 Exchange 服务器。 |
| [FileSystem](./filesystem/) | 指定存储类型为文件系统共享。 |
| [Registry](./registry/) | 指定存储类型为系统注册表。 |
| [ExCatalog](./excatalog/) | 指定存储类型为通过 Exchange 的集中部署。 |
