## TextStrikeType Enum

此类型指定删除线类型。


## 字段

| 字段 | 描述 |
| --- | --- |
| [Single](./single/) | 在文本上应用单一删除线。 |
| [Double](./double/) | 在文本上应用双删除线。仅适用于形状或图表的文本。 |
