## ImageType Enum

指定图像的类型（格式）。

```go

type ImageType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Unknown](./unknown/) | 未知的图像类型。 |
| [Emf](./emf/) | Windows 增强型图元文件。 |
| [Wmf](./wmf/) | Windows 图元文件。 |
| [Pict](./pict/) | Macintosh PICT。 |
| [Jpeg](./jpeg/) | JPEG JFIF。 |
| [Png](./png/) | 可移植网络图形。 |
| [Bmp](./bmp/) | Windows 位图 |
| [Gif](./gif/) | Gif |
| [Tiff](./tiff/) | Tiff |
| [Svg](./svg/) | Svg |
| [Svm](./svm/) | Svm |
| [Gltf](./gltf/) | glTF |
| [OfficeCompatibleEmf](./officecompatibleemf/) | Windows 增强型图元文件，更兼容 Office。 |
| [WebP](./webp/) | Weppy 图像格式 |
