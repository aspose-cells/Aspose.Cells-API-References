## GradientStyleType Enum

表示渐变阴影样式。

```go

type GradientStyleType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [DiagonalDown](./diagonaldown/) | 对角向下阴影样式 |
| [DiagonalUp](./diagonalup/) | 对角向上阴影样式 |
| [FromCenter](./fromcenter/) | 从中心阴影样式 |
| [FromCorner](./fromcorner/) | 从角落阴影样式 |
| [Horizontal](./horizontal/) | 水平阴影样式 |
| [Vertical](./vertical/) | 垂直阴影样式 |
| [Unknown](./unknown/) | 未知阴影样式。仅用于模板文件中不属于 GradientStyleType 任意成员的阴影样式。 |
