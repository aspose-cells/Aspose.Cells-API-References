## TextFontAlignType Enum

表示字体对齐的不同类型。

```go

type TextFontAlignType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Automatic](./automatic/) | 当文本流为水平或简单垂直时，与 fontBaseline 相同，但对于其他垂直模式则与 fontCenter 相同。 |
| [Bottom](./bottom/) | 这些字母锚定在单行的最底部。 |
| [Baseline](./baseline/) | 这些字母锚定在单行的底部基线。 |
| [Center](./center/) | 这些字母锚定在单行的两条基线之间。 |
| [Top](./top/) | 这些字母锚定在单行的顶部基线。 |
