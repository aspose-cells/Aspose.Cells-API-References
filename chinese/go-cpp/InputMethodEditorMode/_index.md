## InputMethodEditorMode Enum

表示输入法编辑器的默认运行时模式。

```go

type InputMethodEditorMode int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [NoControl](./nocontrol/) | 不控制输入法。 |
| [On](./on/) | 输入法开启。 |
| [Off](./off/) | 输入法关闭。英文模式。 |
| [Disable](./disable/) | 输入法关闭。用户无法通过键盘开启输入法。 |
| [Hiragana](./hiragana/) | 输入法开启，使用全角平假名模式。 |
| [Katakana](./katakana/) | 输入法开启，使用全角片假名模式。 |
| [KatakanaHalf](./katakanahalf/) | 输入法开启，使用半角片假名模式。 |
| [AlphaFull](./alphafull/) | 输入法开启，使用全角字母数字模式。 |
| [Alpha](./alpha/) | 输入法开启，使用半角字母数字模式。 |
| [HangulFull](./hangulfull/) | 输入法开启，使用全角韩文模式。 |
| [Hangul](./hangul/) | 输入法开启，使用半角韩文模式。 |
| [HanziFull](./hanzifull/) | 输入法开启，使用全角汉字模式。 |
| [Hanzi](./hanzi/) | 输入法开启，使用半角汉字模式。 |
