## ControlListStyle Enum

表示 ListBox 或 ComboBox 中列表的视觉外观。

```go

type ControlListStyle int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Plain](./plain/) | 显示一个列表，当选中项时其背景会被高亮。 |
| [Option](./option/) | 显示一个列表，每个条目旁的选项按钮或复选框显示该项的选择状态。 |
