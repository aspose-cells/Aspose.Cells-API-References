## TextVerticalType Enum

表示文本方向类型。

```go

type TextVerticalType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Vertical](./vertical/) | 东亚竖排显示。 |
| [Horizontal](./horizontal/) | 水平文本。 |
| [VerticalLeftToRight](./verticallefttoright/) | 垂直显示，文本从上到下流动，然后 LEFT to RIGHT。 |
| [Vertical90](./vertical90/) | 每行顺时针旋转 90 度。 |
| [Vertical270](./vertical270/) | 每行顺时针旋转 270 度。 |
| [Stacked](./stacked/) | 确定所有文本是否为竖排。 |
| [StackedRightToLeft](./stackedrighttoleft/) | 指定垂直 WordArt 应从右到左显示，而不是从左到右。 |
