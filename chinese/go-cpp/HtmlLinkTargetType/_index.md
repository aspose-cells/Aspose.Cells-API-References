## HtmlLinkTargetType Enum

表示 HTML <a/> 标签中 target 属性的类型。

```go

type HtmlLinkTargetType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Blank](./blank/) | 在新窗口或标签页中打开链接的文档 |
| [Parent](./parent/) | 在父框架中打开链接的文档 |
| [Self](./self/) | 在点击时相同的框架中打开链接的文档（这是默认设置） |
| [Top](./top/) | 在窗口的完整主体中打开链接的文档 |
