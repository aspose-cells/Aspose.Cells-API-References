## EncryptionType Enum

加密类型。仅用于 excel2003。我们将使用与 Excel 相同的 SHA AES 加密 2007/2010 工作簿，此 EncryptionType 将被忽略。

```go

type EncryptionType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [XOR](./xor/) | XOR 加密算法。 |
| [Compatible](./compatible/) | 兼容 Office 97/2000。 |
| [EnhancedCryptographicProviderV1](./enhancedcryptographicproviderv1/) | 增强加密。 |
| [StrongCryptographicProvider](./strongcryptographicprovider/) | 强加密算法。 |
