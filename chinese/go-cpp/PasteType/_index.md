type PasteType int32

| [ColumnWidths](./columnwidths/) | 仅复制范围的宽度。 |

| [FormulasAndNumberFormats](./formulasandnumberformats/) | 仅复制范围内的公式和数字格式。 |
| [Validation](./validation/) | 仅复制范围内的验证。 |
