## PrintCommentsType Enum

表示注释随工作表打印的方式。

```go

type PrintCommentsType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [PrintInPlace](./printinplace/) | 表示在工作表上显示的方式打印批注。 |
| [PrintNoComments](./printnocomments/) | 表示不打印批注。 |
| [PrintSheetEnd](./printsheetend/) | 表示在工作表末尾打印批注。 |
| [PrintWithThreadedComments](./printwiththreadedcomments/) | 表示在工作表上显示的方式打印批注，包括线程批注。 |
