## ExcelRenderingBehavior Enum

指定在渲染工作簿时要应用的 Excel 特定渲染行为。

```go

type ExcelRenderingBehavior int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [None](./none/) | 不应用 Excel 特定的渲染行为。 |
| [CellTextLengthLimit](./celltextlengthlimit/) | 应用 Excel 的单元格文本输出长度限制。例如，Excel 在未换行的单元格中仅输出前 1024 个字符。 |
| [All](./all/) | 应用所有受支持的 Excel 特定渲染行为。 |
