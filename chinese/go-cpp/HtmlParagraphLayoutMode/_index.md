## HtmlParagraphLayoutMode Enum

指定在加载 HTML 时 &lt;p&gt; 元素的渲染方式。

```go

type HtmlParagraphLayoutMode int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Normal](./normal/) | 将 &lt;p&gt; 在 &lt;td&gt; 中视为单元格内的内联内容。 |
| [AsRow](./asrow/) | 对每个 &lt;p&gt; 元素启动新行。 |
