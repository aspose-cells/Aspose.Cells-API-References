## DateKind Enum

指定 Date 对象是表示本地时间、协调世界时 (UTC)，还是未指定为本地时间或 UTC。

```go

type DateKind int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Unspecified](./unspecified/) | 表示的时间既未指定为本地时间，也未指定为协调世界时 (UTC)。 |
| [Utc](./utc/) | 表示的时间为 UTC。 |
