## ControlMousePointerType Enum

表示控件的鼠标指针所显示的图标类型。

```go

type ControlMousePointerType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Default](./default/) | 标准指针。 |
| [Arrow](./arrow/) | 箭头。 |
| [Cross](./cross/) | 十字准星指针。 |
| [IBeam](./ibeam/) | I 型光标。 |
| [SizeNESW](./sizenesw/) | 指向东北和西南的双向箭头。 |
| [SizeNS](./sizens/) | 指向北和南的双向箭头。 |
| [SizeNWSE](./sizenwse/) | 指向西北和东南的双向箭头。 |
| [SizeWE](./sizewe/) | 指向西和东的双向箭头。 |
| [UpArrow](./uparrow/) | 向上箭头。 |
| [HourGlass](./hourglass/) | 沙漏。 |
| [NoDrop](./nodrop/) | “Not” 符号（带对角线的圆）位于被拖动对象的上方。 |
| [AppStarting](./appstarting/) | 带有沙漏的箭头。 |
| [Help](./help/) | 带有问号的箭头。 |
| [SizeAll](./sizeall/) | “Size-all” 光标（指向北、南、东和西的箭头）。 |
| [Custom](./custom/) | 使用 MouseIcon 属性指定的图标。 |
