## HtmlFormatHandlingType Enum

指定如何处理来自 HTML 源的格式化

```go

type HtmlFormatHandlingType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [All](./all/) | 将所有 HTML 格式随数据一起转移到工作表中。 |
| [None](./none/) | 将数据作为未格式化的文本导入（仍会设置数据类型）。 |
| [Rtf](./rtf/) | 将导入工作表的数据的 HTML 格式转换为富文本格式。 |
