## ProtectionType Enum

表示工作簿/工作表的保护类型。

```go

type ProtectionType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [All](./all/) | 表示保护全部。 |
| [Contents](./contents/) | 表示保护内容，用于工作表保护。 |
| [Objects](./objects/) | 表示保护对象，用于工作表保护。 |
| [Scenarios](./scenarios/) | 表示保护方案，用于工作表保护。 |
| [Structure](./structure/) | 表示保护结构，用于工作簿保护。 |
| [Windows](./windows/) | 表示保护窗口，用于工作簿保护。 |
| [None](./none/) | 表示无保护。仅用于 Reading 属性。 |
