## EquationFractionType Enum

此项指定分数线的显示样式。

```go

type EquationFractionType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Bar](./bar/) | 这指定分子在上方，分母在下方，并在中间用一条横线分隔。 |
| [NoBar](./nobar/) | 这指定分子在上方，分母在下方，但中间没有横线分隔。 |
| [Linear](./linear/) | 这指定分子在左侧，分母在右侧，中间用 '/' 分隔。 |
| [Skewed](./skewed/) | 这指定分子在左上，分母在右下，中间用 \"/\" 分隔。 |
