## TextCrossType Enum

枚举当文本宽度大于单元格宽度时的显示文本类型。

```go

type TextCrossType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Default](./default/) | 显示类似 Microsoft Excel 的文本。 |
| [CrossKeep](./crosskeep/) | 通过跨越其他单元格显示所有文本，并保留被跨越单元格的文本。 |
| [CrossOverride](./crossoverride/) | 通过跨越其他单元格显示所有文本，并覆盖被跨越单元格的文本。 |
| [StrictInCell](./strictincell/) | 仅在单元格宽度范围内显示文本。 |
