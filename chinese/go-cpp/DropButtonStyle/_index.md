## DropButtonStyle Enum

表示下拉按钮上显示的符号。

```go

type DropButtonStyle int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Plain](./plain/) | 显示一个没有符号的按钮。 |
| [Arrow](./arrow/) | 显示一个带下箭头的按钮。 |
| [Ellipsis](./ellipsis/) | 显示一个带省略号（...）的按钮。 |
| [Reduce](./reduce/) | 显示一个带水平线（类似下划线字符）的按钮。 |
