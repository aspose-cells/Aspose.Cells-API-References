## ColorType Enum

表示所有颜色类型

```go

type ColorType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Automatic](./automatic/) | 自动颜色。 |
| [AutomaticIndex](./automaticindex/) | 这是自动颜色，但显示的颜色取决于操作系统的设置。 |
| [RGB](./rgb/) | RGB 颜色。 |
| [IndexedColor](./indexedcolor/) | 颜色调色板中的颜色索引。 |
| [Theme](./theme/) | 主题颜色。 |
