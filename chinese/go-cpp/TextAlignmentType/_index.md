## TextAlignmentType Enum

```go

type TextAlignmentType int32
```

## 字段

| 字段 | 描述 |
| --- | --- |
| [General](./general/) | 表示一般文本对齐。 |
| [Bottom](./bottom/) | 表示底部文本对齐。 |
| [Center](./center/) | 表示居中文本对齐。 |
| [CenterAcross](./centeracross/) | 表示跨中心文本对齐。 |
| [Distributed](./distributed/) | 表示分散文本对齐。 |
| [Fill](./fill/) | 表示填充文本对齐。 |
| [Justify](./justify/) | 表示两端对齐文本。 |
| [Left](./left/) | 表示左对齐文本。 |
| [Right](./right/) | 表示右对齐文本。 |
| [Top](./top/) | 表示顶部文本对齐。 |
| [JustifiedLow](./justifiedlow/) | 为阿拉伯文文本调整卡希达长度以对齐文本。 |
| [ThaiDistributed](./thaidistributed/) | 特殊分配泰文文本，因为每个字符被视为一个单词。 |
