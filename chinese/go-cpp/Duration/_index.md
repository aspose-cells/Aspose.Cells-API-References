## Duration Struct

表示分辨率为 100 纳秒（tick）的时间间隔。

```go

type Duration int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [value](./value/) | 时间间隔的内部表示，以刻度为单位。1 刻度 = 100 纳秒。 |
