## TextOverflowType Enum

表示文本垂直或水平溢出的方式。

```go

type TextOverflowType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Clip](./clip/) | 注意顶部和底部的屏障。不要提供任何文本不可见的提示。 |
| [Ellipsis](./ellipsis/) | 注意顶部和底部的屏障。使用省略号表示有文本不可见。仅适用于垂直溢出。 |
| [Overflow](./overflow/) | 文本溢出且不考虑顶部和底部的屏障。 |
