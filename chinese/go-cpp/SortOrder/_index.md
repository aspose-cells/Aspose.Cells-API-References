## SortOrder Enum

表示数据范围的排序顺序。

```go

type SortOrder int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Ascending](./ascending/) | 按升序对数据进行排序 |
| [Descending](./descending/) | 按降序对数据进行排序 |
| [Natural](./natural/) | 保持原始数据顺序不进行排序。仅适用于某些特殊场景，例如数据透视表。 |
