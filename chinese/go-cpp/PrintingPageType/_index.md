## PrintingPageType Enum

指示哪些页面将不被打印。

```go

type PrintingPageType int32


```

## 字段

| 字段 | 描述 |
| --- | --- |
| [Default](./default/) | 打印所有页面。 |
| [IgnoreBlank](./ignoreblank/) | 不要打印单元格为空的页面。 |
| [IgnoreStyle](./ignorestyle/) | 不要打印仅包含样式的单元格的页面。 |
