## GridJsWorkbook.SetTransParentView method

设置工作簿中编辑遮盖形状的透明度。

```csharp
public void SetTransParentView(string excelFilePath, string uid, bool isTransparent)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| excelFilePath | String | Excel 文件的路径。 |
| uid | String | 工作簿的唯一标识符。如果为 null 或为空，将根据文件路径生成新的 uid。 |
| isTransparent | 布尔 | 如果为 true，则将透明度设置为 0.89（半透明）；如果为 false，则将透明度设置为 1（完全不透明/不可见）。 |
