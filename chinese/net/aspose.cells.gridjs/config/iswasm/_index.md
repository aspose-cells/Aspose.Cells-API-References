## Config.IsWasm property

获取/设置 GridJs 是否在浏览器 WebAssembly 主机中运行，而不是在服务器进程中运行。为 true 时不使用 FileCacheDirectory / 磁盘 / interrupt-thread 路径，文件缓存必须来自 GridJsOptions.CacheImp。GridJsOptions.IsWasm 在构建 GridJs 服务时设置此项，使得一个 Aspose.Cells.GridJs.dll 可服务于两种主机。默认值为 false。

```csharp
public static bool IsWasm { get; set; }
```
