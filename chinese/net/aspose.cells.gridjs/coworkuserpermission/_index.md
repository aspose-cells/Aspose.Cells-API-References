## CoWorkUserPermission enumeration

表示协作模式下的用户权限。当前仅在 Java 版本可用，未来将在 .net/python 版本中提供。

```csharp
public enum CoWorkUserPermission
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| READ_ONLY | `0` | 只读权限，用户只能查看内容，不能进行任何修改。 |
| EDITABLE | `1` | 可编辑权限，用户可以查看并编辑内容。 |
| DOWNLOAD | `2` | 下载权限，用户可以查看、编辑并将内容下载到本地存储。 |
| ADMIN | `3` | 管理员权限，用户拥有包括管理操作在内的全部访问权限。 |
