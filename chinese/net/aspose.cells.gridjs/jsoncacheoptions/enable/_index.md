## JsonCacheOptions.Enable property

获取/设置 是否启用 JSON 缓存以获得更快的响应。启用后，GridJs 将缓存生成的 JSON 并在后续请求中复用。默认值为 false。注意：需要设置 Implementation 以使用自定义缓存存储。

```csharp
public bool Enable { get; set; }
```
