## GridJsOptions.IslimitShapeOrImage property

获取/设置 是否限制单个工作表中显示的形状/图像总数。如果设为 true，GridJs 将把单个工作表中显示的形状或图像总数限制为 MaxShapeOrImageCount。默认值为 true。

```csharp
public bool IslimitShapeOrImage { get; set; }
```
