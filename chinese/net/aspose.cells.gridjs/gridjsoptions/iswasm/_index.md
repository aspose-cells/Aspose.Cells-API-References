## GridJsOptions.IsWasm property

获取/设置 GridJs 是否在浏览器 WebAssembly 主机中运行，而不是在服务器进程中。为 true 时，不使用 FileCacheDirectory / 磁盘 / 中断线程路径，文件缓存必须来自 CacheImp，因为浏览器主机没有本地磁盘。它在运行时选择代码路径，因此同一个 Aspose.Cells.GridJs.dll 可服务于两种主机。默认值为 false。

```csharp
public bool IsWasm { get; set; }
```
