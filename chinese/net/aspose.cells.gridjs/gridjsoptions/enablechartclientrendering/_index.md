## GridJsOptions.EnableChartClientRendering property

获取/设置 是否启用客户端图表渲染。如果设为 false，GridJs 将仅输出图表图像/形状，不需要客户端图表渲染。默认值为 true。

```csharp
public bool EnableChartClientRendering { get; set; }
```
