## GridJsOptions.IgnoreEmptyContent property

获取/设置 是否显示包含数据、样式、合并单元格和形状的最大范围。如果最后一行或列的单元格没有值和公式但具有自定义样式，则在此值为 true 时我们不会显示该行/列。默认值为 true。

```csharp
public bool IgnoreEmptyContent { get; set; }
```
