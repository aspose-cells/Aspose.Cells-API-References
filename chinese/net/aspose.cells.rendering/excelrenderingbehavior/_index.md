## ExcelRenderingBehavior enumeration

指定在渲染工作簿时要应用的 Excel 特定渲染行为。

```csharp
[Flags]
public enum ExcelRenderingBehavior
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 不应用 Excel 特定渲染行为。 |
| CellTextLengthLimit | `1` | 应用 Excel 的单元格文本输出长度限制。例如，Excel 在未换行的单元格中仅输出前 1024 个字符。 |
| All | `FFFFFFFFFFFFFFFF` | 应用所有受支持的 Excel 特定渲染行为。 |
