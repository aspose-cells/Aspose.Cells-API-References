## GridExportTableOptions.CheckMixedValueType property

False，Aspose.Cells 将基于第一行的值类型设置 DataColumn 的类型以提升性能。True，Aspose.Cells 将在设置 DataColumn 类型之前检查列中的值类型是否混合。如果值类型混合，DataColumn 的类型将为 string。

```csharp
public bool CheckMixedValueType { get; set; }
```
