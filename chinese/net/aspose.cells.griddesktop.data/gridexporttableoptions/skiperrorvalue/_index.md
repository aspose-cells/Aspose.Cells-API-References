## GridExportTableOptions.SkipErrorValue property

指示是否跳过列的无效值。例如，如果列类型是 decimal，值大于 decimal.MaxValue 并且此属性为 true，则我们将不再抛出异常。默认值为 false。

public bool SkipErrorValue { get; set; }
