## GridImageOrPrintOptions.AllColumnsInOnePagePerSheet property

如果 AllColumnsInOnePagePerSheet 为 true，则一个工作表的所有列内容将输出到结果的唯一一页。pagesetup 的纸张宽度将失效，而 pagesetup 的其他设置仍然生效。

```csharp
public bool AllColumnsInOnePagePerSheet { get; set; }
```
