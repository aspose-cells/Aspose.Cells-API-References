## GridImageOrPrintOptions.Quality property

获取或设置一个值，用于确定生成图像的质量，仅在将页面保存为 `Jpeg` 格式时使用。默认值为 100。

```csharp
public int Quality { get; set; }
```

### 备注

仅在保存为 JPEG 时生效。该值必须在 0 到 100 之间。默认值为 100。
