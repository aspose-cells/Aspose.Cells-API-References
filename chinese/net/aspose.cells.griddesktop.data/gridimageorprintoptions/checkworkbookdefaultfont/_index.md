## GridImageOrPrintOptions.CheckWorkbookDefaultFont property

当 Excel 中的字符是 Unicode 且单元格样式未设置正确的字体时，它们可能在 PDF、图像中显示为方块。将此设置为 true 可尝试首先使用工作簿的默认字体来显示这些字符。

```csharp
public bool CheckWorkbookDefaultFont { get; set; }
```

### 备注

默认值为 true。
