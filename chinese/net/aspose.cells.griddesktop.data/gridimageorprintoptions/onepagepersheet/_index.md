## GridImageOrPrintOptions.OnePagePerSheet property

如果 OnePagePerSheet 为 true，单个工作表的所有内容将仅输出为结果中的一页。pagesetup 的纸张尺寸将失效，其他 pagesetup 设置仍然生效。

public bool OnePagePerSheet { get; set; }
