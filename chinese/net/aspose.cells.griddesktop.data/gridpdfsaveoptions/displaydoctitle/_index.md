## GridPdfSaveOptions.DisplayDocTitle property

指示窗口标题栏是否应显示文档标题。

```csharp
public bool DisplayDocTitle { get; set; }
```

### 备注

如果为 false，标题栏将显示 PDF 文件的名称而不是文档标题。默认值为 false。
