## GridPdfSaveOptions.EmbedStandardWindowsFonts property

设置为 true 以嵌入 TrueType 字体。仅影响 ASCII 字符 32-127。字符代码大于 127 的字体始终嵌入。对于 PDF/A-1a、PDF/A-1b 标准，字体始终嵌入。默认值为 true。

```csharp
public bool EmbedStandardWindowsFonts { get; set; }
```
