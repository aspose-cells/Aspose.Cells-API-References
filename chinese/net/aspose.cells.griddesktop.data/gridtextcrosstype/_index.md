## GridTextCrossType enumeration

枚举当文本宽度大于单元格宽度时的显示文本类型。

```csharp
public enum GridTextCrossType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Default | `1` | 显示文本方式类似于 Microsoft Excel。 |
| CrossKeep | `2` | 通过跨越其他单元格显示所有文本，并保留被跨越单元格的文本。 |
| CrossOverride | `3` | 通过跨越其他单元格显示所有文本，并覆盖被跨越单元格的文本。 |
| StrictInCell | `4` | 仅在单元格宽度范围内显示文本。 |
