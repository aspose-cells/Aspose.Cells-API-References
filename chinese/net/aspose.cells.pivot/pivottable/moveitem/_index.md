## PivotTable.MoveItem method

上移或下移一个项目。

```csharp
public void MoveItem(PivotFieldType region, string[] nodes, bool absolute, int offset)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 区域 | PivotFieldType | 该区域。仅适用于行或列。 |
| 节点 | String[] | 该项目。 |
| 绝对 | 布尔 | 指示偏移量是否为绝对位置。 |
| 偏移量 | Int32 | 如果 absolute 为 true：0 表示移动到开头，-1 表示移动到结尾，其他值表示绝对位置；否则 offset 为相对位置。 |
