## PivotTableRefreshOption.IsKeepOriginalOrder property

指示是否保持透视项的原始顺序与旧数据源相同。

```csharp
public bool IsKeepOriginalOrder { get; set; }
```

### 备注

仅适用于未排序的透视字段。刷新此类透视字段时，Ms Excel 保持旧数据源的原始顺序。此属性的默认值为 true，表示与 Ms Excel 相同的行为。如果用户需要将透视字段完全刷新为新数据源中的数据，则应将此属性设置为 false。
