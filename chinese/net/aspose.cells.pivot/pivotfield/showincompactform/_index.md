## PivotField.ShowInCompactForm property

获取或设置一个值，指示此行字段是否使用紧凑形式布局。仅适用于行字段。

```csharp
public bool ShowInCompactForm { get; set; }
```

### 备注

紧凑形式是大纲布局的子模式。仅当 [`ShowInOutlineForm`](../showinoutlineform/) 为 true 时，此设置才生效。
