## PivotTableCreateOptions.UseSameSource property

获取或设置一个值，指示是否与现有数据透视表共享相同的数据源。默认值为 true。

```csharp
public bool UseSameSource { get; set; }
```

### 备注

设置为 true 时，多个数据透视表可以复用同一个数据透视缓存，以降低内存消耗。
