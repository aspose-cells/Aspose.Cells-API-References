## MainWeb.IgnoreStyleWithNoData property

获取或设置 GridWeb 是否忽略显示没有单元格值但仍具有样式的行或列。如果设置为 true，性能将更好。默认值为 false，这意味着如果最后连续的行/列没有单元格值但已设置样式，我们仍会显示它们。此选项仅在 EnableAsync 为 false 时有效。EnableAsync 为 true 时此选项无效，这意味着 GridWeb 将显示所有带样式的行/列。

```csharp
public bool IgnoreStyleWithNoData { get; set; }
```
