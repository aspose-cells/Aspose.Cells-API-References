## Validation.LoadValueList method

从 DataView 对象加载值列表。您可以指定 DataView 的值字段和文本字段。每个值和文本对将合并为一个字符串，之间用逗号分隔。

```csharp
public void LoadValueList(DataView view, string valueField, string textField, bool valuePrefixText)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 视图 | DataView | DataView 对象。 |
| valueField | String | 值字段名称。 |
| textField | String | 文本字段名称。 |
| valuePrefixText | 布尔 | 指示是否在每个显示的文本前添加值前缀。 |
