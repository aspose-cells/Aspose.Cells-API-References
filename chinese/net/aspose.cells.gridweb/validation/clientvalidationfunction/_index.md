## Validation.ClientValidationFunction property

获取或设置客户端验证 JavaScript 函数名称。

```csharp
public string ClientValidationFunction { get; set; }
```

### 备注

使用 ClientValidationFunction 属性来指定客户端验证函数的名称。函数应按以下形式声明：function customValicationFunction(source, value) 参数 "source" 是单元格对象。参数 "value" 是要检查的单元格的字符串值。如果值有效，函数应返回 true。
