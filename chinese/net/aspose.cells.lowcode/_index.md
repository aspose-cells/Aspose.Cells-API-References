**Aspose.Cells.LowCode** 命名空间提供一套简单且易于使用的 API，用于低代码方式下最常用的操作。

## 类

| 类 | 描述 |
| --- | --- |
| [AbstractLowCodeLoadOptionsProvider](./abstractlowcodeloadoptionsprovider/) | 实现提供多种加载选项，以供使用多个输入（例如模板文件）的流程使用。 |
| [AbstractLowCodeProtectionProvider](./abstractlowcodeprotectionprovider/) | 实现提供保护设置。 |
| [AbstractLowCodeSaveOptionsProvider](./abstractlowcodesaveoptionsprovider/) | 实现提供多种保存选项，以供需要多个输出的流程使用。例如，[`SpreadsheetSplitter`](../aspose.cells.lowcode/spreadsheetsplitter/) 功能需要多个目标来保存拆分后的文件。 |
| [HtmlConverter](./htmlconverter/) | 用于在 HTML 文件（html 或 mht）与其他电子表格文件格式之间转换的转换器。 |
| [ImageConverter](./imageconverter/) | 用于将模板文件转换为图像的转换器。 |
| [JsonConverter](./jsonconverter/) | 用于在 JSON 数据结构与其他电子表格文件格式之间转换的转换器。 |
| [LowCodeHtmlSaveOptions](./lowcodehtmlsaveoptions/) | 以低代码方式保存 HTML 的选项。 |
| [LowCodeImageSaveOptions](./lowcodeimagesaveoptions/) | 以低代码方式保存图像的选项。 |
| [LowCodeLoadOptions](./lowcodeloadoptions/) | 加载模板文件的选项。 |
| [LowCodeMergeOptions](./lowcodemergeoptions/) | 将多个模板文件合并为一个的选项。 |
| [LowCodePdfSaveOptions](./lowcodepdfsaveoptions/) | 以低代码方式保存 PDF 的选项。 |
| [LowCodeSaveOptions](./lowcodesaveoptions/) | 以低代码方式保存生成结果的选项。 |
| [LowCodeSaveOptionsProviderOfAssembling](./lowcodesaveoptionsproviderofassembling/) | 实现提供保存选项，以将拆分的部分保存到文件，并且生成文件的路径命名为（可能包含目录）：[`PathHeader`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/pathheader/)+[`SheetPrefix`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/sheetprefix/)+SheetIndex（或 SheetName）+[`SplitPartPrefix`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/splitpartprefix/)+SplitPartIndex+[`PathTail`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/pathtail/)。 |
| [LowCodeSaveOptionsProviderOfPlaceHolders](./lowcodesaveoptionsproviderofplaceholders/) | 实现提供保存选项，以将拆分的部分保存到文件，并且生成文件的路径使用占位符定义。 |
| [LowCodeSplitOptions](./lowcodesplitoptions/) | 拆分电子表格的选项。 |
| [PdfConverter](./pdfconverter/) | 用于将模板文件转换为 PDF 的转换器。 |
| [SplitPartInfo](./splitpartinfo/) | 表示多个输入/输出中的单个输入/输出信息，例如在将电子表格转换为图像时要渲染的当前页。 |
| [SpreadsheetConverter](./spreadsheetconverter/) | 用于在不同电子表格文件格式之间转换的转换器，例如 xls、xlsx、xlsb、SpreadsheetML 等。 |
| [SpreadsheetLocker](./spreadsheetlocker/) | 用于锁定电子表格文件的低代码 API。 |
| [SpreadsheetMerger](./spreadsheetmerger/) | 将多个模板文件合并为一个。 |
| [SpreadsheetSplitter](./spreadsheetsplitter/) | 将电子表格文件拆分为多个部分。 |
| [TextConverter](./textconverter/) | 用于在基于文本的格式（csv、tsv、dif 等）与其他电子表格文件格式之间转换的转换器。 |
