## ShapeCollection.Find method

```csharp
public int Find(string what, int previous, FindOptions findOptions)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 什么 | String | 要搜索的文本。 |
| 上一个 | Int32 | 上一个形状包含相同文本的索引。如果从开始搜索，则为 -1。 |
| findOptions | FindOptions | 查找选项 |

### 返回值
