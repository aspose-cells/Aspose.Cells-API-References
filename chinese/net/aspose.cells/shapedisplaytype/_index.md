## ShapeDisplayType enumeration

表示应用程序在此工作簿中显示形状的方式。形状可能包括图表、图像以及应用程序支持的其他对象数据。

```csharp
public enum ShapeDisplayType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| All | `0` | 指示在工作簿中显示所有形状。 |
| Placeholders | `1` | 指示应用程序在工作簿中显示形状的占位符。 |
| None | `2` | 指示在工作簿中隐藏所有形状。 |
