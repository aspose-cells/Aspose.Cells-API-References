## BorderCollection.IsOutline property

指示是否仅将左、右、上、下边框应用于单元格范围的外部边框。默认值为 true。

```csharp
public bool IsOutline { get; set; }
```

### 备注

仅在对条件格式、数据透视表的范围应用时有效。如果为 false，左、右、上、下边框将应用于每个单元格；否则仅应用于单元格范围的外部边框。如果为 true，请为条件格式、数据透视表的范围设置内部边框的水平和垂直边框。
