## GridTxtLoadOptions.TreatQuotePrefixAsValue property

指示是否应将前导单引号视为单元格值的一部分。默认值为 true。如果为 false，前导单引号将从相应单元格的值中移除，并将[`QuotePrefix`](../../../aspose.cells.gridweb/gridtableitemstyle/quoteprefix/) 设置为 true。

```csharp
public bool TreatQuotePrefixAsValue { get; set; }
```
