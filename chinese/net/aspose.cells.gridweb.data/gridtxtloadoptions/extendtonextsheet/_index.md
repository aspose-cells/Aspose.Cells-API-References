## GridTxtLoadOptions.ExtendToNextSheet property

当数据的行或列超出限制时，是否将数据扩展到下一个工作表。如果此属性为 true，超出部分的数据将扩展到当前工作表之后的下一个工作表（如果当前工作表是最后一个，则在当前工作簿中追加新工作表）。如果此属性为 false，超出限制的数据将被忽略。默认值为 false；

```csharp
public bool ExtendToNextSheet { get; set; }
```
