## GridWorkbookSettings.PreservePaddingSpaces property

指示在获取和设置公式时是否保留公式标记之间填充的空格和换行符。默认值为 false。

```csharp
public bool PreservePaddingSpaces { get; set; }
```

### 备注

通常这些空格和换行仅用于视觉目的，是否保留它们不会影响计算结果。出于性能考虑，如果没有特殊需求，处理公式时最好不要保留它们。
