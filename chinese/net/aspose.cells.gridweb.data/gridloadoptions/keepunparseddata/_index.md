## GridLoadOptions.KeepUnparsedData property

在从模板文件加载 Workbook 时，是否在内存中保留未解析的数据。默认值为 true。

```csharp
public bool KeepUnparsedData { get; set; }
```

### 备注

对于仅需要从模板文件读取部分内容且不需要将工作簿保存回去的场景，将此属性设为 false 可能会提升性能，尤其是在与某种 LoadFilter 一起使用时，
