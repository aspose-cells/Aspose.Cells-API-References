## GridLoadOptions.PreservePaddingSpacesInFormula property

指示在获取和设置公式时是否保留公式标记之间填充的空格和换行符。默认值为 false。

```csharp
public bool PreservePaddingSpacesInFormula { get; set; }
```

### 备注

使用此选项从模板文件加载工作簿后，[`PreservePaddingSpaces`](../../gridworkbooksettings/preservepaddingspaces/) 将被设置为与此属性相同的值。
