## WebCells.SetColumnReadonly method

将列设为只读，使用户无法在客户端删除它。这是 GridWeb 的扩展方法，实际 Excel 文件中不会保留或生效。

```csharp
public void SetColumnReadonly(int columnIndex, bool isReadonly)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| columnIndex | Int32 | 列索引。 |
| isReadonly | 布尔 | true 或 false。 |
