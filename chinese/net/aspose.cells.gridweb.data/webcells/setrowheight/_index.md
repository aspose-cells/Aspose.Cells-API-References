## WebCells.SetRowHeight method

设置指定行的高度。接受的宽度类型为 Point、Pixel 或 Inch。

```csharp
public void SetRowHeight(int row, Unit height)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 行 | Int32 | 行索引。 |
| height | Unit | 行高。单位为点，范围应在 0 到 409.5 之间。 |

### 备注

要隐藏行，请将行高设置为零。
