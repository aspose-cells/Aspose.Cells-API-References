## Hyperlink.ActionType property

获取或设置超链接的操作类型。它可以是 ActionTpye.UrlLink 或 ActionType.CellCommand。UrlLink 类型表示超链接指向网页或邮件收件人。例如：\"http://www.aspose.com\" 或 \"mailto:admin@aspose.com\"。CellCommand 类型表示超链接将触发 CellCommand 事件，您可以处理此事件。

```csharp
public virtual HyperlinkActionType ActionType { get; set; }
```
