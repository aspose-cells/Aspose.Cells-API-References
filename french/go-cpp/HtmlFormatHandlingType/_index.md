## HtmlFormatHandlingType Enum

Spécifie comment gérer le formatage provenant de la source HTML

```go

type HtmlFormatHandlingType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [All](./all/) | Transférer toute la mise en forme HTML dans la feuille de calcul avec les données. |
| [None](./none/) | Importer les données en tant que texte non formaté (la définition des types de données se produit toujours). |
| [Rtf](./rtf/) | Convertir la mise en forme HTML en mise en forme texte enrichi sur les données importées dans la feuille de calcul. |
