## GetStringValue function

Obtient la valeur chaîne contenue dans la cellule. Si le type de cette cellule est une chaîne, alors la valeur chaîne elle‑même est renvoyée. Pour les autres types de cellules, la valeur chaîne formatée (formatée avec le style spécifié de cette cellule) sera renvoyée. La valeur de cellule formatée est identique à ce que vous pouvez obtenir depuis Excel en copiant une cellule en tant que texte (par exemple en copiant la cellule vers un éditeur de texte ou en l'exportant vers CSV).

```go

func (instance *Cell) GetStringValue()  (string,  error) 

```
