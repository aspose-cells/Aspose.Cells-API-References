## SetAllColumnsInOnePagePerSheet function

Si AllColumnsInOnePagePerSheet est vrai, le contenu de toutes les colonnes d'une feuille sera exporté sur une seule page dans le résultat. La largeur du format de papier du paramètre pagesetup sera invalide, mais les autres paramètres de pagesetup resteront effectifs.
