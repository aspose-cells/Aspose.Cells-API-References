## SetIsExcel2003Compatible function

Spécifie si le PivotTable est compatible avec Excel2003 lors du rafraîchissement du PivotTable, si vrai, une chaîne doit contenir au maximum 255 caractères, donc si la chaîne dépasse 255 caractères, elle sera tronquée. si faux, une chaîne n'aura pas la restriction susmentionnée. La valeur par défaut est vraie.

func (instance *PivotTable) SetIsExcel2003Compatible(value bool)  error
