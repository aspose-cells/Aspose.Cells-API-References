## SetAutoSize function

Indique si la taille du commentaire est ajustée automatiquement en fonction de son contenu. Note : dans certains cas particuliers (comme l'environnement Mac), ce paramètre peut ne pas prendre effet. Si ce paramètre ne prend pas effet, veuillez le remplacer par FitToTextSize().

func (instance *Comment) SetAutoSize(value bool)  error
