## ShiftType Enum

Représente les options de décalage lors de la suppression d'une plage de cellules.

```go

type ShiftType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Down](./down/) | Déplacer les cellules vers le bas. |
| [Left](./left/) | Déplacer les cellules vers la gauche. |
| [None](./none/) | Ne pas déplacer les cellules. |
| [Right](./right/) | Déplacer les cellules vers la droite. |
| [Up](./up/) | Déplacer les cellules vers le haut. |
