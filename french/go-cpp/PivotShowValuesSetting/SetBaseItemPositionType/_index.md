## SetBaseItemPositionType function

Représente le type de l'élément pivot de base dans le champ de base lorsque le calcul ShowDataAs est utilisé. Valide uniquement pour les champs de données. Parce que PivotItemPosition.Custom est en lecture seule, si vous devez définir PivotItemPosition.Custom, veuillez définir l'attribut PivotField.BaseItemIndex.

```go

func (instance *PivotShowValuesSetting) SetBaseItemPositionType(value PivotItemPositionType)  error

```
