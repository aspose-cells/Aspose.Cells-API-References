## ProtectionType Enum

Représente le type de protection du classeur/feuille de calcul.

```go

type ProtectionType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [All](./all/) | Représente la protection de tout. |
| [Contents](./contents/) | Représente la protection du contenu, utilisée dans la protection de la feuille de calcul. |
| [Objects](./objects/) | Représente la protection des objets, utilisée dans la protection de la feuille de calcul. |
| [Scenarios](./scenarios/) | Représente la protection des scénarios, utilisée dans la protection de la feuille de calcul. |
| [Structure](./structure/) | Représente la protection de la structure, utilisée dans la protection du classeur. |
| [Windows](./windows/) | Représente la protection de la fenêtre, utilisée dans la protection du classeur. |
| [None](./none/) | Représente aucune protection. Seulement pour la propriété Reading. |
