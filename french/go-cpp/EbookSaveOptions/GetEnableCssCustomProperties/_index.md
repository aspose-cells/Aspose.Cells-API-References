## GetEnableCssCustomProperties function

Optimise la sortie du html en utilisant des propriétés personnalisées CSS. Par exemple, dans le cas où il y a plusieurs occurrences d'une même image base64, avec une propriété personnalisée les données de l'image n'ont besoin d'être enregistrées qu'une fois, ce qui améliore les performances du html résultant. La valeur par défaut est false.
