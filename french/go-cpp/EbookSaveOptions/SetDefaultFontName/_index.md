## SetDefaultFontName function

Spécifiez le nom de police par défaut pour l'exportation HTML, la police par défaut sera utilisée lorsque la police du style n'existe pas. Si cette propriété est nulle, Aspose.Cells utilisera une police universelle ayant la même famille que la police originale, la valeur par défaut est nulle.
