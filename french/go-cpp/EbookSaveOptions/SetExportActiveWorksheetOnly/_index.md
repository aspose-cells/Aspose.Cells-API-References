## SetExportActiveWorksheetOnly function

Indique si seul la feuille de calcul active est exportée vers le fichier HTML. Si true, alors seule la feuille active sera exportée vers le fichier HTML ; si false, l'ensemble du classeur sera exporté vers le fichier HTML. La valeur par défaut est false.
