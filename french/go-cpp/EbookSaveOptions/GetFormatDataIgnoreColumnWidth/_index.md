## GetFormatDataIgnoreColumnWidth function

Indique si l'intégralité des données formatées d'une cellule doit être affichée lorsqu'elle déborde de la colonne. Si true, la largeur de la colonne est ignorée et toutes les données de la cellule seront exportées. Si false, les données seront exportées comme dans Excel. La valeur par défaut est false.
