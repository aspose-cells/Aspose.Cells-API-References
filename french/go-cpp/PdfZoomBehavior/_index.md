## PdfZoomBehavior Enum

Spécifie le mode de vue initial lorsque le document PDF généré est ouvert.

```go

type PdfZoomBehavior int32


```

## Champs

| Champ | Description |
| --- | --- |
| [None](./none/) | Utilise le comportement par défaut du visualiseur PDF. |
| [ZoomFactor](./zoomfactor/) | Ouvre le document à un pourcentage de zoom spécifique. |
| [FitPage](./fitpage/) | Adapte toute la page à la fenêtre du visualiseur. |
| [FitWidth](./fitwidth/) | Adapte la largeur de la page à la fenêtre du visualiseur. |
| [FitHeight](./fitheight/) | Adapte la hauteur de la page à la fenêtre du visualiseur. |
