## SortOrder Enum

Représente l'ordre de tri pour la plage de données.

```go

type SortOrder int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Ascending](./ascending/) | Trie les données par ordre croissant |
| [Descending](./descending/) | Trie les données par ordre décroissant |
| [Natural](./natural/) | Conserve l'ordre original des données sans tri. S'applique uniquement à certains scénarios spéciaux tels que le tableau croisé dynamique. |
