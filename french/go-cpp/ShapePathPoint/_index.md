## ShapePathPoint class

Spécifiez les coordonnées de position ou les repères d'angle.Coordonnées de position représentent les coordonnées d'un chemin dans un espace de coordonnées (p. ex. X/Y).Les repères d'angle indiquent les changements angulaires dans un chemin (p. ex. les angles de départ et d'arc).
