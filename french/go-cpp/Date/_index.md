## Date Struct

Représente une date et une heure.

```go

type Date int32


```

## Champs

| Champ | Description |
| --- | --- |
| [year](./year/) | Composant année (1-9999). |
| [month](./month/) | Composant mois (1-12). |
| [day](./day/) | Composant jour (1-31). |
| [hour](./hour/) | Composant heure (0-23). |
| [minute](./minute/) | Composant minute (0-59). |
| [second](./second/) | Composant seconde (0-59). |
| [millisecond](./millisecond/) | Composant milliseconde (0-999). |
| [dateKind](./datekind/) | Spécifie si le temps est local, UTC ou non spécifié. La valeur par défaut est Non spécifié. |
