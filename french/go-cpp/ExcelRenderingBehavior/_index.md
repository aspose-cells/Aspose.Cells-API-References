## ExcelRenderingBehavior Enum

Spécifie les comportements de rendu spécifiques à Excel à appliquer lors du rendu d'un classeur.

```go

type ExcelRenderingBehavior int32


```

## Champs

| Champ | Description |
| --- | --- |
| [None](./none/) | N'applique pas les comportements de rendu spécifiques à Excel. |
| [CellTextLengthLimit](./celltextlengthlimit/) | Applique la limite de longueur de texte des cellules d'Excel. Par exemple, Excel n'affiche que les 1024 premiers caractères dans une cellule non renvoyée à la ligne. |
| [All](./all/) | Applique tous les comportements de rendu spécifiques à Excel pris en charge. |
