## SetCheckAddIn function

Indique s'il faut vérifier les compléments dans les liens externes existants du classeur actuel pour les fonctions définies par l'utilisateur sans lien externe. La valeur par défaut est true(si la fonction définie par l'utilisateur correspond à un complément présent dans les liens externes existants, alors il est considéré comme le complément).
