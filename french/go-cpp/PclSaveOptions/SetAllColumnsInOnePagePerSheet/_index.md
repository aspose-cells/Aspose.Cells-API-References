## SetAllColumnsInOnePagePerSheet function

Si AllColumnsInOnePagePerSheet est true, tout le contenu des colonnes d'une feuille sera exporté sur une seule page dans le résultat. La largeur du papier du paramètre pagesetup sera ignorée, mais les autres paramètres de pagesetup resteront effectifs.
