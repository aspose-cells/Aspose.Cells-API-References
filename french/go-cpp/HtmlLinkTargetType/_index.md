## HtmlLinkTargetType Enum

Représente le type d'attribut target dans la balise HTML <a/>.

```go

type HtmlLinkTargetType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Blank](./blank/) | Ouvre le document lié dans une nouvelle fenêtre ou un nouvel onglet |
| [Parent](./parent/) | Ouvre le document lié dans le cadre parent |
| [Self](./self/) | Ouvre le document lié dans le même cadre que celui où il a été cliqué (c'est la valeur par défaut) |
| [Top](./top/) | Ouvre le document lié dans le corps complet de la fenêtre |
