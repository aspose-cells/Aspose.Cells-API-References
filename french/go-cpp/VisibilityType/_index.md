## VisibilityType Enum

Représente les états de visibilité de la feuille.

```go

type VisibilityType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Visible](./visible/) | Indique que la feuille est visible. |
| [Hidden](./hidden/) | Indique que la feuille est masquée, mais peut être affichée par l'utilisateur via l'interface utilisateur. |
| [VeryHidden](./veryhidden/) | Indique que la feuille est masquée et ne peut pas être affichée dans l'interface utilisateur (UI). Cet état n'est disponible que par programmation. |
