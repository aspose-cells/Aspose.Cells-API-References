## DataBarAxisPosition Enum

Spécifie la position de l'axe pour une plage de cellules avec mise en forme conditionnelle sous forme de barres de données.

```go

type DataBarAxisPosition int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Automatic](./automatic/) | Affiche l'axe à une position variable en fonction du rapport entre la valeur négative minimale et la valeur positive maximale dans la plage. Les valeurs positives sont affichées de gauche à droite. Les valeurs négatives sont affichées de droite à gauche. Lorsque toutes les valeurs sont positives ou toutes les valeurs sont négatives, aucun axe n'est affiché. |
| [Midpoint](./midpoint/) | Affiche l'axe au point médian de la cellule, quel que soit l'ensemble des valeurs dans la plage. Les valeurs positives sont affichées de gauche à droite. Les valeurs négatives sont affichées de droite à gauche. |
| [None](./none/) | Aucun axe n'est affiché, et les valeurs positives et négatives sont affichées de gauche à droite. |
