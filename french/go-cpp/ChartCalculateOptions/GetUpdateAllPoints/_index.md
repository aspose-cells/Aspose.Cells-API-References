## GetUpdateAllPoints function

Indique s'il faut mettre à jour tous les points de données lors du calcul du graphique. Valeur par défaut : False.Quand vous souhaitez obtenir la valeur de chaque point de données du graphique spécifiquement, réglez-le sur true.Si ce paramètre est défini sur True, de nouveaux points de données peuvent être générés lors du calcul du graphique. Cela pourrait augmenter la taille du fichier Excel.
