## SetIsHidePlaceholder function

Cet attribut spécifie la propriété Masquer les espaces réservés sur une matrice. Lorsque cette propriété est activée, les espaces réservés n'apparaissent pas dans la matrice. Par défaut, les espaces réservés apparaissent de sorte que les emplacements où le texte peut être inséré soient visibles.
