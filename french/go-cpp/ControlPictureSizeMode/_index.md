## ControlPictureSizeMode Enum

Représente la façon d'afficher l'image.

```go

type ControlPictureSizeMode int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Clip](./clip/) | Recadre toute partie de l'image qui dépasse les limites du contrôle. |
| [Stretch](./stretch/) | Étire l'image pour remplir la zone du contrôle. Ce réglage déforme l'image soit horizontalement, soit verticalement. |
| [Zoom](./zoom/) | Agrandit l'image, mais ne la déforme ni horizontalement ni verticalement. |
