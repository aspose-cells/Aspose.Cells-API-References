## DateKind Enum

Spécifie si un objet Date représente une heure locale, une heure UTC coordonnée (UTC), ou n'est pas spécifié comme étant locale ou UTC.

```go

type DateKind int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Unspecified](./unspecified/) | Le temps représenté n'est spécifié ni comme heure locale ni comme Temps Universel Coordonné (UTC). |
| [Utc](./utc/) | Le temps représenté est UTC. |
