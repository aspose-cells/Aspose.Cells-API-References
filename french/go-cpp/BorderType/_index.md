## BorderType Enum

Énumère les types de lignes de bordure et de lignes diagonales.

```go

type BorderType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [LeftBorder](./leftborder/) | Représente la ligne de bordure gauche. |
| [RightBorder](./rightborder/) | Représente la ligne de bordure droite existe. |
| [TopBorder](./topborder/) | Représente la ligne de bordure supérieure. |
| [BottomBorder](./bottomborder/) | Représente la ligne de bordure inférieure. |
| [DiagonalDown](./diagonaldown/) | Représente la ligne diagonale du coin supérieur gauche au coin inférieur droit. |
| [DiagonalUp](./diagonalup/) | Représente la ligne diagonale du coin inférieur gauche au coin supérieur droit. |
| [Vertical](./vertical/) | Uniquement pour le style dynamique, tel que le formatage conditionnel, le tableau croisé dynamique. |
| [Horizontal](./horizontal/) | Uniquement pour le style dynamique, tel que le formatage conditionnel, le tableau croisé dynamique. |
| [SideBorders](./sideborders/) | Indique les bordures des quatre côtés : <see cref=\"LeftBorder\"/>,<see cref=\"RightBorder\"/>, <see cref=\"TopBorder\"/> et <see cref=\"BottomBorder\"/>. |
| [Diagonal](./diagonal/) | Combinaison spéciale de plusieurs bordures pour la commodité de l'utilisateur dans certaines API. Indique les bordures diagonales de <see cref=\"DiagonalUp\"/> et <see cref=\"DiagonalDown\"/>. |
| [DynamicStyleBorders](./dynamicstyleborders/) | Indique <see cref=\"Vertical\"/> et <see cref=\"Horizontal\"/> du style dynamique. |
| [None](./none/) | Aucune bordure n'a été spécifiée. |
