## GetBuiltInPreference function

Indique si la propriété du format de nombre est préférable lorsque le style définit à la fois un nombre intégré et un modèle personnalisé. La valeur par défaut est false, ce qui signifie que, par défaut, le modèle personnalisé sera utilisé pour formater les valeurs tant qu'il n'est pas vide pour un style.
