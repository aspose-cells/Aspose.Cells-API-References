## CellsHelper_CreateSafeSheetName_String_Char function

Vérifie le nom de feuille fourni et crée un nom valide si nécessaire. Si le nom de feuille fourni respecte les règles des noms de feuilles Excel, il est renvoyé. Sinon, la chaîne sera tronquée si la longueur dépasse la limite et les caractères invalides seront remplacés par le caractère fourni, puis la valeur de chaîne reconstruite sera renvoyée.
