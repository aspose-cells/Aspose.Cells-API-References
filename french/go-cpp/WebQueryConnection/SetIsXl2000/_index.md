## SetIsXl2000 function

Ce drapeau existe pour la compatibilité ascendante avec d'anciennes feuilles de calcul existantes, et est défini sur true si cette requête web a été actualisée dans une application de feuille de calcul plus récente ou égale à Microsoft Excel 2000.Ceci est un attribut optionnel qui peut être ignoré.
