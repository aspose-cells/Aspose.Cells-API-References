## ControlListStyle Enum

Représente l'apparence visuelle de la liste dans une ListBox ou une ComboBox.

```go

type ControlListStyle int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Plain](./plain/) | Affiche une liste dans laquelle l'arrière-plan d'un élément est mis en évidence lorsqu'il est sélectionné. |
| [Option](./option/) | Affiche une liste dans laquelle un bouton d'option ou une case à cocher à côté de chaque entrée indique l'état de sélection de cet élément. |
