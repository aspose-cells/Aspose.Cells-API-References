## ShapeDisplayType Enum

Représente la façon dont l'application affiche les formes dans ce classeur. Les formes peuvent inclure des graphiques,images, et d'autres données d'objet prises en charge par l'application.

```go

type ShapeDisplayType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [All](./all/) | Indique que toutes les formes sont affichées dans le classeur. |
| [Placeholders](./placeholders/) | Indique que l'application affiche des espaces réservés pour les formes dans le classeur. |
| [None](./none/) | Indique que toutes les formes sont masquées dans le classeur. |
