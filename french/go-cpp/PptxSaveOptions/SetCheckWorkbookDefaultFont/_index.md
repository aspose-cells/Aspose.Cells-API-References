## SetCheckWorkbookDefaultFont function

Lorsque les caractères dans Excel sont Unicode et ne sont pas définis avec la police correcte dans le style de cellule, ils peuvent apparaître sous forme de blocs dans le PDF ou l'image. Réglez cette propriété sur true pour essayer d'utiliser d'abord la police par défaut du classeur afin d'afficher ces caractères.
