## TextFontAlignType Enum

Représente les différents types d'alignement de police.

```go

type TextFontAlignType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Automatic](./automatic/) | Lorsque le flux de texte est horizontal ou vertical simple, il est identique à fontBaseline, mais pour les autres modes verticaux, il est identique à fontCenter. |
| [Bottom](./bottom/) | Les lettres sont ancrées tout en bas d'une seule ligne. |
| [Baseline](./baseline/) | Les lettres sont ancrées à la ligne de base inférieure d'une seule ligne. |
| [Center](./center/) | Les lettres sont ancrées entre les deux lignes de base d'une seule ligne. |
| [Top](./top/) | Les lettres sont ancrées à la ligne de base supérieure d'une seule ligne. |
