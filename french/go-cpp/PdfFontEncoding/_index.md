## PdfFontEncoding Enum

Représente l'encodage de la police intégrée PDF.

```go

type PdfFontEncoding int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Identity](./identity/) | Représente l'utilisation de l'encodage Identity-H pour toutes les polices incorporées dans le pdf. |
| [AnsiPrefer](./ansiprefer/) | Représente la préférence d'utiliser WinAnsiEncoding pour les polices TrueType avec les caractères 32-127, sinon, l'encodage Identity-H sera utilisé pour les polices incorporées dans le pdf. |
