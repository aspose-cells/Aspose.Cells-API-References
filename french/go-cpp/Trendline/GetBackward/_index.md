## GetBackward function

Renvoie ou définit le nombre de périodes (ou d'unités sur un graphique de dispersion) que la courbe de tendance étend vers l'arrière. Le nombre de périodes doit être supérieur ou égal à zéro. Si le type de graphique est en colonnes, le nombre de périodes doit être compris entre 0 et 0,5.
