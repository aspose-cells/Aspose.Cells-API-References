## FontConfigs_GetPreferSystemFontSubstitutes function

Indique s'il faut utiliser d'abord les substituts de police système ou non lorsqu'une police n'est pas présentée et que le substitut de cette police n'est pas défini. Par exemple, sous Ubuntu, la police "Arial" est généralement remplacée par "Liberation Sans". La valeur par défaut est false.
