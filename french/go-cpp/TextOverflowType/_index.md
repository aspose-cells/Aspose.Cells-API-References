## TextOverflowType Enum

Représente la façon dont le texte déborde verticalement ou horizontalement.

```go

type TextOverflowType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Clip](./clip/) | Faites attention aux barrières supérieures et inférieures.Fournissez aucune indication qu'il y a du texte qui n'est pas visible. |
| [Ellipsis](./ellipsis/) | Faites attention aux barrières supérieures et inférieures.Utilisez une ellipse pour indiquer qu'il y a du texte qui n'est pas visible.Uniquement pour le débordement vertical. |
| [Overflow](./overflow/) | Débordez le texte et ne tenez pas compte des barrières supérieures et inférieures. |
