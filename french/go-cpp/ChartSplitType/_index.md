## ChartSplitType Enum

Représente la façon dont les deux sections d'un graphique en secteurs de secteurs ou d'un graphique en barres de secteurs sont séparées.

```go

type ChartSplitType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Position](./position/) | Représente les points de données. Les points de données doivent être répartis entre le diagramme circulaire et le deuxième diagramme en plaçant la dernière position de division des points de données dans le deuxième diagramme. |
| [Value](./value/) | Représente les points de données qui doivent être répartis entre le diagramme circulaire et le deuxième diagramme en plaçant les points de données avec une valeur inférieure à Split Position dans le deuxième diagramme. |
| [PercentValue](./percentvalue/) | Représente les points de données qui doivent être répartis entre le diagramme circulaire et le deuxième diagramme en plaçant les points avec un pourcentage inférieur à Split Position pour cent dans le deuxième diagramme. |
| [Custom](./custom/) | Représente les points de données qui doivent être répartis entre le diagramme circulaire et le deuxième diagramme selon les valeurs de division personnalisées. |
| [Auto](./auto/) | Représente les points de données qui doivent être répartis en utilisant le mécanisme par défaut pour ce type de diagramme. |
