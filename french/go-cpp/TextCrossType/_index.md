## TextCrossType Enum

Énumère le type d'affichage du texte lorsque la largeur du texte est supérieure à celle de la cellule.

```go

type TextCrossType int32


```

## Champs

| Champ | Description |
| --- | --- |
| [Default](./default/) | Affiche le texte comme dans Microsoft Excel. |
| [CrossKeep](./crosskeep/) | Affiche tout le texte en traversant d'autres cellules et conserve le texte des cellules traversées. |
| [CrossOverride](./crossoverride/) | Affiche tout le texte en traversant d'autres cellules et remplace le texte des cellules traversées. |
| [StrictInCell](./strictincell/) | Affiche uniquement le texte à l'intérieur de la largeur de la cellule. |
