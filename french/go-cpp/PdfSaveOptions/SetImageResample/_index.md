## SetImageResample function

Définit le PPI (pixels par pouce) souhaité pour le rééchantillonnage des images et la qualité JPEG. Toutes les images seront converties en JPEG avec le réglage de qualité spécifié, et les images dont le PPI (pixels par pouce) dépasse la valeur spécifiée seront rééchantillonnées.

func (instance *PdfSaveOptions) SetImageResample(desiredppi int32, jpegquality int32)  error
