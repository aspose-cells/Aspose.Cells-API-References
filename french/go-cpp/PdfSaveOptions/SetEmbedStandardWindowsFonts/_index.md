## SetEmbedStandardWindowsFonts function

Vrai pour incorporer les polices True type fonts. Affecte uniquement les caractères ASCII 32-127. Les polices pour les codes de caractères supérieurs à 127 sont toujours incorporées. Les polices sont toujours incorporées pour la norme PDF/A-1a, PDF/A-1b. La valeur par défaut est vraie.
