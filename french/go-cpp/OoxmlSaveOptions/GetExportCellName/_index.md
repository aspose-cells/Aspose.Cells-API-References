## GetExportCellName function

Indique si le nom de la cellule est exporté vers un fichier Excel2007 .xlsx (.xlsm, .xltx, .xltm). Si le fichier de sortie peut être accédé par SQL Server DTS, cette valeur doit être vraie. Mettre la valeur à false augmentera fortement les performances et réduira la taille du fichier lors de la création de gros fichiers. La valeur par défaut est true.
