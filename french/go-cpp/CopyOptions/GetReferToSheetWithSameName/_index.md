## GetReferToSheetWithSameName function

Dans MS Excel, lors de la copie de formules qui font référence à d'autres feuilles de calcul pendant la copie d'une feuille vers une autre, les formules copiées doivent faire référence au classeur source. Cependant, dans certaines situations l'utilisateur peut avoir besoin que les formules copiées fassent référence à des feuilles de calcul portant le même nom dans le même classeur, par exemple lorsque ces feuilles ont déjà été copiées avant cette opération de copie, alors cette propriété doit être définie sur vrai.
