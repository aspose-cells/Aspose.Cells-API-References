## Clear function

Supprime tous les noms définis qui ne sont pas référencés par les formules et la source de données. Si le nom défini est référencé, nous ne faisons que définir Name.ReferTo à null et les masquer.

```go

func (instance *NameCollection) Clear()  error

```
