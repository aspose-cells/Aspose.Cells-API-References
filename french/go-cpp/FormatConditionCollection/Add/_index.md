## Add function

Ajoute une condition de formatage et la plage de cellules affectée aux FormatConditions. Les FormatConditions peuvent contenir jusqu'à trois formats conditionnels. Les références aux autres feuilles ne sont pas autorisées dans les formules de formatage conditionnel.
