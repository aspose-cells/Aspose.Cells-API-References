java.lang.Object
```
public final class CoWorkUserPermission
```

représente la permission utilisateur en mode collaboration. Disponible uniquement dans la version Java pour le moment, sera disponible dans les versions .NET/Python à l'avenir.
## Champs

| Champ | Description |
| --- | --- |
| [ADMIN](#ADMIN) | Permission administrateur, l'utilisateur a un accès complet incluant les opérations de gestion |
| [DOWNLOAD](#DOWNLOAD) | Permission de téléchargement, l'utilisateur peut afficher, modifier et télécharger le contenu vers le stockage local |
| [EDITABLE](#EDITABLE) | Permission d'édition, l'utilisateur peut afficher et modifier le contenu |
| [READ_ONLY](#READ-ONLY) | Permission en lecture seule, l'utilisateur ne peut que visualiser le contenu mais ne peut apporter aucune modification |
