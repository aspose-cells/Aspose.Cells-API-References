Le lien hypertexte possède deux types d'action : UrlLink et CellCommand. Le type de lien hypertexte UrlLink est une ancre dans une cellule ; cliquer dessus naviguera vers une autre page ou ouvrira une nouvelle fenêtre de navigateur. Le type de lien hypertexte CellCommand est un bouton de commande dans une cellule ; cliquer dessus générera un événement côté serveur.

**Remarks**

NOTE : Cette classe est maintenant obsolète. Veuillez utiliser GridHyperlink à la place. Cette classe sera supprimée six mois après août 2014. Aspose s'excuse pour tout inconvénient que vous auriez pu rencontrer.
