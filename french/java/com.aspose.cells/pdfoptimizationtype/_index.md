### MINIMUM_SIZE {#MINIMUM-SIZE}
```
public static final int MINIMUM_SIZE
```


La taille du fichier est plus importante que la qualité d'impression

**Remarks**

Les polices Arial et Times New Roman avec les caractères 32‑127 ne seront pas incorporées dans le PDF. Les lignes de bordure sont optimisées pour une taille de fichier plus petite.
