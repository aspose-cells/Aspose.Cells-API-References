### CLIP {#CLIP}
```
public static final int CLIP
```


Faire attention aux barrières supérieures et inférieures. Ne fournir aucune indication qu'il y a du texte non visible.

### ELLIPSIS {#ELLIPSIS}
```
public static final int ELLIPSIS
```


Faire attention aux barrières supérieures et inférieures. Utilisez une ellipse pour indiquer qu'il y a du texte non visible. Seulement pour le débordement vertical.

### OVERFLOW {#OVERFLOW}
```
public static final int OVERFLOW
```


Débordez le texte sans tenir compte des barrières supérieures et inférieures.
