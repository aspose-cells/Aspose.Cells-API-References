Spécifie comment les hyperliens sont gérés lors du chargement du HTML.
## Champs

| Champ | Description |

| [NORMAL](#NORMAL) | Seul le premier hyperlien d’une cellule est chargé, les suivants sont ignorés. |

### ALLOW_MULTIPLE {#ALLOW-MULTIPLE}
```
public static final int ALLOW_MULTIPLE
```


Tous les hyperliens dans une cellule sont ajoutés à [Worksheet.getHyperlinks()](../../com.aspose.cells/worksheet\#getHyperlinks--). Notez que MS Excel ne prend en charge qu’un seul hyperlien par cellule, ainsi cette option peut générer des fichiers que Excel ne peut pas rendre complètement.

### NORMAL {#NORMAL}
```
public static final int NORMAL
```


Seul le premier hyperlien d’une cellule est chargé, les suivants sont ignorés.
