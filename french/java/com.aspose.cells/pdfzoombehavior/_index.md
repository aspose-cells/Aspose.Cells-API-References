
Spécifie le mode d'affichage initial lorsque le document PDF généré est ouvert.
## Champs

| Champ | Description |
| --- | --- |
| [FIT_HEIGHT](#FIT-HEIGHT) | Ajuste la hauteur de la page dans la fenêtre du visualiseur. |
| [FIT_PAGE](#FIT-PAGE) | Ajuste la page entière dans la fenêtre du visualiseur. |
| [FIT_WIDTH](#FIT-WIDTH) | Ajuste la largeur de la page dans la fenêtre du visualiseur. |
| [NONE](#NONE) | Utilise le comportement par défaut du visualiseur PDF. |
| [ZOOM_FACTOR](#ZOOM-FACTOR) | Ouvre le document à un pourcentage de zoom spécifique. |
