Représente la façon dont les deux sections d'un graphique en secteur de secteur ou d'un graphique en secteur à barres sont séparées.

| [PERCENT_VALUE](#PERCENT-VALUE) | Représente les points de données qui doivent être séparés entre le diagramme circulaire et le deuxième graphique en plaçant les points dont le pourcentage est inférieur au pourcentage de position de division dans le deuxième graphique. |

### AUTO {#AUTO}
```

```


Représente les points de données qui doivent être séparés en utilisant le mécanisme par défaut pour ce type de graphique.

**Remarks**

NOTE: Ce membre est maintenant obsolète. À la place, veuillez utiliser la propriété Series.IsAutoSplit. Cette propriété sera supprimée 12 mois plus tard à compter de septembre 2023. Aspose s'excuse pour tout désagrément que vous avez pu rencontrer.

### PERCENT_VALUE {#PERCENT-VALUE}
```
public static final int PERCENT_VALUE
```


Représente les points de données qui doivent être séparés entre le diagramme circulaire et le deuxième graphique en plaçant les points dont le pourcentage est inférieur au pourcentage de position de division dans le deuxième graphique.

### POSITION {#POSITION}
```
public static final int POSITION
```


Représente les points de données. Les points de données doivent être séparés entre le diagramme circulaire et le deuxième graphique en plaçant la dernière position de division des points de données dans le deuxième graphique.
