java.lang.Object
```
public final class TextCrossType
```

Énumère le type d'affichage du texte lorsque la largeur du texte dépasse celle de la cellule.
## Champs

| Champ | Description |
| --- | --- |
| [CROSS_KEEP](#CROSS-KEEP) | Affiche tout le texte en traversant d'autres cellules et conserve le texte des cellules traversées. |
| [CROSS_OVERRIDE](#CROSS-OVERRIDE) | Affiche tout le texte en traversant d'autres cellules et remplace le texte des cellules traversées. |
| [DEFAULT](#DEFAULT) | Affiche le texte comme dans Microsoft Excel. |
| [STRICT_IN_CELL](#STRICT-IN-CELL) | Affiche uniquement le texte à l'intérieur de la largeur de la cellule. |
