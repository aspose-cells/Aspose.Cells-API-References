Spécifie la position de l'axe pour une plage de cellules avec une mise en forme conditionnelle sous forme de barres de données.
## Champs

| Champ | Description |
| --- | --- |

| [MIDPOINT](#MIDPOINT) | Affiche l'axe au point médian de la cellule, quel que soit l'ensemble des valeurs dans la plage. |
| [NONE](#NONE) | Aucun axe n'est affiché, et les valeurs positives et négatives sont affichées de gauche à droite. |

### AUTOMATIC {#AUTOMATIC}
```
public static final int AUTOMATIC
```


Afficher l'axe à une position variable en fonction du rapport entre la valeur négative minimale et la valeur positive maximale dans la plage. Les valeurs positives sont affichées de gauche à droite. Les valeurs négatives sont affichées de droite à gauche. Lorsque toutes les valeurs sont positives ou toutes les valeurs sont négatives, aucun axe n'est affiché.

### MIDPOINT {#MIDPOINT}
```
public static final int MIDPOINT
```


Afficher l'axe au point médian de la cellule, quel que soit l'ensemble des valeurs dans la plage. Les valeurs positives sont affichées de gauche à droite. Les valeurs négatives sont affichées de droite à gauche.

### NONE {#NONE}
```
public static final int NONE
```


Aucun axe n'est affiché, et les valeurs positives et négatives sont affichées de gauche à droite.
