### getUseSameSource() {#getUseSameSource--}
```
public boolean getUseSameSource()
```


Obtient une valeur indiquant s'il faut partager la même source de données avec les tableaux croisés dynamiques existants. La valeur par défaut est true.

**Remarks**

Lorsqu'il est défini sur true, plusieurs tableaux croisés dynamiques peuvent réutiliser un même cache de tableau croisé dynamique pour réduire la consommation de mémoire.
