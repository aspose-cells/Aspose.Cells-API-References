Spécifie comment gérer le formatage provenant de la source HTML
## Champs

| Champ | Description |
| --- | --- |
| [ALL](#ALL) | Transférer tout le formatage HTML dans la feuille de calcul avec les données. |
| [NONE](#NONE) | Importer les données en texte non formaté (la définition des types de données se produit toujours). |
| [RTF](#RTF) | Convertir le formatage HTML en formatage texte enrichi sur les données importées dans la feuille de calcul. |
