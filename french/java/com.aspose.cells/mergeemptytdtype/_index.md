### DEFAULT {#DEFAULT}
```
public static final int DEFAULT
```


Affiche comme MS Excel.

### MERGE_FORCELY {#MERGE-FORCELY}
```
public static final int MERGE_FORCELY
```


Fusion forcée des éléments TD vides lors de l'exportation du fichier en html. La taille du fichier html sera considérablement réduite après avoir réglé la valeur sur true. Si vous souhaitez importer le fichier html dans Excel ou exporter des lignes de grille parfaites lors de l'enregistrement du fichier en html, veuillez conserver la valeur par défaut.

### NONE {#NONE}
```
public static final int NONE
```


Les éléments TD vides ne seront pas fusionnés lors de l'exportation du fichier en html. Cela générera un fichier html nettement plus volumineux.
