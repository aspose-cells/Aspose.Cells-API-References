### getOffset() {#getOffset--}
```
public int getOffset()
```


Obtient la distance des étiquettes par rapport à l'axe des catégories. Cela s'applique uniquement à l'axe des catégories (x).

**Remarks**

La distance par défaut est de 100 pour cent, ce qui représente l'espacement par défaut entre les étiquettes de l'axe et la ligne de l'axe. La valeur peut être un pourcentage entier de 0 à 1000, relatif à la taille de police de l''étiquette de l'axe.

int
