Indique le type de règle utilisé pour décrire une zone ou un aspect du tableau croisé dynamique.
## Champs

| Champ | Description |
| --- | --- |
| [ALL](#ALL) | Représente l'intégralité du tableau croisé dynamique. |
| [BUTTON](#BUTTON) | Représente un bouton de champ. |
| [DATA](#DATA) | Représente un élément dans la zone de données. |
| [NONE](#NONE) | Pas de zone de tableau croisé dynamique. |
| [NORMAL](#NORMAL) | Représente un en-tête ou un élément. |
| [ORIGIN](#ORIGIN) | Représente les cellules vides en haut à gauche du tableau croisé dynamique (en haut à droite pour les feuilles RTL). |
