```
public final class ShapeDisplayType
```

Représente la façon dont l'application affiche les formes dans ce classeur. Les formes peuvent inclure des graphiques, des images et d'autres données d'objet prises en charge par l'application.
## Champs

| Champ | Description |
| --- | --- |
| [ALL](#ALL) | Indique que toutes les formes doivent être affichées dans le classeur. |
| [NONE](#NONE) | Indique que toutes les formes doivent être masquées dans le classeur. |
| [PLACEHOLDERS](#PLACEHOLDERS) | Indique que l'application affiche des espaces réservés pour les formes dans le classeur. |
