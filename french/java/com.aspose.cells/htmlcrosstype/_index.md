## Champs

| Champ | Description |
| --- | --- |
| [CROSS](#CROSS) | Afficher la chaîne croisée HTML, cette performance pour créer de gros fichiers html sera plus de dix fois plus rapide que de définir la valeur sur Default ou FitToCell. |
| [CROSS_HIDE_RIGHT](#CROSS-HIDE-RIGHT) | Afficher la chaîne croisée HTML et masquer la chaîne de droite lorsque les textes se chevauchent. |
| [DEFAULT](#DEFAULT) | Affichage comme MS Excel, dépend de la cellule suivante. |
| [FIT_TO_CELL](#FIT-TO-CELL) | Affichage uniquement de la chaîne dans la largeur de la cellule. |
| [MS_EXPORT](#MS-EXPORT) | Afficher la chaîne comme MS Excel lors de l'exportation HTML. |
