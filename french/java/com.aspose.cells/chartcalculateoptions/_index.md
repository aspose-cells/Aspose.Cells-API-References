### getUpdateAllPoints() {#getUpdateAllPoints--}
```
public boolean getUpdateAllPoints()
```


Indique s'il faut mettre à jour tous les points de données lors du calcul du graphique. Valeur par défaut : False. Lorsque vous souhaitez obtenir la valeur de chaque point de données du graphique spécifiquement, définissez-la sur true. Si ce paramètre est défini sur True, de nouveaux points de données peuvent être générés lors du calcul du graphique. Cela peut augmenter la taille du fichier Excel.
