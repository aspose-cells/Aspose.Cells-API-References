## HyperlinkLoadMode enumeration

Spécifie comment les hyperliens sont gérés lors du chargement du HTML.

```csharp
public enum HyperlinkLoadMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Normal | `0` | Seul le premier hyperlien d’une cellule est chargé, les suivants sont ignorés. |
| AllowMultiple | `1` | Tous les hyperliens d’une cellule sont ajoutés à [`Hyperlinks`](../worksheet/hyperlinks/). Notez que MS Excel ne prend en charge qu’un seul hyperlien par cellule, donc cette option peut produire des fichiers qu’Excel ne peut pas rendre complètement. |
