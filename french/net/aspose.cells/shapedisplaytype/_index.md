## ShapeDisplayType enumeration

Représente la façon dont l'application affiche les formes dans ce classeur. Les formes peuvent inclure des graphiques, des images et d'autres données d'objet prises en charge par l'application.

```csharp
public enum ShapeDisplayType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| All | `0` | Indique que toutes les formes sont affichées dans le classeur. |
| Placeholders | `1` | Indique que l'application affiche des espaces réservés pour les formes dans le classeur. |
| None | `2` | Indique que toutes les formes sont masquées dans le classeur. |
