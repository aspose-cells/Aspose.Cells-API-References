## WebWorksheet.IsProtected property

Obtient ou définit si la feuille de calcul est protégée. Lorsqu'une feuille de calcul est protégée, toutes les cellules ne peuvent pas être modifiées sauf la cellule dont la propriété IsLocked est false.

public bool IsProtected { get; set; }
