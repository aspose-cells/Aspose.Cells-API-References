## GridTxtLoadOptions.ExtendToNextSheet property

Indique si les données sont étendues à la feuille suivante lorsque les lignes ou colonnes dépassent la limite. Si cette propriété est vraie, les données supplémentaires seront transférées à la feuille suivante derrière la feuille actuelle (si la feuille actuelle est la dernière, une nouvelle feuille sera ajoutée au classeur). Si cette propriété est fausse, les données dépassant la limite seront ignorées. La valeur par défaut est false ;

```csharp
public bool ExtendToNextSheet { get; set; }
```
