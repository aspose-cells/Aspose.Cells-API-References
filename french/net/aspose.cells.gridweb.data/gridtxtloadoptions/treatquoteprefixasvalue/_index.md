## GridTxtLoadOptions.TreatQuotePrefixAsValue property

Indique si le signe de guillemet simple initial doit être considéré comme faisant partie de la valeur d'une cellule. La valeur par défaut est true. Si elle est false, le guillemet simple initial sera supprimé de la valeur de la cellule correspondante et [`QuotePrefix`](../../../aspose.cells.gridweb/gridtableitemstyle/quoteprefix/) sera défini sur true pour la cellule.

```csharp
public bool TreatQuotePrefixAsValue { get; set; }
```
