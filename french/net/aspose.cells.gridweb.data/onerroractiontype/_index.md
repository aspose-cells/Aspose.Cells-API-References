## OnErrorActionType enumeration

Utilisé dans l'événement CellError du GridWeb. L'utilisateur définit OnErrorActionQuery.OnErrorAction pour indiquer au contrôle d'arrêter le traitement ou d'ignorer l'erreur.

```csharp
public enum OnErrorActionType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Throw | `0` | Lance l'exception actuelle. |
| Stop | `1` | Arrête le traitement en cours. |
| Ignore | `2` | Ignore l'erreur et continue le traitement. |
