## Hyperlink.ActionType property

Obtient ou définit le type d'action du hyperlien. Il peut être ActionTpye.UrlLink ou ActionType.CellCommand. Le type UrlLink signifie que le hyperlien est un lien vers une page web ou un courrier électronique. Par exemple : "http://www.aspose.com" ou "mailto:admin@aspose.com". Le type CellCommand signifie que le hyperlien déclenchera un événement CellCommand, que vous pouvez gérer.

```csharp
public virtual HyperlinkActionType ActionType { get; set; }
```
