## GridLoadOptions.PreservePaddingSpacesInFormula property

Indique s'il faut conserver les espaces et les sauts de ligne qui sont insérés entre les jetons de formule lors de l'obtention et de la définition des formules. La valeur par défaut est false.

```csharp
public bool PreservePaddingSpacesInFormula { get; set; }
```

### Remarques

Après le chargement du classeur à partir du fichier modèle avec cette option, [`PreservePaddingSpaces`](../../gridworkbooksettings/preservepaddingspaces/) sera définie sur la même valeur que cette propriété.
