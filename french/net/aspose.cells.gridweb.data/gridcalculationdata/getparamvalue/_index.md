## GridCalculationData.GetParamValue method

Obtient l'objet valeur représentée du paramètre à l'index donné.

```csharp
public object GetParamValue(int index)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| indice | Int32 | index du paramètre (base 0) |

### Valeur de retour

Si le paramètre est une valeur simple, alors il renvoie la valeur simple. Si le paramètre est une référence, alors il renvoie l'objet ReferredArea.
