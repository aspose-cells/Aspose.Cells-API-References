## HyperlinkActionType enumeration

Un hyperlien possède deux types d'action : UrlLink et CellCommand. Le type d'hyperlien UrlLink est une ancre dans une cellule, cliquer dessus naviguera vers une autre page ou ouvrira une nouvelle fenêtre du navigateur. Le type d'hyperlien CellCommand est un bouton de commande dans une cellule, cliquer dessus générera un événement côté serveur.

```csharp
public enum HyperlinkActionType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| UrlLink | `0` | Lien URL. Une ancre dans une cellule. |
| CellCommand | `1` | Bouton de commande de cellule. |
| SimpleImage | `2` | Juste une image simple. |
