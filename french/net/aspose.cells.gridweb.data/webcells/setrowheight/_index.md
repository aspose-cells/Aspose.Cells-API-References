## WebCells.SetRowHeight method

Définit la hauteur de la ligne spécifiée. Le type de largeur accepté est Point, Pixel ou Pouce.

```csharp
public void SetRowHeight(int row, Unit height)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| ligne | Int32 | Index de ligne. |
| hauteur | Unité | Hauteur de la ligne. En unité de point, elle doit être comprise entre 0 et 409,5. |

### Remarques

Pour masquer une ligne, définissez la hauteur de la ligne à zéro.
