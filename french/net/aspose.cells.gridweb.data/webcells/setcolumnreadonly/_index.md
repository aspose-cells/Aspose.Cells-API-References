## WebCells.SetColumnReadonly method

Définit une colonne en lecture seule afin que l'utilisateur ne puisse pas la supprimer côté client. Cette méthode étendue de GridWeb spécifiquement ne sera pas conservée et n'affectera pas le fichier Excel réel.

```csharp
public void SetColumnReadonly(int columnIndex, bool isReadonly)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| columnIndex | Int32 | index de colonne. |
| isReadonly | Boolean | vrai ou faux. |
