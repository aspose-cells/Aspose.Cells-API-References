## WebCells.GetColumnReadonly method

Obtient si une colonne est en lecture seule. il s'agit d'une méthode étendue de GridWeb spécifiquement, elle ne sera pas conservée ni prise en compte dans le fichier Excel réel.

```csharp
public bool GetColumnReadonly(int columnIndex)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| columnIndex | Int32 | index de colonne. |

### Valeur de retour

Si en lecture seule, renvoie vrai.
