L'espace de noms **Aspose.Cells.Properties** fournit des classes pour travailler avec les propriétés de feuille de calcul personnalisées et intégrées telles que le titre, les mots‑clés, l'entreprise, etc.

## Classes

| Classe | Description |
| --- | --- |
| [BuiltInDocumentPropertyCollection](./builtindocumentpropertycollection/) | Une collection de propriétés de document intégrées. |
| [ContentTypeProperty](./contenttypeproperty/) | Représente les informations d'identifiant. |
| [ContentTypePropertyCollection](./contenttypepropertycollection/) | Une collection d'objets [`ContentTypeProperty`](../aspose.cells.properties/contenttypeproperty/) qui représentent des informations supplémentaires. |
| [CustomDocumentPropertyCollection](./customdocumentpropertycollection/) | Une collection de propriétés de document personnalisées. |
| [CustomProperty](./customproperty/) | Représente une propriété personnalisée qui stocke des paires nom‑valeur de données arbitraires définies par l'utilisateur pour la feuille de calcul. |
| [CustomPropertyCollection](./custompropertycollection/) | Une collection d'objets [`CustomProperty`](../aspose.cells.properties/customproperty/) qui représentent des informations supplémentaires. |
| [DocumentProperty](./documentproperty/) | Représente une propriété de document personnalisée ou intégrée. |
| [DocumentPropertyCollection](./documentpropertycollection/) | Classe de base pour les collections [`BuiltInDocumentPropertyCollection`](../aspose.cells.properties/builtindocumentpropertycollection/) et [`CustomDocumentPropertyCollection`](../aspose.cells.properties/customdocumentpropertycollection/). |
