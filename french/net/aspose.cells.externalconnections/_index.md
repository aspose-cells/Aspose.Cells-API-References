L'espace de noms **Aspose.Cells.ExternalConnections** fournit des classes pour les connexions externes afin de récupérer des données depuis des sources externes telles que les bases de données et le Web.

## Classes

| Classe | Description |
| --- | --- |
| [ConnectionParameter](./connectionparameter/) | Spécifie les propriétés concernant tous les paramètres utilisés avec les connexions de données externes. Les paramètres sont valides pour les requêtes ODBC et Web. |
| [ConnectionParameterCollection](./connectionparametercollection/) | Spécifie la collection [`ConnectionParameter`](../aspose.cells.externalconnections/connectionparameter/) |
| [DataModelConnection](./datamodelconnection/) | Spécifie une connexion de modèle de données |
| [DBConnection](./dbconnection/) | Spécifie toutes les propriétés associées à une connexion de données externes ODBC ou OLE DB. |
| [ExternalConnection](./externalconnection/) | Spécifie une connexion de données externes |
| [ExternalConnectionCollection](./externalconnectioncollection/) | Spécifie la collection [`ExternalConnection`](../aspose.cells.externalconnections/externalconnection/) |
| [WebQueryConnection](./webqueryconnection/) | Spécifie les propriétés d'une source de requête Web. Une requête Web récupérera des données à partir de tables HTML, et peut également fournir des paramètres HTTP "Get" à traiter par le serveur Web lors de la génération du HTML en incluant les paramètres et les éléments de paramètres. |
## Énumération

| Énumération | Description |
| --- | --- |
| [ConnectionDataSourceType](./connectiondatasourcetype/) | Spécifie le type de source de base de données externe |
| [ConnectionParameterType](./connectionparametertype/) | Spécifie le type de paramètre de la connexion externe |
| [CredentialsMethodType](./credentialsmethodtype/) | Spécifie la méthode d'identifiants utilisée pour l'accès au serveur. |
| [ExternalConnectionClassType](./externalconnectionclasstype/) | Représente le type de connexion |
| [HtmlFormatHandlingType](./htmlformathandlingtype/) | Spécifie comment gérer le formatage à partir de la source HTML |
| [OLEDBCommandType](./oledbcommandtype/) | Spécifie le type de commande OLE DB. |
| [ReConnectionMethodType](./reconnectionmethodtype/) | Spécifie ce que l'application de feuille de calcul doit faire lorsqu'une connexion échoue. |
| [SqlDataType](./sqldatatype/) | Spécifie le type de données SQL du paramètre. Valide uniquement pour les sources ODBC. |
