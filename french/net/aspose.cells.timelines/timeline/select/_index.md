## Timeline.Select method

```csharp
public void Select(DateTime start, DateTime end, bool calculate)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| début | DateTime | La date et l'heure de début |
| fin | DateTime | La date et l'heure de fin |

### Remarques

[`CurrentLevel`](../currentlevel/) must be set before calling this method. If this method is called, [`SelectionLevel`](../selectionlevel/) will be [`CurrentLevel`](../currentlevel/).
