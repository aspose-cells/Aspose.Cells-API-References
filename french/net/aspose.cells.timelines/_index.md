L'espace de noms **Aspose.Cells.Timelines** contient des classes qui permettent d'accéder et de dessiner des chronologies dans les fichiers de feuilles de calcul Excel.

## Classes

| Classe | Description |
| --- | --- |
| [Timeline](./timeline/) | Description résumée de la vue Chronologie En raison de MS Excel, Excel 2003 ne prend pas en charge la Chronologie. |
| [TimelineCollection](./timelinecollection/) | Spécifie la collection de tous les objets [`Timeline`](../aspose.cells.timelines/timeline/) de la feuille de calcul. Elle est prise en charge depuis Excel 2013. |
## Énumération

| Énumération | Description |
| --- | --- |
| [TimelineLevelType](./timelineleveltype/) | Représente le type de niveau de [`Timeline`](../aspose.cells.timelines/timeline/) |
