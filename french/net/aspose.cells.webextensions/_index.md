L'espace de noms **Aspose.Cells.WebExtensions** contient des classes pour accéder aux compléments Office dans les fichiers Excel.

## Classes

| Classe | Description |
| --- | --- |
| [WebExtension](./webextension/) | Représente une instance de complément Office. |
| [WebExtensionBinding](./webextensionbinding/) | Représente une relation de liaison entre un Office Add-in et les données du document. |
| [WebExtensionBindingCollection](./webextensionbindingcollection/) | Représente la liste des relations de liaison entre un Office Add-in et les données du document. |
| [WebExtensionCollection](./webextensioncollection/) | Représente la liste des extensions web. |
| [WebExtensionProperty](./webextensionproperty/) | Représente une propriété personnalisée d'Office Add-in. |
| [WebExtensionPropertyCollection](./webextensionpropertycollection/) | Représente la liste des propriétés d'extension web. |
| [WebExtensionReference](./webextensionreference/) | Représente l'identification de l'emplacement du fournisseur et de la version de l'extension. |
| [WebExtensionReferenceCollection](./webextensionreferencecollection/) | Représente la liste des références d'extension web. |
| [WebExtensionTaskPane](./webextensiontaskpane/) | Représente un objet de volet de tâche persistant. |
| [WebExtensionTaskPaneCollection](./webextensiontaskpanecollection/) | Représente la liste des volets de tâche. |
