## Slicer.SelectItems method

```csharp
public void SelectItems(string[] labels, bool append)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| étiquettes | String[] | Étiquettes sélectionnées. |
| ajouter | Boolean | False signifie uniquement sélectionner ces étiquettes et désélectionner les autres. True signifie conserver les éléments déjà sélectionnés et sélectionner ces étiquettes. |
