## BorderLineType enumeration

Spécifie le type de ligne de bordure pour une gridCell.

```csharp
public enum BorderLineType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Pas de bordure. |
| Thin | `1` | Une bordure à ligne pleine. |
| Medium | `2` | Une bordure à ligne pleine. L'épaisseur de la ligne est de 2f. |
| Dashed | `3` | Une bordure à ligne pointillée. |
| Dotted | `4` | Une bordure à pointillés. |
| Thick | `5` | Une bordure à ligne solide. L'épaisseur de la ligne est de 3f. |
| MediumDashed | `8` | Une bordure à ligne pointillée. L'épaisseur de la ligne est de 2f. |
| ThinDashDotted | `9` | Une bordure à ligne tiret-point. |
| MediumDashDotted | `10` | Une bordure à ligne tiret-point. L'épaisseur de la ligne est de 2f. |
| ThinDashDotDotted | `11` | Une bordure à ligne tiret-point-tiret. |
| MediumDashDotDotted | `12` | Une bordure à ligne tiret-point-tiret. L'épaisseur de la ligne est de 2f. |
