## ComboBox.SelectedIndex property

Obtient ou définit l'index spécifiant l'élément actuellement sélectionné. La définition de l'index appellera automatiquement la méthode GridDesktop.RunAllFormulas si la propriété GridDesktop.RecalculateFormulas est vraie.

public int SelectedIndex { get; set; }
