## GridDesktop.StartFormatPainter method

Notifie GridDesktop de démarrer le FormatPainter.

```csharp
public void StartFormatPainter(bool formatOnce)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| formatOnce | Boolean | si formatOnce est true, FormatPainter ne peut être utilisé qu'une fois ; si formatOnce est false, FormatPainter peut être utilisé plusieurs fois, jusqu'à ce que EndFormatPainter() soit invoqué. |

### Exemples

```csharp
[C#]
gridDesktop1.StartFormatPainter(true);

[Visual Basic]
gridDesktop1.StartFormatPainter(True)

```
