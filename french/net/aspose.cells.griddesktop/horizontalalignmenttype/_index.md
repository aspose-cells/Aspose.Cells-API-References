## HorizontalAlignmentType enumeration

Spécifie comment une gridcell est alignée horizontalement.

```csharp
public enum HorizontalAlignmentType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| General | `0` | Si le type d'objet est un nombre, l'objet est aligné à droite de la cellule de grille. Si le type d'objet est une chaîne, l'objet est aligné à gauche de la cellule de grille. |
| Left | `1` | L'objet ou le texte est aligné à gauche de la cellule de grille. |
| Centred | `2` | L'objet ou le texte est aligné au centre de la cellule de grille. |
| Right | `3` | L'objet ou le texte est aligné à droite de la cellule de grille. |
| Filled | `4` | L'objet ou le texte est rempli dans la cellule de la grille. |
| Justified | `5` |  |
| CentredAcross | `6` |  |
| Distributed | `7` |  |
