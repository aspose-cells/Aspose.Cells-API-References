## Style.Color property

Obtient ou définit la couleur d'ombrage de la cellule. lorsque le motif est none, il renvoie Color.Empty ; lorsque le motif est BackgroundType.Solid, il renvoie ForegroundColor ; dans les autres cas il renvoie BackgroundColor
