## Style.Clone method

Crée et renvoie une copie de cet objet. **NOTE:** Si vous clonez un style nommé, le nom n'est pas cloné car le nom du style doit être unique. Par conséquent, le style cloné ne sera pas \"égal à\" le style original.

```csharp
public Style Clone()
```

### Valeur de retour

Renvoie un nouvel objet Style.
