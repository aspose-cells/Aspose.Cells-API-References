## Worksheet.AutoFitRowsMerged method

Ajuste automatiquement toutes les lignes de cette feuille de calcul. Il ajustera également la hauteur des lignes lorsque les cellules sont fusionnées dans une ligne.

```csharp
public void AutoFitRowsMerged()
```

### Remarques

Si les cellules sont fusionnées dans une ligne et que les lignes sont ajustées automatiquement dans MS Excel, MS Excel n'augmente pas la hauteur de la ligne. Aspose.Cells augmentera la hauteur de la ligne pour adapter les données des cellules.
