## Worksheet.SetProtected method

Définit si la plage de cellules est protégée. Ceci est une méthode étendue utilisée uniquement dans Grid. Cette méthode n'a aucun rapport avec la propriété cell.Style.CellLocked. Elle n'aura aucun effet après l'enregistrement du fichier Excel.

```csharp
public void SetProtected(CellRange range, bool isProtected)
```

| plage | CellRange | Objet CellRange. |
| isProtected | Boolean | Valeur booléenne à définir. |
