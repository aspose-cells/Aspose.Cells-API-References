## Worksheet.ImportDataTable method

Importe un objet DataTable dans une feuille de calcul.

```csharp
public int ImportDataTable(DataTable dataTable, bool isFieldNameShown, int firstRow, 
    int firstColumn)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| dataTable | DataTable | L'objet DataTable à importer. |
| isFieldNameShown | Boolean | Indique si le nom de champ du datatable sera importé dans la première ligne. |
| firstRow | Int32 | Le numéro de ligne de la première cellule à importer. |
| firstColumn | Int32 | Le numéro de colonne de la première cellule à importer. |

### Valeur de retour

Nombre total de lignes importées.
