## PivotTableCreateOptions.UseSameSource property

Obtient ou définit une valeur indiquant s'il faut partager la même source de données avec les tableaux croisés dynamiques existants. La valeur par défaut est true.

```csharp
public bool UseSameSource { get; set; }
```

### Remarques

Lorsqu'elle est définie sur true, plusieurs tableaux croisés dynamiques peuvent réutiliser un même cache de pivot pour réduire la consommation de mémoire.
