## PivotTableCreateOptions.IsXlsClassic property

Obtient ou définit une valeur indiquant s'il faut créer un PivotTable au style Excel 97-2003 classique.

```csharp
public bool IsXlsClassic { get; set; }
```

### Remarques

Le PivotTable classique utilise la mise en page et le formatage hérités d'Excel 97-2003. Lorsqu'il n'est pas explicitement défini, la valeur par défaut est déterminée par le format de fichier du classeur cible.
