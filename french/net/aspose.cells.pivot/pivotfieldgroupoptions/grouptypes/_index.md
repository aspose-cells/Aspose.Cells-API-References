## PivotFieldGroupOptions.GroupTypes property

Obtient ou définit le type de regroupement pour le champ du tableau croisé dynamique.

```csharp
public PivotGroupByType[] GroupTypes { get; set; }
```

### Remarques

L'ordre dans cette propriété sera ignoré. Lors de la spécification de plusieurs types de groupe, les champs de groupe de base seront insérés par ordre croissant et le champ de groupe sera affiché dans la région ligne/colonne par ordre décroissant (Années → Trimestres → Mois → Jours → Heures → Minutes → Secondes).
