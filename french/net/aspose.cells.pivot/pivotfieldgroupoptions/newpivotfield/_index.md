## PivotFieldGroupOptions.NewPivotField property

Obtient ou définit une valeur indiquant si de nouveaux champs du tableau croisé dynamique doivent être créés après le regroupement.

```csharp
public bool NewPivotField { get; set; }
```

### Remarques

Si elle n'est pas explicitement définie, la valeur par défaut est false pour le regroupement numérique et true pour le regroupement date‑heure, true pour le groupe discret. Ne fonctionne que pour le premier nouveau champ pivot de groupe du champ de base.
