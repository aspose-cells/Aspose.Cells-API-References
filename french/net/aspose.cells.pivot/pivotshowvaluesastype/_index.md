## PivotShowValuesAsType enumeration

Représente le type de calcul pour la fonctionnalité "Afficher les valeurs comme" des valeurs du champ de tableau croisé dynamique.

```csharp
public enum PivotShowValuesAsType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Normal | `0` | Représente la valeur brute, aucun calcul personnalisé. |
| DifferenceFrom | `1` | Affiche la valeur comme la différence par rapport à un élément de base spécifié. |
| PercentageOf | `2` | Affiche la valeur en pourcentage d'un élément de base spécifié. |
| PercentageDifferenceFrom | `3` | Affiche la valeur en différence de pourcentage par rapport à un élément de base spécifié. |
| RunningTotalIn | `4` | Affiche la valeur comme un total cumulé le long du champ de base spécifié. |
| PercentageOfRow | `5` | Affiche la valeur en pourcentage du total de la ligne. |
| PercentageOfColumn | `6` | Affiche la valeur en pourcentage du total de la colonne. |
| PercentageOfTotal | `7` | Affiche la valeur en pourcentage du total général. |
| Index | `8` | Calcul d'index : (Cell Value × Grand Total of Grand Totals) / (Row Grand Total × Column Grand Total). |
| PercentageOfParentRowTotal | `9` | Affiche la valeur en pourcentage du total de l'élément de ligne parent. |
| PercentageOfParentColumnTotal | `10` | Affiche la valeur en pourcentage du total de l'élément de colonne parent. |
| PercentageOfParentTotal | `11` | Affiche la valeur en pourcentage du total de l'élément parent dans le champ de base spécifié. |
| PercentageOfRunningTotalIn | `12` | Affiche la valeur en pourcentage du total cumulé le long du champ de base spécifié. |
| RankSmallestToLargest | `13` | Classe les valeurs du plus petit au plus grand dans le champ de base spécifié. |
| RankLargestToSmallest | `14` | Classe les valeurs du plus grand au plus petit dans le champ de base spécifié. |
