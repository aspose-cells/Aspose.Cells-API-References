## PivotTableRefreshOption.KeepCachedLocalGroupData property

Indique s'il faut conserver les données de groupe locales en cache si les valeurs maximale et minimale restent inchangées. La valeur par défaut est false, ce qui signifie rafraîchir le groupe avec les paramètres locaux.

```csharp
public bool KeepCachedLocalGroupData { get; set; }
```
