## PivotTableRefreshOption.IsKeepOriginalOrder property

Indique s'il faut conserver l'ordre original des éléments du tableau croisé dynamique comme dans l'ancienne source de données.

```csharp
public bool IsKeepOriginalOrder { get; set; }
```

### Remarques

Applicable uniquement au champ de tableau croisé qui n'est pas trié. Lors du rafraîchissement d'un tel champ, Ms Excel conserve l'ordre original de l'ancienne source de données. La valeur par défaut de cette propriété est true, ce qui représente le même comportement que Ms Excel. Si l'utilisateur souhaite que le champ de tableau croisé soit entièrement rafraîchi comme les données de la nouvelle source, cette propriété doit être définie sur false.
