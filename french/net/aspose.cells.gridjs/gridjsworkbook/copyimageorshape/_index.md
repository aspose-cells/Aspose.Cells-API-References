## GridJsWorkbook.CopyImageOrShape method

```csharp
public string CopyImageOrShape(string uid, string p)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| uid | String | L'identifiant unique pour le cache de fichier. |
| p | String | La chaîne JSON pour l'opération qui spécifie l'emplacement de la cellule, elle contient le nom de la feuille de calcul, la ligne supérieure gauche, la colonne supérieure gauche pour l'image ou la forme, etc. {name:'sheet1',ri:1,ci:1,srcid:2,srcname:'sheet2',isshape:true} |

La chaîne JSON de la nouvelle image copiée
