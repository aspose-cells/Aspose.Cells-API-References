## GridJsWorkbook.JsonToStreamByUid method

Récupère la chaîne JSON du fichier depuis le cache en utilisant l'identifiant unique spécifié, définit le nom de fichier de sortie dans le JSON, et l'écrit dans le flux.

```csharp
public bool JsonToStreamByUid(Stream stream, string uid, string filename)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| stream | Stream | Le flux qui sera écrit |
| uid | String | L'identifiant unique pour le cache de fichier. |
| nom de fichier | String | Spécifie le nom du fichier dans le JSON. Si défini sur null, le nom de fichier par défaut est : book1. |
