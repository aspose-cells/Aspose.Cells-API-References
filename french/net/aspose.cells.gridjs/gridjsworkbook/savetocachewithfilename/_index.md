## GridJsWorkbook.SaveToCacheWithFileName method

Enregistre les données en mémoire dans le fichier de cache avec le nom de fichier spécifié et définit également le mot de passe d'ouverture, le format d'enregistrement est basé sur l'extension du nom de fichier.

```csharp
public void SaveToCacheWithFileName(string uid, string filename, string password)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| uid | String | L'identifiant unique pour le cache de fichier. |
| nom de fichier | String | Le nom de fichier à enregistrer. |
| mot de passe | String | Le mot de passe d’ouverture du fichier Excel. La valeur peut être nulle si aucun mot de passe n’est défini. |
