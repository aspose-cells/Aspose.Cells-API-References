## GridJsWorkbook.SetTransParentView method

Définit la transparence des formes de rédaction dans le classeur.

```csharp
public void SetTransParentView(string excelFilePath, string uid, bool isTransparent)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| excelFilePath | String | Le chemin du fichier Excel. |
| uid | String | L'identifiant unique du classeur. Si null ou vide, un nouvel uid sera généré à partir du chemin du fichier. |
| isTransparent | Boolean | Si vrai, définit la transparence à 0,89 (semi-transparente) ; si faux, définit la transparence à 1 (complètement opaque/invisible). |
