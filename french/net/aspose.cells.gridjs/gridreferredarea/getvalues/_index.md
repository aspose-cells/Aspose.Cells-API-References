## GridReferredArea.GetValues method

Obtient les valeurs des cellules dans cette zone.

```csharp
public object GetValues()
```

### Valeur de retour

Si cette zone est invalide, "#REF!" sera renvoyé ; si cette zone ne comporte qu’une seule cellule, alors renvoyez l’objet valeur de cellule ; sinon renvoyez un tableau contenant toutes les valeurs de cette zone.
