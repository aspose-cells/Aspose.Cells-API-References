## CoWorkUserPermission enumeration

représente l'autorisation de l'utilisateur en mode collaboration. Disponible uniquement dans la version Java pour le moment, sera disponible dans les versions .net/python à l'avenir.

```csharp
public enum CoWorkUserPermission
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| READ_ONLY | `0` | Autorisation en lecture seule, L'utilisateur ne peut que visualiser le contenu mais ne peut apporter aucune modification |
| EDITABLE | `1` | Autorisation modifiable, L'utilisateur peut visualiser et modifier le contenu |
| DOWNLOAD | `2` | Autorisation de téléchargement, L'utilisateur peut visualiser, modifier et télécharger le contenu vers le stockage local |
| ADMIN | `3` | Autorisation d'administrateur, L'utilisateur a un accès complet incluant les opérations de gestion |
