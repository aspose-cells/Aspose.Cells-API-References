## Config.AutoFitColumnsOnLoad property

Indique s'il faut ajuster automatiquement la largeur des colonnes lors du chargement du fichier. La valeur par défaut est `false`. Avertissement : définir cette valeur sur `true` effectuera une opération d'ajustement automatique de toutes les colonnes après le chargement, ce qui peut avoir un impact notable sur les performances.

```csharp
public static bool AutoFitColumnsOnLoad { get; set; }
```
