## Config.MaxShapeOrImageWidthOrHeight property

Obtient/Définit la largeur ou hauteur maximale pour une forme ou une image, GridJs ignorera la forme ou l'image dont la largeur ou la hauteur dépasse cette valeur, cela prend effet lorsque IslimitShapeOrImage=true. La valeur par défaut est 10000.

```csharp
public static int MaxShapeOrImageWidthOrHeight { get; set; }
```
