## Config.IsWasm property

Obtient/definit si GridJs s'exécute à l'intérieur d'un hôte WebAssembly dans le navigateur au lieu d'un processus serveur. Lorsque true, aucun chemin FileCacheDirectory / disque / thread d'interruption n'est utilisé et le cache de fichiers doit provenir de GridJsOptions.CacheImp. GridJsOptions.IsWasm définit cela lors de la construction du service GridJs, de sorte qu'un seul Aspose.Cells.GridJs.dll sert les deux hôtes. La valeur par défaut est false.

```csharp
public static bool IsWasm { get; set; }
```
