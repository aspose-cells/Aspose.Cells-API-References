## Config.AutoFitRowsHeightOnLoad property

Indique s'il faut ajuster automatiquement la hauteur des lignes lors du chargement du fichier. La valeur par défaut est `false`. Avertissement : définir cette valeur sur `true` effectuera une opération d'ajustement automatique de toutes les lignes après le chargement, ce qui peut avoir un impact notable sur les performances.

```csharp
public static bool AutoFitRowsHeightOnLoad { get; set; }
```
