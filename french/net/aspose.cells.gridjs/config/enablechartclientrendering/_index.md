## Config.EnableChartClientRendering property

Obtient/definit si le rendu des graphiques côté client est activé. Si défini sur false, GridJs reviendra uniquement aux images/formes de graphiques générées par le serveur. La valeur par défaut est true.

```csharp
public static bool EnableChartClientRendering { get; set; }
```
