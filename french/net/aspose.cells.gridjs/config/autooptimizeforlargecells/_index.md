## Config.AutoOptimizeForLargeCells property

Obtient/Définit s'il faut optimiser automatiquement les performances de chargement pour une feuille de calcul avec de grandes cellules. Cela ignorera certains styles /borders pour réduire le temps de chargement. La valeur par défaut est true.

public static bool AutoOptimizeForLargeCells { get; set; }
