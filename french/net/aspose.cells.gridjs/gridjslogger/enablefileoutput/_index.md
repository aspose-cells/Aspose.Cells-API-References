## GridJsLogger.EnableFileOutput property

Obtient ou définit si les messages de journal doivent être écrits dans un fichier. La valeur par défaut est false. Vous devez appeler [`SetLogFile`](../setlogfile/) ou [`SetLogDirectory`](../setlogdirectory/) avant d'activer.

```csharp
public static bool EnableFileOutput { get; set; }
```
