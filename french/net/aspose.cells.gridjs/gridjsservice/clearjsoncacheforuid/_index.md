## GridJsService.ClearJsonCacheForUid method

Efface toutes les entrées du cache JSON appartenant à l'ID unique spécifié. Appelez ceci après avoir modifié le fichier source hors bande afin que la prochaine requête régénère le JSON.

```csharp
public void ClearJsonCacheForUid(string uid)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| uid | String | L'identifiant unique pour le cache de fichier. |
