## GridJsOptions.CacheImp field

Implémentation personnalisée pour le stockage du cache. Si vous souhaitez stocker le cache sous forme de flux, vous devez le définir et l'implémenter. Un hôte WebAssembly (IsWasm = true) doit le définir, car il n'y a pas de disque local pour le cache de fichiers par défaut.

```csharp
public GridCacheForStream CacheImp;
```
