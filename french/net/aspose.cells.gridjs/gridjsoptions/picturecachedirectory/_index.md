## GridJsOptions.PictureCacheDirectory property

Obtient/Définit le répertoire de cache pour les images. (cela prend effet lorsque GridJsWorkbook.CacheImp est null) Le chemin par défaut sera \"_piccache\" à l'intérieur du FileCacheDirectory.

public string PictureCacheDirectory { get; set; }
