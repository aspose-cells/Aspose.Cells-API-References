## GridJsOptions.IgnoreEmptyContent property

Obtient/Définit si l'on doit afficher la plage maximale qui comprend les données, le style, les cellules fusionnées et les formes. Si la dernière ligne ou colonne contient des cellules sans valeur ni formule mais avec un style personnalisé, alors nous n'afficherons pas cette ligne/colonne lorsque cette valeur est vraie. La valeur par défaut est vraie.

```csharp
public bool IgnoreEmptyContent { get; set; }
```
