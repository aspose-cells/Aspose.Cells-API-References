## GridJsOptions.IsWasm property

Obtient/Définit si GridJs s'exécute à l'intérieur d'un hôte WebAssembly de navigateur au lieu d'un processus serveur. Lorsque true, aucun chemin FileCacheDirectory / disque / thread d'interruption n'est utilisé, et le cache de fichiers doit provenir de CacheImp, car un hôte navigateur n'a pas de disque local. Il sélectionne les chemins de code à l'exécution, de sorte qu'un seul Aspose.Cells.GridJs.dll sert les deux hôtes. La valeur par défaut est false.

```csharp
public bool IsWasm { get; set; }
```
