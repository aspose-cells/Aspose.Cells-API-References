## GridJsOptions.IslimitShapeOrImage property

Obtient/Définit si la limitation du nombre total de formes/images affichées dans une feuille de calcul est activée, si réglé sur true, GridJs limitera le nombre total de formes ou d'images affichées dans une feuille de calcul à MaxShapeOrImageCount. La valeur par défaut est true.

```csharp
public bool IslimitShapeOrImage { get; set; }
```
