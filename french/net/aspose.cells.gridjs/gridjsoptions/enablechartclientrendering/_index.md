## GridJsOptions.EnableChartClientRendering property

Obtient/Définit s'il faut activer le rendu de graphiques côté client. Si défini sur false, GridJs n'émettra que des images/formes de graphiques et ne nécessitera pas de rendu côté client. La valeur par défaut est true.

```csharp
public bool EnableChartClientRendering { get; set; }
```
