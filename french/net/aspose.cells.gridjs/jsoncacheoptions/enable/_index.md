## JsonCacheOptions.Enable property

Obtient/Définit si la mise en cache JSON est activée pour une réponse plus rapide. Lorsqu'elle est activée, GridJs mettra en cache le JSON généré et le réutilisera pour les requêtes suivantes. La valeur par défaut est false. Remarque : vous devez définir Implementation pour utiliser un stockage de cache personnalisé.

```csharp
public bool Enable { get; set; }
```
