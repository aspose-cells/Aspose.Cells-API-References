L'espace de noms **Aspose.Cells.LowCode** fournit un ensemble d'API simples et faciles à utiliser pour les opérations les plus fréquemment utilisées de manière low‑code.

## Classes

| Classe | Description |
| --- | --- |
| [AbstractLowCodeLoadOptionsProvider](./abstractlowcodeloadoptionsprovider/) | Implémentation pour fournir plusieurs options de chargement pour les processus qui utilisent plusieurs entrées (comme les fichiers de modèle). |
| [AbstractLowCodeProtectionProvider](./abstractlowcodeprotectionprovider/) | Implémentation pour fournir les paramètres de protection. |
| [AbstractLowCodeSaveOptionsProvider](./abstractlowcodesaveoptionsprovider/) | Implémentation pour fournir plusieurs options d'enregistrement pour les processus qui nécessitent plusieurs sorties. Par exemple, la fonctionnalité [`SpreadsheetSplitter`](../aspose.cells.lowcode/spreadsheetsplitter/) nécessite plusieurs destinations pour enregistrer les fichiers découpés. |
| [HtmlConverter](./htmlconverter/) | Convertisseur pour la conversion entre les fichiers html (html ou mht) et d'autres formats de fichiers de feuille de calcul. |
| [ImageConverter](./imageconverter/) | Convertisseur pour convertir le fichier de modèle en images. |
| [JsonConverter](./jsonconverter/) | Convertisseur pour la conversion entre la structure de données json et d'autres formats de fichiers de feuille de calcul. |
| [LowCodeHtmlSaveOptions](./lowcodehtmlsaveoptions/) | Options pour enregistrer le html de manière low‑code. |
| [LowCodeImageSaveOptions](./lowcodeimagesaveoptions/) | Options pour enregistrer l'image de manière low‑code. |
| [LowCodeLoadOptions](./lowcodeloadoptions/) | Options pour charger le fichier de modèle. |
| [LowCodeMergeOptions](./lowcodemergeoptions/) | Options pour fusionner plusieurs fichiers de modèle en un seul. |
| [LowCodePdfSaveOptions](./lowcodepdfsaveoptions/) | Options pour enregistrer le pdf de manière low‑code. |
| [LowCodeSaveOptions](./lowcodesaveoptions/) | Options pour enregistrer les résultats générés de manière low‑code. |
| [LowCodeSaveOptionsProviderOfAssembling](./lowcodesaveoptionsproviderofassembling/) | Implémentation pour fournir des options d'enregistrement qui enregistrent les parties découpées dans des fichiers et le chemin du fichier résultant est nommé comme (il peut contenir des répertoires) : [`PathHeader`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/pathheader/)+[`SheetPrefix`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/sheetprefix/)+SheetIndex(ou SheetName) +[`SplitPartPrefix`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/splitpartprefix/)+SplitPartIndex+[`PathTail`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/pathtail/). |
| [LowCodeSaveOptionsProviderOfPlaceHolders](./lowcodesaveoptionsproviderofplaceholders/) | Implémentation pour fournir des options d'enregistrement qui enregistrent les parties découpées dans des fichiers et le chemin du fichier résultant est défini avec des espaces réservés. |
| [LowCodeSplitOptions](./lowcodesplitoptions/) | Options pour diviser la feuille de calcul. |
| [PdfConverter](./pdfconverter/) | Convertisseur pour convertir le fichier modèle en pdf. |
| [SplitPartInfo](./splitpartinfo/) | Représente les informations d'une entrée/sortie pour plusieurs entrées/sorties, comme la page actuelle à rendre lors de la conversion d'une feuille de calcul en image. |
| [SpreadsheetConverter](./spreadsheetconverter/) | Convertisseur pour la conversion entre différents formats de fichiers de feuilles de calcul, tels que xls, xlsx, xlsb, spreadsheet ml... |
| [SpreadsheetLocker](./spreadsheetlocker/) | API low-code pour verrouiller le fichier de feuille de calcul. |
| [SpreadsheetMerger](./spreadsheetmerger/) | Fusionne plusieurs fichiers modèle en un seul. |
| [SpreadsheetSplitter](./spreadsheetsplitter/) | Divise le fichier de feuille de calcul en plusieurs parties. |
| [TextConverter](./textconverter/) | Convertisseur pour la conversion entre les formats basés sur du texte (csv, tsv, dif...) et d'autres formats de fichiers de feuilles de calcul. |
