## GridPivotTable.RefreshData method

Actualise les données et les paramètres du pivottable à partir de sa source de données.

```csharp
public void RefreshData()
```

### Remarques

Nous collecterons les données de la source de données vers un cache de tableau croisé, puis calculerons les données du cache dans les cellules. Cette méthode n'est utilisée que pour rassembler toutes les données dans un cache de tableau croisé.
