## GridHyperlink.ImageURL property

Obtenir ou définir l'URL de l'image pour le lien, il n'existe aucune propriété imageurl dans l'hyperlien, donc on utilise en fait TextToDisplay pour enregistrer cette valeur, TextToDisplay sera défini à &lt;img src=value &gt; ce qui modifiera la valeur de TextToDisplay.

```csharp
public string ImageURL { get; set; }
```
