## GridImageOrPrintOptions.VerticalResolution property

Obtient ou définit la résolution verticale des images générées, en points par pouce. S'applique à la méthode de génération d'images sauf pour les images au format EMF.

```csharp
public int VerticalResolution { get; set; }
```

### Remarques

La valeur par défaut est 96.
