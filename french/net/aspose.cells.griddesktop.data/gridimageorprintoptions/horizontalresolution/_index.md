## GridImageOrPrintOptions.HorizontalResolution property

Obtient ou définit la résolution horizontale des images générées, en points par pouce. S'applique à la méthode de génération d'images sauf pour les images au format EMF.

```csharp
public int HorizontalResolution { get; set; }
```

### Remarques

La valeur par défaut est 96.
