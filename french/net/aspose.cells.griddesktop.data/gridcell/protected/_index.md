## GridCell.Protected property

Indique si la cellule est protégée. Si la valeur est "true", l'utilisateur ne peut pas modifier la cellule via l'interface utilisateur. Cet attribut n'a aucun rapport avec la propriété Style.CellLocked et ne sera pas enregistré dans le fichier lors de l'exportation des données de la grille. La valeur par défaut est "false".

```csharp
public bool Protected { get; set; }
```
