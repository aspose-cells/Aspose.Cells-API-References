## PdfZoomBehavior enumeration

Spécifie le mode d'affichage initial lorsque le document PDF généré est ouvert.

```csharp
public enum PdfZoomBehavior
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Utilise le comportement par défaut du visualiseur PDF. |
| ZoomFactor | `1` | Ouvre le document à un pourcentage de zoom spécifique. |
| FitPage | `2` | Adapte la page entière à la fenêtre du visualiseur. |
| FitWidth | `3` | Adapte la largeur de la page à la fenêtre du visualiseur. |
| FitHeight | `4` | S'adapte à la hauteur de la page dans la fenêtre du visualiseur. |
