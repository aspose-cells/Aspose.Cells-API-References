## WorkbookRender.CustomPrint method

Le client peut contrôler les paramètres de page de l’imprimante lors de l’impression de chaque page à l’aide de cette fonction.

```csharp
public int CustomPrint(bool nextPageAfterPrint, PrintPageEventArgs printPageEventArgs)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| nextPageAfterPrint | Boolean | Si vrai, l'imprimante passera à la page suivante après avoir imprimé la page actuelle |
| printPageEventArgs | PrintPageEventArgs | System.Drawing.Printing.PrintPageEventArgs |

### Valeur de retour

Index de la page suivante indirect, basé sur zéro
