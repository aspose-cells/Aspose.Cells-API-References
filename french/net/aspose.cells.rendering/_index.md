L'espace de noms **Aspose.Cells.Rendering** fournit des classes pour le rendu d'images et de PDF.

## Classes

| Classe | Description |
| --- | --- |
| [CustomRenderSettings](./customrendersettings/) | Représente les paramètres personnalisés pendant le rendu. |
| [DrawObject](./drawobject/) | DrawObject sera initialisé et renvoyé lors du rendu. |
| [DrawObjectEventHandler](./drawobjecteventhandler/) | Interface pour obtenir DrawObject et Bound lors du rendu. |
| [ImageOrPrintOptions](./imageorprintoptions/) | Permet de spécifier des options lors du rendu d'une feuille de calcul en images, de l'impression d'une feuille de calcul ou du rendu d'un graphique en image. |
| [PageEndSavingArgs](./pageendsavingargs/) | Les informations d'une page terminent le processus d'enregistrement. |
| [PageSavingArgs](./pagesavingargs/) | Informations pour le processus d'enregistrement d'une page. |
| [PageStartSavingArgs](./pagestartsavingargs/) | Informations pour le processus de démarrage de l'enregistrement d'une page. |
| [PdfBookmarkEntry](./pdfbookmarkentry/) | PdfBookmarkEntry est une entrée dans le signet PDF. Si la propriété Text de l'instance actuelle est null ou \"\", l'instance actuelle sera masquée et les enfants seront insérés au même niveau. |
| [RenderingFont](./renderingfont/) | Police pour le rendu. |
| [RenderingWatermark](./renderingwatermark/) | Filigrane pour le rendu. |
| [SheetPrintingPreview](./sheetprintingpreview/) | Aperçu d'impression de la feuille de calcul. |
| [SheetRender](./sheetrender/) | Représente un rendu de feuille de calcul qui peut rendre la feuille de calcul en diverses images telles que (BMP, PNG, JPEG, TIFF...). Le constructeur de cette classe doit être utilisé après la modification de la configuration de page, du style de cellule. |
| [SheetSet](./sheetset/) | Décrit un ensemble de feuilles. |
| [SvgImageOptions](./svgimageoptions/) | Options pour générer une image Svg. |
| [WorkbookPrintingPreview](./workbookprintingpreview/) | Aperçu d'impression du classeur. |
| [WorkbookRender](./workbookrender/) | Représente un rendu de classeur. Le constructeur de cette classe doit être utilisé après la modification de la configuration de page, du style de cellule. |
