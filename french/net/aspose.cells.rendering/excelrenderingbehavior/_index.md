## ExcelRenderingBehavior enumeration

Spécifie les comportements de rendu spécifiques à Excel à appliquer lors du rendu d'un classeur.

```csharp
[Flags]
public enum ExcelRenderingBehavior
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | N’applique pas les comportements de rendu spécifiques à Excel. |
| CellTextLengthLimit | `1` | Applique la limite de longueur de texte des cellules d’Excel. Par exemple, Excel ne restitue que les 1024 premiers caractères dans une cellule non renvoyée à la ligne. |
| All | `FFFFFFFFFFFFFFFF` | Applique tous les comportements de rendu spécifiques à Excel pris en charge. |
