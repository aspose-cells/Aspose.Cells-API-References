## HtmlParagraphLayoutMode enumeration

Spécifie comment les éléments HTML &lt;p&gt; sont rendus lors du chargement du HTML.

```csharp
public enum HtmlParagraphLayoutMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Normal | `0` | Traitez &lt;p&gt; à l'intérieur de &lt;td&gt; comme du contenu en ligne dans une seule cellule. |
| AsRow | `1` | Commence une nouvelle ligne pour chaque élément &lt;p&gt;. |
