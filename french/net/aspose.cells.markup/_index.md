L'espace de noms **Aspose.Cells.Markup** contient des classes qui représentent les sémantiques définies par le client dans un document : balises intelligentes, XML personnalisé et d'autres balises de balisage.

## Classes

| Classe | Description |
| --- | --- |
| [CustomXmlPart](./customxmlpart/) | Représente une partie de stockage de données XML personnalisées (données XML personnalisées dans un package). |
| [CustomXmlPartCollection](./customxmlpartcollection/) | Représente une partie de stockage de données XML personnalisées (données XML personnalisées dans un package). |
| [SmartTag](./smarttag/) | Représente une balise intelligente. |
| [SmartTagCollection](./smarttagcollection/) | Représente toutes les balises intelligentes dans la cellule. |
| [SmartTagOptions](./smarttagoptions/) | Représente les options de la balise intelligente. |
| [SmartTagProperty](./smarttagproperty/) | Représente la propriété de la balise intelligente de la cellule. |
| [SmartTagPropertyCollection](./smarttagpropertycollection/) | Représente toutes les propriétés de la balise intelligente de la cellule. |
| [SmartTagSetting](./smarttagsetting/) | Représente tous les objets [`SmartTagCollection`](../aspose.cells.markup/smarttagcollection/) dans la feuille de calcul. |
