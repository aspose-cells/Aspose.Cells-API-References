## Validation.ClientValidationFunction property

Obtient ou définit le nom de la fonction JavaScript de validation côté client.

```csharp
public string ClientValidationFunction { get; set; }
```

### Remarques

Utilisez la propriété ClientValidationFunction pour spécifier le nom de la fonction de validation côté client. La fonction doit être déclarée sous cette forme : function customValicationFunction(source, value) Le paramètre "source" est l'objet cellule. Le paramètre "value" est la valeur chaîne d'une cellule à vérifier. La fonction doit renvoyer true si la valeur est valide.
