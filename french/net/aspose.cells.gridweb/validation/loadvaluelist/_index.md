## Validation.LoadValueList method

Charge la liste de valeurs à partir d'un objet DataView. Vous pouvez spécifier le champ de valeur et le champ de texte du DataView. Chaque paire valeur et texte sera combinée en une seule chaîne, séparée par une virgule.

```csharp
public void LoadValueList(DataView view, string valueField, string textField, bool valuePrefixText)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| vue | DataView | L'objet DataView. |
| valueField | String | Le nom du champ de valeur. |
| textField | String | Le nom du champ de texte. |
| valuePrefixText | Boolean | Indique s'il faut ajouter un préfixe de valeur à chaque texte affiché. |
