## MainWeb.ShowCellEditBox property

Indique si Gridweb affiche la barre d'outils de zone de texte comme dans MS-EXCEL. Si activé, une zone de texte pour la cellule actuelle sera affichée dans Gridweb. Si nous activons cette fonctionnalité, nous devons importer la bibliothèque jquery js dans vos fichiers aspx pour prendre en charge cette nouvelle fonctionnalité. Toutes les dernières versions de jquery sont compatibles, etc.

```csharp
public bool ShowCellEditBox { get; set; }
```
