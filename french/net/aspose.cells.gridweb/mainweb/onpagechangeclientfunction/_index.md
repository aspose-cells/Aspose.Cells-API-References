## MainWeb.OnPageChangeClientFunction property

Obtient ou définit la fonction côté client à appeler après le changement d'index de page. Ne prend effet que lorsque EnablePaging est true. La fonction client doit être déclarée ainsi : function MyOnPageChange(index) { console.log(\"current page is:\"+index); }Note : Vous pouvez utiliser le pointeur \"this\" dans la fonction client pour référencer le contrôle de grille qui déclenche l'événement.

```csharp
public string OnPageChangeClientFunction { get; set; }
```
