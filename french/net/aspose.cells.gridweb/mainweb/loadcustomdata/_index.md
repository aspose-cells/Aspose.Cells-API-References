## MainWeb.LoadCustomData event

Se déclenche lorsque le SessionMode du contrôle est défini sur Custom et doit charger les données de la feuille. Vous pouvez gérer cet événement en mode Session personnalisé pour charger les données de la feuille depuis un fichier ou une base de données.

```csharp
public event WorkbookEventHandler LoadCustomData;
```
