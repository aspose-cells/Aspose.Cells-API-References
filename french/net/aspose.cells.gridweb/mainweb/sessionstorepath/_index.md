## MainWeb.SessionStorePath property

Obtient ou définit le chemin de stockage du cache de session lorsque le mode de session est File ou ViewState, etc. : gridweb.SessionStorePath=\"c:/mytempdir/session\"; alors les données de session seront stockées dans c:/mytempdir/session

public string SessionStorePath { get; set; }
