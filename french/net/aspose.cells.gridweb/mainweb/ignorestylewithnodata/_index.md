## MainWeb.IgnoreStyleWithNoData property

Obtient ou définit si GridWeb ignore l'affichage des lignes ou colonnes qui ne contiennent pas de valeurs de cellule mais qui sont tout de même stylisées. Si la valeur est true, les performances seront meilleures. La valeur par défaut est false, ce qui signifie que si la dernière ligne/colonne consécutive n'a pas de valeurs de cellule mais est stylisée, nous les afficherons quand même. Cette option n'est valable que lorsque EnableAsync est false. Cette option n'a aucun effet lorsque EnableAsync est true, ce qui signifie que GridWeb affichera toutes les lignes/colonnes avec style.

```csharp
public bool IgnoreStyleWithNoData { get; set; }
```
