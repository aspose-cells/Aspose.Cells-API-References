## MainWeb.OnCellErrorClientFunction property

Obtient ou définit le nom de la fonction côté client à appeler lorsqu'une validation de cellule échoue. La fonction client doit être déclarée ainsi : function MyOnCellError(cell) { alert(this.getCellValueByCell(cell)); } Note : Vous pouvez utiliser le pointeur "this" dans la fonction client pour référencer le contrôle de grille qui déclenche l'événement.

```csharp
public string OnCellErrorClientFunction { get; set; }
```
