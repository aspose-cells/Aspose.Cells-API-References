## MainWeb.OnShapeSelectedClientFunction property

Obtient ou définit la fonction côté client à appeler lorsqu'une forme est sélectionnée. La fonction client doit être déclarée ainsi : function MyOnSelectShape(shape) { var name=shape.getAttribute(\"namevalue\") var text=shape.getAttribute(\"textvalue\") var value=shape.getAttribute(\"controlvalue\") var type=shape.getAttribute(\"msotype\") }Note : Vous pouvez utiliser le pointeur \"this\" dans la fonction client pour référencer le contrôle de grille qui déclenche l'événement.

```csharp
public string OnShapeSelectedClientFunction { get; set; }
```
