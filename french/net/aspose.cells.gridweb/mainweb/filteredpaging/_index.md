## MainWeb.FilteredPaging property

Obtient ou définit si la pagination après filtrage des données est activée, cela prendra effet lorsque EnablePaging est true.

```csharp
public bool FilteredPaging { get; set; }
```

### Remarques

Lorsque défini sur vrai, le contrôle paginera en fonction des données filtrées, la valeur par défaut est false.
