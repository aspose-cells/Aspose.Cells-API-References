## MainWeb.OnDoubleClickCellClientFunction property

Obtient ou définit la fonction côté client à appeler lorsqu'une cellule est double-cliquée. La fonction client doit être déclarée ainsi : function MyOnDoubleClickCell(cell) { this.setCellValueByCell(cell, \"test\"); }Note : Vous pouvez utiliser le pointeur \"this\" dans la fonction client pour référencer le contrôle de grille qui déclenche l'événement.

public string OnDoubleClickCellClientFunction { get; set; }
