## MainWeb.ColumnDeleting event

Se produit lorsque l'utilisateur tente de supprimer une colonne depuis le menu côté client. Vous pouvez gérer cet événement et définir le paramètre cancel sur True pour annuler l'opération de suppression.

```csharp
public event RowColumnEventHandler ColumnDeleting;
```
