## MainWeb.OnCellUnselectedClientFunction property

Obtient ou définit la fonction côté client à appeler lorsqu'une cellule est désélectionnée. La fonction client doit être déclarée ainsi : function MyOnUnselectCell(cell) { this.setCellValueByCell(cell, "test"); } Note : Vous pouvez utiliser le pointeur "this" dans la fonction client pour référencer le contrôle de grille qui déclenche l'événement.

```csharp
public string OnCellUnselectedClientFunction { get; set; }
```
