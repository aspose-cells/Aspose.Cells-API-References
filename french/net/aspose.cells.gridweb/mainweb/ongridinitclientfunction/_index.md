## MainWeb.OnGridInitClientFunction property

Obtient ou définit le nom de la fonction côté client à appeler lorsque la grille est initialisée. La fonction client doit être déclarée ainsi : function MyOnGridInit(grid) { alert(\"The grid is initialized: \" + grid.id); }Note : Vous pouvez utiliser le pointeur \"this\" dans la fonction client pour référencer le contrôle de grille qui déclenche l'événement.

public string OnGridInitClientFunction { get; set; }
