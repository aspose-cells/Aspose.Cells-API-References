## MainWeb.EnableStyleDialogbox property

Obtient ou définit si la boîte de dialogue de style côté client est activée.

```csharp
public bool EnableStyleDialogbox { get; set; }
```

### Remarques

Lorsque définie sur true, l'utilisateur peut utiliser la boîte de dialogue de style pour définir le style d'une cellule en sélectionnant "Format Cell..." dans le menu contextuel.
