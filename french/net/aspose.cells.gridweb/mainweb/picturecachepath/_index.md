## MainWeb.PictureCachePath property

Obtient ou définit le chemin de stockage des images pour le classeur, toutes les formes et images seront stockées dans ce répertoire, le chemin par défaut est acwcache sous le répertoire de base de l'application actuelle ; les utilisateurs doivent mettre en place un service planifié pour nettoyer les fichiers dont la durée de session est expirée.

```csharp
public static string PictureCachePath { get; set; }
```
