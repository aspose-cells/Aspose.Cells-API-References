## MainWeb.OnAjaxCallFinishedClientFunction property

Obtient ou définit le nom de la fonction côté client à appeler lorsque l'appel ajax est terminé. La fonction client doit être déclarée ainsi : function GridAjaxcallFinished() { alert(this.id+" ajaxcall finished "); } Note : Vous pouvez utiliser le pointeur "this" dans la fonction client pour référencer le contrôle de grille qui déclenche l'événement.

public string OnAjaxCallFinishedClientFunction { get; set; }
