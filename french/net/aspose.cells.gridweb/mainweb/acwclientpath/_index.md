## MainWeb.ACWClientPath property

Obtient ou définit le chemin web des fichiers script/image du contrôle. Par exemple : "http://localhost/acw_client". Vous pouvez également définir cette valeur dans le fichier web.config. Ajoutez cette section à la section `<configuration>` :`<appSettings>``<add key="aspose.cells.gridweb.acw_client_path" value="/acw_client/" />``</appSettings>`

public string ACWClientPath { get; set; }
