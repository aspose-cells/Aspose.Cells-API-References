## MainWeb.RowDeleting event

Se produit lorsque l'utilisateur tente de supprimer une ligne depuis le menu côté client. Vous pouvez gérer cet événement et lancer une exception RejectDeleteException pour annuler l'opération de suppression.

```csharp
public event RowColumnEventHandler RowDeleting;
```
