## MainWeb.EnablePaging property

Obtient ou définit si le mode de pagination du contrôle est activé.

```csharp
public bool EnablePaging { get; set; }
```

### Remarques

Lorsque défini sur true, le contrôle affichera PageSize lignes de données à la fois, et affichera le sélecteur de page dans la barre d'onglets.
