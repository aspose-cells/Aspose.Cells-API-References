## MainWeb.EnableDoubleClickEvent property

Obtient ou définit si l'événement double-clic côté client est activé.

```csharp
public bool EnableDoubleClickEvent { get; set; }
```

### Remarques

Lorsque défini sur true, le contrôle recevra les événements double-clic côté client et vous pourrez gérer ces événements côté serveur. Sinon, le contrôle ignorera tous les événements double-clic.
