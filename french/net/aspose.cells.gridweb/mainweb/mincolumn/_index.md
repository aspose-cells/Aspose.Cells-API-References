## MainWeb.MinColumn property

Obtient ou définit l'index minimal de colonne affichée (basé sur zéro) de la feuille Web. Le contrôle utilise la plus petite valeur entre MinColumn et la colonne minimale des données de la feuille.

```csharp
public int MinColumn { get; set; }
```

### Exemples

```csharp
[C#]
	// Crée une "fenêtre d'affichage" 4x4.
	GridWeb1.MinRow = 2;
	GridWeb1.MaxRow = 5;
	GridWeb1.MinColumn = 3;
	GridWeb1.MaxColumn = 6;

[Visual Basic]
	' Creates a 4x4 "display window".
	GridWeb1.MinRow = 2
	GridWeb1.MaxRow = 5
	GridWeb1.MinColumn = 3
	GridWeb1.MaxColumn = 6
```
