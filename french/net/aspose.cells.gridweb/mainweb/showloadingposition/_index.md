## MainWeb.ShowLoadingPosition property

Spécifie la position gauche, haut (en px) pour afficher la boîte de dialogue de chargement pendant le postback vers le serveur, etc. 100,200 signifie que la position gauche, haut de la boîte de dialogue de chargement est à 100px,200px.

public string ShowLoadingPosition { get; set; }
