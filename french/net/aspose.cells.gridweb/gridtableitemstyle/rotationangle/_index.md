## GridTableItemStyle.RotationAngle property

Obtient ou définit l'attribut Rotation.

```csharp
public short RotationAngle { get; set; }
```

### Remarques

0 : Non tourné.

255 : De haut en bas.

-90: Downward.

90 : Vers le haut.

Vous pouvez définir 255 ou une valeur comprise entre -90 et 90.
