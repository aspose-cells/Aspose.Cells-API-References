## GridTableItemStyle.IsLocked property

Obtient ou définit une valeur indiquant si une cellule peut être modifiée ou non lorsque sa feuille de calcul est protégée. Lorsque la feuille est protégée et que IsLocked est vrai, la cellule ne peut pas être modifiée. Lorsque la feuille est protégée et que IsLocked est faux, la cellule peut être modifiée.

```csharp
public bool IsLocked { get; set; }
```
