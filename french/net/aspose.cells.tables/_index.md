L'espace de noms **Aspose.Cells.Tables** contient des classes qui représentent les tables, lignes, cellules et leur mise en forme pour les fichiers de feuilles de calcul Excel.

## Classes

| Classe | Description |
| --- | --- |
| [ListColumn](./listcolumn/) | Représente une colonne dans une Table. |
| [ListColumnCollection](./listcolumncollection/) | Représente une liste de tous les objets [`ListColumn`](../aspose.cells.tables/listcolumn/) dans la table. |
| [ListObject](./listobject/) | Représente une table dans une feuille de calcul. |
| [ListObjectCollection](./listobjectcollection/) | Représente une collection d'objets [`ListObject`](../aspose.cells.tables/listobject/) dans la feuille de calcul. |
| [TableStyle](./tablestyle/) | Représente le style de la table. |
| [TableStyleCollection](./tablestylecollection/) | Représente tous les styles de table personnalisés. |
| [TableStyleElement](./tablestyleelement/) | Représente l'élément du style de table. |
| [TableStyleElementCollection](./tablestyleelementcollection/) | Représente tous les éléments du style de table. |
| [TableToRangeOptions](./tabletorangeoptions/) | Représente les options lors de la conversion d'une table en plage. |
## Énumération

| [TableStyleType](./tablestyletype/) | Représente le type de style de table intégré. |
| [TotalsCalculation](./totalscalculation/) | Détermine le type de calcul dans la ligne Totaux de la colonne de liste. |
