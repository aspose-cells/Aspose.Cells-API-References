## PivotShowValuesAsType enumeration

Represents the calculation type for the "Show Values As" feature of pivot field values.

```csharp
public enum PivotShowValuesAsType
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Normal | `0` | Represents raw value, no custom calculation. |
| DifferenceFrom | `1` | Shows the value as the difference from a specified base item. |
| PercentageOf | `2` | Shows the value as a percentage of a specified base item. |
| PercentageDifferenceFrom | `3` | Shows the value as percentage difference from a specified base item. |
| RunningTotalIn | `4` | Shows the value as a running total along the specified base field. |
| PercentageOfRow | `5` | Shows the value as percentage of the row total. |
| PercentageOfColumn | `6` | Shows the value as percentage of the column total. |
| PercentageOfTotal | `7` | Shows the value as percentage of the grand total. |
| Index | `8` | Index calculation: (Cell Value × Grand Total of Grand Totals) / (Row Grand Total × Column Grand Total). |
| PercentageOfParentRowTotal | `9` | Shows the value as percentage of its parent row item total. |
| PercentageOfParentColumnTotal | `10` | Shows the value as percentage of its parent column item total. |
| PercentageOfParentTotal | `11` | Shows the value as percentage of its parent item total in the specified base field. |
| PercentageOfRunningTotalIn | `12` | Shows the value as percentage running total along the specified base field. |
| RankSmallestToLargest | `13` | Ranks values from smallest to largest within the specified base field. |
| RankLargestToSmallest | `14` | Ranks values from largest to smallest within the specified base field. |
