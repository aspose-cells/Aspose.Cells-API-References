## PivotTable.MoveItem method

Move one item up or down.

```csharp
public void MoveItem(PivotFieldType region, string[] nodes, bool absolute, int offset)
```

| Parameter | Type | Description |
| --- | --- | --- |
| region | PivotFieldType | The region. Only for row or column. |
| nodes | String[] | The item. |
| absolute | Boolean | Indicates whether offset is absolute position. |
| offset | Int32 | If absolute is true :0 move to beginning, -1 move to End, others mean absolute position; else offset is a relative position. |
