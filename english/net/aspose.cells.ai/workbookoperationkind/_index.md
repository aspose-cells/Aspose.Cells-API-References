## WorkbookOperationKind enumeration

The operations the intent router may select. Used to restrict routing scope and to name the operation chosen by ProcessAsync.

```csharp
public enum WorkbookOperationKind
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Summarize | `0` | Summarizes a workbook or region. |
| Ask | `1` | Answers a question about a workbook. |
| Inspect | `2` | Checks a workbook for formula, data and structure issues. |
| ExplainFormula | `3` | Explains the formula in a target cell. |
| GenerateFormula | `4` | Generates a formula in a target cell. |
| Edit | `5` | Edits the workbook within writable locations. |
| Compare | `6` | Compares two workbooks. |
