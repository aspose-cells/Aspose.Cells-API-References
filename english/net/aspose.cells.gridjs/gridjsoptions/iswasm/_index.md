## GridJsOptions.IsWasm property

Gets/Sets whether GridJs runs inside a browser WebAssembly host instead of a server process. When true, no FileCacheDirectory / disk / interrupt-thread path is used, and the file cache must come from CacheImp, because a browser host has no local disk. It selects code paths at runtime, so one Aspose.Cells.GridJs.dll serves both hosts. the default value is false.
