## JsonCacheOptions.Enable property

Gets/Sets whether to enable JSON caching for faster response. When enabled, GridJs will cache the generated JSON and reuse it for subsequent requests. The default value is false. Note: You need to set Implementation to use custom cache storage.

public bool Enable { get; set; }
