## Config.IsWasm property

Gets/Sets whether GridJs runs inside a browser WebAssembly host instead of a server process. When true, no FileCacheDirectory / disk / interrupt-thread path is used and the file cache must come from GridJsOptions.CacheImp. GridJsOptions.IsWasm sets this when the GridJs service is constructed, so one Aspose.Cells.GridJs.dll serves both hosts. the default value is false.
