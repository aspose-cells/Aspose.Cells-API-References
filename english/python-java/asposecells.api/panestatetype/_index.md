## PaneStateType enumeration

Utility class containing constants. Represents state of the sheet's pane.

## Values

| Name | Description |
| --- | --- |
| FROZEN | Panes are frozen, but were not before being frozen. |
| FROZEN_SPLIT | Panes are frozen and were split before being frozen. |
| SPLIT | Panes are split, but not frozen. |
| NORMAL | Panes are not frozen and not split. |
