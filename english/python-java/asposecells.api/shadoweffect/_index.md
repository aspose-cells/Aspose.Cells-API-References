## ShadowEffect class

This class specifies the shadow effect of the chart element or shape.

## Properties

| Name | Type | Description |
| --- | --- | --- |
| [PresetType](#presettype) | int | Gets and sets the preset shadow type of the shadow. The value of the property is PresetShadowType integer constant. |
| [Color](#color) | CellsColor | Gets and sets the color of the shadow. |
| [Transparency](#transparency) | float | Gets and sets the degree of transparency of the shadow. Range from 0.0 (opaque) to 1.0 (clear). |
| [Size](#size) | float | Gets and sets the size of the shadow. Range from 0 to 2.0. Meaningless in inner shadow. |
| [Blur](#blur) | float | Gets and sets the blur of the shadow. Range from 0 to 100 points. |
| [Angle](#angle) | float | Gets and sets the lighting angle. Range from 0 to 359.9 degrees. |
| [Distance](#distance) | float | Gets and sets the distance of the shadow. Range from 0 to 200 points. |
