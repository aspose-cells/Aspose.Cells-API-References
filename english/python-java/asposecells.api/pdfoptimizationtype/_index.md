## PdfOptimizationType enumeration

Utility class containing constants. Specifies a type of optimization.

## Values

| Name | Description |
| --- | --- |
| STANDARD | High print quality |
| MINIMUM_SIZE | File size is more important than print quality Font Arial and Times New Roman with characters 32-127 will not be embedded in pdf. Border lines are optimized for smaller file size. |
