The API provides comprehensive support for Excel file formats including XLS, XLSX, XLSM, CSV, and ODS, as well as advanced features such as formulas, charts, pivot tables, and conditional formatting. All classes are grouped under the asposecells.api namespace, giving a clear hierarchical structure for accessing workbook, worksheet, cell, and styling objects. Developers can integrate these capabilities into Python applications while leveraging the underlying Java engine for high performance.
