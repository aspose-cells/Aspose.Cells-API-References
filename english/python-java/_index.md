The API provides classes for reading, writing, and modifying Excel workbooks, supporting formats such as XLS, XLSX, CSV, ODS, and PDF. Developers can programmatically manage worksheets, cells, charts, formulas, and styling, as well as perform data import/export and advanced calculations. All functionality is exposed through the asposecells.api namespace, which groups the core classes for easy discovery and integration.
