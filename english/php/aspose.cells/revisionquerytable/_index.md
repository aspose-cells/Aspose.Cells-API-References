## RevisionQueryTable class

Represents a revision of a query table field change.

## Properties

| Name | Type | Description |
| --- | --- | --- |
| [Type](#type) | Number | Represents the type of the revision. The value of the property is RevisionType integer constant. |
| [CellArea](#cellarea) | CellArea | Gets the location of the affected query table. |
| [FieldId](#fieldid) | Number | Gets ID of the specific query table field that was removed. |
| [Worksheet](#worksheet) | Worksheet | Gets the worksheet. |
| [Id](#id) | Number | Gets the number of this revision. Zero means this revision does not contains id. |
