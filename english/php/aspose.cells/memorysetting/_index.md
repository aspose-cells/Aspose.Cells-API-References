## MemorySetting enumeration

Utility class containing constants. Memory usage options.

## Values

| Name | Description |
| --- | --- |
| NORMAL | Default option for cells model. This option is applied for all versions. |
| MEMORY_PREFERENCE | Memory performance preferrable. With this option the data will be held in compact format so for common scenarios it may give lower memory cost. However, this option also may degrade R/W performance a bit in some special cases. This option is available since v 8.0.0. |
| FILE_CACHE |  |
