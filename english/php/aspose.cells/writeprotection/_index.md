## WriteProtection class

Specifies write protection settings for a workbook.

## Properties

| Name | Type | Description |
| --- | --- | --- |
| [Author](#author) | String | Gets and sets the author. |
| [RecommendReadOnly](#recommendreadonly) | boolean | Indicates if the Read Only Recommended option is selected. |
| [IsWriteProtected](#iswriteprotected) | boolean | Indicates whether this workbook is write protected. |
| [Password](#password) | String | Sets the protected password to modify the file. |

## Methods

| Name | Description |
| --- | --- |
| [validatePassword](#validatepassword) | Returns true if the specified password is the same as the write-protection password the file was protected with. |

### WriteProtection.Author property {#author}

**Type:** String

### WriteProtection.RecommendReadOnly property {#recommendreadonly}

**Type:** boolean

### WriteProtection.IsWriteProtected property {#iswriteprotected}

### validatePassword(password) {#validatepassword}
