## ControlMatchEntryType enumeration

Utility class containing constants. Represents how a ListBox or ComboBox searches its list as the user types.

## Values

| Name | Description |
| --- | --- |
| FIRST_LETTER | The control searches for the next entry that starts with the character entered. Repeatedly typing the same letter cycles through all entries beginning with that letter. |
| COMPLETE | As each character is typed, the control searches for an entry matching all characters entered. |
| NONE | The list will not be searched when characters are typed. |
