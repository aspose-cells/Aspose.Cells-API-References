## ConditionalFormattingIcon class

Represents the custom icon of conditional formatting rule.

## Properties

| Name | Type | Description |
| --- | --- | --- |
| [ImageData](#imagedata) | byte[] | Gets the icon set data. |
| [Type](#type) | Number | Gets and sets the icon set type. The value of the property is IconSetType integer constant. |
| [Index](#index) | Number | Gets and sets the icon's index in the icon set. |

## Methods

| Name | Description |
| --- | --- |
| [getIconImageData](#geticonimagedata) | Get the icon set data |
| [getImageData](#getimagedata) | Gets the image data with the setting of cell. |

### ConditionalFormattingIcon.ImageData property {#imagedata}

Gets the icon set data.

**Type:** byte[]

### ConditionalFormattingIcon.Type property {#type}

Gets and sets the icon set type. The value of the property is IconSetType integer constant.

**Type:** Number

### ConditionalFormattingIcon.Index property {#index}

Gets and sets the icon's index in the icon set.

**Type:** Number

### getIconImageData(type, index) {#geticonimagedata}

Get the icon set data

| Parameter | Type | Description |
| --- | --- | --- |
| type | Number | A IconSetType value. icon's type |
| index | Number | icon's index |

### getImageData(cell) {#getimagedata}

Gets the image data with the setting of cell.

| Parameter | Type | Description |
| --- | --- | --- |
| cell | Cell | The setting of cell. |

**Returns:** Returns the image data of icon.
