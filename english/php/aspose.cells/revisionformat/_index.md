## RevisionFormat class

Represents a revision record of information about a formatting change.

## Properties

| Name | Type | Description |
| --- | --- | --- |
| [Type](#type) | Number | Gets the type of revision. The value of the property is RevisionType integer constant. |
| [Areas](#areas) | CellArea[] | The range to which this formatting was applied. |
| [Style](#style) | Style | Gets the applied style. |
| [Worksheet](#worksheet) | Worksheet | Gets the worksheet. |
| [Id](#id) | Number | Gets the number of this revision. Zero means this revision does not contains id. |
