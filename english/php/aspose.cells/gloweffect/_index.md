## GlowEffect class

This class specifies a glow effect, in which a color blurred outline is added outside the edges of the object.

## Properties

| Name | Type | Description |
| --- | --- | --- |
| [Color](#color) | CellsColor | Gets the color of the glow effect. |
| [Radius](#radius) | Number | Gets and sets the radius of the glow, in unit of points. NOTE: This member is now obsolete. Instead, please use GlowEffe |
| [Size](#size) | Number | Gets and sets the radius of the glow, in unit of points. |
| [Transparency](#transparency) | Number | Gets and sets the degree of transparency of the glow effect. Range from 0.0 (opaque) to 1.0 (clear). |

### GlowEffect.Color property {#color}

Gets the color of the glow effect.

**Type:** CellsColor

### GlowEffect.Radius property {#radius}

Gets and sets the radius of the glow, in unit of points. NOTE: This member is now obsolete. Instead, please use GlowEffect.Size property. This property will be removed 6 months later since September 2016. Aspose apologizes for any inconvenience you may have experienced.

**Type:** Number

### GlowEffect.Size property {#size}

Gets and sets the radius of the glow, in unit of points.

**Type:** Number

### GlowEffect.Transparency property {#transparency}

Gets and sets the degree of transparency of the glow effect. Range from 0.0 (opaque) to 1.0 (clear).

**Type:** Number
