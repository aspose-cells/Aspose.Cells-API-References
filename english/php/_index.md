The API provides a comprehensive set of classes within the aspose.cells namespace, allowing manipulation of workbooks, worksheets, cells, charts, and formulas. Developers can work with a wide range of Excel file formats—including XLS, XLSX, CSV, and ODS—as well as export to PDF, HTML, and image formats. All functionality is accessed through the single aspose.cells namespace, simplifying integration into PHP projects via Java.
