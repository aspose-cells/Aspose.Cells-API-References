## ShowDropButtonType

Utility class containing constants. Specifies when to show the drop button

## Values

| Name | Description |
| --- | --- |
| NEVER | Never show the drop button. |
| FOCUS | Show the drop button when the control has the focus. |
| ALWAYS | Always show the drop button. |
