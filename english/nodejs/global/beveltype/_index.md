## BevelType

Utility class containing constants. Represents a preset for a type of bevel which can be applied to a shape in 3D.

## Values

| Name | Description |
| --- | --- |
| NONE | No bevel |
| ANGLE | Angle |
| ART_DECO | Art deco |
| CIRCLE | Circle |
| CONVEX | Convex |
| COOL_SLANT | Cool slant |
| CROSS | Cross |
| DIVOT | Divot |
| HARD_EDGE | Hard edge |
| RELAXED_INSET | Relaxed inset |
| RIBLET | Riblet |
| SLOPE | Slope |
| SOFT_ROUND | Soft round |
