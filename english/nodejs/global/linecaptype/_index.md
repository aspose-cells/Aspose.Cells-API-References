## LineCapType

Utility class containing constants. Represents the caps of a line

## Values

| Name | Description |
| --- | --- |
| SQUARE | Square protrudes by half line width. |
| ROUND | Rounded ends. |
| FLAT | Line ends at end point. |
| NONE | None cap |
