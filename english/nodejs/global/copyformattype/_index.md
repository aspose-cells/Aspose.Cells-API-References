## CopyFormatType

Utility class containing constants. Represents type of copying format when inserting rows.

## Values

| Name | Description |
| --- | --- |
| SAME_AS_ABOVE | Formats same as above row. |
| SAME_AS_BELOW | Formats same as below row. |
| CLEAR | Clears formatting. |
