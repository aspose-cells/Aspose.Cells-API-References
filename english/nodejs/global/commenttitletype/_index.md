## CommentTitleType

Utility class containing constants. Represents comment title type while rendering when comment is set to display at end of sheet.

## Values

| Name | Description |
| --- | --- |
| CELL | Represents comment title cell. |
| COMMENT | Represents comment title comment. |
| NOTE | Represents comment title note. |
| REPLY | Represents comment title reply. |
