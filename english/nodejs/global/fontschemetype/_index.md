## FontSchemeType

Utility class containing constants. Represents the scheme type of the font.

## Values

| Name | Description |
| --- | --- |
| NONE | None |
| MAJOR | Major scheme. |
| MINOR | Minor scheme. The font's name will be automatically changed with the language. |
