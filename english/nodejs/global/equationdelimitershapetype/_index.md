## EquationDelimiterShapeType

Utility class containing constants. This specifies the shape of delimiters in the delimiter object.

## Values

| Name | Description |
| --- | --- |
| CENTERED | The divider is centered around the entire height of its content. |
| MATCH | The divider is altered to exactly match their contents' height. |
