## EncryptionType

Utility class containing constants. Encryption Type. Only used by excel2003. We will encrypt 2007/2010 workbook using SHA AES the same as Excel does, and this EncryptionType will be ignored.

## Values

| Name | Description |
| --- | --- |
| XOR | XOR encryption algorithm. |
| COMPATIBLE | Office 97/2000 compatible. |
| ENHANCED_CRYPTOGRAPHIC_PROVIDER_V_1 | Enhanced encryption. |
| STRONG_CRYPTOGRAPHIC_PROVIDER | Strong encryption algorithm. |
