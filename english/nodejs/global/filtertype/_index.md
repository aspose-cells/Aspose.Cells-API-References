## FilterType

Utility class containing constants. The filter type.

## Values

| Name | Description |
| --- | --- |
| COLOR_FILTER | Filter by fill color of the cell. |
| CUSTOM_FILTERS | Custom filter type. |
| DYNAMIC_FILTER | Dynamic filter type. |
| MULTIPLE_FILTERS | When multiple values are chosen to filter by, or when a group of date values are chosen to filter by, this element groups those criteria together. |
| ICON_FILTER | Filter by icon of conditional formatting. |
| TOP_10 | Top 10 filter. |
| NONE | No filter. |
