## ChartTextDirectionType

Utility class containing constants. Represents the text direction type of the chart.

## Values

| Name | Description |
| --- | --- |
| HORIZONTAL | Horizontal direction type. |
| VERTICAL | Vertical direction type. |
| ROTATE_90 | Rotate 90 angle. |
| ROTATE_270 | Rotate 270 angle. |
| STACKED | Stacked text. |
