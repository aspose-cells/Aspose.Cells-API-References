## ChartLineFormattingType

Utility class containing constants. Represents line format type of chart line.

## Values

| Name | Description |
| --- | --- |
| AUTOMATIC | Represents automatic formatting type. |
| SOLID | Represents solid formatting type. |
| NONE | Represents none formatting type. |
| GRADIENT | Gradient |
