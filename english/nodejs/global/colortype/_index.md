## ColorType

Utility class containing constants. Represents all color type

## Values

| Name | Description |
| --- | --- |
| AUTOMATIC | Automatic color. |
| AUTOMATIC_INDEX | It's automatic color,but the displayed color depends the setting of the OS System. Not supported. |
| RGB | The RGB color. |
| INDEXED_COLOR | The color index in the color palette. |
| THEME | The theme color. |
