## ControlPictureAlignmentType

Utility class containing constants. Represents the alignment of the picture inside the Form or Image.

## Values

| Name | Description |
| --- | --- |
| TOP_LEFT | The top left corner. |
| TOP_RIGHT | The top right corner. |
| CENTER | The center. |
| BOTTOM_LEFT | The bottom left corner. |
| BOTTOM_RIGHT | The bottom right corner. |
