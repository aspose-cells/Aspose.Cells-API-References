## DisplayDrawingObjects

Utility class containing constants. Represents whether and how to show objects in the workbook.

## Values

| Name | Description |
| --- | --- |
| DISPLAY_SHAPES | Show all objects |
| PLACEHOLDERS | Show placeholders |
| HIDE | Hide all shapes. |
