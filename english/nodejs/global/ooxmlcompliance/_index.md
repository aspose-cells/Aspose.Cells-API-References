## OoxmlCompliance

Utility class containing constants. Allows to specify which OOXML specification will be used when saving in the Xlsx format.

## Values

| Name | Description |
| --- | --- |
| ECMA_376_2006 | ECMA-376 1st Edition, 2006. |
| ISO_29500_2008_STRICT | ISO/IEC 29500:2008 Strict compliance level. |
