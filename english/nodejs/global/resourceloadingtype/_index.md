## ResourceLoadingType

Utility class containing constants. Represents how to loading the linked resource.

## Values

| Name | Description |
| --- | --- |
| DEFAULT | Loads this resource as usual. |
| SKIP | Skips loading of this resource. |
| USER_PROVIDED | Use stream provided by user |
