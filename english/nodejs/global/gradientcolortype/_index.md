## GradientColorType

Utility class containing constants. Represents the gradient color type for the specified fill.

## Values

| Name | Description |
| --- | --- |
| NONE | No gradient color |
| ONE_COLOR | One gradient color |
| PRESET_COLORS | Preset gradient colors |
| TWO_COLORS | Two gradient colors |
