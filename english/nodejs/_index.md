The API lets developers generate, edit, and render Excel workbooks, supporting formats such as XLS, XLSX, CSV, ODS, and PDF. It also provides advanced features like formulas, charts, pivot tables, and conditional formatting. All functionality is grouped into the aspose.cells namespace for core spreadsheet operations and the Global namespace for shared utilities and constants.
