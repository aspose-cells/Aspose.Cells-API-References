## refresh(hideRows)

Gets all hidden rows' indexes.

| Parameter | Type | Description |
| --- | --- | --- |
| hideRows | boolean | If true, hide the filtered rows. |

**Returns:** Array of Number — `Array of Number` Returns all hidden rows indexes.
