## FontSetting class

Represents a range of characters within the cell text.

```js
new FontSetting(startIndex, length, sheets)
```

## Methods

| Name | Description |
| --- | --- |
| [getFont()](#getfont) | Returns the font of this object. |
| [getLength()](#getlength) | Gets the length of the characters. |
| [getStartIndex()](#getstartindex) | Gets the start index of the characters. |
| [getTextOptions()](#gettextoptions) | Returns the text options. |
| [getType()](#gettype) | Gets the type of text node. The value of the property is TextNodeType integer constant. |
| [setWordArtStyle(style)](#setwordartstyle) | Sets the preset WordArt style. Only for the text of shape/chart. |
