## CellValue class

Represents the cell value and corresponding type.

```js
new CellValue()
```

## Methods

| Name | Description |
| --- | --- |
| [getType()](#gettype) | Gets/sets the type of cell value. The value of the property is CellValueType integer constant. |
| [getValue()](#getvalue) | Gets/sets the cell value. The value must be of the correct type of object corresponding to the Type: TypeValueCellValueT |
| [setType()](#settype) | Gets/sets the type of cell value. The value of the property is CellValueType integer constant. |
| [setValue()](#setvalue) | Gets/sets the cell value. The value must be of the correct type of object corresponding to the Type: TypeValueCellValueT |

### getType() {#gettype}

Gets/sets the type of cell value. The value of the property is CellValueType integer constant.

### getValue() {#getvalue}

Gets/sets the cell value. The value must be of the correct type of object corresponding to the Type: TypeValueCellValueType.IS_NULLnull, any other object will be ignoredCellValueType.IS_NUMERICdoubleCellValueType.IS_DATE_TIMEDateTimeCellValueType.IS_STRINGstringCellValueType.IS_BOOLboolCellValueType.IS_ERRORerror string such as "#VALUE!", "#NAME?", ...
