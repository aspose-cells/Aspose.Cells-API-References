## getOffset(rowOffset, columnOffset)

Gets Range range by offset.

| Parameter | Type | Description |
| --- | --- | --- |
| rowOffset | Number | Row offset in this range, zero based. |
| columnOffset | Number | Column offset in this range, zero based. |

**Returns:** Range — `Range`
