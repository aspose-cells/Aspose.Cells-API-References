## add(uri, name)

Adds a smart tag.

| Parameter | Type | Description |
| --- | --- | --- |
| uri | String | Specifies the namespace URI of the smart tag |
| name | String | Specifies the name of the smart tag. |

**Returns:** Number — `Number` The index of smart tag in the list.
