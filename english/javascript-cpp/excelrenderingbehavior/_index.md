## ExcelRenderingBehavior enumeration
Specifies Excel-specific rendering behaviors to apply when rendering a workbook.
### Values
| Name | Value | Description |
| --- | --- | --- |
| None | `0` | Does not apply Excel-specific rendering behaviors. |
| CellTextLengthLimit | `1` | Applies Excel's cell text output length limit. For example, Excel outputs only the first 1024 characters in a non-wrapped cell. |
| All | `-1` | Applies all supported Excel-specific rendering behaviors. |
