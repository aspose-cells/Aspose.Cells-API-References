## ExcelRenderingBehavior enum


Specifies Excel-specific rendering behaviors to apply when rendering a workbook.

```cpp
enum class ExcelRenderingBehavior
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | 0 | <br>Does not apply Excel-specific rendering behaviors. |
| CellTextLengthLimit | 1 | <br>Applies Excel's cell text output length limit. For example, Excel outputs only the first 1024 characters in a non-wrapped cell. |
| All | -1 | <br>Applies all supported Excel-specific rendering behaviors. |
