## AccessCacheOptions enumeration

خيارات التخزين المؤقت للوصول إلى البيانات. يمكن دمج خيارات متعددة باستخدام المشغل "&#x7C;".

```csharp
[Flags]
public enum AccessCacheOptions
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | `0` | لا تخزين مؤقت لأي وصول إلى البيانات. |
| All | `FFFFFFFFFFFFFFFF` | تطبيق جميع التحسينات الممكنة لجميع أنواع الوصول إلى البيانات في المصنف. يجب عدم تغيير أي إعدادات أو بيانات أثناء الوصول المُحسّن. |
| PositionAndSize | `3` | تطبيق تحسين محتمل للحصول على موضع وحجم الكائن (مثل Shape). يجب عدم تغيير إعدادات ارتفاع الصف وعرض العمود أثناء الوصول المُحسّن. |
| CellsData | `9` | تطبيق تحسين محتمل للحصول على قيم الخلايا. يجب عدم تغيير بيانات الخلايا (البيانات وإعدادات الخلية، الصف) أثناء الوصول المُحسّن، ولا يجب إنشاء كائنات Cell/Row جديدة (مثل باستخدام [`Item`](../cells/item/)). |
| CellDisplay | `100086` | تطبيق تحسين محتمل للحصول على النتائج المتعلقة بالعرض للخلايا ([`DisplayStringValue`](../cell/displaystringvalue/), [`GetStyle`](../cell/getstyle/), [`GetDisplayStyle`](../cell/getdisplaystyle/), إلخ). يجب عدم تغيير بيانات الخلايا والكائنات المتعلقة بالأنماط (أنماط Cell/Row/Column، عرض العمود، إلخ) أثناء الوصول المُحسّن. |
| GetFormula | `200000` | تطبيق تحسين محتمل للحصول على الصيغ. يجب عدم تغيير جميع البيانات والإعدادات التي قد تؤثر على تعبير الصيغة (اسم Worksheet، نص Name، عمود الجدول، إلخ) أثناء الوصول المُحسّن. |
| SetFormula | `400000` | تطبيق تحسين محتمل لتعيين الصيغ. يجب عدم تغيير جميع البيانات والإعدادات التي قد تؤثر على تعبير الصيغة (اسم Worksheet، نص Name، عمود الجدول، إلخ) أثناء الوصول المُحسّن. |
| CalculateFormula | `800009` | تطبيق تحسين محتمل لحساب الصيغ. يجب عدم تغيير بيانات الخلايا أثناء الوصول المُحسّن، ولا يجب إنشاء كائنات جديدة (Cell، Row، إلخ) (مثل باستخدام [`Item`](../cells/item/)). |
| ConditionalFormatting | `1000009` | تطبيق تحسين محتمل للحصول على نتيجة تنسيق الشروط. يجب عدم تغيير جميع البيانات والإعدادات التي قد تؤثر على نتيجة تنسيقات الشرط (إعدادات تنسيقات الشرط، قيم الخلايا التابعة، إلخ) أثناء الوصول المُحسّن. |
| Validation | `2000009` | تطبيق تحسين محتمل للحصول على نتيجة التحقق. يجب عدم تغيير جميع البيانات والإعدادات التي قد تؤثر على نتيجة التحقق (إعدادات التحقق، قيم الخلايا التابعة، إلخ) أثناء الوصول المُحسّن. |

### ملاحظات

لبعض الميزات، يتطلب الوصول إلى مجموعة بيانات كبيرة الكثير من العمليات المتكررة والمعقدة مثل البحث، الحساب، ... إلخ، وهذه العمليات ستستغرق وقتًا إضافيًا كبيرًا. في الحالات الشائعة، تظل جميع البيانات التابعة غير متغيرة أثناء الوصول، لذا يمكن إنشاء بعض التخزين المؤقت واستخدامه لتحسين أداء الوصول. لهذا الغرض، نوفر هذه API لتمكين المستخدم من تحديد نوع الوصول إلى البيانات الذي يحتاج إلى تحسين عبر آلية التخزين المؤقت الممكنة. يرجى ملاحظة أنه قد يُطلب أن تكون مجموعة البيانات مختلفة \"قراءة فقط\" حسب الخيارات المختلفة. كما أن أداء الوصول إلى البيانات يعتمد على جوانب متعددة، ولا يضمن استخدام آلية التخزين المؤقت تحسين الأداء. في بعض الحالات، مثل عندما تكون مجموعة البيانات المستهدفة صغيرة، قد يؤدي استخدام التخزين المؤقت إلى استهلاك وقت إضافي لأن عملية التخزين المؤقت نفسها تحتاج إلى وقت إضافي.

### أمثلة

```csharp
namespace AsposeCellsExamples
{
    using Aspose.Cells;
    using System;

    public class AccessCacheOptionsDemo
    {
        public static void AccessCacheOptionsExample()
        {
            // إنشاء دفتر عمل جديد
            Workbook workbook = new Workbook();
            Worksheet worksheet = workbook.Worksheets[0];

            // ابدأ التخزين المؤقت للوصول مع خيارات محددة
            workbook.StartAccessCache(AccessCacheOptions.PositionAndSize | AccessCacheOptions.CellsData);

            // قم بتنفيذ بعض العمليات التي تستفيد من التخزين المؤقت
            for (int i = 0; i < 10; i++)
            {
                for (int j = 0; j < 10; j++)
                {
                    worksheet.Cells[i, j].PutValue(i + j);
                }
            }

            // إغلاق التخزين المؤقت للوصول
            workbook.CloseAccessCache(AccessCacheOptions.PositionAndSize | AccessCacheOptions.CellsData);

            // احفظ المصنف
            workbook.Save("AccessCacheOptionsExample.xlsx");
        }
    }
}
```
