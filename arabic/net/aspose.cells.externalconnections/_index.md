توفر مساحة الاسم **Aspose.Cells.ExternalConnections** فئات للاتصالات الخارجية لاسترجاع البيانات من مصادر خارجية مثل قواعد البيانات والويب.

## فئات

| فئة | الوصف |
| --- | --- |
| [ConnectionParameter](./connectionparameter/) | يحدد الخصائص المتعلقة بأي معلمات تُستخدم مع اتصالات البيانات الخارجية. المعلمات صالحة لاستعلامات ODBC والويب. |
| [ConnectionParameterCollection](./connectionparametercollection/) | يحدد مجموعة [`ConnectionParameter`](../aspose.cells.externalconnections/connectionparameter/) |
| [DataModelConnection](./datamodelconnection/) | يحدد اتصال نموذج البيانات |
| [DBConnection](./dbconnection/) | يحدد جميع الخصائص المرتبطة باتصال بيانات خارجي ODBC أو OLE DB. |
| [ExternalConnection](./externalconnection/) | يحدد اتصال بيانات خارجي |
| [ExternalConnectionCollection](./externalconnectioncollection/) | يحدد مجموعة [`ExternalConnection`](../aspose.cells.externalconnections/externalconnection/) |
| [WebQueryConnection](./webqueryconnection/) | يحدد الخصائص لمصدر استعلام الويب. سيسترجع استعلام الويب البيانات من جداول HTML، ويمكنه أيضاً تزويد معلمات HTTP "Get" لتتم معالجتها بواسطة خادم الويب عند توليد HTML من خلال تضمين المعلمات وعناصر المعلمات. |
