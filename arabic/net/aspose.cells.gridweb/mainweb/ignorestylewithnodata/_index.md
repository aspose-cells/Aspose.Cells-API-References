## MainWeb.IgnoreStyleWithNoData property

يحصل أو يعيّن ما إذا كان GridWeb يتجاهل إظهار الصفوف أو الأعمدة التي لا تحتوي على قيم خلايا ولكنها لا تزال مُنسقة. إذا تم تعيينه إلى true، ستكون الأداء أفضل. القيمة الافتراضية هي false، مما يعني أنه إذا كان الصف/العمود المتتالي الأخير لا يحتوي على قيم خلايا ولكنه مُنسق، فسنظل نعرضه. هذا الخيار صالح فقط عندما يكون EnableAsync مساويًا لـ false. هذا الخيار لا يؤثر عندما يكون EnableAsync مساويًا لـ true، مما يعني أن GridWeb سيعرض جميع الصفوف/الأعمدة مع التنسيق.

```csharp
public bool IgnoreStyleWithNoData { get; set; }
```
