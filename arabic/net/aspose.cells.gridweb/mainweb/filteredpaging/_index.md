## MainWeb.FilteredPaging property

يحصل أو يضبط ما إذا كان سيتم تمكين الصفحات بعد تصفية البيانات، سيصبح ساريًا عندما تكون EnablePaging true.

```csharp
public bool FilteredPaging { get; set; }
```

### ملاحظات

عند الضبط على true، سيقوم التحكم بالتقسيم بناءً على البيانات المصفاة، القيمة الافتراضية هي false.
