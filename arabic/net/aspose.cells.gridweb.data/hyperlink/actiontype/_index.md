## Hyperlink.ActionType property

يحصل أو يعيّن نوع إجراء الارتباط التشعبي. قد يكون ActionTpye.UrlLink أو ActionType.CellCommand. نوع UrlLink يعني أن الارتباط التشعبي هو رابط إلى صفحة ويب أو إلى بريد إلكتروني. على سبيل المثال: "http://www.aspose.com" أو "mailto:admin@aspose.com". نوع CellCommand يعني أن الارتباط التشعبي سيطلق حدث CellCommand، ويمكنك معالجة هذا الحدث.

```csharp
public virtual HyperlinkActionType ActionType { get; set; }
```
