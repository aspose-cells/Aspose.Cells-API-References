## GridTxtLoadOptions.ExtendToNextSheet property

ما إذا كان يتم تمديد البيانات إلى الورقة التالية عندما تتجاوز الصفوف أو الأعمدة الحد. إذا كانت هذه الخاصية true، سيتم تمديد البيانات الإضافية إلى الورقة التالية خلف الحالية (إذا كانت الورقة الحالية هي الأخيرة، ستُضاف ورقة جديدة إلى المصنف الحالي). إذا كانت false، سيتم تجاهل البيانات التي تتجاوز الحد. القيمة الافتراضية هي false؛

```csharp
public bool ExtendToNextSheet { get; set; }
```
