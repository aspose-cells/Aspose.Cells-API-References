## GridHyperlink.ImageURL property

احصل أو عيّن عنوان URL للصورة للارتباط، لا توجد خاصية imageurl في الارتباط التشعبي، لذا يتم استخدام TextToDisplay لتسجيل هذه القيمة، سيتم تعيين TextToDisplay إلى &lt;img src=value &gt; وبالتالي سيتغير قيمة TextToDisplay

```csharp
public string ImageURL { get; set; }
```
