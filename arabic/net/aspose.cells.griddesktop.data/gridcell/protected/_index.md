## GridCell.Protected property

يشير إلى ما إذا كانت الخلية محمية. إذا كانت القيمة "true"، لا يمكن للمستخدم تعديل الخلية عبر واجهة المستخدم. هذه الخاصية لا علاقة لها بخصية Style.CellLocked ولن يتم حفظها في الملف عند تصدير بيانات الشبكة. القيمة الافتراضية هي "false".

```csharp
public bool Protected { get; set; }
```
