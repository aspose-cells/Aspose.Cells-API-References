## PivotTableCreateOptions.UseSameSource property

```csharp
public bool UseSameSource { get; set; }
```

### ملاحظات

عند تعيينه إلى true، يمكن لعدة جداول محورية إعادة استخدام ذاكرة تخزين مؤقت للمحور واحدة لتقليل استهلاك الذاكرة.
