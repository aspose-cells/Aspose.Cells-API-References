| معامل | نوع | الوصف |
| --- | --- | --- |
| excelFilePath | String | مسار ملف Excel. |
| uid | String | المعرّف الفريد لدفتر العمل. إذا كان null أو فارغًا، سيتم إنشاء معرف جديد بناءً على مسار الملف. |
