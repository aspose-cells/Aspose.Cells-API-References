## Config.EnableChartClientRendering property

يحصل/يضبط ما إذا كان سيتم تمكين رسم المخططات من جانب العميل. إذا تم ضبطه على false، سيعود GridJs إلى استخدام صور/أشكال المخططات التي يولدها الخادم فقط. القيمة الافتراضية هي true.

```csharp
public static bool EnableChartClientRendering { get; set; }
```
