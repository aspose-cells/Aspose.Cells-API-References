## Config.IsWasm property

يحصل/يضبط ما إذا كان GridJs يعمل داخل مضيف WebAssembly للمتصفح بدلاً من عملية خادم. عندما يكون true، لا يتم استخدام مسار FileCacheDirectory / القرص / مسار مقاطعة الخيط ويجب أن يأتي ذاكرة التخزين المؤقت للملفات من GridJsOptions.CacheImp. تقوم GridJsOptions.IsWasm بتعيين هذا عند إنشاء خدمة GridJs، لذا فإن ملف Aspose.Cells.GridJs.dll واحد يخدم كلا المضيفين. القيمة الافتراضية هي false.

```csharp
public static bool IsWasm { get; set; }
```
