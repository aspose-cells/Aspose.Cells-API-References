## DirectoryType Enum

يمثل نوع الدليل لاسم الملف.

```go

type DirectoryType int32


```

## الحقول

| حقل | الوصف |
| --- | --- |
| [Volume](./volume/) | يمثل حرف محرك أقراص MS-DOS. يتبعه حرف المحرك. أو أسماء ملفات UNC، مثل \\server\share\myfile.xls |
| [SameVolume](./samevolume/) | يشير إلى أن مصنف المصدر على نفس محرك الأقراص مثل مصنف التابع (يتم حذف حرف المحرك) |
| [DownDirectory](./downdirectory/) | يشير إلى أن مصنف المصدر في دليل فرعي من الدليل الحالي. |
| [UpDirectory](./updirectory/) | يشير إلى أن مصنف المصدر في الدليل الأب للدليل الحالي. |
