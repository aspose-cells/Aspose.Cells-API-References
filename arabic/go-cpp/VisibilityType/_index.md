## VisibilityType Enum

يمثل حالات ظهور الورقة.

```go

type VisibilityType int32


```

## الحقول

| حقل | الوصف |
| --- | --- |
| [Visible](./visible/) | يشير إلى أن الورقة مرئية. |
| [Hidden](./hidden/) | يشير إلى أن الورقة مخفية، ولكن يمكن للمستخدم إظهارها عبر واجهة المستخدم. |
| [VeryHidden](./veryhidden/) | يشير إلى أن الورقة مخفية ولا يمكن إظهارها في واجهة المستخدم (UI). هذه الحالة متاحة فقط برمجيًا. |
