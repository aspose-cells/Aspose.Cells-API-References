## AccessCacheOptions Enum

خيارات التخزين المؤقت للوصول إلى البيانات. يمكن دمج خيارات متعددة باستخدام المشغل "|".

```go

type AccessCacheOptions int32


```

## الحقول

| حقل | الوصف |
| --- | --- |
| [None](./none/) | لا تخزين مؤقت لأي وصول إلى البيانات. |
| [All](./all/) | تطبيق جميع التحسينات الممكنة لجميع أنواع الوصول إلى البيانات في دفتر العمل. يجب عدم تغيير أي إعدادات أو بيانات أثناء الوصول المحسّن. |
| [PositionAndSize](./positionandsize/) | تطبيق تحسين ممكن للحصول على موضع وحجم الكائن (مثل Shape). يجب عدم تغيير إعدادات ارتفاع الصف وعرض العمود أثناء الوصول المحسّن. |
| [CellsData](./cellsdata/) | تطبيق تحسين ممكن للحصول على قيم الخلايا. يجب عدم تغيير بيانات الخلايا (البيانات وإعدادات الخلية والصف) أثناء الوصول المحسّن، ولا يجب إنشاء كائنات خلية/صف جديدة (مثل بواسطة <see cref="Cells.this[int, int]"/>). |
| [CellDisplay](./celldisplay/) | تطبيق تحسين ممكن للحصول على النتائج المتعلقة بالعرض للخلايا (<see cref="Cell.DisplayStringValue"/>, <see cref="Cell.GetStyle()"/>, <see cref="Cell.GetDisplayStyle()"/>, إلخ). يجب عدم تغيير بيانات الخلايا والكائنات المتعلقة بالأنماط (أنماط الخلية/الصف/العمود، عرض العمود، إلخ) أثناء الوصول المحسّن. |
| [GetFormula](./getformula/) | تطبيق تحسين ممكن للحصول على الصيغ. يجب عدم تغيير جميع البيانات والإعدادات التي قد تؤثر على تعبير الصيغة (اسم ورقة العمل، نص الاسم، عمود الجدول، إلخ) أثناء الوصول المحسّن. |
| [SetFormula](./setformula/) | تطبيق تحسين ممكن لتعيين الصيغ. يجب عدم تغيير جميع البيانات والإعدادات التي قد تؤثر على تعبير الصيغة (اسم ورقة العمل، نص الاسم، عمود الجدول، إلخ) أثناء الوصول المحسّن. |
| [CalculateFormula](./calculateformula/) | تطبيق تحسين ممكن لحساب الصيغ. يجب عدم تغيير بيانات الخلايا أثناء الوصول المحسّن، ولا يجب إنشاء كائنات جديدة (خلية، صف، إلخ) (مثل بواسطة <see cref="Cells.this[int, int]"/>). |
| [ConditionalFormatting](./conditionalformatting/) | تطبيق تحسين ممكن للحصول على نتيجة تنسيق الشروط. يجب عدم تغيير جميع البيانات والإعدادات التي قد تؤثر على نتيجة تنسيقات الشرط (إعدادات تنسيقات الشرط، قيم الخلايا المعتمدة، إلخ) أثناء الوصول المحسّن. |
| [Validation](./validation/) | تطبيق تحسين ممكن للحصول على نتيجة التحقق. يجب عدم تغيير جميع البيانات والإعدادات التي قد تؤثر على نتيجة التحقق (إعدادات التحقق، قيم الخلايا المعتمدة، إلخ) أثناء الوصول المحسّن. |
