### getOffset() {#getOffset--}
```
public int getOffset()
```


يحصل على المسافة بين التسميات والمحور الفئوي. ينطبق هذا فقط على المحور الفئوي (x).

**Remarks**

المسافة الافتراضية هي 100 بالمئة، والتي تمثل التباعد الافتراضي بين تسميات المحور وخط المحور. يمكن أن تكون القيمة نسبة مئوية صحيحة من 0 إلى 1000، نسبة إلى حجم خط تسميات المحور''.

**Returns:**
int
