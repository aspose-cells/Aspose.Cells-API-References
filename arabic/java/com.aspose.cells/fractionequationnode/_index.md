```
public class FractionEquationNode extends EquationNode
```

هذه الفئة تحدد معادلة الكسر، المكوّنة من البسط والمقام مفصولين بشريط كسر. يمكن أن يكون شريط الكسر أفقيًا أو قطريًا، حسب خصائص الكسر. تُستخدم معادلة الكسر أيضًا لتمثيل دالة التكديس، التي تضع عنصرًا فوق آخر دون شريط كسر.
