### getHeightRatioToChart() {#getHeightRatioToChart--}
```
public double getHeightRatioToChart()
```


يحصل على ارتفاع صندوق حدود مساحة الرسم بوحدة نسبة مساحة المخطط.

**Remarks**

الصندوق المحيط بمنطقة الرسم يشمل منطقة الرسم وعلامات الفواصل (تسميات الفواصل) وحدًا صغيرًا حول علامات الفواصل. إذا لم يتم إنشاء القيمة بواسطة MS Excel، يرجى استدعاء الطريقة Chart.Calculate() قبل استدعاء هذه الطريقة.

الـ **XRatioToChart**, **YRatioToChart**, **WidthRatioToChart** و **HeightRatioToChart** الخاص بـ **PlotArea** يمثل صندوق الحدود لمنطقة الرسم الذي يشمل منطقة الرسم، علامات الفواصل (تسميات العلامات)، وحدود صغيرة حول علامات الفواصل. إذا كنت تريد الحصول على الحجم الفعلي لمنطقة الرسم، يجب عليك استدعاء خصائص **InnerXRatioToChart**, **InnerYRatioToChart**, **InnerWidthRatioToChart** و **InnerHeightRatioToChart**.

بالنسبة لـ Excel 2007 أو أحدث، القيمة الافتراضية هي صفر. يجب عليك الحصول على القيمة بعد استدعاء Chart.Calculate().

HeightPixel = HeightRatioToChart \* chart.ChartObject.Width. ملاحظة: عندما يتم تعيين HeightRatioToChart، سيتم تعيين خاصية IsInnerMode تلقائيًا إلى false.

**Returns:**
double
