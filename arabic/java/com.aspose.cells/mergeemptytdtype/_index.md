### MERGE_FORCELY {#MERGE-FORCELY}
```
public static final int MERGE_FORCELY
```


دمج عنصر TD فارغ بالقوة عند تصدير الملف إلى html. سيقل حجم ملف html بشكل كبير بعد ضبط القيمة إلى true. إذا كنت تريد استيراد ملف html إلى excel أو تصدير خطوط الشبكة المثالية عند حفظ الملف إلى html، يرجى الحفاظ على القيمة الافتراضية.

### NONE {#NONE}
```
public static final int NONE
```


عناصر TD الفارغة لن يتم دمجها عند تصدير الملف إلى html. سيؤدي ذلك إلى إنشاء ملف html أكبر بشكل كبير.
