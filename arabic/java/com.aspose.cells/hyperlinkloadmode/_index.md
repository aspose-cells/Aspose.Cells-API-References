### ALLOW_MULTIPLE {#ALLOW-MULTIPLE}
```
public static final int ALLOW_MULTIPLE
```


يتم إضافة جميع الروابط التشعبية في الخلية إلى [Worksheet.getHyperlinks()](../../com.aspose.cells/worksheet\#getHyperlinks--). لاحظ أن برنامج MS Excel نفسه يدعم رابطًا تشعبيًا واحدًا فقط لكل خلية، لذا قد ينتج عن هذا الخيار ملفات لا يستطيع Excel عرضها بالكامل.
