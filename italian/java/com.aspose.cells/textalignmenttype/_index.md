Enumera i tipi di allineamento del testo.
## Campi

| Campo | Descrizione |
| --- | --- |
| [BOTTOM](#BOTTOM) | Rappresenta l'allineamento del testo in basso. |
| [CENTER](#CENTER) | Rappresenta l'allineamento del testo al centro. |
| [CENTER_ACROSS](#CENTER-ACROSS) | Rappresenta l'allineamento del testo centrato su tutta la larghezza. |
| [DISTRIBUTED](#DISTRIBUTED) | Rappresenta l'allineamento del testo distribuito. |
| [FILL](#FILL) | Rappresenta l'allineamento del testo riempito. |
| [GENERAL](#GENERAL) | Rappresenta l'allineamento generale del testo. |
| [JUSTIFIED_LOW](#JUSTIFIED-LOW) | Allinea il testo con una lunghezza kashida regolata per il testo arabo. |
| [JUSTIFY](#JUSTIFY) | Rappresenta l'allineamento del testo giustificato. |
| [LEFT](#LEFT) | Rappresenta l'allineamento del testo a sinistra. |
| [RIGHT](#RIGHT) | Rappresenta l'allineamento del testo a destra. |
| [THAI_DISTRIBUTED](#THAI-DISTRIBUTED) | Distribuisce il testo tailandese in modo speciale, poiché ogni carattere è trattato come una parola. |
| [TOP](#TOP) | Rappresenta l'allineamento del testo superiore. |
