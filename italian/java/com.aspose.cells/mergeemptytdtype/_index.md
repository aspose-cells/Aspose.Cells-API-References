Rappresenta il tipo di unione per un elemento TD vuoto durante l'esportazione di un file in HTML.
## Campi

| Campo | Descrizione |
| --- | --- |
| [DEFAULT](#DEFAULT) | Visualizza come MS Excel. |
| [MERGE_FORCELY](#MERGE-FORCELY) | Unione forzata degli elementi TD vuoti durante l'esportazione del file in html. |
| [NONE](#NONE) | Gli elementi TD vuoti non saranno uniti durante l'esportazione del file in html. |

### DEFAULT {#DEFAULT}
```
public static final int DEFAULT
```


Visualizza come MS Excel.

### MERGE_FORCELY {#MERGE-FORCELY}
```
public static final int MERGE_FORCELY
```


Unione forzata degli elementi TD vuoti durante l'esportazione del file in html. La dimensione del file html sarà notevolmente ridotta impostando il valore su true. Se desideri importare il file html in Excel o esportare linee di griglia perfette quando salvi il file in html, mantieni il valore predefinito.

### NONE {#NONE}
```
public static final int NONE
```


Gli elementi TD vuoti non verranno uniti durante l'esportazione del file in html. Questo genererà un file html notevolmente più grande.
