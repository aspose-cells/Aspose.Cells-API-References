```
public final class IconSetType
```

Tipo di set di icone per la formattazione condizionale. I valori soglia per attivare le diverse icone all'interno di un set sono configurabili e l'ordine delle icone è reversibile.

| Campo | Descrizione |

| [ARROWS_4](#ARROWS-4) | Set di icone a 4 frecce. |

| [TRAFFIC_LIGHTS_4](#TRAFFIC-LIGHTS-4) | Set di icone con 4 semafori. |
