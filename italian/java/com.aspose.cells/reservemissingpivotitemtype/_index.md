### ALL {#ALL}
```
public static final int ALL
```


Riserva tutti gli elementi mancanti.

**Remarks**

In Excel, finché Excel non è chiuso, gli elementi mancanti generati dal primo aggiornamento della tabella pivot verranno mantenuti, anche se si aggiorna ripetutamente.

### DEFAULT {#DEFAULT}
```
public static final int DEFAULT
```


Rimuove i vecchi elementi pivot mancanti e riserva gli elementi eliminati della nuova origine dati come elementi mancanti.

### NONE {#NONE}
```
public static final int NONE
```


Rimuove tutti gli elementi pivot mancanti.

**Remarks**

L'ordine dei vecchi elementi pivot mancanti verrà ignorato.
