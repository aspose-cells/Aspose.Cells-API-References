Determina il tipo di calcolo nella riga Totali della colonna dell'elenco.
## Campi

| Campo | Descrizione |
| --- | --- |
| [AVERAGE](#AVERAGE) | Rappresenta il calcolo medio dei totali. |
| [COUNT](#COUNT) | Rappresenta il calcolo dei totali di conteggio. |
| [COUNT_NUMS](#COUNT-NUMS) | Rappresenta il calcolo dei totali di conteggio numeri. |
| [CUSTOM](#CUSTOM) | Rappresenta il calcolo personalizzato. |
| [MAX](#MAX) | Rappresenta il calcolo dei totali massimo. |
| [MIN](#MIN) | Rappresenta il calcolo dei totali minimo. |
| [NONE](#NONE) | Rappresenta il calcolo dei totali nessuno. |
| [STD_DEV](#STD-DEV) | Rappresenta il calcolo dei totali deviazione standard. |
| [SUM](#SUM) | Rappresenta il calcolo dei totali somma. |
| [VAR](#VAR) | Rappresenta il calcolo dei totali varianza. |
