Rappresenta il tipo di protezione del workbook/foglio di lavoro.
## Campi

| Campo | Descrizione |
| --- | --- |
| [ALL](#ALL) | Rappresenta la protezione di tutto. |
| [CONTENTS](#CONTENTS) | Rappresenta la protezione del contenuto, usata nella protezione del foglio di lavoro. |
| [NONE](#NONE) | Rappresenta nessuna protezione. |
| [OBJECTS](#OBJECTS) | Rappresenta la protezione degli oggetti, usata nella protezione del foglio di lavoro. |
| [SCENARIOS](#SCENARIOS) | Rappresenta la protezione degli scenari, usata nella protezione del foglio di lavoro. |
| [STRUCTURE](#STRUCTURE) | Rappresenta la protezione della struttura, usata nella protezione della cartella di lavoro. |
| [WINDOWS](#WINDOWS) | Rappresenta la protezione della finestra, usata nella protezione della cartella di lavoro. |
