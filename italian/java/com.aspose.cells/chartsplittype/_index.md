```
public final class ChartSplitType
```

Rappresenta il modo in cui le due sezioni di un grafico a torta di torta o a barra di torta sono suddivise.
## Campi

| Campo | Descrizione |
| --- | --- |
| [AUTO](#AUTO) | Rappresenta i punti dati che devono essere suddivisi utilizzando il meccanismo predefinito per questo tipo di grafico. |
| [CUSTOM](#CUSTOM) | Rappresenta i punti dati che devono essere suddivisi tra il grafico a torta e il secondo grafico in base ai valori di divisione personalizzati. |
| [PERCENT_VALUE](#PERCENT-VALUE) | Rappresenta i punti dati che devono essere suddivisi tra il grafico a torta e il secondo grafico inserendo i punti con una percentuale inferiore alla percentuale di Posizione di Divisione nel secondo grafico. |
| [POSITION](#POSITION) | Rappresenta i punti dati. |
| [VALUE](#VALUE) | Rappresenta i punti dati che devono essere suddivisi tra il grafico a torta e il secondo grafico inserendo i punti dati con valore inferiore alla Posizione di Divisione nel secondo grafico. |
