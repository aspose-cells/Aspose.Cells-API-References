Rappresenta il modo in cui il testo trabocca verticalmente o orizzontalmente.
## Campi

| Campo | Descrizione |
| --- | --- |
| [CLIP](#CLIP) | Prestare attenzione alle barriere superiore e inferiore. |
| [ELLIPSIS](#ELLIPSIS) | Prestare attenzione alle barriere superiore e inferiore. |
| [OVERFLOW](#OVERFLOW) | Eseguire l'overflow del testo senza prestare attenzione alle barriere superiore e inferiore. |

### CLIP {#CLIP}
```
public static final int CLIP
```


Prestare attenzione alle barriere superiore e inferiore. Non fornire alcuna indicazione che ci sia del testo non visibile.

### ELLIPSIS {#ELLIPSIS}
```
public static final int ELLIPSIS
```


Prestare attenzione alle barriere superiore e inferiore. Utilizzare un'ellissi per indicare che c'è del testo non visibile. Solo per overflow verticale.

### OVERFLOW {#OVERFLOW}
```
public static final int OVERFLOW
```


Eseguire l'overflow del testo senza prestare attenzione alle barriere superiore e inferiore.
