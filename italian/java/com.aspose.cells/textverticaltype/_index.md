## Campi

| Campo | Descrizione |
| --- | --- |
| [HORIZONTAL](#HORIZONTAL) | Testo orizzontale. |
| [STACKED](#STACKED) | Determina se tutto il testo è verticale |
| [STACKED_RIGHT_TO_LEFT](#STACKED-RIGHT-TO-LEFT) | Specifica che il WordArt verticale dovrebbe essere mostrato da destra a sinistra anziché da sinistra a destra. |
| [VERTICAL](#VERTICAL) | Visualizzazione verticale dell'Est asiatico. |
| [VERTICAL_270](#VERTICAL-270) | Ogni linea è ruotata di 270 gradi in senso orario |
| [VERTICAL_90](#VERTICAL-90) | Ogni linea è ruotata di 90 gradi in senso orario |
| [VERTICAL_LEFT_TO_RIGHT](#VERTICAL-LEFT-TO-RIGHT) | Visualizzato verticalmente e il testo scorre dall'alto verso il basso poi DA SINISTRA A DESTRA |
