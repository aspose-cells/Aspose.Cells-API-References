```

```

Rappresenta il tipo di riempimento automatico.
## Campi

| Campo | Descrizione |
| --- | --- |
| [COPY](#COPY) | Copia il valore e il formato dell'area di origine nell'area di destinazione |
| [DEFAULT](#DEFAULT) | Riempie automaticamente l'area di destinazione con il valore e il formato. |
| [FORMATS](#FORMATS) | Copia solo il formato dell'area di origine nell'area di destinazione. |
| [SERIES](#SERIES) | Estende il valore nell'area di origine all'area di destinazione sotto forma di serie e copia il formato nell'area di destinazione. |
| [VALUES](#VALUES) | Copia solo il valore dell'area di origine nell'area di destinazione. |
