```
public final class ShapeDisplayType
```

Rappresenta come l'applicazione visualizza le forme in questa cartella di lavoro. Le forme possono includere grafici, immagini e altri dati oggetto supportati dall'applicazione.
## Campi

| Campo | Descrizione |
| --- | --- |
| [ALL](#ALL) | Indica che tutte le forme siano mostrate nella cartella di lavoro. |
| [NONE](#NONE) | Indica che tutte le forme siano nascoste nella cartella di lavoro. |
| [PLACEHOLDERS](#PLACEHOLDERS) | Indica che l'applicazione mostri segnaposti per le forme nella cartella di lavoro. |
