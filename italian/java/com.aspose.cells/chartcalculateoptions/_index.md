### getUpdateAllPoints() {#getUpdateAllPoints--}
```
public boolean getUpdateAllPoints()
```


Indica se aggiornare tutti i punti dati durante il calcolo del grafico. Predefinito: False. Quando si desidera ottenere il valore per ciascun punto dati nel grafico specificamente, impostarlo su true. Se questo parametro è impostato su True, i nuovi punti dati potrebbero essere generati quando il grafico viene calcolato. Questo potrebbe rendere il file Excel più grande.

boolean
