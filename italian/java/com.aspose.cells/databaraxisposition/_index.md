Specifica la posizione dell'asse per un intervallo di celle con formattazione condizionale come barre dati.
## Campi

| Campo | Descrizione |
| --- | --- |
| [AUTOMATIC](#AUTOMATIC) | Visualizza l'asse in una posizione variabile basata sul rapporto tra il valore negativo minimo e il valore positivo massimo nell'intervallo. |
| [MIDPOINT](#MIDPOINT) | Visualizza l'asse al punto medio della cella indipendentemente dal set di valori nell'intervallo. |
| [NONE](#NONE) | Nessun asse viene visualizzato e sia i valori positivi che quelli negativi vengono mostrati nella direzione da sinistra a destra. |

### AUTOMATIC {#AUTOMATIC}
```
public static final int AUTOMATIC
```


Visualizza l'asse in una posizione variabile in base al rapporto tra il valore negativo minimo e il valore positivo massimo nell'intervallo. I valori positivi sono visualizzati in direzione da sinistra a destra. I valori negativi sono visualizzati in direzione da destra a sinistra. Quando tutti i valori sono positivi o tutti i valori sono negativi, l'asse non viene visualizzato.

### MIDPOINT {#MIDPOINT}
```
public static final int MIDPOINT
```


Visualizza l'asse al punto medio della cella indipendentemente dal set di valori nell'intervallo. I valori positivi sono visualizzati in direzione da sinistra a destra. I valori negativi sono visualizzati in direzione da destra a sinistra.

### NONE {#NONE}
```
public static final int NONE
```


Nessun asse viene visualizzato e sia i valori positivi che quelli negativi vengono mostrati nella direzione da sinistra a destra.
