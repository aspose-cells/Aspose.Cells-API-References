**Inheritance:**
java.lang.Object
```
public final class ControlMousePointerType
```

Rappresenta il tipo di icona visualizzata come puntatore del mouse per il controllo.
## Campi

| Campo | Descrizione |
| --- | --- |
| [APP_STARTING](#APP-STARTING) | Freccia con una clessidra. |
| [ARROW](#ARROW) | Freccia. |
| [CROSS](#CROSS) | Puntatore a mirino. |
| [CUSTOM](#CUSTOM) | Utilizza l'icona specificata dalla proprietà MouseIcon. |
| [DEFAULT](#DEFAULT) | Puntatore standard. |
| [HELP](#HELP) | Freccia con un punto interrogativo. |
| [HOUR_GLASS](#HOUR-GLASS) | Clessidra. |
| [I_BEAM](#I-BEAM) | Cursore a I. |
| [NO_DROP](#NO-DROP) | "Not" simbolo (cerchio con una linea diagonale) sopra l'oggetto trascinato. |
| [SIZE_ALL](#SIZE-ALL) | "Size-all" cursore (frecce che puntano a nord, sud, est e ovest). |
| [SIZE_NESW](#SIZE-NESW) | Doppia freccia che punta a nord-est e sud-ovest. |
| [SIZE_NS](#SIZE-NS) | Doppia freccia che punta a nord e sud. |
| [SIZE_NWSE](#SIZE-NWSE) | Doppia freccia che punta a nord-ovest e sud-est. |
| [SIZE_WE](#SIZE-WE) | Doppia freccia che punta a ovest e a est. |
| [UP_ARROW](#UP-ARROW) | Freccia verso l'alto. |
