Rappresenta cinque tipi di stringa incrociata html.
## Campi

| Campo | Descrizione |
| --- | --- |
| [CROSS](#CROSS) | Visualizza la stringa incrociata HTML, questa prestazione per la creazione di grandi file html sarà più di dieci volte più veloce rispetto all'impostazione del valore su Default o FitToCell. |
| [CROSS_HIDE_RIGHT](#CROSS-HIDE-RIGHT) | Visualizza la stringa incrociata HTML e nascondi la stringa di destra quando i testi si sovrappongono. |
| [DEFAULT](#DEFAULT) | Visualizza come MS Excel, dipende dalla cella successiva. |
| [FIT_TO_CELL](#FIT-TO-CELL) | Visualizza solo la stringa entro la larghezza della cella. |
| [MS_EXPORT](#MS-EXPORT) | Visualizza la stringa come MS Excel esportando HTML. |
