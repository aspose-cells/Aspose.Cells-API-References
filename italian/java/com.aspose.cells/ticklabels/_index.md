### getOffset() {#getOffset--}
```
public int getOffset()
```


Ottiene la distanza delle etichette dall'asse delle categorie. Questo si applica solo all'asse delle categorie (x).

**Remarks**

La distanza predefinita è 100 percento, che rappresenta la spaziatura predefinita tra le etichette dell'asse e la linea dell'asse. Il valore può essere una percentuale intera da 0 a 1000, relativa alla dimensione del carattere dell'etichetta dell'asse.

**Returns:**
int

### getRotationAngle() {#getRotationAngle--}
```
public int getRotationAngle()
```


Rappresenta l'angolo di rotazione del testo in senso orario.

**Remarks**

\-90: Verso il basso.

90: Verso l'alto.
