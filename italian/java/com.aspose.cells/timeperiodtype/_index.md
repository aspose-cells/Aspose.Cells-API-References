java.lang.Object
```
public final class TimePeriodType
```

Utilizzato in una regola di formattazione condizionale FormatConditionType.TimePeriod. Questi sono periodi di tempo dinamici, che cambiano in base alla data in cui la formattazione condizionale viene aggiornata / applicata.
## Campi

| Campo | Descrizione |
| --- | --- |
| [LAST_7_DAYS](#LAST-7-DAYS) | Una data negli ultimi sette giorni. |
| [LAST_MONTH](#LAST-MONTH) | Una data che si verifica nell'ultimo mese solare. |
| [LAST_WEEK](#LAST-WEEK) | Una data che si è verificata la scorsa settimana. |
| [LAST_YEAR](#LAST-YEAR) | Una data che si è verificata l'anno scorso. |
| [NEXT_MONTH](#NEXT-MONTH) | Una data che si verifica nel prossimo mese di calendario. |
| [NEXT_WEEK](#NEXT-WEEK) | Una data che si verifica la prossima settimana. |
| [NEXT_YEAR](#NEXT-YEAR) | Una data che si verifica l'anno prossimo. |
| [THIS_MONTH](#THIS-MONTH) | Una data che si verifica in questo mese di calendario. |
| [THIS_WEEK](#THIS-WEEK) | Una data che si verifica questa settimana. |
| [THIS_YEAR](#THIS-YEAR) | Una data che si verifica quest'anno. |
| [TODAY](#TODAY) | La data di oggi. |
| [TOMORROW](#TOMORROW) | La data di domani. |
| [YESTERDAY](#YESTERDAY) | La data di ieri. |
