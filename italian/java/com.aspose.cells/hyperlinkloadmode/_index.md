## Campi

| --- | --- |
| [ALLOW_MULTIPLE](#ALLOW-MULTIPLE) | Tutti i collegamenti ipertestuali in una cella vengono aggiunti a [Worksheet.getHyperlinks()](../../com.aspose.cells/worksheet\#getHyperlinks--). |

### ALLOW_MULTIPLE {#ALLOW-MULTIPLE}
```
public static final int ALLOW_MULTIPLE
```


Tutti i collegamenti ipertestuali in una cella vengono aggiunti a [Worksheet.getHyperlinks()](../../com.aspose.cells/worksheet\#getHyperlinks--). Nota che MS Excel supporta solo un collegamento ipertestuale per cella, quindi questa opzione potrebbe generare file che Excel non può rendere completamente.

### NORMAL {#NORMAL}
```
public static final int NORMAL
```


Viene caricato solo il primo collegamento ipertestuale in una cella, i successivi vengono ignorati.
