Enumera i tipi di posizione della legenda.
## Campi

| Campo | Descrizione |
| --- | --- |
| [BOTTOM](#BOTTOM) | Visualizza la legenda nella parte inferiore dell'area di tracciamento del grafico. |
| [CORNER](#CORNER) | Visualizza la legenda nell'angolo dell'area di tracciamento del grafico. |
| [LEFT](#LEFT) | Visualizza la legenda a sinistra dell'area di tracciamento del grafico. |
| [NOT_DOCKED](#NOT-DOCKED) | Indica che la legenda non è ancorata. |
| [RIGHT](#RIGHT) | Visualizza la legenda a destra dell'area di tracciamento del grafico. |
| [TOP](#TOP) | Visualizza la legenda nella parte superiore dell'area di tracciamento del grafico. |
