**Inheritance:**
java.lang.Object
```
public final class LineType
```

Enumera il tipo di bordo di [Picture](../../com.aspose.cells/picture) o di linea di [Chart](../../com.aspose.cells/chart).
## Campi

| Campo | Descrizione |
| --- | --- |
| [DARK_GRAY](#DARK-GRAY) | Rappresenta una linea grigio scuro. |
| [DASH](#DASH) | Rappresenta una linea tratteggiata. |
| [DASH_DOT](#DASH-DOT) | Rappresenta una linea tratto-punto |
| [DASH_DOT_DOT](#DASH-DOT-DOT) | Rappresenta una linea tratto-punto-punto. |
| [DOT](#DOT) | Rappresenta una linea puntinata. |
| [LIGHT_GRAY](#LIGHT-GRAY) | Rappresenta una linea grigio chiaro. |
| [MEDIUM_GRAY](#MEDIUM-GRAY) | Rappresenta una linea grigio medio. |
| [SOLID](#SOLID) | Rappresenta una linea solida. |
