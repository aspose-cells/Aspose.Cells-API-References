**Inheritance:**
java.lang.Object
```
public final class VisibilityType
```

Rappresenta gli stati per la visibilità del foglio.
## Campi

| Campo | Descrizione |
| --- | --- |
| [HIDDEN](#HIDDEN) | Indica che il foglio è nascosto, ma può essere mostrato dall'utente tramite l'interfaccia utente. |
| [VERY_HIDDEN](#VERY-HIDDEN) | Indica che il foglio è nascosto e non può essere mostrato nell'interfaccia utente (UI). |
| [VISIBLE](#VISIBLE) | Indica che il foglio è visibile. |
