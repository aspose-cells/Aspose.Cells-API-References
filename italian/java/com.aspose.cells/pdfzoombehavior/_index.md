```
public final class PdfZoomBehavior
```

Specifica la modalità di visualizzazione iniziale quando il documento PDF generato viene aperto.
## Campi

| Campo | Descrizione |
| --- | --- |
| [FIT_HEIGHT](#FIT-HEIGHT) | Adatta l'altezza della pagina all'interno della finestra del visualizzatore. |
| [FIT_PAGE](#FIT-PAGE) | Adatta l'intera pagina all'interno della finestra del visualizzatore. |
| [FIT_WIDTH](#FIT-WIDTH) | Adatta la larghezza della pagina alla finestra del visualizzatore. |
| [NONE](#NONE) | Utilizza il comportamento predefinito del visualizzatore PDF. |
| [ZOOM_FACTOR](#ZOOM-FACTOR) | Apre il documento a una percentuale di zoom specifica. |
