java.lang.Object
```
public final class EquationNodeType
```

Tipo di nodo dell'equazione. Nota: (1)[1-99] Attualmente c'è solo un nodo nell'ambito, e il suo valore di enumerazione è 1. Il nodo specificato è usato per memorizzare testo matematico. (2)[100-199] Indica che il nodo è un componente di alcuni nodi di funzioni speciali. (3)[200-] Indica che il nodo ha alcune funzioni speciali.
