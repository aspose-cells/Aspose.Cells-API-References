```
public final class TextCrossType
```

Enumera il tipo di visualizzazione del testo quando la larghezza del testo è maggiore della larghezza della cella.
## Campi

| Campo | Descrizione |
| --- | --- |
| [CROSS_KEEP](#CROSS-KEEP) | Visualizza tutto il testo attraversando altre celle e conserva il testo delle celle attraversate. |
| [CROSS_OVERRIDE](#CROSS-OVERRIDE) | Visualizza tutto il testo attraversando altre celle e sovrascrive il testo delle celle attraversate. |
| [DEFAULT](#DEFAULT) | Visualizza il testo come in Microsoft Excel. |
| [STRICT_IN_CELL](#STRICT-IN-CELL) | Visualizza solo il testo entro la larghezza della cella. |
