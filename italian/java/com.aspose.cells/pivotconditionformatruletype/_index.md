Rappresenta il tipo di regola di formattazione condizionale della PivotTable.
## Campi

| Campo | Descrizione |
| --- | --- |
| [ALL](#ALL) | Indica che la formattazione condizionale Top N viene valutata su tutto l'intervallo di ambito. |
| [COLUMN](#COLUMN) | Indica che la formattazione condizionale Top N viene valutata per ogni colonna. |
| [NONE](#NONE) | Indica che la formattazione condizionale Top N non viene valutata |
| [ROW](#ROW) | Indica che la formattazione condizionale Top N viene valutata per ogni riga. |
