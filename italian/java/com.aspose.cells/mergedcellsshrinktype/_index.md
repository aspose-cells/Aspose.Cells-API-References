Rappresenta la strategia per ridurre le celle unite per operazioni come l'eliminazione di righe/colonne vuote.
## Campi

| Campo | Descrizione |
| --- | --- |
| [KEEP_HEADER_ONLY](#KEEP-HEADER-ONLY) | Mantiene solo le righe/colonne di intestazione dell'area unita quando la cella in alto a sinistra dell'area unita non è vuota. |
| [NONE](#NONE) | Lascia le celle unite così come sono senza alcuna modifica. |
| [SHRINK_TO_FIT](#SHRINK-TO-FIT) | Riduce l'area unita se necessario, rimuovendo righe dal basso o colonne da destra, garantendo che tutti i contenuti rimangano visibili. |
