```
public final class PivotAreaType
```

Indica il tipo di regola utilizzata per descrivere un'area o un aspetto della PivotTable.
## Campi

| Campo | Descrizione |
| --- | --- |
| [ALL](#ALL) | Rappresenta l'intera PivotTable. |
| [BUTTON](#BUTTON) | Rappresenta un pulsante di campo. |
| [DATA](#DATA) | Rappresenta qualcosa nell'area dati. |
| [NONE](#NONE) | Nessuna area Pivot. |
| [NORMAL](#NORMAL) | Rappresenta un'intestazione o un elemento. |
| [ORIGIN](#ORIGIN) | Rappresenta le celle vuote in alto a sinistra della PivotTable (in alto a destra per fogli RTL). |
| [TOP_RIGHT](#TOP-RIGHT) | Rappresenta le celle vuote in alto a destra della PivotTable (in alto a sinistra per fogli RTL). |
