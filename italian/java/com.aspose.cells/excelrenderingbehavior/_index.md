```
public final class ExcelRenderingBehavior
```

Specifica i comportamenti di rendering specifici di Excel da applicare durante il rendering di una cartella di lavoro.
## Campi

| Campo | Descrizione |
| --- | --- |
| [ALL](#ALL) | Applica tutti i comportamenti di rendering specifici di Excel supportati. |
| [CELL_TEXT_LENGTH_LIMIT](#CELL-TEXT-LENGTH-LIMIT) | Applica il limite di lunghezza dell'output del testo delle celle di Excel. |
| [NONE](#NONE) | Non applica i comportamenti di rendering specifici di Excel. |

### ALL {#ALL}
```
public static final int ALL
```


Applica tutti i comportamenti di rendering specifici di Excel supportati.

### CELL_TEXT_LENGTH_LIMIT {#CELL-TEXT-LENGTH-LIMIT}
```
public static final int CELL_TEXT_LENGTH_LIMIT
```


Applica il limite di lunghezza dell'output del testo delle celle di Excel. Ad esempio, Excel visualizza solo i primi 1024 caratteri in una cella non avvolta.

### NONE {#NONE}
```
public static final int NONE
```
