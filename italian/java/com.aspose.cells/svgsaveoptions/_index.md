```
public class SvgSaveOptions extends ImageSaveOptions
```

Rappresenta le opzioni di salvataggio Svg. Per un utilizzo avanzato, si prega di utilizzare [WorkbookRender](../../com.aspose.cells/workbookrender) o [SheetRender](../../com.aspose.cells/sheetrender).

**Remarks**

NOTA: Questa classe è ora obsoleta. Invece, si prega di utilizzare la classe ImageSaveOptions. Questa proprietà sarà rimossa 12 mesi dopo, a partire da marzo 2023. Aspose si scusa per eventuali disagi che potresti aver riscontrato.
