java.lang.Object
```
public final class OnErrorActionType
```

Usato nell'evento CellError di GridWeb. L'utente imposta OnErrorActionQuery.OnErrorAction per indicare al controllo di Interrompere l'elaborazione o Ignorare l'errore.
## Campi

| Campo | Descrizione |
| --- | --- |
| [IGNORE](#IGNORE) | Ignora l'errore e continua l'elaborazione. |
| [STOP](#STOP) | Interrompe l'elaborazione corrente. |
| [THROW](#THROW) | Lancia l'eccezione corrente. |
