Usato in WebCellException. Rappresenta il tipo di errore della cella.
## Campi

| Campo | Descrizione |
| --- | --- |
| [DATA_SOURCE_DELETE_ERROR](#DATA-SOURCE-DELETE-ERROR) | Quando si elimina la riga di binding del foglio verso la fonte dati, si è verificato un errore. |
| [DATA_SOURCE_INSERT_ERROR](#DATA-SOURCE-INSERT-ERROR) | Quando si inserisce la riga di binding del foglio verso la fonte dati, si è verificato un errore. |
| [DATA_SOURCE_UPDATE_ERROR](#DATA-SOURCE-UPDATE-ERROR) | Quando si aggiorna la riga di binding del foglio o il campo dell'oggetto, si è verificato un errore. |
| [VALIDATION_ERROR](#VALIDATION-ERROR) | La convalida della cella è fallita. |
