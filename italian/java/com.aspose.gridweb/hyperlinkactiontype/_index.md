java.lang.Object
```
public final class HyperlinkActionType
```

Il collegamento ipertestuale ha due tipi di azione: UrlLink e CellCommand. Il collegamento di tipo UrlLink è un'ancora in una cella; cliccandolo si naviga a un'altra pagina o si apre una nuova finestra del browser. Il collegamento di tipo CellCommand è un pulsante di comando in una cella; cliccandolo si genera un evento lato server.

**Remarks**

NOTA: Questa classe è ora obsoleta. Si prega di utilizzare GridHyperlink invece. Questa classe sarà rimossa dopo 6 mesi da agosto 2014. Aspose si scusa per eventuali disagi che potresti aver riscontrato.
