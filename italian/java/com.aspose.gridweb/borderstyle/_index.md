Il BorderStyle rappresenta le diverse opzioni di stile del bordo per un controllo web.
## Campi

| Campo | Descrizione |
| --- | --- |
| [Dashed](#Dashed) | Rappresenta una linea tratteggiata. |
| [Dotted](#Dotted) | Rappresenta una linea tratteggiata. |
| [Double](#Double) | Rappresenta una linea doppia. |
| [Groove](#Groove) | Rappresenta una linea a scanalatura. |
| [Inset](#Inset) | Rappresenta una linea interna. |
| [None](#None) | Rappresenta nessuna linea. |
| [NotSet](#NotSet) | Rappresenta una linea non impostata. |
| [Outset](#Outset) | Rappresenta una linea esterna. |
| [Ridge](#Ridge) | Rappresenta una linea a cresta. |
| [Solid](#Solid) | Rappresenta una linea solida. |
