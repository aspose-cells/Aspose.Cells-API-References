```
public final class CoWorkUserPermission
```

Rappresenta i permessi dell'utente nella modalità di collaborazione. Disponibile solo nella versione Java al momento, sarà disponibile nelle versioni .net/python in futuro.
## Campi

| Campo | Descrizione |
| --- | --- |
| [ADMIN](#ADMIN) | Permesso amministratore, l'utente ha pieno accesso incluse le operazioni di gestione |
| [DOWNLOAD](#DOWNLOAD) | Permesso di download, l'utente può visualizzare, modificare e scaricare il contenuto nella memoria locale |
| [EDITABLE](#EDITABLE) | Permesso modificabile, l'utente può visualizzare e modificare il contenuto |
| [READ_ONLY](#READ-ONLY) | Permesso di sola lettura, l'utente può solo visualizzare il contenuto ma non può apportare modifiche |
