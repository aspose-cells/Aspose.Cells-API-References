## FontSetting class

Represents a range of characters within the cell text.

```javascript
class FontSetting;
```


### Example
```javascript
const { Workbook, Color, SaveFormat } = AsposeCells;

//Istanziare un oggetto Workbook
var workbook = new Workbook();
//Aggiungere un nuovo foglio di lavoro all'oggetto Excel
workbook.worksheets.add();
//Ottenere il riferimento del foglio di lavoro appena aggiunto passando il suo indice di foglio
var worksheet = workbook.worksheets.get(0);
//Accedere alla cella "A1" dal foglio di lavoro
var cell = worksheet.cells.get("A1");
//Aggiungere un valore alla cella "A1"
cell.putValue("Visit Aspose!");
//ottenere carattere
var charactor = cell.characters(6, 7);
//Impostare il carattere dei caratteri selezionati a grassetto
charactor.font.isBold = true;
//Impostare il colore del carattere dei caratteri selezionati a blu
charactor.font.color = Color.Blue;
//Salvare il file Excel
var uint8Array = workbook.save(SaveFormat.Xlsx);
```
