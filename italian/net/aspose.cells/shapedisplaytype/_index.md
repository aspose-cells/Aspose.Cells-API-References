## ShapeDisplayType enumeration

Rappresenta come l'applicazione visualizza le forme in questa cartella di lavoro. Le forme possono includere grafici, immagini e altri dati oggetto supportati dall'applicazione.

```csharp
public enum ShapeDisplayType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| All | `0` | Indica che tutte le forme siano mostrate nella cartella di lavoro. |
| Placeholders | `1` | Indica che l'applicazione mostri segnaposti per le forme nella cartella di lavoro. |
| None | `2` | Indica che tutte le forme siano nascoste nella cartella di lavoro. |
