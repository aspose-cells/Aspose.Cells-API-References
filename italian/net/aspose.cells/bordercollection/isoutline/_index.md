## BorderCollection.IsOutline property

Indica se i bordi sinistro, destro, superiore e inferiore devono essere applicati solo ai bordi esterni di un intervallo di celle. Il valore predefinito è true.

```csharp
public bool IsOutline { get; set; }
```

### Osservazioni

Funziona solo quando viene applicato a un intervallo per formattazioni condizionali, tabelle pivot. Se false, sinistro, destro, superiore e inferiore verranno applicati a ciascuna cella, altrimenti solo ai bordi esterni di un intervallo di celle. Se true, impostare i bordi orizzontali e verticali dei bordi interni dell'intervallo per formattazioni condizionali, tabelle pivot.
