Lo spazio dei nomi **Aspose.Cells.DataModels** fornisce classi per accedere e aggiornare i modelli di dati della cartella di lavoro.

## Classi

| Classe | Descrizione |
| --- | --- |
| [DataModel](./datamodel/) | Rappresenta il modello di dati. |
| [DataModelRelationship](./datamodelrelationship/) | Rappresenta una singola relazione nel modello di dati del foglio di calcolo. |
| [DataModelRelationshipCollection](./datamodelrelationshipcollection/) | Rappresenta le relazioni. |
| [DataModelTable](./datamodeltable/) | Rappresenta le proprietà di una singola tabella nel modello di dati del foglio di calcolo. |
| [DataModelTableCollection](./datamodeltablecollection/) | Rappresenta l'elenco della tabella del modello di dati. |
