Il namespace **Aspose.Cells.WebExtensions** contiene classi per accedere agli add-in di Office nei file Excel.

## Classi

| Classe | Descrizione |
| --- | --- |
| [WebExtension](./webextension/) | Rappresenta un'istanza di Office Add-in. |
| [WebExtensionBinding](./webextensionbinding/) | Rappresenta una relazione di binding tra un Office Add-in e i dati nel documento. |
| [WebExtensionBindingCollection](./webextensionbindingcollection/) | Rappresenta l'elenco delle relazioni di binding tra un Office Add-in e i dati nel documento. |
| [WebExtensionCollection](./webextensioncollection/) | Rappresenta l'elenco delle estensioni web. |
| [WebExtensionProperty](./webextensionproperty/) | Rappresenta una proprietà personalizzata di Office Add-in. |
| [WebExtensionPropertyCollection](./webextensionpropertycollection/) | Rappresenta l'elenco delle proprietà delle estensioni web. |
| [WebExtensionReference](./webextensionreference/) | Rappresenta l'identificazione della posizione del provider e della versione dell'estensione. |
| [WebExtensionReferenceCollection](./webextensionreferencecollection/) | Rappresenta l'elenco dei riferimenti alle estensioni web. |
| [WebExtensionTaskPane](./webextensiontaskpane/) | Rappresenta un oggetto taskpane persistente. |
| [WebExtensionTaskPaneCollection](./webextensiontaskpanecollection/) | Rappresenta l'elenco dei pannelli attività. |
## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [WebExtensionStoreType](./webextensionstoretype/) | Rappresenta il tipo di archivio dell'estensione web. |
