Lo spazio dei nomi **Aspose.Cells.Properties** fornisce classi per lavorare con le proprietà del foglio di calcolo personalizzate e predefinite, come titolo, parole chiave, azienda ecc.

## Classi

| Classe | Descrizione |
| --- | --- |
| [BuiltInDocumentPropertyCollection](./builtindocumentpropertycollection/) | Una raccolta di proprietà del documento integrate. |
| [ContentTypeProperty](./contenttypeproperty/) | Rappresenta le informazioni dell'identificatore. |
| [ContentTypePropertyCollection](./contenttypepropertycollection/) | Una raccolta di oggetti [`ContentTypeProperty`](../aspose.cells.properties/contenttypeproperty/) che rappresentano informazioni aggiuntive. |
| [CustomDocumentPropertyCollection](./customdocumentpropertycollection/) | Una raccolta di proprietà del documento personalizzate. |
| [CustomProperty](./customproperty/) | Rappresenta una proprietà personalizzata che memorizza coppie nome‑valore di dati arbitrari definiti dall'utente per il foglio di lavoro. |
| [CustomPropertyCollection](./custompropertycollection/) | Una raccolta di oggetti [`CustomProperty`](../aspose.cells.properties/customproperty/) che rappresentano informazioni aggiuntive. |
| [DocumentProperty](./documentproperty/) | Rappresenta una proprietà del documento personalizzata o integrata. |
| [DocumentPropertyCollection](./documentpropertycollection/) | Classe base per le raccolte [`BuiltInDocumentPropertyCollection`](../aspose.cells.properties/builtindocumentpropertycollection/) e [`CustomDocumentPropertyCollection`](../aspose.cells.properties/customdocumentpropertycollection/). |
