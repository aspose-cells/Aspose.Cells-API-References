Lo spazio dei nomi **Aspose.Cells.LowCode** fornisce un insieme di API semplici e facili da usare per le operazioni più frequenti in modalità low‑code.

| Classe | Descrizione |
| --- | --- |

| [AbstractLowCodeSaveOptionsProvider](./abstractlowcodesaveoptionsprovider/) | Implementazione per fornire più opzioni di salvataggio per i processi che richiedono più output. | [HtmlConverter](./htmlconverter/) | Convertitore per la conversione tra file HTML (HTML o MHT) e altri formati di file di foglio di calcolo. |
| [ImageConverter](./imageconverter/) | Convertitore per la conversione di file modello in immagini. |
| [JsonConverter](./jsonconverter/) | Convertitore per la conversione tra la struttura dati JSON e altri formati di file di foglio di calcolo. |
| [LowCodeHtmlSaveOptions](./lowcodehtmlsaveoptions/) | Opzioni per salvare HTML in modalità low code. |

| [SpreadsheetMerger](./spreadsheetmerger/) | Unisce più file modello in uno solo. |
| [SpreadsheetSplitter](./spreadsheetsplitter/) | Divide il file di foglio di calcolo in più parti. |
| [TextConverter](./textconverter/) | Convertitore per la conversione tra formati basati su testo (csv, tsv, dif…) e altri formati di file di foglio di calcolo. |
