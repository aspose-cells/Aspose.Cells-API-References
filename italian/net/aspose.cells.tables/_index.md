Il namespace **Aspose.Cells.Tables** contiene classi che rappresentano tabelle, righe, celle e la loro formattazione per i file di fogli di calcolo Excel.

## Classi

| Classe | Descrizione |
| --- | --- |
| [ListColumn](./listcolumn/) | Rappresenta una colonna in una Tabella. |
| [ListColumnCollection](./listcolumncollection/) | Rappresenta un elenco di tutti gli oggetti [`ListColumn`](../aspose.cells.tables/listcolumn/) nella tabella. |
| [ListObject](./listobject/) | Rappresenta una tabella in un foglio di lavoro. |
| [ListObjectCollection](./listobjectcollection/) | Rappresenta una raccolta di oggetti [`ListObject`](../aspose.cells.tables/listobject/) nel foglio di lavoro. |
| [TableStyle](./tablestyle/) | Rappresenta lo stile della tabella. |
| [TableStyleCollection](./tablestylecollection/) | Rappresenta tutti gli stili di tabella personalizzati. |
| [TableStyleElement](./tablestyleelement/) | Rappresenta l'elemento dello stile della tabella. |
| [TableStyleElementCollection](./tablestyleelementcollection/) | Rappresenta tutti gli elementi dello stile della tabella. |
| [TableToRangeOptions](./tabletorangeoptions/) | Rappresenta le opzioni durante la conversione della tabella in intervallo. |
## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [TableDataSourceType](./tabledatasourcetype/) | Rappresenta il tipo di origine dati della tabella. |
| [TableStyleElementType](./tablestyleelementtype/) | Rappresenta il tipo di elemento di stile della Tabella o della PivotTable. |
| [TableStyleType](./tablestyletype/) | Rappresenta il tipo di stile di tabella incorporato. |
| [TotalsCalculation](./totalscalculation/) | Determina il tipo di calcolo nella riga Totali della colonna dell'elenco. |
