## Hyperlink.ActionType property

Ottiene o imposta il tipo di azione dell'ipertesto. Può essere ActionTpye.UrlLink o ActionType.CellCommand. Il tipo UrlLink indica che l'ipertesto è un collegamento a una pagina web o a una mail. Per esempio: "http://www.aspose.com" o "mailto:admin@aspose.com". Il tipo CellCommand indica che l'ipertesto genererà un evento CellCommand, e potrai gestire questo evento.

public virtual HyperlinkActionType ActionType { get; set; }
