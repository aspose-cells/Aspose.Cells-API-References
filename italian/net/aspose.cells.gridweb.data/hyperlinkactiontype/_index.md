## HyperlinkActionType enumeration

Un collegamento ipertestuale ha due tipi di azione: UrlLink e CellCommand. Il collegamento di tipo UrlLink è un'ancora in una cella; cliccandolo si naviga a un'altra pagina o si apre una nuova finestra del browser. Il collegamento di tipo CellCommand è un pulsante di comando in una cella; cliccandolo genera un evento lato server.

```csharp
public enum HyperlinkActionType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| UrlLink | `0` | Collegamento Url. Un'ancora in una cella. |
| CellCommand | `1` | Pulsante di comando cella. |
| SimpleImage | `2` | solo un'immagine semplice |
