## GridValidation.LoadValueList method

Carica l'elenco dei valori da un oggetto DataView. È possibile specificare il campo valore e il campo testo del DataView. Ogni coppia valore e testo verrà combinata in una singola stringa, con una virgola tra di esse.

```csharp
public void LoadValueList(DataView view, string valueField, string textField, bool valuePrefixText)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| view | DataView | L'oggetto DataView. |
| valueField | String | Il nome del campo valore. |
| textField | String | Il nome del campo testo. |
| valuePrefixText | Booleano | Indica se aggiungere un prefisso al valore a ciascun testo visualizzato. |
