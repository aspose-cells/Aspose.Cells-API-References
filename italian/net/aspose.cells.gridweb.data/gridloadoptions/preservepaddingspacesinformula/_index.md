## GridLoadOptions.PreservePaddingSpacesInFormula property

Indica se preservare quegli spazi e interruzioni di riga inseriti tra i token della formula durante l'ottenimento e l'impostazione delle formule. Il valore predefinito è false.

```csharp
public bool PreservePaddingSpacesInFormula { get; set; }
```

### Osservazioni

Dopo aver caricato la cartella di lavoro dal file modello con questa opzione, [`PreservePaddingSpaces`](../../gridworkbooksettings/preservepaddingspaces/) verrà impostato allo stesso valore di questa proprietà.
