## GridCells.Export method

Esporta i dati nella raccolta Cells di un WebWorksheet in un nuovo oggetto DataTable

```csharp
public DataTable Export(int startRow, int startColumn, int rows, int columns, 
    bool exportColumnName, bool isVertical)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| startRow | Int32 | Il numero di riga della prima cella da esportare. |
| startColumn | Int32 | Il numero di colonna della prima cella da esportare. |
| righe | Int32 | Numero di righe da importare. |
| colonne | Int32 | Numero di colonne da importare. |
| exportColumnName | Booleano | Indica se i dati nella prima riga vengono esportati come nome della colonna del DataTable |
| isVertical | Booleano | True se una riga nel file Excel rappresenta una riga nel DataTable. False se una colonna nel file Excel rappresenta una riga nel DataTable. |

### Valore di ritorno

Oggetto DataTable esportato.
