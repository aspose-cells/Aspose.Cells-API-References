## GridCalculationData.CalculatedValue property

Ottiene o imposta il valore calcolato per questa funzione.

```csharp
public object CalculatedValue { get; set; }
```

### Osservazioni

L'utente dovrebbe impostare questa proprietà nel suo motore di calcolo personalizzato per quelle funzioni supportate dal motore, e il valore impostato verrà restituito quando si legge questa proprietà. Leggere questa proprietà prima di impostarla farà sì che la funzione venga calcolata dal motore di calcolo predefinito di Aspose.Cells e il valore calcolato verrà restituito.
