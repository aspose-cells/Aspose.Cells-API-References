## WebCells.GetColumnReadonly method

Ottiene se una colonna è di sola lettura. Questo è un metodo esteso di GridWeb specificamente, non verrà mantenuto né avrà effetto nel file Excel reale.

```csharp
public bool GetColumnReadonly(int columnIndex)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| columnIndex | Int32 | indice colonna. |

### Valore di ritorno

Se è di sola lettura restituisce true.
