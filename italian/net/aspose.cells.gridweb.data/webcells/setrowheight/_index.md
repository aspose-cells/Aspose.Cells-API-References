## WebCells.SetRowHeight method

Imposta l'altezza della riga specificata. Il tipo di larghezza accettato è Point, Pixel o Inch.

```csharp
public void SetRowHeight(int row, Unit height)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| riga | Int32 | Indice della riga. |
| altezza | Unità | Altezza della riga. In unità di punto, deve essere compresa tra 0 e 409,5. |

### Osservazioni

Per nascondere una riga, imposta l'altezza della riga a zero.
