## GridHtmlSaveOptions.ExportArea property

Ottiene o imposta l'area CellArea da esportare del foglio di lavoro attivo corrente. Se imposti questo attributo, l'area di stampa del foglio di lavoro attivo corrente verrà omessa. Solo l'area specificata verrà esportata quando si salva il file in html.

public GridCellArea ExportArea { get; set; }
