## GridTxtLoadOptions.TreatQuotePrefixAsValue property

Indica se il segno di apice singolo iniziale deve essere considerato parte del valore di una cella. Il valore predefinito è true. Se è false, l'apice singolo iniziale verrà rimosso dal valore della cella corrispondente e [`QuotePrefix`](../../../aspose.cells.gridweb/gridtableitemstyle/quoteprefix/) sarà impostato su true per la cella.

```csharp
public bool TreatQuotePrefixAsValue { get; set; }
```
