## GridTxtLoadOptions.ExtendToNextSheet property

Indica se estendere i dati al foglio successivo quando le righe o le colonne superano il limite. Se questa proprietà è true, i dati aggiuntivi saranno spostati al foglio successivo rispetto a quello corrente (se il foglio corrente è l'ultimo, verrà aggiunto un nuovo foglio alla cartella di lavoro). Se la proprietà è false, i dati che superano il limite verranno ignorati. Il valore predefinito è false;

```csharp
public bool ExtendToNextSheet { get; set; }
```
