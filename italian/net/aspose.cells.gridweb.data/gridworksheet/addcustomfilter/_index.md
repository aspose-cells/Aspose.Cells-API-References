## GridWorksheet.AddCustomFilter method

Aggiunge un filtro personalizzato per la riga specificata.

```csharp
public void AddCustomFilter(int row, string critira)
```

### Osservazioni

La stringa dei criteri di filtro. Nota che usiamo , e ; come caratteri di separazione, quindi il valore della cella non deve contenere tali caratteri di separazione. Di seguito sono riportati esempi di stringhe di criteri //column 0 with value 12.3 CELL0 = 12.3 //column 1 with value ABC CELL1 = ABC //column 0 with value 123 or 456 or ABC and column 1 with value ABC CELL0 = 123,456,ABC; CELL1 = ABC
