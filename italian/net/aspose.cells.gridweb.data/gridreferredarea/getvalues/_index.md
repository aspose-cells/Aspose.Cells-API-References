## GridReferredArea.GetValues method

Ottiene i valori delle celle in quest'area.

```csharp
public object GetValues()
```

### Valore di ritorno

Se quest'area è non valida, verrà restituito "#REF!"; se quest'area è una singola cella, verrà restituito l'oggetto valore della cella; altrimenti restituisce un array per tutti i valori in quest'area.
