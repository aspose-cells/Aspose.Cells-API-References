Lo spazio dei nomi **Aspose.Cells.Markup** contiene classi che rappresentano semantiche definite dal cliente in un documento: smart tag, XML personalizzato e altri tag di markup.

## Classi

| Classe | Descrizione |
| --- | --- |
| [CustomXmlPart](./customxmlpart/) | Rappresenta una parte di archiviazione dati XML personalizzata (dati XML personalizzati all'interno di un pacchetto). |
| [CustomXmlPartCollection](./customxmlpartcollection/) | Rappresenta una parte di archiviazione dati XML personalizzata (dati XML personalizzati all'interno di un pacchetto). |
| [SmartTag](./smarttag/) | Rappresenta uno smart tag. |
| [SmartTagCollection](./smarttagcollection/) | Rappresenta tutti gli smart tag nella cella. |
| [SmartTagOptions](./smarttagoptions/) | Rappresenta le opzioni dello smart tag. |
| [SmartTagProperty](./smarttagproperty/) | Rappresenta la proprietà dello smart tag della cella. |
| [SmartTagPropertyCollection](./smarttagpropertycollection/) | Rappresenta tutte le proprietà dello smart tag della cella. |
| [SmartTagSetting](./smarttagsetting/) | Rappresenta tutti gli oggetti [`SmartTagCollection`](../aspose.cells.markup/smarttagcollection/) nel foglio di lavoro. |
