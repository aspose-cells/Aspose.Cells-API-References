## GridTableItemStyle.RotationAngle property

Ottiene o imposta l'attributo Rotazione.

```csharp
public short RotationAngle { get; set; }
```

### Osservazioni

0: Non ruotato.

255: Dall'alto verso il basso.

-90: Downward.

90: Verso l'alto.

Puoi impostare 255 o un valore compreso tra -90 e 90.
