## GridTableItemStyle.IsLocked property

Ottiene o imposta un valore che indica se una cella può essere modificata o meno quando il foglio di lavoro è protetto. Quando il foglio è protetto e IsLocked è vero, la cella non può essere modificata. Quando il foglio è protetto e IsLocked è falso, la cella può essere modificata.

```csharp
public bool IsLocked { get; set; }
```
