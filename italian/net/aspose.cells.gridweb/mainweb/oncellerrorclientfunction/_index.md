## MainWeb.OnCellErrorClientFunction property

Ottiene o imposta il nome della funzione lato client da chiamare quando la convalida di una cella fallisce. La funzione client deve essere dichiarata così: function MyOnCellError(cell) { alert(this.getCellValueByCell(cell)); }Nota: è possibile utilizzare il puntatore \"this\" nella funzione client per fare riferimento al controllo della griglia che genera l'evento.

public string OnCellErrorClientFunction { get; set; }
