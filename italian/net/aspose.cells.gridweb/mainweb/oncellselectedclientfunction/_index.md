## MainWeb.OnCellSelectedClientFunction property

Ottiene o imposta la funzione lato client da chiamare quando una cella è selezionata. La funzione client deve essere dichiarata così: function MyOnSelectCell(cell) { GridWeb1.setCellValueByCell(cell, \"test\"); }Nota: è possibile utilizzare il puntatore \"this\" nella funzione client per fare riferimento al controllo della griglia che genera l'evento.

public string OnCellSelectedClientFunction { get; set; }
