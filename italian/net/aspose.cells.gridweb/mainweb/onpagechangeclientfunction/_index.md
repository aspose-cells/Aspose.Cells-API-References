## MainWeb.OnPageChangeClientFunction property

Ottiene o imposta la funzione lato client da chiamare dopo il cambiamento dell'indice di pagina. Ha effetto solo quando EnablePaging è true. La funzione client dovrebbe essere dichiarata così: function MyOnPageChange(index) { console.log("current page is:"+index); }Nota: è possibile utilizzare il puntatore "this" nella funzione client per puntare al controllo grid che genera l'evento.

```csharp
public string OnPageChangeClientFunction { get; set; }
```
