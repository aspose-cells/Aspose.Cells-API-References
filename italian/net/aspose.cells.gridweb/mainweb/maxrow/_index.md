## MainWeb.MaxRow property

Ottiene o imposta l'indice massimo di visualizzazione della riga (basato su zero) del foglio web. Il controllo utilizza il valore più grande tra MaxRow e la riga massima dei dati del foglio.

```csharp
public int MaxRow { get; set; }
```

### Esempi

```csharp
[C#]
	// Crea una "finestra di visualizzazione" 4x4.
	GridWeb1.MinRow = 2;
	GridWeb1.MaxRow = 5;
	GridWeb1.MinColumn = 3;
	GridWeb1.MaxColumn = 6;

[Visual Basic]
	' Creates a 4x4 "display window".
	GridWeb1.MinRow = 2
	GridWeb1.MaxRow = 5
	GridWeb1.MinColumn = 3
	GridWeb1.MaxColumn = 6
```
