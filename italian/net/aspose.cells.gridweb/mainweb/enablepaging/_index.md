## MainWeb.EnablePaging property

Ottiene o imposta se abilitare la modalità di paginazione del controllo.

```csharp
public bool EnablePaging { get; set; }
```

### Osservazioni

Quando impostato su true, il controllo visualizzerà una volta PageSize righe di dati e mostrerà il controllo di selezione della pagina nella barra delle schede.
