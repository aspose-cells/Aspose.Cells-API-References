## MainWeb.ACWClientPath property

Ottiene o imposta il percorso web dei file script/immagine del controllo. Per esempio: "http://localhost/acw_client". È inoltre possibile impostare questo valore nel file web.config. Aggiungere questa sezione alla sezione `<configuration>`:`<appSettings>``<add key="aspose.cells.gridweb.acw_client_path" value="/acw_client/" />``</appSettings>`

public string ACWClientPath { get; set; }
