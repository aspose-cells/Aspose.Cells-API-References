## MainWeb.OnCellUnselectedClientFunction property

Ottiene o imposta la funzione lato client da chiamare quando una cella è deselezionata. La funzione client deve essere dichiarata così: function MyOnUnselectCell(cell) { this.setCellValueByCell(cell, \"test\"); }Nota: è possibile utilizzare il puntatore \"this\" nella funzione client per fare riferimento al controllo della griglia che genera l'evento.

public string OnCellUnselectedClientFunction { get; set; }
