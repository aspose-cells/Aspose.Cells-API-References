## MainWeb.IgnoreStyleWithNoData property

Ottiene o imposta se GridWeb ignora la visualizzazione di righe o colonne che non contengono valori di cella ma sono comunque formattate. Se impostato su true, le prestazioni saranno migliori. Il valore predefinito è false, il che significa che se l'ultima riga/colonna consecutiva non ha valori di cella ma è formattata, verrà comunque visualizzata. Questa opzione è valida solo quando EnableAsync è false. Questa opzione non ha effetto quando EnableAsync è true, il che significa che GridWeb mostrerà tutte le righe/colonne con stile.

```csharp
public bool IgnoreStyleWithNoData { get; set; }
```
