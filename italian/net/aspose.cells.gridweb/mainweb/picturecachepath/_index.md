## MainWeb.PictureCachePath property

Ottiene o imposta il percorso di archiviazione delle immagini per la cartella di lavoro, tutte le forme e le immagini saranno memorizzate in questa directory, il percorso predefinito è acwcache nella Directory Base dell'applicazione corrente; gli utenti devono implementare un servizio di pianificazione per pulire i file fuori dal tempo di sessione.

```csharp
public static string PictureCachePath { get; set; }
```
