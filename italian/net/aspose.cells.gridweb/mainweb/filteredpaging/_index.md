## MainWeb.FilteredPaging property

Ottiene o imposta se abilitare la paginazione dopo il filtraggio dei dati, avrà effetto quando EnablePaging è true.

```csharp
public bool FilteredPaging { get; set; }
```

### Osservazioni

Quando impostato su true, il controllo paginerà in base ai dati filtrati; il valore predefinito è false.
