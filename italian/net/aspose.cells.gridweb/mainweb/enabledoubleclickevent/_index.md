## MainWeb.EnableDoubleClickEvent property

Ottiene o imposta se abilitare l'evento di doppio clic lato cliente.

```csharp
public bool EnableDoubleClickEvent { get; set; }
```

### Osservazioni

Quando impostato su true, il controllo riceverà gli eventi di doppio clic lato client e potrai gestire questi eventi sul lato server. Altrimenti il controllo ignorerà tutti gli eventi di doppio clic.
