## MainWeb.ShowCellEditBox property

Indica se Gridweb mostra la barra degli strumenti della casella di modifica come in MS-EXCEL. Se abilitata, una casella di modifica per la cella corrente verrà visualizzata in Gridweb. Se abilitiamo questa funzionalità, è necessario importare la libreria jquery js nei file aspx per supportare questa nuova funzionalità. Qualsiasi versione recente di jquery va bene, ecc.

```csharp
public bool ShowCellEditBox { get; set; }
```
