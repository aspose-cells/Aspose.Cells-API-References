## MainWeb.SessionStorePath property

Ottiene o imposta il percorso di archiviazione della cache di sessione quando la modalità di sessione è File o ViewState, ecc: gridweb.SessionStorePath="c:/mytempdir/session"; quindi memorizzerà i dati di sessione in c:/mytempdir/session

public string SessionStorePath { get; set; }
