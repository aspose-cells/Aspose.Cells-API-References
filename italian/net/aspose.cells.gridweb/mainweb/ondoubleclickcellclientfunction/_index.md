## MainWeb.OnDoubleClickCellClientFunction property

Ottiene o imposta la funzione lato client da chiamare quando una cella viene doppio cliccata. La funzione client dovrebbe essere dichiarata così: function MyOnDoubleClickCell(cell) { this.setCellValueByCell(cell, "test"); }Nota: è possibile utilizzare il puntatore "this" nella funzione client per puntare al controllo grid che genera l'evento.

public string OnDoubleClickCellClientFunction { get; set; }
