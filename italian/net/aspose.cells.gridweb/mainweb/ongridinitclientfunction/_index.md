## MainWeb.OnGridInitClientFunction property

Ottiene o imposta il nome della funzione lato client da chiamare quando la griglia è inizializzata. La funzione client dovrebbe essere dichiarata così: function MyOnGridInit(grid) { alert("The grid is initialized: " + grid.id); }Nota: è possibile utilizzare il puntatore "this" nella funzione client per puntare al controllo grid che genera l'evento.

public string OnGridInitClientFunction { get; set; }
