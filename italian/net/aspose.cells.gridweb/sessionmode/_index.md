## SessionMode enumeration

Rappresenta la modalità di sessione della griglia.

```csharp
public enum SessionMode
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Session | `0` | Utilizza la sessione di sistema per memorizzare/ripristinare automaticamente i dati del foglio della griglia. |
| ViewState | `1` | Utilizza lo viewstate della pagina per memorizzare/ripristinare automaticamente i dati del foglio della griglia. |
| Custom | `2` | Utilizza l'evento LoadCustomData per caricare manualmente i dati del foglio della griglia. E utilizza l'evento SheetDataUpdated per salvare i dati del foglio della griglia. |
| File | `3` | Utilizza il file di sistema per memorizzare/ripristinare automaticamente i dati del foglio della griglia; è necessario impostare SessionStorePath per specificare la directory dei file. |
