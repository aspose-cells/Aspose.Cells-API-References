## Validation.ClientValidationFunction property

Ottiene o imposta il nome della funzione JavaScript di convalida client.

```csharp
public string ClientValidationFunction { get; set; }
```

### Osservazioni

Utilizza la proprietà ClientValidationFunction per specificare il nome della funzione di validazione client. La funzione deve essere dichiarata nella seguente forma: `function customValicationFunction(source, value)` Il parametro "source" è l'oggetto cella. Il parametro "value" è il valore stringa di una cella da verificare. La funzione deve restituire true se il valore è valido.
