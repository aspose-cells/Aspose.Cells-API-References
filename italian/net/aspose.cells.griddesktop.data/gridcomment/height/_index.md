## GridComment.Height property

Ottieni o imposta l'altezza del commento. Il valore predefinito è 120. Il valore di input deve essere compreso tra 20 e 1000. Verrà impostato a 20 se viene inserito un valore inferiore a 20. Verrà impostato a 1000 se viene inserito un valore superiore a 1000.

public int Height { get; set; }
