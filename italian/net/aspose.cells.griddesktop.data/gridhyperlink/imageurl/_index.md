## GridHyperlink.ImageURL property

Ottieni o imposta l'URL dell'immagine per il collegamento; non esistono proprietà imageurl nel collegamento ipertestuale, quindi si usa effettivamente TextToDisplay per registrare questo valore, TextToDisplay verrà impostato a &lt;img src=valore &gt; così cambierà il valore di TextToDisplay

```csharp
public string ImageURL { get; set; }
```
