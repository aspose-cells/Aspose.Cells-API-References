## GridImageOrPrintOptions.HorizontalResolution property

Ottiene o imposta la risoluzione orizzontale per le immagini generate, in punti per pollice. Si applica al metodo di generazione dell'immagine, eccetto le immagini in formato EMF.

```csharp
public int HorizontalResolution { get; set; }
```

### Osservazioni

Il valore predefinito è 96.
