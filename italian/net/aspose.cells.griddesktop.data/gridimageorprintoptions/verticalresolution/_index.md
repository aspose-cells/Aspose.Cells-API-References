## GridImageOrPrintOptions.VerticalResolution property

Ottiene o imposta la risoluzione verticale per le immagini generate, in punti per pollice. Si applica al metodo di generazione dell'immagine, eccetto le immagini in formato EMF.

```csharp
public int VerticalResolution { get; set; }
```

### Osservazioni

Il valore predefinito è 96.
