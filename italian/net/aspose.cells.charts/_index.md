Lo spazio dei nomi **Aspose.Cells.Charts** fornisce classi che consentono l'accesso e la creazione di grafici e sparkline nei fogli di calcolo Microsoft Excel.

| Classe | Descrizione |
| --- | --- |

| [ChartArea](./chartarea/) | Incapsula l'oggetto che rappresenta l'area del grafico nel foglio di lavoro. |
| [ChartCalculateOptions](./chartcalculateoptions/) | Rappresenta le opzioni per il calcolo di un grafico. |
| [ChartCollection](./chartcollection/) | Incapsula una raccolta di oggetti [`Chart`](../aspose.cells.charts/chart/). |
| [ChartDataTable](./chartdatatable/) | Rappresenta una tabella dati del grafico. |
| [ChartDataValue](./chartdatavalue/) | Incapsula il valore dei dati del grafico |
| [ChartFrame](./chartframe/) | Incapsula l'oggetto che rappresenta l'oggetto frame in un grafico. |
| [ChartGlobalizationSettings](./chartglobalizationsettings/) | Rappresenta le impostazioni di globalizzazione per un grafico. |
| [ChartPoint](./chartpoint/) | Rappresenta un singolo punto in una serie in un grafico. |
| [ChartPointCollection](./chartpointcollection/) | Rappresenta una raccolta che contiene tutti i punti in una serie. |
| [ChartTextFrame](./charttextframe/) | Incapsula l'oggetto che rappresenta l'oggetto frame che contiene testo. |

| [DisplayUnitLabel](./displayunitlabel/) | Rappresenta l'etichetta dell'unità di visualizzazione. |
| [DropBars](./dropbars/) | Rappresenta le barre su e giù in un grafico. |
| [ErrorBar](./errorbar/) | Rappresenta la barra di errore della serie di dati. |

| [Legend](./legend/) | Incapsula l'oggetto che rappresenta la legenda del grafico. |
| [LegendEntry](./legendentry/) | Rappresenta una voce della legenda in una legenda del grafico. |
| [LegendEntryCollection](./legendentrycollection/) | Rappresenta una raccolta di tutti gli oggetti [`LegendEntry`](../aspose.cells.charts/legendentry/) nella legenda del grafico specificata. |
| [Marker](./marker/) | Rappresenta il marcatore in un grafico a linee, a dispersione o radar. |

| [PlotArea](./plotarea/) | Incapsula l'oggetto che rappresenta l'area di tracciamento in un grafico. |
| [Series](./series/) | Incapsula l'oggetto che rappresenta una singola serie di dati in un grafico. |
| [SeriesCollection](./seriescollection/) | Incapsula una raccolta di oggetti [`Series`](../aspose.cells.charts/series/). |
| [SeriesLayoutProperties](./serieslayoutproperties/) | Rappresenta le proprietà del layout della serie. |
| [Sparkline](./sparkline/) | Una sparkline rappresenta un piccolo grafico o immagine in una cella del foglio di lavoro che fornisce una rappresentazione visiva dei dati. |
| [SparklineCollection](./sparklinecollection/) | Incapsula una raccolta di oggetti [`Sparkline`](../aspose.cells.charts/sparkline/). |
| [SparklineGroup](./sparklinegroup/) | [`Sparkline`](../aspose.cells.charts/sparkline/) è organizzato in un gruppo di sparkline. Un SparklineGroup contiene un numero variabile di elementi sparkline. Un gruppo di sparkline specifica il tipo, le impostazioni di visualizzazione e le impostazioni dell'asse per le sparkline. |
| [SparklineGroupCollection](./sparklinegroupcollection/) | Incapsula una raccolta di oggetti [`SparklineGroup`](../aspose.cells.charts/sparklinegroup/). |
| [TickLabelItem](./ticklabelitem/) | Rappresenta un'etichetta di graduazione nel grafico. |
| [TickLabels](./ticklabels/) | Rappresenta le etichette dei segni di graduazione associate ai segni di graduazione su un asse del grafico. |
| [Title](./title/) | Incapsula l'oggetto che rappresenta il titolo del grafico o dell'asse. |
| [Trendline](./trendline/) | Rappresenta una linea di tendenza in un grafico. |
| [TrendlineCollection](./trendlinecollection/) | Rappresenta una raccolta di tutti gli oggetti [`Trendline`](../aspose.cells.charts/trendline/) per la serie di dati specificata. |
| [Walls](./walls/) | Incapsula l'oggetto che rappresenta le pareti di un grafico 3-D. |
