## Style.Indent property

Rappresenta il livello m_IndentLevel per la cella o l'intervallo. Può essere solo un intero da 0 a 15.

```csharp
public int Indent { get; set; }
```

### Osservazioni

Se il tipo di allineamento orizzontale del testo è impostato su un valore diverso da sinistra o destra, il livello m_IndentLevel verrà reimpostato a zero.
