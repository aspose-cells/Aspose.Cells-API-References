## Style.Color property

Ottiene o imposta il colore di ombreggiatura della cella. Quando il modello è none, restituisce Color.Empty; quando il modello è BackgroundType.Solid, restituisce ForegroundColor; negli altri casi restituisce BackgroundColor.

```csharp
public Color Color { get; set; }
```
