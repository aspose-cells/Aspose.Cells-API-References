## ComboBox.SelectedIndex property

Ottiene o imposta l'indice che specifica l'elemento attualmente selezionato. Impostare l'indice chiamerà automaticamente il metodo GridDesktop.RunAllFormulas se la proprietà GridDesktop.RecalculateFormulas è true.

public int SelectedIndex { get; set; }
