## GridDesktop.EnableClipboardCopyPaste property

Indica se copiare/incollare basandosi negli appunti, in modo da poter copiare/incollare con MS-EXCEL. Copia/incolla solo il valore della cella, non copia alcuna altra impostazione della cella come formato, stile del bordo e così via. Il valore predefinito è false.

```csharp
public bool EnableClipboardCopyPaste { get; set; }
```
