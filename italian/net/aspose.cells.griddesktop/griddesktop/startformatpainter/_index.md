## GridDesktop.StartFormatPainter method

Notifica GridDesktop di avviare FormatPainter.

```csharp
public void StartFormatPainter(bool formatOnce)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| formatOnce | Booleano | se formatOnce è true, FormatPainter può essere usato una sola volta; se formatOnce è false, FormatPainter può essere usato più volte, fino a quando viene invocato EndFormatPainter(). |

### Esempi

```csharp
[C#]
gridDesktop1.StartFormatPainter(true);

[Visual Basic]
gridDesktop1.StartFormatPainter(True)

```
