## PivotFieldSortSetting.SortBy property

Rappresenta l'indice del campo per cui è ordinato. Un valore di -1 indica l'ordinamento per i valori propri dell'elemento pivot. Quando è maggiore o uguale a zero, rappresenta l'indice del campo dati nella regione dei dati.

public int SortBy { get; set; }
