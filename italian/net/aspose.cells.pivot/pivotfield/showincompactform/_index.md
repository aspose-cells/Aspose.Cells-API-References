## PivotField.ShowInCompactForm property

Ottiene o imposta un valore che indica se questo campo di riga utilizza il layout a forma compatta. Si applica solo ai campi di riga.

```csharp
public bool ShowInCompactForm { get; set; }
```

### Osservazioni

La forma compatta è una sotto-modalità del layout a contorno. Questa impostazione ha effetto solo quando [`ShowInOutlineForm`](../showinoutlineform/) è true.
