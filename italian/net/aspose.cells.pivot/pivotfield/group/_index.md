## Group() {#group}

Raggruppa automaticamente il campo.

```csharp
public bool Group()
```

### Osservazioni

Se il campo contiene solo valori vuoti e data/ora, il campo sarà raggruppato per Mesi. Se il campo contiene solo valori vuoti e numeri, il campo sarà raggruppato per Numero. Altrimenti restituisce solo false senza alcun raggruppamento.
