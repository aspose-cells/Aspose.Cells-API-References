## PivotTableRefreshOption.IsKeepOriginalOrder property

Indica se mantenere l'ordine originale degli elementi pivot come nella vecchia fonte dati.

```csharp
public bool IsKeepOriginalOrder { get; set; }
```

### Osservazioni

Applicabile solo per il campo pivot non ordinato. Quando si aggiorna questo tipo di campo pivot, Ms Excel mantiene l'ordine originale della vecchia origine dati. Il valore predefinito di questa proprietà è true, rappresentando lo stesso comportamento di Ms Excel. Se l'utente necessita che il campo pivot venga aggiornato completamente come i dati nella nuova origine dati, questa proprietà dovrebbe essere impostata a false.
