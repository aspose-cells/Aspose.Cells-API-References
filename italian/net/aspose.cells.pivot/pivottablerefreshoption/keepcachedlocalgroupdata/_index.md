## PivotTableRefreshOption.KeepCachedLocalGroupData property

Indica se mantenere i dati di gruppo locali nella cache se i valori massimo e minimo rimangono invariati. Il valore predefinito è false, il che significa aggiornare il gruppo con impostazioni locali.

```csharp
public bool KeepCachedLocalGroupData { get; set; }
```

Questa è una soluzione temporanea, per favore localizza le tabelle pivot implementando [`PivotGlobalizationSettings`](../../../aspose.cells.settings/pivotglobalizationsettings/)
