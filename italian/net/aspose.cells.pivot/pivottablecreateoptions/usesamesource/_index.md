## PivotTableCreateOptions.UseSameSource property

Ottiene o imposta un valore che indica se condividere la stessa origine dati con le tabelle pivot esistenti. Il valore predefinito è true.

```csharp
public bool UseSameSource { get; set; }
```

### Osservazioni

Quando impostato su true, più tabelle pivot possono riutilizzare una singola cache pivot per ridurre il consumo di memoria.
