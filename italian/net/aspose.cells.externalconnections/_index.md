Lo spazio dei nomi **Aspose.Cells.ExternalConnections** fornisce classi per connessioni esterne al fine di recuperare dati da fonti esterne come database e Web.

## Classi

| Classe | Descrizione |
| --- | --- |
| [ConnectionParameter](./connectionparameter/) | Specifica le proprietà di tutti i parametri utilizzati con connessioni dati esterne. I parametri sono validi per ODBC e query web. |
| [ConnectionParameterCollection](./connectionparametercollection/) | Specifica la collezione [`ConnectionParameter`](../aspose.cells.externalconnections/connectionparameter/) |
| [DataModelConnection](./datamodelconnection/) | Specifica una connessione al modello di dati |
| [DBConnection](./dbconnection/) | Specifica tutte le proprietà associate a una connessione dati esterna ODBC o OLE DB. |
| [ExternalConnection](./externalconnection/) | Specifica una connessione dati esterna |
| [ExternalConnectionCollection](./externalconnectioncollection/) | Specifica la collezione [`ExternalConnection`](../aspose.cells.externalconnections/externalconnection/) |
| [WebQueryConnection](./webqueryconnection/) | Specifica le proprietà per una sorgente di query web. Una query web recupererà dati da tabelle HTML e può anche fornire parametri HTTP \"Get\" da elaborare dal server web nella generazione dell'HTML includendo i parametri e gli elementi dei parametri. |
## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [ConnectionDataSourceType](./connectiondatasourcetype/) | Specifica il tipo di origine del database esterno |
| [ConnectionParameterType](./connectionparametertype/) | Specifica il tipo di parametro della connessione esterna |
| [CredentialsMethodType](./credentialsmethodtype/) | Specifica il metodo Credentials utilizzato per l'accesso al server. |
| [ExternalConnectionClassType](./externalconnectionclasstype/) | Rappresenta il tipo di connessione |
| [HtmlFormatHandlingType](./htmlformathandlingtype/) | Specifica come gestire la formattazione dalla sorgente HTML |
| [OLEDBCommandType](./oledbcommandtype/) | Specifica il tipo di comando OLE DB. |
| [ReConnectionMethodType](./reconnectionmethodtype/) | Specifica cosa deve fare l'applicazione di foglio di calcolo quando una connessione fallisce. |
| [SqlDataType](./sqldatatype/) | Specifica il tipo di dato SQL del parametro. Valido solo per le origini ODBC. |
