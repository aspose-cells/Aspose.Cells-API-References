## Config.IslimitShapeOrImage property

Ottiene/Imposta se limitare il conteggio totale di forme/immagini visualizzate in un foglio di lavoro. Se impostato su true, GridJs limiterà il conteggio totale di forme o immagini visualizzate in un foglio di lavoro a MaxShapeOrImageCount. Il valore predefinito è true.

```csharp
public static bool IslimitShapeOrImage { get; set; }
```
