## Config.AutoFitRowsHeightOnLoad property

Indica se adattare automaticamente l'altezza delle righe durante il caricamento del file. Il valore predefinito è `false`. Attenzione: impostare questo a `true` eseguirà un'operazione di adattamento automatico di tutte le righe dopo il caricamento, il che può avere un impatto notevole sulle prestazioni.

```csharp
public static bool AutoFitRowsHeightOnLoad { get; set; }
```
