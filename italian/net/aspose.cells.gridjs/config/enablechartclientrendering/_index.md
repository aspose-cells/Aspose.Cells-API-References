## Config.EnableChartClientRendering property

Ottiene/Imposta se abilitare il rendering dei grafici lato client. Se impostato su false, GridJs tornerà a utilizzare solo immagini/forme di grafico generate dal server. Il valore predefinito è true.

```csharp
public static bool EnableChartClientRendering { get; set; }
```
