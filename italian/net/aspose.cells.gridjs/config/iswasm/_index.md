## Config.IsWasm property

Ottiene/Imposta se GridJs viene eseguito all'interno di un host WebAssembly del browser invece di un processo server. Quando true, non viene utilizzato alcun percorso FileCacheDirectory / disco / thread di interruzione e la cache dei file deve provenire da GridJsOptions.CacheImp. GridJsOptions.IsWasm imposta questo quando il servizio GridJs viene costruito, così un unico Aspose.Cells.GridJs.dll serve entrambi gli host. Il valore predefinito è false.

```csharp
public static bool IsWasm { get; set; }
```
