## Config.AutoOptimizeForLargeCells property

Ottiene/Imposta se ottimizzare automaticamente le prestazioni di caricamento per fogli di lavoro con celle grandi. Ignorerà alcuni stili/bordi per ridurre il tempo di caricamento. Il valore predefinito è true.

public static bool AutoOptimizeForLargeCells { get; set; }
