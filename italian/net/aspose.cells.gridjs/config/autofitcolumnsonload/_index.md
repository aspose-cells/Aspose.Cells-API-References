## Config.AutoFitColumnsOnLoad property

Indica se adattare automaticamente la larghezza delle colonne durante il caricamento del file. Il valore predefinito è `false`. Attenzione: impostare questo a `true` eseguirà un'operazione di adattamento automatico di tutte le colonne dopo il caricamento, il che può avere un impatto notevole sulle prestazioni.

```csharp
public static bool AutoFitColumnsOnLoad { get; set; }
```
