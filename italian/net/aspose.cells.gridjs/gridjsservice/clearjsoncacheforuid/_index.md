## GridJsService.ClearJsonCacheForUid method

Cancella tutte le voci della cache JSON appartenenti all'ID univoco specificato. Esegui questa operazione dopo aver modificato il file sorgente al di fuori del flusso normale, così la prossima richiesta rigenera il JSON.

```csharp
public void ClearJsonCacheForUid(string uid)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| uid | String | L'ID univoco per la cache del file. |
