## JsonCacheOptions.Enable property

Ottiene/Imposta se abilitare la cache JSON per una risposta più veloce. Quando abilitato, GridJs memorizzerà nella cache il JSON generato e lo riutilizzerà per le richieste successive. Il valore predefinito è false. Nota: è necessario impostare Implementation per utilizzare un archivio cache personalizzato.

```csharp
public bool Enable { get; set; }
```
