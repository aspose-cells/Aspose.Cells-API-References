## CoWorkUserProvider interface

Rappresenta l'interfaccia del provider utente nella modalità collaborativa. Disponibile solo nella versione Java al momento, sarà disponibile nelle versioni .net/python in futuro. L'applicazione cliente può implementare questa interfaccia per fornire le informazioni sull'utente.
