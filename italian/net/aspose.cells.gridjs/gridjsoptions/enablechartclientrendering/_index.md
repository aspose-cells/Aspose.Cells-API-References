## GridJsOptions.EnableChartClientRendering property

Ottiene/Imposta se abilitare il rendering dei grafici lato client. Se impostato su false, GridJs emetterà solo immagini/forme dei grafici e non richiederà il rendering lato client. Il valore predefinito è true.

```csharp
public bool EnableChartClientRendering { get; set; }
```
