## GridJsOptions.CacheImp field

Implementazione personalizzata per l'archiviazione della cache. Se desideri memorizzare la cache in modalità stream, devi impostarla e implementarla. Un host WebAssembly (IsWasm = true) deve impostarla, poiché non esiste un disco locale per la cache dei file predefinita.

public GridCacheForStream CacheImp;
