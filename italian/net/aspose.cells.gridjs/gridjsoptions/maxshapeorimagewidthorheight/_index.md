## GridJsOptions.MaxShapeOrImageWidthOrHeight property

Ottiene/Imposta la larghezza o altezza massima per una forma o un'immagine; GridJs ignorerà la forma o l'immagine con larghezza o altezza superiore a questo valore, ha effetto quando IslimitShapeOrImage=true. Il valore predefinito è 10000.

```csharp
public int MaxShapeOrImageWidthOrHeight { get; set; }
```
