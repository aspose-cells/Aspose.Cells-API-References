## GridJsOptions.IgnoreEmptyContent property

Ottiene/Imposta se mostrare l'intervallo massimo che include dati, stile, celle unite e forme. Se l'ultima riga o colonna contiene celle senza valore e formula ma con stile personalizzato, allora non mostreremo questa riga/colonna quando questo valore è true. Il valore predefinito è true.

```csharp
public bool IgnoreEmptyContent { get; set; }
```
