## GridJsOptions.IsWasm property

Ottiene/Imposta se GridJs viene eseguito all'interno di un host WebAssembly del browser anziché di un processo server. Quando è true, non viene utilizzato alcun percorso FileCacheDirectory / disco / thread di interruzione, e la cache dei file deve provenire da CacheImp, poiché un host browser non ha disco locale. Seleziona i percorsi di codice a runtime, quindi un unico Aspose.Cells.GridJs.dll serve entrambi gli host. Il valore predefinito è false.

```csharp
public bool IsWasm { get; set; }
```
