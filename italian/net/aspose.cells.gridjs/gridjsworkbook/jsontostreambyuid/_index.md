## GridJsWorkbook.JsonToStreamByUid method

Recupera la stringa JSON del file dalla cache usando l'ID unico specificato, imposta il nome file di output nel JSON e scrivila nello stream.

```csharp
public bool JsonToStreamByUid(Stream stream, string uid, string filename)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| stream | Stream | Lo stream che verrà scritto |
| uid | String | L'ID univoco per la cache del file. |
| filename | String | Specifica il nome del file nel JSON. Se impostato a null, il nome file predefinito è: book1. |
