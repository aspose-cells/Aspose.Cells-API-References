## GridJsWorkbook.SetTransParentView method

Imposta la trasparenza delle forme di redazione nella cartella di lavoro.

```csharp
public void SetTransParentView(string excelFilePath, string uid, bool isTransparent)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| excelFilePath | String | Il percorso del file Excel. |
| uid | String | L'identificatore univoco per la cartella di lavoro. Se null o vuoto, verrà generato un nuovo uid basato sul percorso del file. |
| isTransparent | Booleano | Se vero, imposta la trasparenza a 0,89 (semi-trasparente); se falso, imposta la trasparenza a 1 (completamente opaco/invisibile). |
