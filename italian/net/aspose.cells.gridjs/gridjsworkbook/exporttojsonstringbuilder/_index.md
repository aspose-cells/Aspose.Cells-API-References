## GridJsWorkbook.ExportToJsonStringBuilder method

Ottiene la stringa JSON dai dati in memoria, imposta il nome file di output nel JSON.

```csharp
public StringBuilder ExportToJsonStringBuilder(string filename, string uid = null)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| filename | String | Specifica il nome file nel JSON. Se impostato a null, il nome file predefinito è: book1.. |
| uid | String | ID univoco opzionale per la cache JSON. Se fornito e la cache è abilitata, verrà controllata/aggiornata la cache. |

### Valore di ritorno

Il StringBuilder JSON.
