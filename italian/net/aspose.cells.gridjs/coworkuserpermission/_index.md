## CoWorkUserPermission enumeration

rappresenta il permesso dell'utente nella modalità collaborativa. Disponibile solo nella versione Java al momento, sarà disponibile nelle versioni .net/python in futuro.

```csharp
public enum CoWorkUserPermission
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| READ_ONLY | `0` | Permesso di sola lettura, l'utente può solo visualizzare il contenuto ma non può apportare modifiche |
| EDITABLE | `1` | Permesso modificabile, l'utente può visualizzare e modificare il contenuto |
| DOWNLOAD | `2` | Permesso di download, l'utente può visualizzare, modificare e scaricare il contenuto nella memoria locale |
| ADMIN | `3` | Permesso di amministratore, l'utente ha accesso completo incluse le operazioni di gestione |
