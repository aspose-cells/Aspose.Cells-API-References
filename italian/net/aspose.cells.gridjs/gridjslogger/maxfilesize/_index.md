## GridJsLogger.MaxFileSize property

Ottiene o imposta la dimensione massima (in byte) per un singolo file di log prima del rollover. È efficace solo quando il rollover è abilitato. 0 significa nessun limite di dimensione. Il valore predefinito è 0.

public static long MaxFileSize { get; set; }
