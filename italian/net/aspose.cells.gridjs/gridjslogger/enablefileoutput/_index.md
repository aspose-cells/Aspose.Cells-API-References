## GridJsLogger.EnableFileOutput property

Ottiene o imposta se inviare i messaggi di log su un file. Il valore predefinito è false. È necessario chiamare [`SetLogFile`](../setlogfile/) o [`SetLogDirectory`](../setlogdirectory/) prima di abilitare.

public static bool EnableFileOutput { get; set; }
