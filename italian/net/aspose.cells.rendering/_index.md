Il namespace **Aspose.Cells.Rendering** fornisce classi per il rendering di immagini e PDF.

## Classi

| Classe | Descrizione |
| --- | --- |
| [CustomRenderSettings](./customrendersettings/) | Rappresenta le impostazioni personalizzate durante il rendering. |
| [DrawObject](./drawobject/) | DrawObject verrà inizializzato e restituito durante il rendering. |
| [DrawObjectEventHandler](./drawobjecteventhandler/) | Interfaccia per ottenere DrawObject e Bound durante il rendering. |
| [ImageOrPrintOptions](./imageorprintoptions/) | Consente di specificare le opzioni durante il rendering del foglio di lavoro in immagini, la stampa del foglio di lavoro o il rendering del grafico in immagine. |
| [PageEndSavingArgs](./pageendsavingargs/) | Informazioni per una pagina terminano il processo di salvataggio. |
| [PageSavingArgs](./pagesavingargs/) | Informazioni per il processo di salvataggio di una pagina. |
| [PageStartSavingArgs](./pagestartsavingargs/) | Informazioni per l'avvio del processo di salvataggio di una pagina. |
| [PdfBookmarkEntry](./pdfbookmarkentry/) | PdfBookmarkEntry è una voce nel segnalibro PDF. Se la proprietà Text dell'istanza corrente è null o "", l'istanza corrente sarà nascosta e i figli saranno inseriti al livello corrente. |
| [RenderingFont](./renderingfont/) | Font per il rendering. |
| [RenderingWatermark](./renderingwatermark/) | Filigrana per il rendering. |
| [SheetPrintingPreview](./sheetprintingpreview/) | Anteprima di stampa del foglio di lavoro. |
| [SheetRender](./sheetrender/) | Rappresenta il rendering di un foglio di lavoro che può renderizzare il foglio in varie immagini come (BMP, PNG, JPEG, TIFF...). Il costruttore di questa classe deve essere utilizzato dopo la modifica di pagesetup e dello stile delle celle. |
| [SheetSet](./sheetset/) | Descrive un insieme di fogli. |
| [SvgImageOptions](./svgimageoptions/) | Opzioni per la generazione di un'immagine Svg. |
| [WorkbookPrintingPreview](./workbookprintingpreview/) | Anteprima di stampa della cartella di lavoro. |
| [WorkbookRender](./workbookrender/) | Rappresenta il rendering di una cartella di lavoro. Il costruttore di questa classe deve essere utilizzato dopo la modifica di pagesetup e dello stile delle celle. |
