## PdfZoomBehavior enumeration

Specifica la modalità di visualizzazione iniziale quando il documento PDF generato viene aperto.

```csharp
public enum PdfZoomBehavior
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| None | `0` | Utilizza il comportamento predefinito del visualizzatore PDF. |
| ZoomFactor | `1` | Apre il documento a una percentuale di zoom specifica. |
| FitPage | `2` | Adatta l'intera pagina alla finestra del visualizzatore. |
| FitWidth | `3` | Adatta la larghezza della pagina alla finestra del visualizzatore. |
| FitHeight | `4` | Adatta l'altezza della pagina alla finestra del visualizzatore. |
