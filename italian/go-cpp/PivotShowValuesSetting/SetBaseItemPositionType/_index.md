## SetBaseItemPositionType function

Rappresenta il tipo dell'elemento pivot base nel campo base quando il calcolo ShowDataAs è in uso. Valido solo per i campi dati. Poiché PivotItemPosition.Custom è solo in lettura, se è necessario impostare PivotItemPosition.Custom, impostare l'attributo PivotField.BaseItemIndex.
