## HtmlSpaceMode Enum

Specifica come gli spazi bianchi sono rappresentati nell'HTML generato.

```go

type HtmlSpaceMode int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Character](./character/) | Usa le entità dei caratteri HTML (come &amp;nbsp;, &amp;ensp) per rappresentare gli spazi bianchi |
| [Css](./css/) | Utilizza le proprietà CSS, come padding, per rappresentare gli spazi bianchi. |
