## CrossType Enum

Rappresenta il tipo di intersezione dell'asse.

```go

type CrossType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Automatic](./automatic/) | Microsoft Excel imposta il punto di intersezione dell'asse. |
| [Maximum](./maximum/) | L'asse si incrocia al valore massimo. |
| [Minimum](./minimum/) | L'asse si incrocia al valore minimo. |
| [Custom](./custom/) | L'asse si incrocia al valore personalizzato. |
