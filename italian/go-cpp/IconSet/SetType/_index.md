## SetType function

Ottieni o imposta il tipo di set di icone da visualizzare. Impostare il tipo verificherà automaticamente se il conteggio corrente di Cfvos è conforme al nuovo tipo. Se non è conforme, i vecchi Cfvos verranno puliti e verranno aggiunti i Cfvos predefiniti.

```go

func (instance *IconSet) SetType(value IconSetType)  error

```
