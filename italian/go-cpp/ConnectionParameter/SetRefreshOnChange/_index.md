## SetRefreshOnChange function

Flag che indica se la query deve aggiornarsi automaticamente quando il contenuto di una cella che fornisce il valore del parametro cambia. Se true, i dati esterni vengono aggiornati utilizzando il nuovo valore del parametro ogni volta che si verifica una modifica. Se false, i dati esterni vengono aggiornati solo quando richiesto dall'utente, o quando qualche altro evento attiva l'aggiornamento (ad esempio, apertura della cartella di lavoro).

func (instance *ConnectionParameter) SetRefreshOnChange(value bool)  error
