## PivotAreaType Enum

Indica il tipo di regola utilizzata per descrivere un'area o un aspetto della Tabella Pivot.

```go

type PivotAreaType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [None](./none/) | Nessuna area Pivot. |
| [Normal](./normal/) | Rappresenta un'intestazione o un elemento. |
| [Data](./data/) | Rappresenta qualcosa nell'area dati. |
| [All](./all/) | Rappresenta l'intera PivotTable. |
| [Origin](./origin/) | Rappresenta le celle vuote in alto a sinistra della PivotTable (in alto a destra per i fogli RTL). |
| [Button](./button/) | Rappresenta un pulsante di campo. |
| [TopRight](./topright/) | Rappresenta le celle vuote in alto a destra della PivotTable (in alto a sinistra per i fogli RTL). |
