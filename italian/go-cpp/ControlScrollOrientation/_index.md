## ControlScrollOrientation Enum

Rappresenta il tipo di orientamento dello scorrimento

```go

type ControlScrollOrientation int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Auto](./auto/) | Il controllo è visualizzato orizzontalmente quando la larghezza del controllo è maggiore della sua altezza. Il controllo è visualizzato verticalmente altrimenti. |
| [Vertical](./vertical/) | Il controllo è visualizzato verticalmente. |
| [Horizontal](./horizontal/) | Il controllo è visualizzato orizzontalmente. |
