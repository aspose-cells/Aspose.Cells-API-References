## WebExtensionStoreType Enum

Rappresenta il tipo di archivio dell'estensione web.

```go

type WebExtensionStoreType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [OMEX](./omex/) | Specifica che il tipo di archivio è Office.com. |
| [SPCatalog](./spcatalog/) | Specifica che il tipo di archivio è il catalogo aziendale SharePoint. |
| [SPApp](./spapp/) | Specifica che il tipo di archivio è un'applicazione web SharePoint. |
| [Exchange](./exchange/) | Specifica che il tipo di archivio è un server Exchange. |
| [FileSystem](./filesystem/) | Specifica che il tipo di archivio è una condivisione del file system. |
| [Registry](./registry/) | Specifica che il tipo di archivio è il registro di sistema. |
| [ExCatalog](./excatalog/) | Specifica che il tipo di archivio è Distribuzione Centralizzata tramite Exchange. |
