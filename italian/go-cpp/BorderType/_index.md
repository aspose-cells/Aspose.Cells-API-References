## BorderType Enum

Enumera i tipi di linee di bordo e linee diagonali.

```go

type BorderType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [LeftBorder](./leftborder/) | Rappresenta la linea del bordo sinistro. |
| [RightBorder](./rightborder/) | Rappresenta la linea del bordo destro esistente. |
| [TopBorder](./topborder/) | Rappresenta la linea del bordo superiore. |
| [BottomBorder](./bottomborder/) | Rappresenta la linea del bordo inferiore. |
| [DiagonalDown](./diagonaldown/) | Rappresenta la linea diagonale dall'angolo in alto a sinistra a quello in basso a destra. |
| [DiagonalUp](./diagonalup/) | Rappresenta la linea diagonale dall'angolo in basso a sinistra a quello in alto a destra. |
| [Vertical](./vertical/) | Solo per stile dinamico, come formattazione condizionale, tabella pivot. |
| [Horizontal](./horizontal/) | Solo per stile dinamico, come formattazione condizionale, tabella pivot. |
| [SideBorders](./sideborders/) | Indica i quattro bordi laterali: <see cref="LeftBorder"/>,<see cref="RightBorder"/>, <see cref="TopBorder"/> e <see cref="BottomBorder"/>. |
| [Diagonal](./diagonal/) | Combinazione speciale di più bordi per comodità dell'utente in alcune API. Indica i bordi diagonali di <see cref="DiagonalUp"/> e <see cref="DiagonalDown"/>. |
| [DynamicStyleBorders](./dynamicstyleborders/) | Indica <see cref="Vertical"/> e <see cref="Horizontal"/> dello stile dinamico. |
| [None](./none/) | Nessun bordo è stato specificato. |
