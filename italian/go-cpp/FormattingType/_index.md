## FormattingType Enum

Rappresenta il tipo di formattazione applicata a un oggetto <see cref=\"Area\"/> o a un oggetto <see cref=\"Line\"/>.

```go

type FormattingType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Automatic](./automatic/) | Rappresenta il tipo di formattazione automatica. |
| [Custom](./custom/) | Rappresenta un tipo di formattazione personalizzato. |
| [None](./none/) | Rappresenta il tipo di formattazione nessuna. |
