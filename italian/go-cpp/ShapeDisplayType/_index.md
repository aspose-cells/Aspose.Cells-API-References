## ShapeDisplayType Enum

Rappresenta come l'applicazione visualizza le forme in questa cartella di lavoro. Le forme possono includere grafici, immagini e altri dati di oggetti supportati dall'applicazione.

```go

type ShapeDisplayType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [All](./all/) | Indica che tutte le forme siano visualizzate nella cartella di lavoro. |
| [Placeholders](./placeholders/) | Indica che l'applicazione mostri segnaposti per le forme nella cartella di lavoro. |
| [None](./none/) | Indica che tutte le forme siano nascoste nella cartella di lavoro. |
