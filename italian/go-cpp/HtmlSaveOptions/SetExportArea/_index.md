## SetExportArea function

Ottiene o imposta l'area di cella da esportare del foglio di lavoro attivo corrente. Se imposti questo attributo, l'area di stampa del foglio di lavoro attivo corrente verrà omessa. Solo l'area specificata verrà esportata durante il salvataggio del file in html.

```go

func (instance *HtmlSaveOptions) SetExportArea(value *CellArea)  error

```
