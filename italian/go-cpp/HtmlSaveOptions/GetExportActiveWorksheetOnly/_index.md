## GetExportActiveWorksheetOnly function

Indica se esportare solo il foglio di lavoro attivo in un file html. Se true, verrà esportato solo il foglio di lavoro attivo; se false, verrà esportata l'intera cartella di lavoro. Il valore predefinito è false.
