## WeightType Enum

Enumera i tipi di peso per il bordo di un'immagine o per una linea di grafico.

```go

type WeightType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [HairLine](./hairline/) | Rappresenta lo spessore di una linea sottile. |
| [MediumLine](./mediumline/) | Rappresenta lo spessore di una linea media. |
| [SingleLine](./singleline/) | Rappresenta lo spessore di una linea singola. |
| [WideLine](./wideline/) | Rappresenta lo spessore di una linea larga. |
