## PdfFontEncoding Enum

Rappresenta la codifica del carattere incorporato nel PDF.

```go

type PdfFontEncoding int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Identity](./identity/) | Rappresenta l'uso della codifica Identity-H per tutti i font incorporati nel pdf. |
| [AnsiPrefer](./ansiprefer/) | Rappresenta la preferenza di usare WinAnsiEncoding per i font TrueType con caratteri da 32 a 127; altrimenti, verrà usata la codifica Identity-H per i font incorporati nel pdf. |
