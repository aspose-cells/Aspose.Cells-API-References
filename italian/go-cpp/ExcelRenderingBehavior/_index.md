## ExcelRenderingBehavior Enum

Specifica i comportamenti di rendering specifici di Excel da applicare durante il rendering di una cartella di lavoro.

```go

type ExcelRenderingBehavior int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [None](./none/) | Non applica comportamenti di rendering specifici di Excel. |
| [CellTextLengthLimit](./celltextlengthlimit/) | Applica il limite di lunghezza dell'output di testo delle celle di Excel. Per esempio, Excel restituisce solo i primi 1024 caratteri in una cella non avvolta. |
| [All](./all/) | Applica tutti i comportamenti di rendering specifici di Excel supportati. |
