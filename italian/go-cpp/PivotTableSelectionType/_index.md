## PivotTableSelectionType Enum

Specifica cosa può essere selezionato in una PivotTable durante una selezione strutturata. Queste costanti possono essere combinate per selezionare più tipi.

```go

type PivotTableSelectionType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [DataAndLabel](./dataandlabel/) | Dati e etichette |
| [DataOnly](./dataonly/) | Seleziona solo i dati |
| [LabelOnly](./labelonly/) | Seleziona solo le etichette |
