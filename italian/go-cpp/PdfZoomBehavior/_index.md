## PdfZoomBehavior Enum

Specifica la modalità di visualizzazione iniziale quando il documento PDF generato viene aperto.

```go

type PdfZoomBehavior int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [None](./none/) | Utilizza il comportamento predefinito del visualizzatore PDF. |
| [ZoomFactor](./zoomfactor/) | Apre il documento a una percentuale di zoom specifica. |
| [FitPage](./fitpage/) | Adatta l'intera pagina all'interno della finestra del visualizzatore. |
| [FitWidth](./fitwidth/) | Adatta la larghezza della pagina alla finestra del visualizzatore. |
| [FitHeight](./fitheight/) | Adatta l'altezza della pagina alla finestra del visualizzatore. |
