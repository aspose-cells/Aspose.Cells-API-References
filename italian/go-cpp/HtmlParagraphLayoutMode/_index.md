## HtmlParagraphLayoutMode Enum

Specifica come gli elementi HTML &lt;p&gt; vengono renderizzati durante il caricamento di HTML.

```go
type HtmlParagraphLayoutMode int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Normal](./normal/) | Tratta &lt;p&gt; all'interno di &lt;td&gt; come contenuto inline in una singola cella. |
| [AsRow](./asrow/) | Avvia una nuova riga per ogni elemento &lt;p&gt;. |
