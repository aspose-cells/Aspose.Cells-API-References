## HtmlLinkTargetType Enum

Rappresenta il tipo di attributo target nel tag HTML <a/>.

```go

type HtmlLinkTargetType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Blank](./blank/) | Apre il documento collegato in una nuova finestra o scheda |
| [Parent](./parent/) | Apre il documento collegato nel frame genitore |
| [Self](./self/) | Apre il documento collegato nello stesso frame in cui è stato cliccato (questo è il valore predefinito) |
| [Top](./top/) | Apre il documento collegato nell'intero corpo della finestra |
