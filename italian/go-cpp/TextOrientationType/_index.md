## TextOrientationType Enum

Enumera i tipi di orientamento del testo.

```go

type TextOrientationType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [ClockWise](./clockwise/) | Ruota il testo di 90 gradi in senso orario. |
| [CounterClockWise](./counterclockwise/) | Ruota il testo di 90 gradi in senso antiorario. |
| [NoRotation](./norotation/) | Rappresenta il valore predefinito. |
| [TopToBottom](./toptobottom/) | Visualizza il testo dall'alto verso il basso della cella. Testo impilato. |
