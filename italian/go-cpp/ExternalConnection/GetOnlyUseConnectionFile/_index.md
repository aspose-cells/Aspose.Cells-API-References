## GetOnlyUseConnectionFile function

Indica se l'applicazione di foglio elettronico deve sempre e solo utilizzare le informazioni di connessione nel file di connessione esterno indicato dall'attributo odcFile quando la connessione viene aggiornata. Se false, l'applicazione di foglio elettronico deve seguire la procedura indicata dall'attributo reconnectionMethod.
