## TextTabAlignmentType Enum

Rappresenta i tipi di allineamento delle tabulazioni di testo.

```go

type TextTabAlignmentType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Center](./center/) | Il testo a questa tabulazione è allineato al centro. |
| [Decimal](./decimal/) | A questa tabulazione, i decimali sono allineati. |
| [Left](./left/) | Il testo a questa tabulazione è allineato a sinistra. |
| [Right](./right/) | Il testo a questa tabulazione è allineato a destra. |
