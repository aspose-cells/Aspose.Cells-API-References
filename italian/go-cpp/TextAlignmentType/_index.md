## TextAlignmentType Enum

Enumera i tipi di allineamento del testo.

```go

type TextAlignmentType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [General](./general/) | Rappresenta l'allineamento generale del testo. |
| [Bottom](./bottom/) | Rappresenta l'allineamento del testo in basso. |
| [Center](./center/) | Rappresenta l'allineamento del testo al centro. |
| [CenterAcross](./centeracross/) | Rappresenta l'allineamento del testo centrato su tutta la linea. |
| [Distributed](./distributed/) | Rappresenta l'allineamento del testo distribuito. |
| [Fill](./fill/) | Rappresenta l'allineamento del testo di riempimento. |
| [Justify](./justify/) | Rappresenta l'allineamento del testo giustificato. |
| [Left](./left/) | Rappresenta l'allineamento del testo a sinistra. |
| [Right](./right/) | Rappresenta l'allineamento del testo a destra. |
| [Top](./top/) | Rappresenta l'allineamento del testo in alto. |
| [JustifiedLow](./justifiedlow/) | Allinea il testo con una lunghezza di kashida regolata per il testo arabo. |
| [ThaiDistributed](./thaidistributed/) | Distribuisce il testo tailandese in modo speciale, perché ogni carattere è trattato come una parola. |
