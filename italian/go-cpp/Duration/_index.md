## Duration Struct

Rappresenta un intervallo di tempo con una risoluzione di 100 nanosecondi (tick).

```go

type Duration int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [value](./value/) | Rappresentazione interna dell'intervallo di tempo in tick. 1 tick = 100 nanosecondi. |
