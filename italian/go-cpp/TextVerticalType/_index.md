## TextVerticalType Enum

Rappresenta il tipo di direzione del testo.

```go

type TextVerticalType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Vertical](./vertical/) | Visualizzazione verticale dell'Est asiatico. |
| [Horizontal](./horizontal/) | Testo orizzontale. |
| [VerticalLeftToRight](./verticallefttoright/) | Visualizzato verticalmente e il testo scorre dall'alto verso il basso poi DA SINISTRA A DESTRA |
| [Vertical90](./vertical90/) | Ogni riga è ruotata di 90 gradi in senso orario |
| [Vertical270](./vertical270/) | Ogni riga è ruotata di 270 gradi in senso orario |
| [Stacked](./stacked/) | Determina se tutto il testo è verticale |
| [StackedRightToLeft](./stackedrighttoleft/) | Specifica che il WordArt verticale dovrebbe essere mostrato da destra a sinistra anziché da sinistra a destra. |
