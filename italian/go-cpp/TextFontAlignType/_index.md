## TextFontAlignType Enum

Rappresenta i diversi tipi di allineamento del carattere.

```go

type TextFontAlignType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Automatic](./automatic/) | Quando il flusso di testo è orizzontale o verticale semplice, è lo stesso di fontBaseline, ma per le altre modalità verticali è lo stesso di fontCenter. |
| [Bottom](./bottom/) | Le lettere sono ancorate al fondo molto basso di una singola riga. |
| [Baseline](./baseline/) | Le lettere sono ancorate alla linea di base inferiore di una singola riga. |
| [Center](./center/) | Le lettere sono ancorate tra le due linee di base di una singola riga. |
| [Top](./top/) | Le lettere sono ancorate alla linea di base superiore di una singola riga. |
