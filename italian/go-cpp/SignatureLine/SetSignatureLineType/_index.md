## SetSignatureLineType function

Ottiene o imposta il tipo di firma. Default - Quando il valore predefinito è impostato, il valore corrispondente di ProviderId è fissato a {0000000000-0000-0000-0000-0000000000}. Stamp - Quando il valore è Stamp, il valore corrispondente di ProviderId è solitamente {000CD6A4-0000-0000-C000-000000000046}. Custom - Quando il valore è Custom, il valore corrispondente di ProviderId di solito deve essere impostato dall'utente. dovrebbe essere ottenuto dalla documentazione fornita con il provider.
