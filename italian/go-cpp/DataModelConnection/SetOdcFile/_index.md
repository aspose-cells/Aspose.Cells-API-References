## SetOdcFile function

Specifica il percorso completo al file di connessione esterno da cui è stata creata questa connessione. Se una connessione fallisce durante un tentativo di aggiornamento dei dati, e reconnectionMethod=1, l'applicazione di foglio elettronico proverà di nuovo utilizzando le informazioni dal file di connessione esterno invece dell'oggetto di connessione incorporato nella cartella di lavoro.
