## SetSecondCategoryData function

Ottiene o imposta l'intervallo dei valori del secondo asse di categoria. Può essere un intervallo di celle (ad esempio, "d1:e10"), o una sequenza di valori (ad esempio, "{2,6,8,10}"). Ha effetto solo quando alcune serie sono state tracciate sul secondo asse.
