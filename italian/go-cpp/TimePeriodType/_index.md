## TimePeriodType Enum

Usato in una regola di formattazione condizionale FormatConditionType.TimePeriod. Questi sono periodi di tempo dinamici, che cambiano in base alla data in cui la formattazione condizionale viene aggiornata / applicata.

```go

type TimePeriodType int32


```
