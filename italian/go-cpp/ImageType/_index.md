## ImageType Enum

Specifica il tipo (formato) di un'immagine.

```go

type ImageType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Unknown](./unknown/) | Un tipo di immagine sconosciuto. |
| [Emf](./emf/) | Windows Enhanced Metafile. |
| [Wmf](./wmf/) | Windows Metafile. |
| [Pict](./pict/) | Macintosh PICT. |
| [Jpeg](./jpeg/) | JPEG JFIF. |
| [Png](./png/) | Portable Network Graphics. |
| [Bmp](./bmp/) | Windows Bitmap |
| [Gif](./gif/) | Gif |
| [Tiff](./tiff/) | Tiff |
| [Svg](./svg/) | Svg |
| [Svm](./svm/) | Svm |
| [Gltf](./gltf/) | glTF |
| [OfficeCompatibleEmf](./officecompatibleemf/) | Windows Enhanced Metafile che è più compatibile con Office. |
| [WebP](./webp/) | Formato immagine Weppy |
