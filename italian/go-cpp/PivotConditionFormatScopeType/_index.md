## PivotConditionFormatScopeType Enum

Rappresenta il tipo di ambito di formattazione condizionale della Tabella Pivot.

```go

type PivotConditionFormatScopeType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Data](./data/) | Indica che la formattazione condizionale è applicata ai campi dati selezionati. |
| [Field](./field/) | Indica che la formattazione condizionale è applicata alle intersezioni dei campi PivotTable selezionati. |
| [Selection](./selection/) | Indica che la formattazione condizionale è applicata alle celle selezionate. |
