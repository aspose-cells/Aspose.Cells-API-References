## GetAlignColumnPadding function

Indica se l'allineamento delle colonne è abilitato per le tabelle Markdown generate. Quando abilitato, le colonne sono allineate riempiendo il contenuto delle celle con il carattere specificato (tipicamente ' ' per gli spazi). Impostare a '\0' per disabilitare l'allineamento delle colonne (predefinito).

func (instance *MarkdownSaveOptions) GetAlignColumnPadding()  (byte,  error)
