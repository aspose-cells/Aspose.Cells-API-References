## BackgroundType Enum

Enumera i tipi di modello di sfondo della cella.

```go

type BackgroundType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [DiagonalCrosshatch](./diagonalcrosshatch/) | Rappresenta un motivo a reticolato diagonale. |
| [DiagonalStripe](./diagonalstripe/) | Rappresenta un motivo a strisce diagonali. |
| [Gray6](./gray6/) | Rappresenta un motivo grigio al 6,25% |
| [Gray12](./gray12/) | Rappresenta il modello grigio al 12,5% |
| [Gray25](./gray25/) | Rappresenta il pattern grigio al 25%. |
| [Gray50](./gray50/) | Rappresenta il pattern grigio al 50%. |
| [Gray75](./gray75/) | Rappresenta il pattern grigio al 75%. |
| [HorizontalStripe](./horizontalstripe/) | Rappresenta il modello a strisce orizzontali. |
| [None](./none/) | Rappresenta nessuno sfondo. |
| [ReverseDiagonalStripe](./reversediagonalstripe/) | Rappresenta il modello a strisce diagonali inverse. |
| [Solid](./solid/) | Rappresenta il pattern solido. |
| [ThickDiagonalCrosshatch](./thickdiagonalcrosshatch/) | Rappresenta il modello a reticolato diagonale spesso. |
| [ThinDiagonalCrosshatch](./thindiagonalcrosshatch/) | Rappresenta il modello a reticolato diagonale sottile. |
| [ThinDiagonalStripe](./thindiagonalstripe/) | Rappresenta il modello a strisce diagonali sottili. |
| [ThinHorizontalCrosshatch](./thinhorizontalcrosshatch/) | Rappresenta il modello a reticolato orizzontale sottile. |
| [ThinHorizontalStripe](./thinhorizontalstripe/) | Rappresenta il modello a strisce orizzontali sottili. |
| [ThinReverseDiagonalStripe](./thinreversediagonalstripe/) | Rappresenta il modello a strisce diagonali inverse sottili. |
| [ThinVerticalStripe](./thinverticalstripe/) | Rappresenta il modello a strisce verticali sottili. |
| [VerticalStripe](./verticalstripe/) | Rappresenta il modello a strisce verticali. |
