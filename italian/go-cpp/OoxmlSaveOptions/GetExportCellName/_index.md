## GetExportCellName function

Indica se esportare il nome della cella in un file Excel2007 .xlsx (.xlsm, .xltx, .xltm). Se il file di output può essere accessibile da SQL Server DTS, questo valore deve essere true. Impostare il valore a false aumenterà notevolmente le prestazioni e ridurrà la dimensione del file quando si creano file di grandi dimensioni. Il valore predefinito è true.
