## PasteType Enum

Rappresenta il tipo di incolla speciale.

```go

type PasteType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [All](./all/) | Copia tutti i dati dell'intervallo. |
| [Default](./default/) | Funziona come il comportamento "All" di MS Excel. |
| [AllExceptBorders](./allexceptborders/) | Copia tutti i dati dell'intervallo senza l'intervallo. |
| [DefaultExceptBorders](./defaultexceptborders/) | Funziona come il comportamento "All except borders" di MS Excel. |
| [ColumnWidths](./columnwidths/) | Copia solo le larghezze dell'intervallo. |
| [RowHeights](./rowheights/) | Copia solo le altezze dell'intervallo. |
| [Comments](./comments/) | Copia solo i commenti nell'intervallo. |
| [Formats](./formats/) | Copia solo i formati nell'intervallo. |
| [Formulas](./formulas/) | Copia solo le formule nell'intervallo. |
| [FormulasAndNumberFormats](./formulasandnumberformats/) | Copia solo le formule e i formati numerici nell'intervallo. |
| [Validation](./validation/) | Copia solo le convalide nell'intervallo. |
| [Values](./values/) | Copia solo i valori nell'intervallo. |
| [ValuesAndFormats](./valuesandformats/) | Copia solo i valori e i formati nell'intervallo. |
| [ValuesAndNumberFormats](./valuesandnumberformats/) | Copia solo i valori e i formati numerici nell'intervallo. |
