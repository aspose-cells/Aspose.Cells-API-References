## CellValueType Enum

Specifica un tipo di valore della cella.

```go

type CellValueType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [IsUnknown](./isunknown/) | Il tipo di valore della cella è sconosciuto. |
| [IsNull](./isnull/) | Cella vuota. Il valore corrispondente dovrebbe essere null. |
| [IsNumeric](./isnumeric/) | Il valore della cella è numerico. Il valore corrispondente deve essere int o double. |
| [IsDateTime](./isdatetime/) | Il valore della cella è datetime. Il valore corrispondente deve essere DateTime. |
| [IsString](./isstring/) | Il valore della cella è stringa. Il valore corrispondente deve essere stringa. |
| [IsBool](./isbool/) | Il valore della cella è booleano. Il valore corrispondente deve essere bool. |
| [IsError](./iserror/) | La cella contiene un valore di errore. Il valore corrispondente deve essere una stringa di errore. |
