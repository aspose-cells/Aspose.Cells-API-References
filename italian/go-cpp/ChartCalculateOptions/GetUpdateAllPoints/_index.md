## GetUpdateAllPoints function

Indica se aggiornare tutti i punti dati durante l'esecuzione del calcolo del grafico. Predefinito: False. Quando si desidera ottenere il valore per ciascun punto dati nel grafico in modo specifico, impostarlo su true. Se questo parametro è impostato su True, i nuovi punti dati possono essere generati quando il grafico viene calcolato. Questo potrebbe rendere il file Excel più grande.
