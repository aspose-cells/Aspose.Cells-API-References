## GetTreatQuotePrefixAsValue function

Indica se il segno di apice singolo iniziale deve essere considerato parte del valore di una cella. Il valore predefinito è true. Se è false, l'apice singolo iniziale verrà rimosso dal valore della cella corrispondente e Style.QuotePrefix sarà impostato a true per la cella.
