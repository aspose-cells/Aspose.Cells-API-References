## PivotConditionFormatRuleType Enum

Rappresenta il tipo di regola di formattazione condizionale della Tabella Pivot.

```go

type PivotConditionFormatRuleType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [None](./none/) | Indica che la formattazione condizionale Top N non è valutata |
| [All](./all/) | Indica che la formattazione condizionale Top N è valutata su tutta l'intervallo di ambito. |
| [Row](./row/) | Indica che la formattazione condizionale Top N è valutata per ogni riga. |
| [Column](./column/) | Indica che la formattazione condizionale Top N è valutata per ogni colonna. |
