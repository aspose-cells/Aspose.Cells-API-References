## PrintingPageType Enum

Indica quali pagine non verranno stampate.

```go

```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Default](./default/) | Stampa tutte le pagine. |
| [IgnoreBlank](./ignoreblank/) | Non stampare le pagine in cui le celle sono vuote. |
| [IgnoreStyle](./ignorestyle/) | Non stampare le pagine in cui le celle contengono solo stili. |
