## ShiftType Enum

Rappresenta le opzioni di spostamento durante l'eliminazione di un intervallo di celle.

```go

type ShiftType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Down](./down/) | Sposta le celle verso il basso. |
| [Left](./left/) | Sposta le celle verso sinistra. |
| [None](./none/) | Non spostare le celle. |
| [Right](./right/) | Sposta le celle verso destra. |
| [Up](./up/) | Sposta le celle verso l'alto. |
