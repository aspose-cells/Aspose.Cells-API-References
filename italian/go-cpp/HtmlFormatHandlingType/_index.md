## HtmlFormatHandlingType Enum

Specifica come gestire la formattazione dalla sorgente HTML

```go

type HtmlFormatHandlingType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [All](./all/) | Trasferisci tutta la formattazione HTML nel foglio di lavoro insieme ai dati. |
| [None](./none/) | Importa i dati come testo non formattato (l'impostazione dei tipi di dati avviene comunque). |
| [Rtf](./rtf/) | Traduci la formattazione HTML in formattazione rich text sui dati importati nel foglio di lavoro. |
