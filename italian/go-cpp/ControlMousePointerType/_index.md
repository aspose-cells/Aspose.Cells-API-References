## ControlMousePointerType Enum

Rappresenta il tipo di icona visualizzata come puntatore del mouse per il controllo.

```go

type ControlMousePointerType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Default](./default/) | Puntatore standard. |
| [Arrow](./arrow/) | Freccia. |
| [Cross](./cross/) | Puntatore a croce. |
| [IBeam](./ibeam/) | Cursore a barra verticale. |
| [SizeNESW](./sizenesw/) | Doppia freccia che punta a nord-est e sud-ovest. |
| [SizeNS](./sizens/) | Doppia freccia che punta a nord e sud. |
| [SizeNWSE](./sizenwse/) | Doppia freccia che punta a nord-ovest e sud-est. |
| [SizeWE](./sizewe/) | Doppia freccia che punta a ovest e est. |
| [UpArrow](./uparrow/) | Freccia verso l'alto. |
| [HourGlass](./hourglass/) | Clessidra. |
| [NoDrop](./nodrop/) | "Not" simbolo (cerchio con una linea diagonale) sopra l'oggetto trascinato. |
| [AppStarting](./appstarting/) | Freccia con una clessidra. |
| [Help](./help/) | Freccia con un punto interrogativo. |
| [SizeAll](./sizeall/) | "Size-all" cursore (frecce che puntano a nord, sud, est e ovest). |
| [Custom](./custom/) | Utilizza l'icona specificata dalla proprietà MouseIcon. |
