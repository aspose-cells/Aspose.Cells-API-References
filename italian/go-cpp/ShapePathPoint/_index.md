## ShapePathPoint class

Specifica le coordinate di posizione o i marcatori di angolo. Le coordinate di posizione rappresentano le coordinate di un percorso in uno spazio di coordinate (es. X/Y). I marcatori di angolo indicano variazioni angolari in un percorso (es. gli angoli di inizio e di swing di un arco).

```go

type ShapePathPoint struct  {
	ptr unsafe.Pointer
}

```
