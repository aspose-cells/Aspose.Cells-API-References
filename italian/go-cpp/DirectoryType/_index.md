## DirectoryType Enum

Rappresenta il tipo di directory del nome file.

```go

type DirectoryType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Volume](./volume/) | Rappresenta una lettera di unità MS-DOS. È seguita dalla lettera di unità. O nomi di file UNC, come \\server\share\myfile.xls |
| [SameVolume](./samevolume/) | Indica che la cartella di lavoro di origine si trova sulla stessa unità della cartella di lavoro dipendente (la lettera dell'unità è omessa) |
| [DownDirectory](./downdirectory/) | Indica che la cartella di lavoro di origine è in una sottocartella della directory corrente. |
| [UpDirectory](./updirectory/) | Indica che la cartella di lavoro di origine è nella directory padre della directory corrente. |
