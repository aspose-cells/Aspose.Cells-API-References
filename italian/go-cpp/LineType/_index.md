## LineType Enum

Enumera il tipo di bordo <see cref="Picture"/> o linea <see cref="Chart"/>.

```go

type LineType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [DarkGray](./darkgray/) | Rappresenta una linea grigio scuro. |
| [Dash](./dash/) | Rappresenta una linea tratteggiata. |
| [DashDot](./dashdot/) | Rappresenta una linea tratto-punto |
| [DashDotDot](./dashdotdot/) | Rappresenta una linea tratto-punto-punto. |
| [Dot](./dot/) | Rappresenta una linea a punti. |
| [LightGray](./lightgray/) | Rappresenta una linea grigio chiaro. |
| [MediumGray](./mediumgray/) | Rappresenta una linea grigio medio |
| [Solid](./solid/) | Rappresenta una linea solida |
