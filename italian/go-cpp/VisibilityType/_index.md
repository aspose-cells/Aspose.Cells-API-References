## VisibilityType Enum

Rappresenta gli stati di visibilità del foglio.

```go

type VisibilityType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Visible](./visible/) | Indica che il foglio è visibile. |
| [Hidden](./hidden/) | Indica che il foglio è nascosto, ma può essere mostrato dall'utente tramite l'interfaccia utente. |
| [VeryHidden](./veryhidden/) | Indica che il foglio è nascosto e non può essere mostrato nell'interfaccia utente (UI). Questo stato è disponibile solo programmaticamente. |
