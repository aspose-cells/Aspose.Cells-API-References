## GetEnableCssCustomProperties function

Ottimizza l'output di html utilizzando le proprietà personalizzate CSS. Ad esempio, nello scenario in cui ci sono più occorrenze della stessa immagine base64, con la proprietà personalizzata i dati dell'immagine devono essere salvati una sola volta, così le prestazioni dell'html risultante possono essere migliorate. Il valore predefinito è false.
