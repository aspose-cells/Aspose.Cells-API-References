## PlacementType Enum

Rappresenta il modo in cui l'oggetto di disegno è collegato alle celle sottostanti.

```go

type PlacementType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [FreeFloating](./freefloating/) | Non spostare né ridimensionare con le celle. |
| [Move](./move/) | Sposta ma non ridimensionare con le celle. |
| [MoveAndSize](./moveandsize/) | Sposta e ridimensiona con le celle. |
