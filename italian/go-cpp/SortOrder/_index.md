## SortOrder Enum

Rappresenta l'ordine di ordinamento per l'intervallo di dati.

```go

type SortOrder int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Ascending](./ascending/) | Ordina i dati in ordine crescente |
| [Descending](./descending/) | Ordina i dati in ordine decrescente |
| [Natural](./natural/) | Mantiene l'ordine originale dei dati senza ordinare. Si applica solo a scenari speciali come PivotTable. |
