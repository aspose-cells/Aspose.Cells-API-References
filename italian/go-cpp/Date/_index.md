## Date Struct

Rappresenta una data e ora.

```go

type Date int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [year](./year/) | Componente anno (1-9999). |
| [month](./month/) | Componente mese (1-12). |
| [day](./day/) | Componente giorno (1-31). |
| [hour](./hour/) | Componente ora (0-23). |
| [minute](./minute/) | Componente minuto (0-59). |
| [second](./second/) | Componente secondo (0-59). |
| [millisecond](./millisecond/) | Componente millisecondo (0-999). |
| [dateKind](./datekind/) | Specifica se l'ora è locale, UTC o non specificata. Il valore predefinito è Non specificata. |
