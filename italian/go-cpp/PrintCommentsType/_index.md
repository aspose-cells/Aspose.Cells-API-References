## PrintCommentsType Enum

Rappresenta il modo in cui i commenti vengono stampati con il foglio.

```go

type PrintCommentsType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [PrintInPlace](./printinplace/) | Rappresenta la stampa dei commenti così come visualizzati nel foglio. |
| [PrintNoComments](./printnocomments/) | Rappresenta il non stampare i commenti. |
| [PrintSheetEnd](./printsheetend/) | Rappresenta la stampa dei commenti alla fine del foglio. |
| [PrintWithThreadedComments](./printwiththreadedcomments/) | Rappresenta la stampa dei commenti così come visualizzati nel foglio, includendo i commenti in thread. |
