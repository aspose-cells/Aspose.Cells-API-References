## HtmlVersion Enum

Indica la versione di HTML utilizzata durante il salvataggio nei formati HTML.

```go

type HtmlVersion int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Default](./default/) | Salva il documento in conformità con l'esportazione HTML di MS Excel. |
| [XHtml](./xhtml/) | Salva il documento in conformità con lo standard XHTML 1.0 Transitional. |
| [Html5](./html5/) | Salva il documento in conformità con lo standard HTML 5. |
