## GradientStyleType Enum

Rappresenta lo stile di sfumatura del gradiente.

```go

type GradientStyleType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [DiagonalDown](./diagonaldown/) | Stile di ombreggiatura diagonale verso il basso |
| [DiagonalUp](./diagonalup/) | Stile di ombreggiatura diagonale verso l'alto |
| [FromCenter](./fromcenter/) | Stile di ombreggiatura dal centro |
| [FromCorner](./fromcorner/) | Stile di ombreggiatura dall'angolo |
| [Horizontal](./horizontal/) | Stile di ombreggiatura orizzontale |
| [Vertical](./vertical/) | Stile di ombreggiatura verticale |
| [Unknown](./unknown/) | Stile di ombreggiatura sconosciuto. Solo per lo stile di ombreggiatura (che non è per alcun membro di GradientStyleType) nel file modello. |
