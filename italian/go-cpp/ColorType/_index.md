## ColorType Enum

Rappresenta tutti i tipi di colore.

```go

type ColorType int32


```

## Campi

| Campo | Descrizione |
| --- | --- |
| [Automatic](./automatic/) | Colore automatico. |
| [AutomaticIndex](./automaticindex/) | È colore automatico, ma il colore visualizzato dipende dall'impostazione del sistema operativo. |
| [RGB](./rgb/) | Il colore RGB. |
| [IndexedColor](./indexedcolor/) | L'indice colore nella tavolozza dei colori. |
| [Theme](./theme/) | Il colore del tema. |
