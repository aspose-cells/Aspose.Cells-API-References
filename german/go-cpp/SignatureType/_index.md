## SignatureType Enum

Gibt den Signaturtyp an.

```go

type SignatureType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Default](./default/) | Der Standardwert, der entsprechende ProviderId‑Wert ist fest auf {0000000000-0000-0000-0000-0000000000} gesetzt. |
| [Stamp](./stamp/) | Der entsprechende ProviderId‑Wert ist normalerweise {000CD6A4-0000-0000-C000-000000000046}. |
| [Custom](./custom/) | Der entsprechende ProviderId‑Wert muss normalerweise vom Benutzer festgelegt werden. Er sollte aus der mit dem Anbieter gelieferten Dokumentation entnommen werden. |
