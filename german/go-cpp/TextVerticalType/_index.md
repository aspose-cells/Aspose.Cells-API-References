## TextVerticalType Enum

Stellt den Textdirektionstyp dar.

```go

type TextVerticalType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Vertical](./vertical/) | Ostasiatische vertikale Anzeige. |
| [Horizontal](./horizontal/) | Horizontaler Text. |
| [VerticalLeftToRight](./verticallefttoright/) | Vertikal angezeigt und der Text fließt von oben nach unten, dann von links nach rechts. |
| [Vertical90](./vertical90/) | Jede Zeile ist um 90 Grad im Uhrzeigersinn gedreht. |
| [Vertical270](./vertical270/) | Jede Zeile ist um 270 Grad im Uhrzeigersinn gedreht. |
| [Stacked](./stacked/) | Bestimmt, ob der gesamte Text vertikal ist. |
| [StackedRightToLeft](./stackedrighttoleft/) | Gibt an, dass vertikales WordArt von rechts nach links statt von links nach rechts angezeigt werden soll. |
