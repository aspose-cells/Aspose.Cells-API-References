## CustomProperty class

Stellt eine benutzerdefinierte Eigenschaft dar, die Namens‑ und Wertpaare beliebiger, vom Benutzer definierter Daten für ein Arbeitsblatt speichert.

```go

type CustomProperty struct  {
	ptr unsafe.Pointer
}

```
