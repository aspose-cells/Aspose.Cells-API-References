## GetEnterKeyBehavior function

Gibt das Verhalten der ENTER-Taste an. True gibt an, dass das Drücken von ENTER eine neue Zeile erzeugt. False gibt an, dass das Drücken von ENTER den Fokus zum nächsten Objekt in der Tab-Reihenfolge verschiebt.
