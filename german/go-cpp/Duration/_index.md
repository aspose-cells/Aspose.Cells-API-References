## Duration Struct

Stellt ein Zeitintervall mit einer Auflösung von 100 Nanosekunden (Tick) dar.

```go

type Duration int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [value](./value/) | Interne Darstellung des Zeitintervalls in Ticks. 1 Tick = 100 Nanosekunden. |
