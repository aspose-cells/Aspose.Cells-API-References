## SetAllColumnsInOnePagePerSheet function

Wenn AllColumnsInOnePagePerSheet true ist, wird der gesamte Spalteninhalt eines Blattes nur auf einer Seite im Ergebnis ausgegeben. Die Breite der Papiergröße der Seiten-einstellung wird ignoriert, während die anderen Einstellungen der Seiten-einstellung weiterhin wirksam bleiben.
