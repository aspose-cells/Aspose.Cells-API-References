## LineType Enum

Enumeriert den Typ des <see cref="Picture"/>-Rahmens oder der <see cref="Chart"/>-Linie.

```go

type LineType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [DarkGray](./darkgray/) | Stellt eine dunkelgraue Linie dar. |
| [Dash](./dash/) | Stellt eine gestrichelte Linie dar. |
| [DashDot](./dashdot/) | Stellt eine Strich-Punkt-Linie dar. |
| [DashDotDot](./dashdotdot/) | Stellt eine Strich-Punkt-Punkt-Linie dar. |
| [Dot](./dot/) | Stellt eine gepunktete Linie dar. |
| [LightGray](./lightgray/) | Stellt eine hellgraue Linie dar. |
| [MediumGray](./mediumgray/) | Stellt eine mittelgraue Linie dar. |
| [Solid](./solid/) | Stellt eine durchgezogene Linie dar. |
