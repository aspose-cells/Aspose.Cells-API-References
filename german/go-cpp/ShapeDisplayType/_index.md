## ShapeDisplayType Enum

Stellt dar, wie die Anwendung Formen in dieser Arbeitsmappe anzeigt. Formen können Diagramme, Bilder und andere Objektdaten umfassen, die die Anwendung unterstützt.

```go

type ShapeDisplayType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [All](./all/) | Gibt an, dass alle Formen in der Arbeitsmappe angezeigt werden. |
| [Placeholders](./placeholders/) | Gibt an, dass die Anwendung Platzhalter für Formen in der Arbeitsmappe anzeigt. |
| [None](./none/) | Gibt an, dass alle Formen in der Arbeitsmappe ausgeblendet werden. |
