## SetSortBy function

Stellt den Index des sortierten Feldes dar. Ein Wert von -1 bedeutet, dass nach den eigenen Werten des Pivot-Elements sortiert wird. Bei einem Wert größer oder gleich null stellt er den Index des Datenfeldes im Datenbereich dar.

```go

func (instance *PivotFieldSortSetting) SetSortBy(value int32)  error

```
