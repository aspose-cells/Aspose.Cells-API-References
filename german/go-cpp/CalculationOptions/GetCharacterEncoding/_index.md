## GetCharacterEncoding function

Gibt die Kodierung an, die beim Kodieren/Dekodieren von Zeichen während der Berechnung von Formeln verwendet wird. Für Funktionen wie CHAR, CODE hängt das berechnete Ergebnis von den Regionseinstellungen und dem Standard‑Zeichensatz der Umgebung ab. Mit dieser Eigenschaft kann der Benutzer die geeignete Kodierung für diese Funktionen angeben, um das erwartete Ergebnis zu erhalten.

```go

func (instance *CalculationOptions) GetCharacterEncoding()  (EncodingType,  error) 

```
