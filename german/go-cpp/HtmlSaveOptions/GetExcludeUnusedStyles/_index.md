## GetExcludeUnusedStyles function

Gibt an, ob ungenutzte Stile ausgeschlossen werden. Für die erzeugten HTML‑Dateien kann das Ausschließen ungenutzter Stile die Dateigröße verkleinern, ohne die visuellen Effekte zu beeinträchtigen. Daher ist der Standardwert dieser Eigenschaft true. Wenn der Benutzer alle Stile in der Arbeitsmappe für das erzeugte HTML beibehalten muss (z. B. wenn die Arbeitsmappe später aus dem erzeugten HTML wiederhergestellt werden soll), setzen Sie diese Eigenschaft auf false.
