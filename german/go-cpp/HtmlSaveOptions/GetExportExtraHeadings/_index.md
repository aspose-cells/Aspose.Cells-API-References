## GetExportExtraHeadings function

Gibt an, ob zusätzliche Überschriften exportiert werden, wenn die Textlänge länger als die maximale Anzeigespalte ist. Der Standardwert ist false. Wenn Sie die HTML‑Datei in Excel importieren möchten, behalten Sie den Standardwert bei.
