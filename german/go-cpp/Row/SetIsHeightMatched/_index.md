## SetIsHeightMatched function

Gibt an, ob die Zeilenhöhe mit der aktuellen Standardschriftart-Einstellung der Arbeitsmappe übereinstimmt. Der Wert True dieser Eigenschaft bedeutet außerdem, dass die Zeilenhöhe "automatisch" ist, ohne dass der Benutzer einen benutzerdefinierten Höhenwert festgelegt hat.
