## PivotAreaType Enum

Gibt den Typ der Regel an, die verwendet wird, um einen Bereich oder Aspekt der PivotTable zu beschreiben.

```go

type PivotAreaType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [None](./none/) | Kein Pivot-Bereich. |
| [Normal](./normal/) | Stellt einen Header oder ein Element dar. |
| [Data](./data/) | Stellt etwas im Datenbereich dar. |
| [All](./all/) | Stellt die gesamte PivotTable dar. |
| [Origin](./origin/) | Stellt die leeren Zellen oben links in der PivotTable dar (oben rechts für RTL-Blätter). |
| [Button](./button/) | Stellt einen Feld-Button dar. |
| [TopRight](./topright/) | Stellt die leeren Zellen oben rechts in der PivotTable dar (oben links für RTL-Blätter). |
