## PdfFontEncoding Enum

Stellt die PDF-eingebettete Schriftkodierung dar.

```go

type PdfFontEncoding int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Identity](./identity/) | Stellt die Verwendung der Identity-H-Codierung für alle eingebetteten Schriften im PDF dar. |
| [AnsiPrefer](./ansiprefer/) | Stellt die bevorzugte Verwendung von WinAnsiEncoding für TrueType-Schriften mit Zeichen 32‑127 dar, andernfalls wird für eingebettete Schriften im PDF die Identity‑H-Codierung verwendet. |
