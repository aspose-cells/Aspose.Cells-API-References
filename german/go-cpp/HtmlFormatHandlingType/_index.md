## HtmlFormatHandlingType Enum

Gibt an, wie die Formatierung aus der HTML‑Quelle behandelt werden soll

```go

type HtmlFormatHandlingType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [All](./all/) | Überträgt alle HTML-Formatierungen zusammen mit den Daten in das Arbeitsblatt. |
| [None](./none/) | Importiert Daten als unformatierten Text (Datentypen werden weiterhin festgelegt). |
| [Rtf](./rtf/) | Übersetzt HTML-Formatierung in Rich-Text-Formatierung für die in das Arbeitsblatt importierten Daten. |
