## SetOnePagePerSheet function

Wenn OnePagePerSheet true ist, wird der gesamte Inhalt eines Blattes nur auf einer Seite im Ergebnis ausgegeben. Die Papiergröße der Seiten-einstellung wird ungültig sein, während die anderen Einstellungen der Seiten-einstellung weiterhin wirksam bleiben.
