## SetAllColumnsInOnePagePerSheet function

Wenn AllColumnsInOnePagePerSheet true ist, wird der gesamte Spalteninhalt eines Blatts nur auf einer Seite im Ergebnis ausgegeben. Die Breite der Papiergröße von PageSetup wird ungültig, während die anderen Einstellungen von PageSetup weiterhin wirksam sind.
