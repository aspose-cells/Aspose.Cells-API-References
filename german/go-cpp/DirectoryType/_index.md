## DirectoryType Enum

Stellt den Verzeichnistyp des Dateinamens dar.

```go

type DirectoryType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Volume](./volume/) | Stellt einen MS-DOS-Laufwerksbuchstaben dar. Es folgt der Laufwerksbuchstabe. Oder UNC-Dateinamen, wie \\server\share\myfile.xls |
| [SameVolume](./samevolume/) | Gibt an, dass die Quellarbeitsmappe sich auf demselben Laufwerk wie die abhängige Arbeitsmappe befindet (der Laufwerksbuchstabe wird weggelassen). |
| [DownDirectory](./downdirectory/) | Gibt an, dass die Quellarbeitsmappe in einem Unterverzeichnis des aktuellen Verzeichnisses liegt. |
| [UpDirectory](./updirectory/) | Gibt an, dass die Quellarbeitsmappe im übergeordneten Verzeichnis des aktuellen Verzeichnisses liegt. |
