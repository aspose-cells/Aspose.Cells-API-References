## SetStdDev function

Abrufen oder Festlegen der Anzahl der Standardabweichungen, die über oder unter dem Durchschnitt in der bedingten Formatierungsregel berücksichtigt werden sollen. Der Eingabewert muss zwischen 0 und 3 liegen (einschließlich 0 und 3). Das Setzen dieses Werts auf 0 bedeutet, dass stdDev nicht festgelegt ist. Der Standardwert ist 0.

```go

func (instance *AboveAverage) SetStdDev(value int32)  error

```
