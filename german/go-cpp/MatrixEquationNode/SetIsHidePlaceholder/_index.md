## SetIsHidePlaceholder function

Dieses Attribut legt die Eigenschaft Hide Placeholders für eine Matrix fest. Wenn diese Eigenschaft aktiviert ist, erscheinen Platzhalter nicht in der Matrix. Standardmäßig erscheinen Platzhalter, sodass die Stellen, an denen Text eingefügt werden kann, sichtbar werden.
