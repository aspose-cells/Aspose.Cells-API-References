## PrintCommentsType Enum

Stellt dar, wie Kommentare mit dem Tabellenblatt gedruckt werden.

```go

type PrintCommentsType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [PrintInPlace](./printinplace/) | Repräsentiert das Drucken von Kommentaren, wie sie im Blatt angezeigt werden. |
| [PrintNoComments](./printnocomments/) | Repräsentiert das Nicht-Drucken von Kommentaren. |
| [PrintSheetEnd](./printsheetend/) | Repräsentiert das Drucken von Kommentaren am Ende des Blattes. |
| [PrintWithThreadedComments](./printwiththreadedcomments/) | Repräsentiert das Drucken von Kommentaren, wie sie im Blatt angezeigt werden, einschließlich Threaded Comments. |
