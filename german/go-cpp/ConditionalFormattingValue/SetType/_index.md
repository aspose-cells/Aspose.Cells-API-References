## SetType function

Lese oder setze den Typ dieses Conditional-Formatting-Wertobjekts. Das Setzen des Typs auf FormatConditionValueType.Min oder FormatConditionValueType.Max setzt "Value" automatisch auf null.

func (instance *ConditionalFormattingValue) SetType(value FormatConditionValueType)  error
