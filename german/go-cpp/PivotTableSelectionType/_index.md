## PivotTableSelectionType Enum

Gibt an, was in einer PivotTable während einer strukturierten Auswahl ausgewählt werden kann. Diese Konstanten können kombiniert werden, um mehrere Typen auszuwählen.

```go

type PivotTableSelectionType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [DataAndLabel](./dataandlabel/) | Daten und Beschriftungen |
| [DataOnly](./dataonly/) | Wählt nur Daten aus |
| [LabelOnly](./labelonly/) | Wählt nur Beschriftungen aus |
