## TextStrikeType Enum

Dieser Typ gibt den Durchstreichungstyp an.

```go

type TextStrikeType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Single](./single/) | Ein einfacher Durchstrich, der auf den Text angewendet wird. |
| [Double](./double/) | Ein doppelter Durchstrich, der auf den Text angewendet wird. Funktioniert nur für den Text von Formen oder Diagrammen. |
| [None](./none/) | Kein Durchstrich wird auf den Text angewendet. |
