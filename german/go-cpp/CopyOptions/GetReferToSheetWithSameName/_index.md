## GetReferToSheetWithSameName function

In MS Excel, wenn Formeln, die sich auf andere Arbeitsblätter beziehen, beim Kopieren eines Arbeitsblatts in ein anderes kopiert werden, sollten die kopierten Formeln auf die Quellarbeitsmappe verweisen. Allerdings kann der Benutzer in manchen Situationen benötigen, dass die kopierten Formeln auf Arbeitsblätter mit demselben Namen in derselben Arbeitsmappe verweisen, zum Beispiel wenn diese Arbeitsblätter bereits vor diesem Kopiervorgang kopiert wurden, dann sollte diese Eigenschaft auf true gesetzt werden.
