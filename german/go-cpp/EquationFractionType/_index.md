## EquationFractionType Enum

Dies gibt den Anzeigestil des Bruchstrichs an.

```go

type EquationFractionType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Bar](./bar/) | Dies gibt an, dass der Zähler oben und der Nenner unten durch einen Balken in der Mitte getrennt ist. |
| [NoBar](./nobar/) | Dies gibt an, dass der Zähler oben und der Nenner unten nicht durch einen Balken in der Mitte getrennt ist. |
| [Linear](./linear/) | Dies gibt an, dass der Zähler links und der Nenner rechts steht, getrennt durch ein '/' dazwischen. |
| [Skewed](./skewed/) | Dies gibt an, dass der Zähler oben links und der Nenner unten rechts steht, getrennt durch ein \"/\". |
