## HtmlLinkTargetType Enum

Stellt den Typ des target‑Attributs im HTML‑<a/>‑Tag dar.

```go

type HtmlLinkTargetType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Blank](./blank/) | Öffnet das verknüpfte Dokument in einem neuen Fenster oder Tab |
| [Parent](./parent/) | Öffnet das verknüpfte Dokument im übergeordneten Frame |
| [Self](./self/) | Öffnet das verknüpfte Dokument im selben Frame, in dem es angeklickt wurde (dies ist die Vorgabe) |
| [Top](./top/) | Öffnet das verknüpfte Dokument im gesamten Fensterinhalt |
