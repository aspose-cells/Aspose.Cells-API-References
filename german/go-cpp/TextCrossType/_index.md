## TextCrossType Enum

Enumeriert den Anzeigetexttyp, wenn die Textbreite größer als die Zellenbreite ist.

```go

type TextCrossType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Default](./default/) | Text wie in Microsoft Excel anzeigen. |
| [CrossKeep](./crosskeep/) | Alle Texte anzeigen, indem andere Zellen überkreuzt werden, und den Text der überkreuzten Zellen beibehalten. |
| [CrossOverride](./crossoverride/) | Alle Texte anzeigen, indem andere Zellen überkreuzt werden, und den Text der überkreuzten Zellen überschreiben. |
| [StrictInCell](./strictincell/) | Nur den Text innerhalb der Zellbreite anzeigen. |
