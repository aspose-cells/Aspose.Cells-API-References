## TextFontAlignType Enum

Stellt die verschiedenen Schriftartausrichtungsarten dar.

```go

type TextFontAlignType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Automatic](./automatic/) | Wenn der Textfluss horizontal oder einfach vertikal ist, entspricht er fontBaseline, aber für andere vertikale Modi entspricht er fontCenter. |
| [Bottom](./bottom/) | Die Buchstaben sind am ganz unteren Rand einer einzelnen Zeile verankert. |
| [Baseline](./baseline/) | Die Buchstaben sind an der unteren Grundlinie einer einzelnen Zeile verankert. |
| [Center](./center/) | Die Buchstaben sind zwischen den beiden Grundlinien einer einzelnen Zeile verankert. |
| [Top](./top/) | Die Buchstaben sind an der oberen Grundlinie einer einzelnen Zeile verankert. |
