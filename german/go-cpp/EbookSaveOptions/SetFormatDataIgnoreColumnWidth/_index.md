## SetFormatDataIgnoreColumnWidth function

Gibt an, ob die gesamten formatierten Zellen­daten angezeigt werden sollen, wenn sie die Spalte überlaufen. Wenn true, wird die Spaltenbreite ignoriert und die gesamten Zellen­daten werden exportiert. Wenn false, werden die Daten wie in Excel exportiert. Der Standardwert ist false.
