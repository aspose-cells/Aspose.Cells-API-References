## DataBarAxisPosition Enum

Gibt die Achsenposition für einen Zellbereich mit bedingter Formatierung als Datenbalken an.

```go

type DataBarAxisPosition int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Automatic](./automatic/) | Anzeige der Achse an einer variablen Position basierend auf dem Verhältnis des kleinsten negativen Werts zum größten positiven Wert im Bereich. Positive Werte werden von links nach rechts angezeigt. Negative Werte werden von rechts nach links angezeigt. Wenn alle Werte positiv oder alle Werte negativ sind, wird keine Achse angezeigt. |
| [Midpoint](./midpoint/) | Anzeige der Achse in der Mitte der Zelle, unabhängig von der Wertemenge im Bereich. Positive Werte werden von links nach rechts angezeigt. Negative Werte werden von rechts nach links angezeigt. |
| [None](./none/) | Es wird keine Achse angezeigt, und sowohl positive als auch negative Werte werden von links nach rechts angezeigt. |
