## GetExportCellName function

Gibt an, ob der Zellname in Excel2007 .xlsx (.xlsm, .xltx, .xltm) Datei exportiert wird. Wenn die Ausgabedatei von SQL Server DTS verwendet werden kann, muss dieser Wert true sein. Das Setzen des Werts auf false erhöht die Leistung erheblich und reduziert die Dateigröße beim Erstellen großer Dateien. Standardwert ist true.
