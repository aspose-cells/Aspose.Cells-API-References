## CellsHelper_CreateSafeSheetName_String_Char function

Überprüft den angegebenen Blattnamen und erstellt bei Bedarf einen gültigen Namen. Wenn der angegebene Blattname den Regeln für Excel-Blattnamen entspricht, wird er zurückgegeben. Andernfalls wird die Zeichenkette abgeschnitten, wenn die Länge das Limit überschreitet, und ungültige Zeichen werden durch das angegebene Zeichen ersetzt, dann wird der wiederhergestellte Zeichenkettenwert zurückgegeben.
