## TextOverflowType Enum

Stellt die Art des vertikalen oder horizontalen Textüberlaufs dar.

```go

type TextOverflowType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Clip](./clip/) | Achten Sie auf obere und untere Barrieren. Geben Sie keinen Hinweis darauf, dass Text nicht sichtbar ist. |
| [Ellipsis](./ellipsis/) | Achten Sie auf obere und untere Barrieren. Verwenden Sie ein Auslassungszeichen, um anzuzeigen, dass Text nicht sichtbar ist. Nur für vertikales Überlaufen. |
| [Overflow](./overflow/) | Lassen Sie den Text überlaufen und ignorieren Sie obere und untere Barrieren. |
