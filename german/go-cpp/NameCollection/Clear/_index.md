## Clear function

Entfernt alle definierten Namen, die nicht von Formeln und Datenquellen referenziert werden. Wenn der definierte Name referenziert wird, setzen wir nur Name.ReferTo auf null und blenden ihn aus.

```go

func (instance *NameCollection) Clear()  error

```
