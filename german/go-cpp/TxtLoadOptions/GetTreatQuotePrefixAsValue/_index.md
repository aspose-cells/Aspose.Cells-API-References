## GetTreatQuotePrefixAsValue function

Gibt an, ob das führende einfache Anführungszeichen als Teil des Werts einer Zelle betrachtet werden soll. Standard ist true. Wenn es false ist, wird das führende einfache Anführungszeichen aus dem entsprechenden Zellenwert entfernt und Style.QuotePrefix wird für die Zelle auf true gesetzt.
