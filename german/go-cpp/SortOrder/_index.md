## SortOrder Enum

Stellt die Sortierreihenfolge für den Datenbereich dar.

```go

type SortOrder int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Ascending](./ascending/) | Sortiert Daten in aufsteigender Reihenfolge |
| [Descending](./descending/) | Sortiert Daten in absteigender Reihenfolge |
| [Natural](./natural/) | Behält die ursprüngliche Datenreihenfolge bei, ohne zu sortieren. Gilt nur für einige spezielle Szenarien wie PivotTable. |
