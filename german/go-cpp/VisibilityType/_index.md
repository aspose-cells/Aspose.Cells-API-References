## VisibilityType Enum

Stellt die Zustände für die Sichtbarkeit des Blattes dar.

```go

type VisibilityType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Visible](./visible/) | Zeigt an, dass das Blatt sichtbar ist. |
| [Hidden](./hidden/) | Zeigt an, dass das Blatt ausgeblendet ist, aber vom Benutzer über die Benutzeroberfläche angezeigt werden kann. |
| [VeryHidden](./veryhidden/) | Zeigt an, dass das Blatt ausgeblendet ist und in der Benutzeroberfläche (UI) nicht angezeigt werden kann. Dieser Zustand ist nur programmgesteuert verfügbar. |
