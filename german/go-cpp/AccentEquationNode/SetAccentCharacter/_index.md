## SetAccentCharacter function

Dieses Attribut gibt den Typ des kombinierten diakritischen Zeichens an, das an die Basis der Akzentfunktion angehängt wird. Das Standardakzentzeichen ist U+0302. Es wird dringend empfohlen, das Attribut AccentType zu verwenden, um das Akzentzeichen festzulegen. Verwenden Sie diese Eigenschaftseinstellung, wenn Sie das benötigte Zeichen in einem bekannten Typ nicht finden können.
