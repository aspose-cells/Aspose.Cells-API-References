## LegendPositionType Enum

Enumeriert die Positionsarten der Legende.

```go

type LegendPositionType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Bottom](./bottom/) | Zeigt die Legende am unteren Rand des Diagrammbereichs an. |
| [Corner](./corner/) | Zeigt die Legende in der Ecke des Diagrammbereichs an. |
| [Left](./left/) | Zeigt die Legende links vom Diagrammbereich an. |
| [NotDocked](./notdocked/) | Gibt an, dass die Legende nicht angedockt ist. |
| [Right](./right/) | Zeigt die Legende rechts vom Diagrammbereich an. |
| [Top](./top/) | Zeigt die Legende oben im Diagrammbereich an. |
