## FormattingType Enum

Stellt den Formatierungstyp dar, der auf ein <see cref=\"Area\"/>-Objekt oder ein <see cref=\"Line\"/>-Objekt angewendet wird.

```go

type FormattingType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Automatic](./automatic/) | Stellt den automatischen Formatierungstyp dar. |
| [Custom](./custom/) | Stellt einen benutzerdefinierten Formatierungstyp dar. |
| [None](./none/) | Stellt den Formatierungstyp 'keine' dar. |
