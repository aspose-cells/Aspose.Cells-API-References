## PrintingPageType Enum

Gibt an, welche Seiten nicht gedruckt werden.

```go

type PrintingPageType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Default](./default/) | Druckt alle Seiten. |
| [IgnoreBlank](./ignoreblank/) | Drucke nicht die Seiten, bei denen die Zellen leer sind. |
| [IgnoreStyle](./ignorestyle/) | Drucke nicht die Seiten, bei denen die Zellen nur Formatierungen enthalten. |
