## SetBackward function

Gibt die Anzahl der Perioden (oder Einheiten in einem Streudiagramm) zurück, über die die Trendlinie nach hinten verläuft, oder setzt sie. Die Anzahl der Perioden muss größer oder gleich null sein. Wenn der Diagrammtyp Säule ist, muss die Anzahl der Perioden zwischen 0 und 0,5 liegen.

func (instance *Trendline) SetBackward(value float64)  error
