## DataLabelShapeType Enum

Gibt die voreingestellte Formgeometrie an, die für ein Diagramm verwendet werden soll.

```go

type DataLabelShapeType int32


```

| Feld | Beschreibung |
| --- | --- |
| [Rect](./rect/) | Stellt die Rechteckform dar. |
| [RoundRect](./roundrect/) | Stellt die abgerundete Rechteckform dar. |
| [Ellipse](./ellipse/) | Stellt die Ellipsenform dar. |
| [RightArrowCallout](./rightarrowcallout/) | Stellt die Form des rechten Pfeil‑Hinweises dar. |
| [DownArrowCallout](./downarrowcallout/) | Stellt die Form des nach unten zeigenden Pfeil‑Hinweises dar. |

| [WedgeRectCallout](./wedgerectcallout/) | Stellt die Form des Keil‑Rechteck‑Hinweises dar. |
| [WedgeRoundRectCallout](./wedgeroundrectcallout/) | Stellt die Keil‑abgerundete Rechteck‑Beschriftungsform dar. |
| [WedgeEllipseCallout](./wedgeellipsecallout/) | Stellt die Keil‑Ellipse‑Beschriftungsform dar. |
