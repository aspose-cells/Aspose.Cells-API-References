## GetRefreshOnChange function

Flag, das angibt, ob die Abfrage automatisch aktualisiert werden soll, wenn sich der Inhalt einer Zelle, die den Parameterwert bereitstellt, ändert. Wenn wahr, werden externe Daten bei jeder Änderung mit dem neuen Parameterwert aktualisiert. Wenn falsch, werden externe Daten nur aktualisiert, wenn der Benutzer dies anfordert oder ein anderes Ereignis die Aktualisierung auslöst (z. B. beim Öffnen der Arbeitsmappe).
