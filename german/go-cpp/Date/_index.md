## Date Struct

Stellt ein Datum und eine Uhrzeit dar.

```go

type Date int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [year](./year/) | Jahreskomponente (1-9999). |
| [month](./month/) | Monatskomponente (1-12). |
| [day](./day/) | Tageskomponente (1-31). |
| [hour](./hour/) | Stundenkomponente (0-23). |
| [minute](./minute/) | Minutenkomponente (0-59). |
| [second](./second/) | Sekundenkomponente (0-59). |
| [millisecond](./millisecond/) | Millisekundenkomponente (0-999). |
| [dateKind](./datekind/) | Gibt an, ob die Zeit lokal, UTC oder nicht angegeben ist. Standardwert ist Unspecified. |
