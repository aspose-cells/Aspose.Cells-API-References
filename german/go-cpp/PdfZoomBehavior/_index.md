## PdfZoomBehavior Enum

Gibt den anfänglichen Ansichtsmodus an, wenn das erzeugte PDF-Dokument geöffnet wird.

```go

type PdfZoomBehavior int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [None](./none/) | Verwendet das Standardverhalten des PDF-Viewers. |
| [ZoomFactor](./zoomfactor/) | Öffnet das Dokument bei einem bestimmten Zoom-Prozentsatz. |
| [FitPage](./fitpage/) | Passt die gesamte Seite in das Viewer-Fenster. |
| [FitWidth](./fitwidth/) | Passt die Seitenbreite in das Viewer-Fenster. |
| [FitHeight](./fitheight/) | Passt die Seitenhöhe in das Viewer-Fenster. |
