## PivotConditionFormatRuleType Enum

Stellt den Regeltyp für die bedingte Formatierung einer PivotTable dar.

```go

type PivotConditionFormatRuleType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [None](./none/) | Gibt an, dass die Top‑N‑bedingte Formatierung nicht ausgewertet wird |
| [All](./all/) | Gibt an, dass die Top‑N‑bedingte Formatierung über den gesamten Geltungsbereich ausgewertet wird. |
| [Row](./row/) | Gibt an, dass die Top‑N‑bedingte Formatierung für jede Zeile ausgewertet wird. |
| [Column](./column/) | Gibt an, dass die Top‑N‑bedingte Formatierung für jede Spalte ausgewertet wird. |
