## ProtectionType Enum

Stellt den Schutztyp für Arbeitsmappe/Arbeitsblatt dar.

```go

type ProtectionType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [All](./all/) | Stellt dar, alles zu schützen. |
| [Contents](./contents/) | Stellt dar, Inhalte zu schützen, verwendet im Arbeitsblatt-Schutz. |
| [Objects](./objects/) | Stellt dar, Objekte zu schützen, verwendet im Arbeitsblatt-Schutz. |
| [Scenarios](./scenarios/) | Stellt dar, Szenarien zu schützen, verwendet im Arbeitsblatt-Schutz. |
| [Structure](./structure/) | Stellt dar, Struktur zu schützen, verwendet im Arbeitsbuch-Schutz. |
| [Windows](./windows/) | Stellt dar, Fenster zu schützen, verwendet im Arbeitsbuch-Schutz. |
| [None](./none/) | Stellt keinen Schutz dar. Nur für die Lese-Eigenschaft. |
