## ShiftType Enum

Stellt die Verschiebungsoptionen beim Löschen eines Zellbereichs dar.

```go

type ShiftType int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Down](./down/) | Verschiebt Zellen nach unten. |
| [Left](./left/) | Verschiebt Zellen nach links. |
| [None](./none/) | Zellen nicht verschieben. |
| [Right](./right/) | Verschiebt Zellen nach rechts. |
| [Up](./up/) | Verschiebt Zellen nach oben. |
