## SetCultureCustom function

Liest und setzt die kulturbasierte Musterzeichenfolge für das Zahlenformat. Wenn für dieses Objekt kein Zahlenformat festgelegt wurde, wird null zurückgegeben. Ist das Zahlenformat eingebaut, wird die dem eingebauten Zahlenformat entsprechende Musterzeichenfolge zurückgegeben.

func (instance *Style) SetCultureCustom(value string)  error
