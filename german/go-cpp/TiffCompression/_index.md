## TiffCompression Enum

Gibt an, welchen Kompressionstyp beim Speichern von Bildern in einer TIFF-Datei angewendet werden soll.

```go

type TiffCompression int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [CompressionNone](./compressionnone/) | Gibt an, dass keine Kompression verwendet wird. |
| [CompressionRle](./compressionrle/) | Gibt das RLE-Kompressionsverfahren an. |
| [CompressionLZW](./compressionlzw/) | Gibt das LZW-Kompressionsverfahren an. |
| [CompressionCCITT3](./compressionccitt3/) | Gibt das CCITT3-Kompressionsverfahren an. |
| [CompressionCCITT4](./compressionccitt4/) | Gibt das CCITT4-Kompressionsverfahren an. |
