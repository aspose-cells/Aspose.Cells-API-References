## IsXl2000 function

Dieses Flag existiert aus Gründen der Abwärtskompatibilität mit älteren bestehenden Tabellenkalkulationsdateien und ist auf true gesetzt, wenn diese Webabfrage in einer Tabellenkalkulationsanwendung, die neuer oder gleich Microsoft Excel 2000 ist, aktualisiert wurde. Dies ist ein optionales Attribut, das ignoriert werden kann.

func (instance *WebQueryConnection) IsXl2000()  (bool,  error)
