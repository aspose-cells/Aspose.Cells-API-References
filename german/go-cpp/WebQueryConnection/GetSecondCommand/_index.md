## GetSecondCommand function

Gibt eine zweite Befehlszeichenfolge an, die beibehalten wird, wenn PivotTable-Server-basierte Seitenfelder verwendet werden. Für ODBC-Verbindungen ist serverCommand in der Regel eine umfangreichere Abfrage als command (keine WHERE-Klausel ist im Ersteren vorhanden). Basierend auf diesen 2 Befehlen (Command und ServerCommand) kann die parameter UI gefüllt und parametrisierte Abfragen erstellt werden.
