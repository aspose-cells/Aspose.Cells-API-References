## SetIsXl97 function

Dieses Flag existiert aus Gründen der Abwärtskompatibilität mit älteren bestehenden Tabellenkalkulationsdateien und ist auf true gesetzt, wenn diese Webabfrage in Microsoft Excel 97 erstellt wurde. Dies ist ein optionales Attribut, das ignoriert werden kann.
