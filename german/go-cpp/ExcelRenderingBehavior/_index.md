## ExcelRenderingBehavior Enum

Gibt Excel-spezifische Rendering-Verhalten an, die beim Rendern einer Arbeitsmappe angewendet werden sollen.

```go

type ExcelRenderingBehavior int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [None](./none/) | Wendet keine Excel-spezifischen Rendering‑Verhalten an. |
| [CellTextLengthLimit](./celltextlengthlimit/) | Wendet das Längenlimit für die Zellen­textausgabe von Excel an. Zum Beispiel gibt Excel nur die ersten 1024 Zeichen in einer nicht umgebrochenen Zelle aus. |
| [All](./all/) | Wendet alle unterstützten Excel-spezifischen Rendering‑Verhalten an. |
