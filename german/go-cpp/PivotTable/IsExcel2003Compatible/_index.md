## IsExcel2003Compatible function

Gibt an, ob die PivotTable beim Aktualisieren mit Excel2003 kompatibel ist; wenn true, muss ein String höchstens 255 Zeichen lang sein, sodass ein längerer String abgeschnitten wird. Wenn false, gilt die genannte Beschränkung nicht. Der Standardwert ist true.
