## GetStringValue function

Liefert den in der Zelle enthaltenen Zeichenkettenwert. Wenn der Typ dieser Zelle Zeichenkette ist, wird der Zeichenkettenwert selbst zurückgegeben. Für andere Zellentypen wird der formatierte Zeichenkettenwert (formatiert mit dem angegebenen Stil dieser Zelle) zurückgegeben. Der formatierte Zellenwert entspricht dem, was Sie in Excel erhalten, wenn Sie eine Zelle als Text kopieren (z. B. das Kopieren der Zelle in einen Texteditor oder das Exportieren in CSV).

```go

func (instance *Cell) GetStringValue()  (string,  error)
```
