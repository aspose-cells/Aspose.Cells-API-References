## TxtLoadStyleStrategy Enum

Gibt an, wie der Stil für geparste Werte angewendet wird, wenn ein Zeichenfolgenwert in eine Zahl oder ein Datum/Uhrzeit konvertiert wird.

```go

type TxtLoadStyleStrategy int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [None](./none/) | Setzt keinen Stil für den geparsten Wert. |
| [BuiltIn](./builtin/) | Setze den Stil als integrierte Nummer/Datum‑Uhrzeit, wenn der geparste Wert einfache numerische/Datum‑Uhrzeit‑Werte ist. |
| [ExactFormat](./exactformat/) | Setze das genaue benutzerdefinierte Format für den geparsten Wert, damit der formatierte Wert dem ursprünglichen Eingabewert entspricht. |
