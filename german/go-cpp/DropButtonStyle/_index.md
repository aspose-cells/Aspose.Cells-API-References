## DropButtonStyle Enum

Stellt das auf der Dropdown-Schaltfläche angezeigte Symbol dar.

```go

type DropButtonStyle int32


```

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Plain](./plain/) | Zeigt einen Button ohne Symbol an. |
| [Arrow](./arrow/) | Zeigt einen Button mit einem Pfeil nach unten an. |
| [Ellipsis](./ellipsis/) | Zeigt einen Button mit Auslassungspunkten (...) an. |
| [Reduce](./reduce/) | Zeigt einen Button mit einer horizontalen Linie, ähnlich einem Unterstrich, an. |
