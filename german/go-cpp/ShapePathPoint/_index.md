## ShapePathPoint class

Geben Sie Positionskoordinaten oder Winkelmarkierungen an. Positionskoordinaten repräsentieren die Koordinaten eines Pfads in einem Koordinatenraum (z. B. X/Y). Winkelmarkierungen zeigen Winkeländerungen in einem Pfad an (z. B. die Start- und Schwenkwinkel eines Bogens).

```go

type ShapePathPoint struct  {
	ptr unsafe.Pointer
}
```
