## SetSecondCategoryData function

Liest oder setzt den Bereich der zweiten Kategorien-Achsenwerte. Es kann ein Zellbereich sein (z. B. "d1:e10"), oder eine Wertefolge (z. B. "{2,6,8,10}"). Wirkt nur, wenn einige Serien auf der zweiten Achse dargestellt wurden.
