## ComboBox.SelectedIndex property

Liest oder setzt den Index, der das aktuell ausgewählte Element angibt. Das Setzen des Index ruft die Methode GridDesktop.RunAllFormulas automatisch auf, wenn die Eigenschaft GridDesktop.RecalculateFormulas true ist.

public int SelectedIndex { get; set; }
