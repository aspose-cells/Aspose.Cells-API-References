## GridDesktop.StartFormatPainter method

Benachrichtigt GridDesktop, um den FormatPainter zu starten.

```csharp
public void StartFormatPainter(bool formatOnce)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| formatOnce | Boolean | Wenn formatOnce true ist, kann FormatPainter einmal verwendet werden, wenn formatOnce false ist, kann FormatPainter mehrfach verwendet werden, bis EndFormatPainter() aufgerufen wird. |

### Beispiele

```csharp
[C#]
gridDesktop1.StartFormatPainter(true);

[Visual Basic]
gridDesktop1.StartFormatPainter(True)

```
