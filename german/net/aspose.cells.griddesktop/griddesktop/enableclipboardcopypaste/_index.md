## GridDesktop.EnableClipboardCopyPaste property

Gibt an, ob Kopieren/Einfügen basierend auf der Zwischenablage erfolgen soll, sodass es mit MS-EXCEL kopieren/einfügen kann. Es kopiert/fügt nur den Zellenwert ein, es kopiert keine anderen Zelleneinstellungen wie Format, Rahmenstil usw. Der Standardwert ist false.

```csharp
public bool EnableClipboardCopyPaste { get; set; }
```
