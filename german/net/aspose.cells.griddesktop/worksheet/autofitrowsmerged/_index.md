## Worksheet.AutoFitRowsMerged method

Passt alle Zeilen in diesem Arbeitsblatt automatisch an. Sie passt die Zeilenhöhe auch automatisch an, wenn Zellen in einer Zeile zusammengeführt werden.

```csharp
public void AutoFitRowsMerged()
```

### Hinweise

Wenn Zellen in einer Zeile zusammengeführt werden und die Zeilen in MS Excel automatisch angepasst werden, erweitert MS Excel die Zeilenhöhe nicht. Aspose.Cells erweitert die Zeilenhöhe, um die Daten der Zellen anzupassen.
