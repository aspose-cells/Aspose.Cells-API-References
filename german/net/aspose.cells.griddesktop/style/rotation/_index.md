## Style.Rotation property

Stellt den Textdrehwinkel dar.

```csharp
public int Rotation { get; set; }
```

### Hinweise

0: Nicht gedreht.

255: Von oben nach unten.

-90: Downward.

90: Aufwärts.

Sie können 255 oder einen Wert im Bereich von -90 bis 90 festlegen.
