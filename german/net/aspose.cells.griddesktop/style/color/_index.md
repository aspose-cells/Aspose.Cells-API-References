## Style.Color property

Liest oder setzt die Schattierungsfarbe der Zelle. Wenn das Muster none ist, wird Color.Empty zurückgegeben; wenn das Muster BackgroundType.Solid ist, wird ForegroundColor zurückgegeben; sonst wird BackgroundColor zurückgegeben.

public Color Color { get; set; }
