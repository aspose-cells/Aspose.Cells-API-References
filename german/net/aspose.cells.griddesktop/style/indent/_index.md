## Style.Indent property

Stellt das m_IndentLevel‑Level für die Zelle oder den Bereich dar. Kann nur ein ganzzahliger Wert von 0 bis 15 sein.

```csharp
public int Indent { get; set; }
```

### Hinweise

Wenn der horizontale Ausrichtungstyp des Textes auf einen anderen Wert als links oder rechts gesetzt ist, wird das m_IndentLevel-Level auf null zurückgesetzt.
