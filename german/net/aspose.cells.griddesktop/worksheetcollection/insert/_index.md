## Insert(int) {#insert_1}

Fügt ein Worksheet in die WorksheetCollection an der angegebenen Position ein. Dieses Worksheet hat 256 Zeilen und 32 Spalten. Der Worksheet-Name wird durch die Add()-Methode erzeugt.

```csharp
public void Insert(int index)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Index | Int32 | Der nullbasierte Index, an dem das Arbeitsblatt eingefügt werden soll. |

### Rückgabewert
