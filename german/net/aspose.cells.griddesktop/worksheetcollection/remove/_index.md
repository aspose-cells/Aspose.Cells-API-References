## WorksheetCollection.Remove method

Entfernt das Worksheet am angegebenen Index der WorksheetCollection. Wenn das betreffende Blatt das letzte Blatt ist, wird nach dem Entfernen ein neues Blatt zur WorksheetCollection hinzugefügt.

public void Remove(int index)
