## HorizontalAlignmentType enumeration

Gibt an, wie eine Rasterzelle horizontal ausgerichtet ist.

```csharp
public enum HorizontalAlignmentType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| General | `0` | Wenn der Objekttyp Zahl ist, wird das Objekt rechts in der Rasterzelle ausgerichtet. Wenn der Objekttyp Zeichenkette ist, wird das Objekt links in der Rasterzelle ausgerichtet. |
| Left | `1` | Das Objekt oder der Text ist links in der Rasterzelle ausgerichtet. |
