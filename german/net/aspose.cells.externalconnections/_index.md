Der **Aspose.Cells.ExternalConnections** Namespace stellt Klassen für externe Verbindungen bereit, um Daten aus externen Quellen wie Datenbanken und dem Web abzurufen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ConnectionParameter](./connectionparameter/) | Gibt Eigenschaften zu allen Parametern an, die mit externen Datenverbindungen verwendet werden. Parameter sind für ODBC‑ und Web‑Abfragen gültig. |
| [ConnectionParameterCollection](./connectionparametercollection/) | Gibt die Sammlung [`ConnectionParameter`](../aspose.cells.externalconnections/connectionparameter/) an |
| [DataModelConnection](./datamodelconnection/) | Gibt eine Datenmodellverbindung an |
| [DBConnection](./dbconnection/) | Gibt alle Eigenschaften an, die mit einer externen ODBC‑ oder OLE‑DB‑Datenverbindung verbunden sind. |
| [ExternalConnection](./externalconnection/) | Gibt eine externe Datenverbindung an |
| [ExternalConnectionCollection](./externalconnectioncollection/) | Gibt die Sammlung [`ExternalConnection`](../aspose.cells.externalconnections/externalconnection/) an |
| [WebQueryConnection](./webqueryconnection/) | Gibt die Eigenschaften für eine Web‑Abfragequelle an. Eine Web‑Abfrage ruft Daten aus HTML‑Tabellen ab und kann außerdem HTTP‑"Get"-Parameter bereitstellen, die vom Web‑Server bei der Generierung des HTML verarbeitet werden, indem die Parameter und Parameterelemente eingebunden werden. |
## Aufzählung

| Aufzählung | Beschreibung |
| --- | --- |
| [ConnectionDataSourceType](./connectiondatasourcetype/) | Gibt den Typ der externen Datenbankquelle an |
| [ConnectionParameterType](./connectionparametertype/) | Gibt den Parametertyp der externen Verbindung an |
| [CredentialsMethodType](./credentialsmethodtype/) | Gibt die Anmeldemethode an, die für den Serverzugriff verwendet wird. |
| [ExternalConnectionClassType](./externalconnectionclasstype/) | Stellt den Verbindungstyp dar |
| [HtmlFormatHandlingType](./htmlformathandlingtype/) | Gibt an, wie die Formatierung aus der HTML-Quelle zu behandeln ist |
| [OLEDBCommandType](./oledbcommandtype/) | Gibt den OLE DB-Befehlstyp an. |
| [ReConnectionMethodType](./reconnectionmethodtype/) | Gibt an, was die Tabellenkalkulationsanwendung tun soll, wenn eine Verbindung fehlschlägt. |
| [SqlDataType](./sqldatatype/) | Gibt den SQL-Datentyp des Parameters an. Nur für ODBC-Quellen gültig. |
