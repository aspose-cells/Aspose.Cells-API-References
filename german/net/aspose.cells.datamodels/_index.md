Der **Aspose.Cells.DataModels** Namespace stellt Klassen zum Zugriff auf und zur Aktualisierung von Datenmodellen der Arbeitsmappe bereit.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DataModel](./datamodel/) | Stellt das Datenmodell dar. |
| [DataModelRelationship](./datamodelrelationship/) | Stellt eine einzelne Beziehung im Datenmodell der Tabellenkalkulation dar. |
| [DataModelRelationshipCollection](./datamodelrelationshipcollection/) | Stellt die Beziehungen dar. |
| [DataModelTable](./datamodeltable/) | Stellt Eigenschaften einer einzelnen Tabelle im Datenmodell der Tabellenkalkulation dar. |
| [DataModelTableCollection](./datamodeltablecollection/) | Stellt die Liste der Datenmodelltabelle dar. |
