## GridJsLogger.EnableFileOutput property

Gibt an, ob Protokollnachrichten in eine Datei ausgegeben werden sollen, oder legt dies fest. Standard ist false. [`SetLogFile`](../setlogfile/) oder [`SetLogDirectory`](../setlogdirectory/) muss vor dem Aktivieren aufgerufen werden.

public static bool EnableFileOutput { get; set; }
