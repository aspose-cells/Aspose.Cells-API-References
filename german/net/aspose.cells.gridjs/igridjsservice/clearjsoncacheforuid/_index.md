## IGridJsService.ClearJsonCacheForUid method

Löscht alle JSON-Cache-Einträge, die zur angegebenen eindeutigen ID gehören. Rufen Sie dies auf, nachdem die Quelldatei außerhalb des normalen Ablaufs geändert wurde, damit die nächste Anforderung das JSON neu generiert.

```csharp
public void ClearJsonCacheForUid(string uid)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| uid | String | Die eindeutige ID für den Dateicache. |
