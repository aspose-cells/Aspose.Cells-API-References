## GridJsOptions.EnableChartClientRendering property

Liest/Setzt, ob das clientseitige Diagrammrendering aktiviert werden soll. Wenn auf false gesetzt, gibt GridJs nur Diagrammbilder/-formen aus und erfordert kein clientseitiges Diagrammrendering. Der Standardwert ist true.

```csharp
public bool EnableChartClientRendering { get; set; }
```
