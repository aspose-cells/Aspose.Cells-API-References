## GridJsOptions.IsWasm property

Liest/Setzt, ob GridJs innerhalb eines Browser-WebAssembly-Hosts statt eines Serverprozesses ausgeführt wird. Wenn true, wird kein FileCacheDirectory / Festplatte / Interrupt-Thread-Pfad verwendet, und der Dateicache muss von CacheImp stammen, da ein Browser-Host keinen lokalen Datenträger hat. Es wählt zur Laufzeit Codepfade aus, sodass eine Aspose.Cells.GridJs.dll beide Hosts bedient. Der Standardwert ist false.

public bool IsWasm { get; set; }
