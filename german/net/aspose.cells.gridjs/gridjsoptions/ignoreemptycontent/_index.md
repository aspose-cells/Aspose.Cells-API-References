## GridJsOptions.IgnoreEmptyContent property

Liest/Setzt, ob der maximale Bereich angezeigt werden soll, der Daten, Stil, zusammengeführte Zellen und Formen enthält. Wenn die letzte Zeile oder Spalte Zellen ohne Wert und Formel, aber mit benutzerdefiniertem Stil enthält, wird diese Zeile/Spalte nicht angezeigt, wenn dieser Wert true ist. Der Standardwert ist true.

```csharp
public bool IgnoreEmptyContent { get; set; }
```
