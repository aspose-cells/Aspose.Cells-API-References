## GridCalculationData.GetParamValue method

Liefert das repräsentierte Wertobjekt des Parameters am angegebenen Index.

```csharp
public object GetParamValue(int index)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Index | Int32 | Der Index des Parameters (0-basiert). |

### Rückgabewert

Wenn der Parameter ein einfacher Wert ist, wird der einfache Wert zurückgegeben. Wenn der Parameter eine Referenz ist, wird ein ReferredArea-Objekt zurückgegeben.
