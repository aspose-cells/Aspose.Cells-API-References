## JsonCacheOptions.Enable property

Liest/Setzt, ob JSON-Caching für schnellere Antworten aktiviert wird. Wenn aktiviert, cached GridJs das erzeugte JSON und verwendet es für nachfolgende Anfragen erneut. Der Standardwert ist false. Hinweis: Sie müssen Implementation setzen, um benutzerdefinierten Cache‑Speicher zu verwenden.

```csharp
public bool Enable { get; set; }
```
