Der **Aspose.Cells.GridJs** Namespace kapselt alle Klassen von GridJs und bietet einfache APIs zum Anzeigen oder Bearbeiten von Tabellendateien über JSON‑Operationen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Config](./config/) | Stellt alle statischen Einstellungen für GridJs dar |
| [DefaultGridJsJsonCache](./defaultgridjsjsoncache/) | Standard‑JSON‑Cache‑Implementierung (L1 Speicher + L2 Festplatte) |
| [GridAbstractCalculationEngine](./gridabstractcalculationengine/) | Stellt die benutzerdefinierte Berechnungs-Engine des Benutzers dar, um die Standard-Berechnungs-Engine von Aspose.Cells zu erweitern. |
| [GridCacheForStream](./gridcacheforstream/) | Diese Klasse enthält die Cache‑Operationen für GridJs. Der Benutzer soll darauf basierend seine eigene Geschäftslogik für die Speicherung implementieren.. |
| [GridCalculationData](./gridcalculationdata/) | Stellt die erforderlichen Daten beim Berechnen einer Funktion dar, wie Funktionsname, Parameter, ...etc. |
| [GridCellException](./gridcellexception/) | Die Ausnahme, die ausgelöst wird, wenn ein spezifizierter GridJs‑Fehler auftritt. |
| [GridInterruptMonitor](./gridinterruptmonitor/) | Stellt alle Operatoren bezüglich der Berechnungsunterbrechung dar. |
| [GridJsControllerBase](./gridjscontrollerbase/) |  |
| [GridJsLogger](./gridjslogger/) | Stellt ein leichtgewichtiges Protokollierungssystem für den GridJs‑Server bereit. Unterstützt Konsolen‑ und Dateiausgabe mit konfigurierbaren Protokollstufen. Standardstufe ist Keine. Im DEBUG‑Build ist die Standardstufe Debug (gibt alle Meldungen aus). Unterstützt das Rollen von Protokolldateien nach Tag/Woche/Monat. |
| [GridJsOptions](./gridjsoptions/) | Stellt alle Ladeoptionen für GridJs dar. |
| [GridJsPermissionException](./gridjspermissionexception/) | stellt eine Berechtigungsausnahme im Kollaborationsmodus dar. Nur in der Java‑Version verfügbar, wird in Zukunft in .net/python‑Versionen verfügbar sein. |
| [GridJsService](./gridjsservice/) | Stellt die grundlegenden Betriebs‑APIs bereit, die in Controller‑Aktionen verwendet werden. |
| [GridJsWorkbook](./gridjsworkbook/) | Stellt die Haupt‑Einstiegsklasse für GridJs dar. |
| [GridReferredArea](./gridreferredarea/) | Stellt einen von der Formel referenzierten Bereich dar. |
| [GridUpdateMonitor](./gridupdatemonitor/) | Überwacht den Benutzer, um Änderungen der Aktualisierungsoperation zu verfolgen. |
| [GridWorkbookSettings](./gridworkbooksettings/) | Stellt die Einstellungen der Arbeitsmappe dar. |
| [JsonCacheOptions](./jsoncacheoptions/) | Konfigurationsoptionen für das JSON‑Caching in GridJs. Steuert das Verhalten des Speicher‑ (L1) und Festplatten‑ (L2) Caches. |
| [OprMessageService](./oprmessageservice/) | Diese Klasse stellt alle Operationen für die Nachrichten‑Synchronisation im kollaborativen Modus bereit. |
