## Config.AutoFitColumnsOnLoad property

Gibt an, ob die Spaltenbreiten beim Laden der Datei automatisch angepasst werden sollen. Der Standardwert ist `false`. Hinweis: Wird dieser Wert auf `true` gesetzt, wird nach dem Laden ein automatisches Anpassen aller Spalten durchgeführt, was die Leistung merklich beeinträchtigen kann.

```csharp
public static bool AutoFitColumnsOnLoad { get; set; }
```
