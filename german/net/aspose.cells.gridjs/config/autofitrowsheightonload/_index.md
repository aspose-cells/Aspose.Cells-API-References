## Config.AutoFitRowsHeightOnLoad property

Gibt an, ob die Zeilenhöhen beim Laden der Datei automatisch angepasst werden sollen. Der Standardwert ist `false`. Hinweis: Wird dieser Wert auf `true` gesetzt, wird nach dem Laden ein automatisches Anpassen aller Zeilen durchgeführt, was die Leistung merklich beeinträchtigen kann.

```csharp
public static bool AutoFitRowsHeightOnLoad { get; set; }
```
