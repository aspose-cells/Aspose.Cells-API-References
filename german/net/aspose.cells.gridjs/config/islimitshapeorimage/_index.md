## Config.IslimitShapeOrImage property

Liest/Setzt, ob die Gesamtzahl der angezeigten Formen/Bilder in einem Arbeitsblatt begrenzt werden soll. Wenn true, begrenzt GridJs die Gesamtzahl der angezeigten Formen oder Bilder in einem Arbeitsblatt auf MaxShapeOrImageCount. Der Standardwert ist true.

public static bool IslimitShapeOrImage { get; set; }
