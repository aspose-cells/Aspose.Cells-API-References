## Config.IsWasm property

Liest/Setzt, ob GridJs in einem Browser‑WebAssembly‑Host anstelle eines Serverprozesses ausgeführt wird. Wenn true, wird kein FileCacheDirectory / Festplatte / Interrupt‑Thread‑Pfad verwendet und der Dateicache muss von GridJsOptions.CacheImp stammen. GridJsOptions.IsWasm setzt dies, wenn der GridJs‑Dienst erstellt wird, sodass eine Aspose.Cells.GridJs.dll beide Hosts bedienen kann. Der Standardwert ist false.

public static bool IsWasm { get; set; }
