## CoWorkUserPermission enumeration

stellt die Benutzerberechtigung im Kollaborationsmodus dar. Nur in der Java‑Version verfügbar, wird in Zukunft in .net/python‑Versionen verfügbar sein.

```csharp
public enum CoWorkUserPermission
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| READ_ONLY | `0` | Nur-Lese-Berechtigung, der Benutzer kann den Inhalt nur anzeigen, aber keine Änderungen vornehmen |
| EDITABLE | `1` | Bearbeitungsberechtigung, der Benutzer kann den Inhalt anzeigen und bearbeiten |
| DOWNLOAD | `2` | Download-Berechtigung, der Benutzer kann den Inhalt anzeigen, bearbeiten und in den lokalen Speicher herunterladen |
| ADMIN | `3` | Administratorberechtigung, der Benutzer hat vollen Zugriff einschließlich Verwaltungsoperationen |
