## ExcelRenderingBehavior enumeration

Gibt Excel‑spezifische Render‑Verhaltensweisen an, die beim Rendern einer Arbeitsmappe angewendet werden.

```csharp
[Flags]
public enum ExcelRenderingBehavior
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Wendet keine Excel-spezifischen Rendering‑Verhalten an. |
| CellTextLengthLimit | `1` | Wendet das Längenlimit für Zelltext von Excel an. Zum Beispiel gibt Excel nur die ersten 1024 Zeichen in einer nicht umbrochenen Zelle aus. |
| All | `FFFFFFFFFFFFFFFF` | Wendet alle unterstützten Excel-spezifischen Rendering‑Verhalten an. |
