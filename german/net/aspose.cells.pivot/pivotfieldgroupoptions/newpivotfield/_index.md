## PivotFieldGroupOptions.NewPivotField property

Liest oder setzt einen Wert, der angibt, ob nach dem Gruppieren neue Pivot‑Felder erstellt werden sollen.

```csharp
public bool NewPivotField { get; set; }
```

### Hinweise

Wenn nicht explizit festgelegt, ist der Standardwert für numerische Gruppierung false und für Datum-Zeit-Gruppierung true, für diskrete Gruppe ebenfalls true. Wirkt nur für das erste neue Gruppen-Pivot-Feld des Basisfeldes.
