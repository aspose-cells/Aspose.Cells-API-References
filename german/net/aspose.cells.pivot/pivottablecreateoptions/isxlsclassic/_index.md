## PivotTableCreateOptions.IsXlsClassic property

Liest oder setzt einen Wert, der angibt, ob eine klassische PivotTable im Excel‑97‑2003‑Stil erstellt werden soll.

```csharp
public bool IsXlsClassic { get; set; }
```

### Hinweise

Klassisches PivotTable verwendet das veraltete Layout und die Formatierung von Excel 97‑2003. Wenn es nicht explizit festgelegt wird, wird der Standardwert anhand des Dateiformats der Zielarbeitsmappe bestimmt.
