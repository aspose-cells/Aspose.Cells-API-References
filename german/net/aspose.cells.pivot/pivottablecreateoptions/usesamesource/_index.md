## PivotTableCreateOptions.UseSameSource property

Liest oder setzt einen Wert, der angibt, ob dieselbe Datenquelle mit bestehenden PivotTables geteilt werden soll. Standardwert ist true.

```csharp
public bool UseSameSource { get; set; }
```

### Hinweise

Wenn auf true gesetzt, können mehrere Pivot‑Tabellen einen Pivot‑Cache wiederverwenden, um den Speicherverbrauch zu reduzieren.
