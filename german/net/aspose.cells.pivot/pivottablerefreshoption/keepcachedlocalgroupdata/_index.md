## PivotTableRefreshOption.KeepCachedLocalGroupData property

Gibt an, ob zwischengespeicherte lokale Gruppendaten beibehalten werden sollen, wenn die maximalen und minimalen Werte unverändert bleiben. Der Standardwert ist false, was bedeutet, dass die Gruppe mit lokaler Einstellung aktualisiert wird.

```csharp
public bool KeepCachedLocalGroupData { get; set; }
```

### Hinweise

Dies ist eine vorübergehende Lösung, bitte lokalisieren Sie Pivot-Tabellen, indem Sie [`PivotGlobalizationSettings`](../../../aspose.cells.settings/pivotglobalizationsettings/) implementieren
