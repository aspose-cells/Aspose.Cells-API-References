## PivotTableRefreshOption.IsKeepOriginalOrder property

Gibt an, ob die ursprüngliche Reihenfolge der Pivot-Elemente wie in der alten Datenquelle beibehalten werden soll.

```csharp
public bool IsKeepOriginalOrder { get; set; }
```

### Hinweise

Nur anwendbar für das Pivot-Feld, das nicht sortiert ist. Beim Aktualisieren einer solchen Art von Pivot-Feld behält Ms Excel die ursprüngliche Reihenfolge der alten Datenquelle bei. Der Standardwert dieser Eigenschaft ist true, was das gleiche Verhalten wie bei Ms Excel darstellt. Wenn der Benutzer das Pivot-Feld vollständig wie die Daten in der neuen Datenquelle aktualisieren möchte, sollte diese Eigenschaft auf false gesetzt werden.
