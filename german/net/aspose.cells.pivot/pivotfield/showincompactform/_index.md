## PivotField.ShowInCompactForm property

Liest oder legt einen Wert fest, der angibt, ob dieses Zeilenfeld das kompakte Layout verwendet. Gilt nur für Zeilenfelder.

```csharp
public bool ShowInCompactForm { get; set; }
```

### Hinweise

Das kompakte Format ist ein Untermodus des Gliederungslayouts. Diese Einstellung wirkt nur, wenn [`ShowInOutlineForm`](../showinoutlineform/) true ist.
