## Group() {#group}

Gruppiert das Feld automatisch.

```csharp
public bool Group()
```

### Hinweise

Wenn das Feld nur leere Werte und Datum/Zeit enthält, wird das Feld nach Monaten gruppiert. Wenn das Feld nur leere Werte und Zahlen enthält, wird das Feld nach Zahlen gruppiert. Andernfalls wird nur false zurückgegeben, ohne Gruppierung.
