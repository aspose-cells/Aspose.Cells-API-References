Der **Aspose.Cells.Properties** Namespace stellt Klassen bereit, um mit benutzerdefinierten und integrierten Tabellenkalkulationseigenschaften wie Titel, Schlüsselwörtern, Unternehmen usw. zu arbeiten.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [BuiltInDocumentPropertyCollection](./builtindocumentpropertycollection/) | Eine Sammlung integrierter Dokumenteigenschaften. |
| [ContentTypeProperty](./contenttypeproperty/) | Stellt Identifikatorinformationen dar. |
| [ContentTypePropertyCollection](./contenttypepropertycollection/) | Eine Sammlung von [`ContentTypeProperty`](../aspose.cells.properties/contenttypeproperty/) Objekten, die zusätzliche Informationen darstellen. |
| [CustomDocumentPropertyCollection](./customdocumentpropertycollection/) | Eine Sammlung benutzerdefinierter Dokumenteigenschaften. |
| [CustomProperty](./customproperty/) | Stellt eine benutzerdefinierte Eigenschaft dar, die Namens‑ und Wertepaare beliebiger benutzerdefinierter Daten für das Arbeitsblatt speichert. |
| [CustomPropertyCollection](./custompropertycollection/) | Eine Sammlung von [`CustomProperty`](../aspose.cells.properties/customproperty/) Objekten, die zusätzliche Informationen darstellen. |
| [DocumentProperty](./documentproperty/) | Stellt eine benutzerdefinierte oder integrierte Dokumenteigenschaft dar. |
| [DocumentPropertyCollection](./documentpropertycollection/) | Basisklasse für die Sammlungen [`BuiltInDocumentPropertyCollection`](../aspose.cells.properties/builtindocumentpropertycollection/) und [`CustomDocumentPropertyCollection`](../aspose.cells.properties/customdocumentpropertycollection/). |
