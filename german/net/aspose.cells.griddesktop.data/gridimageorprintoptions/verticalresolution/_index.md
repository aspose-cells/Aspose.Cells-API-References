## GridImageOrPrintOptions.VerticalResolution property

Liest oder setzt die vertikale Auflösung für erzeugte Bilder, in Punkten pro Zoll. Gilt für die Bildgenerierungsmethode, außer bei Emf-Formatbildern.

```csharp
public int VerticalResolution { get; set; }
```

### Hinweise

Der Standardwert ist 96.
