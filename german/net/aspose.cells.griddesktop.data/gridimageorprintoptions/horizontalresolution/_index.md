## GridImageOrPrintOptions.HorizontalResolution property

Liest oder setzt die horizontale Auflösung für erzeugte Bilder, in Punkten pro Zoll. Gilt für die Bildgenerierungsmethode, außer bei Emf-Formatbildern.

```csharp
public int HorizontalResolution { get; set; }
```

### Hinweise

Der Standardwert ist 96.
