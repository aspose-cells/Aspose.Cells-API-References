## GridComment.Height property

Lese oder setze die Höhe des Kommentars. Der Standardwert ist 120. Der Eingabewert sollte zwischen 20 und 1000 liegen. Er wird auf 20 gesetzt, wenn ein Wert kleiner als 20 eingegeben wird. Er wird auf 1000 gesetzt, wenn ein Wert größer als 1000 eingegeben wird.

public int Height { get; set; }
