## OnErrorActionType enumeration

Wird im CellError‑Ereignis von GridWeb verwendet. Der Benutzer setzt OnErrorActionQuery.OnErrorAction, um der Steuerung mitzuteilen, die Verarbeitung zu stoppen oder den Fehler zu ignorieren.

```csharp
public enum OnErrorActionType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Throw | `0` | Wirft die aktuelle Ausnahme. |
| Stop | `1` | Stoppt die aktuelle Verarbeitung. |
| Ignore | `2` | Ignoriert den Fehler und setzt die Verarbeitung fort. |
