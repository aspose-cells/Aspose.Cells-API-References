## GridCellValueFormatStrategy enumeration

Gibt an, wie der Stil für den Zellwert angewendet wird.

```csharp
public enum GridCellValueFormatStrategy
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Nicht formatiert. |
| CellStyle | `1` | Nur mit dem ursprünglichen Stil der Zelle formatiert. |
| DisplayStyle | `2` | Mit dem angezeigten Stil der Zelle formatiert. |
| DisplayString | `3` | Ruft die in MS Excel angezeigte Zeichenkette ab. Der Hauptunterschied zu DisplayStyle besteht darin, dass diese Option auch die Auswirkung der Spaltenbreite berücksichtigt. Ist die Spaltenbreite zu klein, um die formatierte Zeichenkette vollständig anzuzeigen, kann "#" angezeigt werden, genau wie in MS Excel. |
