## GridCellException.Cell property

Ruft die fehlerhafte Zelle ab. Wenn die Zelle null ist, wird der Fehler durch eine CommitNewBindRow-Operation verursacht, was bedeutet, dass die DataTable die neu erstellte Zeile abgelehnt hat.
