## WebCells.SetRowReadonly method

Setzt eine Zeile auf schreibgeschützt, sodass der Benutzer sie nicht von der Clientseite löschen kann. Dies ist eine erweiterte Methode von GridWeb speziell, sie wird in der tatsächlichen Excel-Datei nicht beibehalten und wirkt sich nicht aus.

```csharp
public void SetRowReadonly(int rowIndex, bool isReadonly)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| rowIndex | Int32 | Zeilenindex. |
| isReadonly | Boolean | wahr oder falsch. |
