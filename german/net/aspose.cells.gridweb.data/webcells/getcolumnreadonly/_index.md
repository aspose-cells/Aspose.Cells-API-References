## WebCells.GetColumnReadonly method

Ermittelt, ob eine Spalte schreibgeschützt ist. Dies ist eine erweiterte Methode von GridWeb speziell, sie wird in der tatsächlichen Excel-Datei nicht beibehalten und wirkt sich nicht aus.

```csharp
public bool GetColumnReadonly(int columnIndex)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| columnIndex | Int32 | Spaltenindex. |

### Rückgabewert

Wenn schreibgeschützt, wird true zurückgegeben.
