## WebCells.Export method

Exportiert Daten aus der Cells-Sammlung eines WebWorksheet in ein neues DataTable-Objekt.

```csharp
public DataTable Export(int startRow, int startColumn, int rows, int columns, 
    bool exportColumnName, bool isVertical)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| startRow | Int32 | Die Zeilennummer der ersten zu exportierenden Zelle. |
| startColumn | Int32 | Die Spaltennummer der ersten zu exportierenden Zelle. |
| Zeilen | Int32 | Anzahl der zu importierenden Zeilen. |
| Spalten | Int32 | Anzahl der zu importierenden Spalten. |
| exportColumnName | Boolean | Gibt an, ob die Daten in der ersten Zeile als Spaltenname des DataTable exportiert werden |
| isVertical | Boolean | Wahr, wenn eine Zeile in der Excel-Datei eine Zeile im DataTable darstellt. Falsch, wenn eine Spalte in der Excel-Datei eine Zeile im DataTable darstellt. |

### Rückgabewert

Exportiertes DataTable-Objekt.
