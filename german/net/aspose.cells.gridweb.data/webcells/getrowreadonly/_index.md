## WebCells.GetRowReadonly method

Ermittelt, ob eine Zeile schreibgeschützt ist. Dies ist eine erweiterte Methode von GridWeb speziell, sie wird in der tatsächlichen Excel-Datei nicht beibehalten und wirkt sich nicht aus.

```csharp
public bool GetRowReadonly(int rowIndex)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| rowIndex | Int32 | Zeilenindex. |

### Rückgabewert

Wenn schreibgeschützt, wird true zurückgegeben.
