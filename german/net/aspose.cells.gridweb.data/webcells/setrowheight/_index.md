## WebCells.SetRowHeight method

Setzt die Höhe der angegebenen Zeile. Der akzeptierte Höhentyp ist Punkt, Pixel oder Zoll.

```csharp
public void SetRowHeight(int row, Unit height)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| row | Int32 | Zeilenindex. |
| Höhe | Einheit | Höhe der Zeile. In Punkt angegeben. Sie sollte zwischen 0 und 409,5 liegen. |

### Hinweise

Um eine Zeile auszublenden, wird die Zeilenhöhe auf Null gesetzt.
