## GridTxtLoadOptions.ExtendToNextSheet property

Ob Daten auf das nächste Blatt erweitert werden, wenn Zeilen oder Spalten das Limit überschreiten. Wenn diese Eigenschaft wahr ist, werden überschüssige Daten auf das nächste Blatt hinter dem aktuellen Blatt erweitert (wenn das aktuelle Blatt das letzte ist, wird ein neues Blatt zum aktuellen Arbeitsbuch hinzugefügt). Wenn diese Eigenschaft falsch ist, werden die Daten, die das Limit überschreiten, ignoriert. Standardwert ist false;

```csharp
public bool ExtendToNextSheet { get; set; }
```
