## GridTxtLoadOptions.TreatQuotePrefixAsValue property

Gibt an, ob das führende einfache Anführungszeichen als Teil des Wertes einer Zelle betrachtet werden soll. Standard ist true. Ist es false, wird das führende einfache Anführungszeichen aus dem entsprechenden Zellenwert entfernt und [`QuotePrefix`](../../../aspose.cells.gridweb/gridtableitemstyle/quoteprefix/) wird für die Zelle auf true gesetzt.

```csharp
public bool TreatQuotePrefixAsValue { get; set; }
```
