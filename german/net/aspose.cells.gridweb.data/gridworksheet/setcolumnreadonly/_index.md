## GridWorksheet.SetColumnReadonly method

Setzt eine Spalte auf schreibgeschützt, sodass der Benutzer sie nicht von der Clientseite löschen kann. Dies ist eine erweiterte Methode von GridWeb speziell, sie wird in der tatsächlichen Excel-Datei nicht beibehalten und wirkt sich nicht aus.

```csharp
public void SetColumnReadonly(int columnIndex, bool isReadonly)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| columnIndex | Int32 | Spaltenindex. |
| isReadonly | Boolean | wahr oder falsch. |
