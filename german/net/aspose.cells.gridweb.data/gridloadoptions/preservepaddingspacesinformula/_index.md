## GridLoadOptions.PreservePaddingSpacesInFormula property

Gibt an, ob Leerzeichen und Zeilenumbrüche, die zwischen Formeltoken eingefügt sind, beim Lesen und Schreiben von Formeln erhalten bleiben sollen. Der Standardwert ist false.

```csharp
public bool PreservePaddingSpacesInFormula { get; set; }
```

### Hinweise

Nach dem Laden der Arbeitsmappe aus einer Vorlagendatei mit dieser Option wird [`PreservePaddingSpaces`](../../gridworkbooksettings/preservepaddingspaces/) auf denselben Wert wie diese Eigenschaft gesetzt.
