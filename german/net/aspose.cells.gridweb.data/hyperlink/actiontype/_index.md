## Hyperlink.ActionType property

Liest oder setzt den Aktionstyp des Hyperlinks. Er kann ActionTpye.UrlLink oder ActionType.CellCommand sein. Der UrlLink‑Typ bedeutet, dass der Hyperlink ein Link zu einer Webseite oder einer E‑Mail‑Empfangsadresse ist. Zum Beispiel: "http://www.aspose.com" oder "mailto:admin@aspose.com". Der CellCommand‑Typ bedeutet, dass der Hyperlink ein CellCommand‑Ereignis auslöst, das Sie behandeln können.

```csharp
public virtual HyperlinkActionType ActionType { get; set; }
```
