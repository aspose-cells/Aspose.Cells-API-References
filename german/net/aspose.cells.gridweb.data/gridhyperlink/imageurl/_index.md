## GridHyperlink.ImageURL property

Abrufen oder Festlegen der Bild-URL für den Link, es gibt keine imageurl-Eigenschaft im Hyperlink, daher wird tatsächlich TextToDisplay verwendet, um diesen Wert zu speichern. TextToDisplay wird auf &lt;img src=value &gt; gesetzt, sodass es den Wert von TextToDisplay ändert.

```csharp
public string ImageURL { get; set; }
```
