Der **Aspose.Cells.Utility** Namespace enthält Hilfsklassen zur Verarbeitung von JSON‑Formaten für Excel‑Tabellendateien.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ConversionUtility](./conversionutility/) | Stellt ein Hilfswerkzeug zum Konvertieren von Dateien in andere Formate dar. |
| [ExportRangeToJsonOptions](./exportrangetojsonoptions/) | Gibt die Optionen an, die beim Exportieren eines Bereichs nach JSON verwendet werden. |
| [JsonLayoutOptions](./jsonlayoutoptions/) | Stellt die Optionen des JSON‑Layouttyps dar. |
| [JsonUtility](./jsonutility/) | Stellt die Hilfsklasse zur Verarbeitung von JSON dar. |
