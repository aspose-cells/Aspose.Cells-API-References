Der **Aspose.Cells.Tables** Namespace enthält Klassen, die Tabellen, Zeilen, Zellen und deren Formatierung für Excel‑Tabellendateien darstellen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ListColumn](./listcolumn/) | Stellt eine Spalte in einer Tabelle dar. |
| [ListColumnCollection](./listcolumncollection/) | Stellt eine Liste aller [`ListColumn`](../aspose.cells.tables/listcolumn/)‑Objekte in der Tabelle dar. |
| [ListObject](./listobject/) | Stellt eine Tabelle in einem Arbeitsblatt dar. |
| [ListObjectCollection](./listobjectcollection/) | Stellt eine Sammlung von [`ListObject`](../aspose.cells.tables/listobject/)‑Objekten im Arbeitsblatt dar. |
| [TableStyle](./tablestyle/) | Stellt den Stil der Tabelle dar. |
| [TableStyleCollection](./tablestylecollection/) | Stellt alle benutzerdefinierten Tabellenvorlagen dar. |
| [TableStyleElement](./tablestyleelement/) | Stellt das Element des Tabellenvorlagestils dar. |
| [TableStyleElementCollection](./tablestyleelementcollection/) | Stellt alle Elemente des Tabellenvorlagestils dar. |
| [TableToRangeOptions](./tabletorangeoptions/) | Stellt die Optionen beim Konvertieren einer Tabelle in einen Bereich dar. |
