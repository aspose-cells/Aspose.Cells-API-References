Der **Aspose.Cells.Timelines** Namespace enthält Klassen, die den Zugriff auf und das Zeichnen von Zeitlinien in Excel‑Tabellendateien ermöglichen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Timeline](./timeline/) | Zusammenfassende Beschreibung der Timeline-Ansicht. Aufgrund von MS Excel unterstützt Excel 2003 keine Timeline. |
| [TimelineCollection](./timelinecollection/) | Gibt die Sammlung aller [`Timeline`](../aspose.cells.timelines/timeline/)‑Objekte im Arbeitsblatt an. Sie wird seit Excel 2013 unterstützt. |
## Aufzählung

| Aufzählung | Beschreibung |
| --- | --- |
| [TimelineLevelType](./timelineleveltype/) | Stellt den Ebenentyp von [`Timeline`](../aspose.cells.timelines/timeline/) dar. |
