## ShapeDisplayType enumeration

Stellt dar, wie die Anwendung Formen in dieser Arbeitsmappe anzeigt. Formen können Diagramme, Bilder und andere Objektdaten umfassen, die die Anwendung unterstützt.

```csharp
public enum ShapeDisplayType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| All | `0` | Gibt an, dass alle Formen im Workbook angezeigt werden. |
| Placeholders | `1` | Gibt an, dass die Anwendung Platzhalter für Formen im Workbook anzeigt. |
| None | `2` | Gibt an, dass alle Formen im Workbook ausgeblendet werden. |
