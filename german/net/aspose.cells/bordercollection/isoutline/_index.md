## BorderCollection.IsOutline property

Gibt an, ob linke, rechte, obere und untere Rahmen nur auf die äußeren Rahmen eines Zellenbereichs angewendet werden sollen. Der Standardwert ist true.

```csharp
public bool IsOutline { get; set; }
```

### Hinweise

Funktioniert nur, wenn es auf einen Bereich für bedingte Formatierungen, Pivot‑Tabellen angewendet wird. Wenn false, werden links, rechts, oben und unten auf jede Zelle angewendet, andernfalls nur auf die äußeren Rahmen eines Zellbereichs. Wenn true, bitte setzen Sie die horizontalen und vertikalen Rahmen der inneren Rahmen des Bereichs für bedingte Formatierungen, Pivot‑Tabellen.
