## HyperlinkLoadMode enumeration

Gibt an, wie Hyperlinks beim Laden von HTML behandelt werden.

```csharp
public enum HyperlinkLoadMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Normal | `0` | Nur der erste Hyperlink in einer Zelle wird geladen, nachfolgende werden ignoriert. |
| AllowMultiple | `1` | Alle Hyperlinks in einer Zelle werden zu [`Hyperlinks`](../worksheet/hyperlinks/) hinzugefügt. Beachten Sie, dass MS Excel selbst nur einen Hyperlink pro Zelle unterstützt, sodass diese Option Dateien erzeugen kann, die Excel nicht vollständig rendern kann. |
