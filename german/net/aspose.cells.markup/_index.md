Der **Aspose.Cells.Markup** Namespace enthält Klassen, die kundenspezifische Semantik in einem Dokument darstellen: Smart‑Tags, benutzerdefiniertes XML und weitere Markup‑Tags.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CustomXmlPart](./customxmlpart/) | Stellt einen benutzerdefinierten XML‑Datenspeicherteil dar (benutzerdefinierte XML‑Daten innerhalb eines Pakets). |
| [CustomXmlPartCollection](./customxmlpartcollection/) | Stellt einen benutzerdefinierten XML‑Datenspeicherteil dar (benutzerdefinierte XML‑Daten innerhalb eines Pakets). |
| [SmartTag](./smarttag/) | Stellt ein SmartTag dar. |
| [SmartTagCollection](./smarttagcollection/) | Stellt alle SmartTags in der Zelle dar. |
| [SmartTagOptions](./smarttagoptions/) | Stellt die Optionen des SmartTags dar. |
| [SmartTagProperty](./smarttagproperty/) | Stellt die Eigenschaft des Zellen‑SmartTags dar. |
| [SmartTagPropertyCollection](./smarttagpropertycollection/) | Stellt alle Eigenschaften des Zellen‑SmartTags dar. |
| [SmartTagSetting](./smarttagsetting/) | Stellt alle [`SmartTagCollection`](../aspose.cells.markup/smarttagcollection/) Objekte im Arbeitsblatt dar. |
