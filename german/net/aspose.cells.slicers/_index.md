## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Slicer](./slicer/) | Zusammenfassende Beschreibung der Slicer‑Ansicht |
| [SlicerCache](./slicercache/) | Stellt die zusammenfassende Beschreibung des Slicer‑Cache dar |
| [SlicerCacheItem](./slicercacheitem/) | Stellt das Slicer‑Datenquellen‑Element dar |
| [SlicerCacheItemCollection](./slicercacheitemcollection/) | Stellt die Sammlung von SlicerCacheItem dar |
| [SlicerCollection](./slicercollection/) | Gibt die Sammlung aller Slicer‑Objekte im angegebenen Arbeitsblatt an. |
