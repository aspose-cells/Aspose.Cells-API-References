Der **Aspose.Cells.WebExtensions** Namespace enthält Klassen zum Zugriff auf Office‑Add‑Ins in Excel‑Dateien.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [WebExtension](./webextension/) | Stellt eine Instanz eines Office‑Add‑Ins dar. |
| [WebExtensionBinding](./webextensionbinding/) | Stellt eine Bindungsbeziehung zwischen einem Office-Add-In und den Daten im Dokument dar. |
| [WebExtensionBindingCollection](./webextensionbindingcollection/) | Stellt die Liste der Bindungsbeziehungen zwischen einem Office-Add-In und den Daten im Dokument dar. |
| [WebExtensionCollection](./webextensioncollection/) | Stellt die Liste der Web-Erweiterungen dar. |
| [WebExtensionProperty](./webextensionproperty/) | Stellt eine benutzerdefinierte Eigenschaft eines Office-Add-Ins dar. |
| [WebExtensionPropertyCollection](./webextensionpropertycollection/) | Stellt die Liste der Web-Erweiterungseigenschaften dar. |
| [WebExtensionReference](./webextensionreference/) | Stellt die Identifizierung des Anbieters, des Speicherorts und der Version der Erweiterung dar. |
| [WebExtensionReferenceCollection](./webextensionreferencecollection/) | Stellt die Liste der Web-Erweiterungsreferenzen dar. |
| [WebExtensionTaskPane](./webextensiontaskpane/) | Stellt ein persistentes Taskpane-Objekt dar. |
| [WebExtensionTaskPaneCollection](./webextensiontaskpanecollection/) | Stellt die Liste der Taskpanes dar. |
