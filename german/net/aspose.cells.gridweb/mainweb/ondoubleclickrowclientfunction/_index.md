## MainWeb.OnDoubleClickRowClientFunction property

Legt die clientseitige Funktion fest, die aufgerufen wird, wenn eine Zeile doppelt angeklickt wird, oder ruft sie ab. Die Clientfunktion sollte wie folgt deklariert werden: function MyOnRowDoubleClick(row) { alert(row); }Hinweis: Sie können den "this"-Zeiger in der Clientfunktion verwenden, um auf das Grid-Steuerelement zu verweisen, das das Ereignis auslöst.

```csharp
public string OnDoubleClickRowClientFunction { get; set; }
```
