## MainWeb.MaxColumn property

Liest oder setzt den maximalen Anzeigespaltenindex(nullbasiert) des Webblatts. Das Steuerelement verwendet den größeren Wert von MaxColumn und dem maximalen Spaltenwert der Blattdaten.

```csharp
public int MaxColumn { get; set; }
```

### Beispiele

```csharp
[C#]
	// Erstellt ein 4 × 4‑„Anzeige‑Fenster“.
	GridWeb1.MinRow = 2;
	GridWeb1.MaxRow = 5;
	GridWeb1.MinColumn = 3;
	GridWeb1.MaxColumn = 6;

[Visual Basic]
	' Creates a 4x4 "display window".
	GridWeb1.MinRow = 2
	GridWeb1.MaxRow = 5
	GridWeb1.MinColumn = 3
	GridWeb1.MaxColumn = 6
```
