## MainWeb.MinColumn property

Liest oder setzt den minimalen Anzeigespaltenindex(nullbasiert) des Webblatts. Das Steuerelement verwendet den kleineren Wert von MinColumn und dem minimalen Spaltenwert der Blattdaten.

```csharp
public int MinColumn { get; set; }
```

### Beispiele

```csharp
[C#]
	// Erstellt ein 4 × 4‑„Anzeige‑Fenster“.
	GridWeb1.MinRow = 2;
	GridWeb1.MaxRow = 5;
	GridWeb1.MinColumn = 3;
	GridWeb1.MaxColumn = 6;

[Visual Basic]
	' Creates a 4x4 "display window".
	GridWeb1.MinRow = 2
	GridWeb1.MaxRow = 5
	GridWeb1.MinColumn = 3
	GridWeb1.MaxColumn = 6
```
