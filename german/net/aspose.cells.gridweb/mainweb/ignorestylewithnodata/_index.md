## MainWeb.IgnoreStyleWithNoData property

Legt fest, ob GridWeb das Anzeigen von Zeilen oder Spalten ignoriert, die keine Zellwerte enthalten, aber dennoch formatiert sind. Wenn auf true gesetzt, ist die Leistung besser. Der Standardwert ist false, was bedeutet, dass wir letzte zusammenhängende Zeilen/Spalten ohne Zellwerte, aber mit Formatierung, weiterhin anzeigen. Diese Option ist nur gültig, wenn EnableAsync false ist. Sie hat keine Wirkung, wenn EnableAsync true ist, was bedeutet, dass GridWeb alle Zeilen/Spalten mit Formatierung anzeigt.

public bool IgnoreStyleWithNoData { get; set; }
