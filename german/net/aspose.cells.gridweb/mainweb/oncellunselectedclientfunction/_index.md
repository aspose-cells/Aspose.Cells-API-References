## MainWeb.OnCellUnselectedClientFunction property

Liest oder setzt die clientseitige Funktion, die aufgerufen wird, wenn eine Zelle deselektiert wird. Die Client‑Funktion sollte wie folgt deklariert werden: function MyOnUnselectCell(cell) { this.setCellValueByCell(cell, \"test\"); } Hinweis: Sie können den \"this\"‑Zeiger in der Client‑Funktion verwenden, um auf das Grid‑Steuerelement zu verweisen, das das Ereignis auslöst.

```csharp
public string OnCellUnselectedClientFunction { get; set; }
```
