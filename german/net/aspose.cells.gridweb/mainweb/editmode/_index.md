## MainWeb.EditMode property

Legt den Bearbeitungsmodus der Steuerung fest.

```csharp
public bool EditMode { get; set; }
```

### Hinweise

Wenn auf true gesetzt, sind die Zellen des Steuerelements editierbar und das "save"- und das "undo"-Symbol werden angezeigt. Wenn auf false gesetzt, sind die Zellen des Steuerelements schreibgeschützt und das "save"- und das "undo"-Symbol werden nicht angezeigt.
