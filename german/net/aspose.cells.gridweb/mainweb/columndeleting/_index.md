## MainWeb.ColumnDeleting event

Tritt auf, wenn der Benutzer versucht, eine Spalte aus dem clientseitigen Menü zu löschen. Sie können dieses Ereignis behandeln und den Abbruchparameter auf True setzen, um den Löschvorgang abzubrechen.

```csharp
public event RowColumnEventHandler ColumnDeleting;
```
