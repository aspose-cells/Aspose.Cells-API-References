## MainWeb.EnablePaging property

Legt fest, ob der Paging-Modus der Steuerung aktiviert werden soll.

```csharp
public bool EnablePaging { get; set; }
```

### Hinweise

Wenn auf true gesetzt, zeigt die Steuerung PageSize Zeilen Daten einmal an und zeigt die Seitenauswahlsteuerung in der Registerkartenleiste an.
