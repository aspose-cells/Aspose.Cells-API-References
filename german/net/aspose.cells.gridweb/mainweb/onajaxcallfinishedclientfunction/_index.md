## MainWeb.OnAjaxCallFinishedClientFunction property

Liest oder setzt den Namen der clientseitigen Funktion, die aufgerufen wird, wenn der Ajax‑Aufruf abgeschlossen ist. Die Client‑Funktion sollte wie folgt deklariert werden: function GridAjaxcallFinished() { alert(this.id+" ajaxcall finished "); } Hinweis: Sie können den \"this\"‑Zeiger in der Client‑Funktion verwenden, um auf das Grid‑Steuerelement zu verweisen, das das Ereignis auslöst.

```csharp
public string OnAjaxCallFinishedClientFunction { get; set; }
```
