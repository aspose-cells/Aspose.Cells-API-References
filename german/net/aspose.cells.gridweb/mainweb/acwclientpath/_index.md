## MainWeb.ACWClientPath property

Liest oder setzt den Web-Pfad der Skript-/Bilddateien des Steuerelements. Beispiel: "http://localhost/acw_client". Sie können diesen Wert auch in der web.config-Datei festlegen. Fügen Sie diesen Abschnitt zum `<configuration>`-Abschnitt hinzu:`<appSettings>``<add key="aspose.cells.gridweb.acw_client_path" value="/acw_client/" />``</appSettings>`

public string ACWClientPath { get; set; }
