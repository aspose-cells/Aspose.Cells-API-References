## MainWeb.EnableDoubleClickEvent property

Legt fest, ob das kundenseitige Doppelklick-Ereignis aktiviert werden soll.

```csharp
public bool EnableDoubleClickEvent { get; set; }
```

### Hinweise

Wenn auf true gesetzt, empfängt die Steuerung Doppelklick-Ereignisse auf Kundenseite und Sie können diese Ereignisse serverseitig verarbeiten. Andernfalls ignoriert die Steuerung alle Doppelklick-Ereignisse.
