## MainWeb.RowDeleting event

Tritt auf, wenn der Benutzer versucht, eine Zeile aus dem clientseitigen Menü zu löschen. Sie können dieses Ereignis behandeln und eine RejectDeleteException-Ausnahme auslösen, um den Löschvorgang abzubrechen.

```csharp
public event RowColumnEventHandler RowDeleting;
```
