## MainWeb.OnDoubleClickCellClientFunction property

Legt die clientseitige Funktion fest, die aufgerufen wird, wenn eine Zelle doppelt angeklickt wird, oder ruft sie ab. Die Clientfunktion sollte wie folgt deklariert werden: function MyOnDoubleClickCell(cell) { this.setCellValueByCell(cell, "test"); }Hinweis: Sie können den "this"-Zeiger in der Clientfunktion verwenden, um auf das Grid-Steuerelement zu verweisen, das das Ereignis auslöst.

```csharp
public string OnDoubleClickCellClientFunction { get; set; }
```
