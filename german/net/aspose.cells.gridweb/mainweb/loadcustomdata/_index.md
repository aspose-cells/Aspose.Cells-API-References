## MainWeb.LoadCustomData event

Wird ausgelöst, wenn der SessionMode des Steuerelements auf Custom gesetzt ist und Blattdaten geladen werden müssen. Sie können dieses Ereignis im benutzerdefinierten Sitzungsmodus behandeln, um Blattdaten aus einer Datei oder Datenbank zu laden.

```csharp
public event WorkbookEventHandler LoadCustomData;
```
