## MainWeb.SessionStorePath property

Legt den Pfad des Sitzungs-Cachespeichers fest, wenn der Sitzungsmodus File oder ViewState ist, usw.: gridweb.SessionStorePath=\"c:/mytempdir/session\"; danach werden Sitzungsdaten in c:/mytempdir/session gespeichert.

```csharp
public string SessionStorePath { get; set; }
```
