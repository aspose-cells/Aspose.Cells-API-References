## MainWeb.EnableStyleDialogbox property

Legt fest, ob das clientseitige Stil-Dialogfeld aktiviert werden soll.

```csharp
public bool EnableStyleDialogbox { get; set; }
```

### Hinweise

Wenn auf true gesetzt, kann der Benutzer das Stil‑Dialogfeld verwenden, um den Stil einer Zelle festzulegen, indem er im Kontextmenü \"Format Cell...\" auswählt.
