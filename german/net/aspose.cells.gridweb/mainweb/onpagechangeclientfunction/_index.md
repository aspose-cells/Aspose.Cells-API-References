## MainWeb.OnPageChangeClientFunction property

Legt die clientseitige Funktion fest, die nach dem Ändern des Seitenindex aufgerufen wird, oder ruft sie ab. Wirkt nur, wenn EnablePaging true ist. Die Clientfunktion sollte wie folgt deklariert werden: function MyOnPageChange(index) { console.log("current page is:"+index); }Hinweis: Sie können den "this"-Zeiger in der Clientfunktion verwenden, um auf das Grid-Steuerelement zu verweisen, das das Ereignis auslöst.

```csharp
public string OnPageChangeClientFunction { get; set; }
```
