## GridTableItemStyle.IsLocked property

Liest oder setzt einen Wert, der angibt, ob eine Zelle geändert werden kann, wenn das Arbeitsblatt geschützt ist. Ist das Arbeitsblatt geschützt und IsLocked ist true, kann die Zelle nicht bearbeitet werden. Ist das Arbeitsblatt geschützt und IsLocked ist false, kann die Zelle bearbeitet werden.

```csharp
public bool IsLocked { get; set; }
```
