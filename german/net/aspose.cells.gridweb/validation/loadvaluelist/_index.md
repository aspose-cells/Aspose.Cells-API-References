## Validation.LoadValueList method

Lädt die Wertliste aus einem DataView‑Objekt. Sie können das Werte‑ und Textfeld des DataView angeben. Jeder Werte‑ und Text‑Paar wird zu einem String kombiniert, getrennt durch ein Komma.

```csharp
public void LoadValueList(DataView view, string valueField, string textField, bool valuePrefixText)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Ansicht | DataView | Das DataView-Objekt. |
| valueField | String | Der Name des Wertefelds. |
| textField | String | Der Name des Textfelds. |
| valuePrefixText | Boolean | Gibt an, ob jedem angezeigten Text ein Wertepräfix hinzugefügt werden soll. |
