## Validation.ClientValidationFunction property

Liest oder setzt den Namen der clientseitigen Validierungs-JavaScript-Funktion.

```csharp
public string ClientValidationFunction { get; set; }
```

### Hinweise

Verwenden Sie die ClientValidationFunction-Eigenschaft, um den Namen der clientseitigen Validierungsfunktion anzugeben. Die Funktion sollte in folgender Form deklariert werden: function customValicationFunction(source, value) Der Parameter \"source\" ist das Zellobjekt. Der Parameter \"value\" ist der Zeichenkettenwert einer zu prüfenden Zelle. Die Funktion sollte true zurückgeben, wenn der Wert gültig ist.
