Der **Aspose.Cells.LowCode** Namespace bietet ein Set einfacher und leicht zu nutzender APIs für die am häufigsten verwendeten Vorgänge in einer Low‑Code‑Umgebung.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [AbstractLowCodeLoadOptionsProvider](./abstractlowcodeloadoptionsprovider/) | Implementierung zur Bereitstellung mehrerer Ladeoptionen für Prozesse, die mehrere Eingaben verwenden (wie Vorlagendateien). |
| [AbstractLowCodeProtectionProvider](./abstractlowcodeprotectionprovider/) | Implementierung zur Bereitstellung von Schutzeinstellungen. |
| [AbstractLowCodeSaveOptionsProvider](./abstractlowcodesaveoptionsprovider/) | Implementierung zur Bereitstellung mehrerer Speicheroptionen für Prozesse, die mehrere Ausgaben benötigen. Beispielsweise erfordert die Funktion [`SpreadsheetSplitter`](../aspose.cells.lowcode/spreadsheetsplitter/) mehrere Ziele, um die geteilten Dateien zu speichern. |
| [HtmlConverter](./htmlconverter/) | Konverter für die Umwandlung zwischen HTML‑Dateien (HTML oder MHT) und anderen Tabellenkalkulationsdateiformaten. |
| [ImageConverter](./imageconverter/) | Konverter zum Konvertieren von Vorlagendateien in Bilder. |
| [JsonConverter](./jsonconverter/) | Konverter für die Umwandlung zwischen JSON‑Datenstrukturen und anderen Tabellenkalkulationsdateiformaten. |
| [LowCodeHtmlSaveOptions](./lowcodehtmlsaveoptions/) | Optionen zum Speichern von HTML in Low‑Code‑Manier. |
| [LowCodeImageSaveOptions](./lowcodeimagesaveoptions/) | Optionen zum Speichern von Bildern in Low‑Code‑Manier. |
| [LowCodeLoadOptions](./lowcodeloadoptions/) | Optionen zum Laden von Vorlagendateien. |
| [LowCodeMergeOptions](./lowcodemergeoptions/) | Optionen zum Zusammenführen mehrerer Vorlagendateien zu einer. |
| [LowCodePdfSaveOptions](./lowcodepdfsaveoptions/) | Optionen zum Speichern von PDF in Low‑Code‑Manier. |
| [LowCodeSaveOptions](./lowcodesaveoptions/) | Optionen zum Speichern generierter Ergebnisse in Low‑Code‑Manier. |
| [LowCodeSaveOptionsProviderOfAssembling](./lowcodesaveoptionsproviderofassembling/) | Implementierung zur Bereitstellung von Speicheroptionen, die geteilte Teile in Dateien speichern und der Pfad der resultierenden Datei wie folgt benannt wird (es können Verzeichnisse enthalten sein): [`PathHeader`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/pathheader/)+[`SheetPrefix`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/sheetprefix/)+SheetIndex (oder SheetName) +[`SplitPartPrefix`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/splitpartprefix/)+SplitPartIndex+[`PathTail`](../aspose.cells.lowcode/lowcodesaveoptionsproviderofassembling/pathtail/). |
| [LowCodeSaveOptionsProviderOfPlaceHolders](./lowcodesaveoptionsproviderofplaceholders/) | Implementierung zur Bereitstellung von Speicheroptionen, die geteilte Teile in Dateien speichern und der Pfad der resultierenden Datei mit Platzhaltern definiert wird. |
| [LowCodeSplitOptions](./lowcodesplitoptions/) | Optionen zum Aufteilen von Tabellenkalkulationen. |
| [PdfConverter](./pdfconverter/) | Konverter zum Konvertieren von Vorlagendateien in PDF. |
| [SplitPartInfo](./splitpartinfo/) | Stellt die Informationen eines Eingabe-/Ausgabe-Elements für mehrere Eingaben/Ausgaben dar, z. B. die aktuelle Seite, die beim Konvertieren einer Tabelle in ein Bild gerendert werden soll. |
| [SpreadsheetConverter](./spreadsheetconverter/) | Konverter für die Umwandlung zwischen verschiedenen Tabellenkalkulationsdateiformaten, wie xls, xlsx, xlsb, SpreadsheetML... |
| [SpreadsheetLocker](./spreadsheetlocker/) | Low‑Code‑API zum Sperren von Tabellenkalkulationsdateien. |
| [SpreadsheetMerger](./spreadsheetmerger/) | Führt mehrere Vorlagendateien zu einer zusammen. |
| [SpreadsheetSplitter](./spreadsheetsplitter/) | Teilt eine Tabellenkalkulationsdatei in mehrere Teile. |
| [TextConverter](./textconverter/) | Konverter für die Umwandlung zwischen textbasierten Formaten (csv, tsv, dif…) und anderen Tabellenkalkulationsdateiformaten. |
