**Inheritance:**
java.lang.Object
```
public final class CoWorkUserPermission
```

Stellt die Benutzerberechtigung im Kollaborationsmodus dar. Nur in der Java-Version verfügbar, wird in Zukunft in .net/python-Versionen verfügbar sein.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [ADMIN](#ADMIN) | Administratorberechtigung, Benutzer hat vollen Zugriff einschließlich Verwaltungsoperationen |
| [DOWNLOAD](#DOWNLOAD) | Downloadberechtigung, Benutzer kann den Inhalt ansehen, bearbeiten und in den lokalen Speicher herunterladen |
| [EDITABLE](#EDITABLE) | Bearbeitungsberechtigung, Benutzer kann den Inhalt ansehen und bearbeiten |
| [READ_ONLY](#READ-ONLY) | Nur-Lese-Berechtigung, Benutzer kann den Inhalt nur ansehen, aber keine Änderungen vornehmen |
