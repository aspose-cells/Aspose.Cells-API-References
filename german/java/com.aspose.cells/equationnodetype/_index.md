```
public final class EquationNodeType
```

Gleichungsknoten‑Typ. Hinweis: (1)[1-99] Derzeit gibt es nur einen Knoten im Geltungsbereich, und sein Enumerationswert ist 1. Der angegebene Knoten wird verwendet, um mathematischen Text zu speichern. (2)[100-199] Gibt an, dass der Knoten ein Bestandteil einiger spezieller Funktionsknoten ist. (3)[200-] Gibt an, dass der Knoten besondere Funktionen hat.
