### getHeightRatioToChart() {#getHeightRatioToChart--}
```
public double getHeightRatioToChart()
```


Ruft die Höhe des Begrenzungsrahmens des Plot‑Bereichs in Einheiten des Verhältnisses zum Diagrammbereich ab.

**Remarks**

Der Begrenzungsrahmen des Plot-Bereichs umfasst den Plot-Bereich, die Achsenmarkierungen (Achsenbeschriftungen) und einen kleinen Rand um die Achsenmarkierungen. Wenn der Wert nicht von MS Excel erstellt wurde, rufen Sie bitte die Methode Chart.Calculate() auf, bevor Sie diese Methode aufrufen.

Die **XRatioToChart**, **YRatioToChart**, **WidthRatioToChart** und **HeightRatioToChart** von **PlotArea** stellen den Begrenzungsrahmen des Plot-Bereichs dar, der den Plot-Bereich, die Achsenmarkierungen (Achsenbeschriftungen) und einen kleinen Rand um die Achsenmarkierungen umfasst. Wenn Sie die tatsächliche Größe des Plot-Bereichs erhalten möchten, sollten Sie die Eigenschaften **InnerXRatioToChart**, **InnerYRatioToChart**, **InnerWidthRatioToChart** und **InnerHeightRatioToChart** aufrufen.

Für Excel 2007 oder neuer ist der Standardwert Null. Sie sollten den Wert erst nach dem Aufruf von Chart.Calculate() abrufen.

HeightPixel = HeightRatioToChart \* chart.ChartObject.Width. Hinweis: Wenn HeightRatioToChart gesetzt wird, wird die Eigenschaft IsInnerMode automatisch auf false gesetzt.

double
