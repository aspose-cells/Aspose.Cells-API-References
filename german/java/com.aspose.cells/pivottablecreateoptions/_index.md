```
public boolean getUseSameSource()
```


Ruft einen Wert ab, der angibt, ob dieselbe Datenquelle mit vorhandenen Pivot-Tabellen geteilt werden soll. Standardwert ist true.

**Remarks**

Wenn auf true gesetzt, können mehrere Pivot-Tabellen denselben Pivot-Cache wiederverwenden, um den Speicherverbrauch zu reduzieren.

### isXlsClassic() {#isXlsClassic--}
```
public boolean isXlsClassic()
```


Ruft einen Wert ab, der angibt, ob ein klassisches PivotTable im Excel‑97‑2003‑Stil erstellt werden soll.

**Remarks**

Klassisches PivotTable verwendet das veraltete Layout und die Formatierung von Excel 97‑2003. Wenn nicht explizit festgelegt, wird der Standardwert anhand des Dateiformats der Zielarbeitsmappe bestimmt.
