Stellt den Verzeichnistyp des Dateinamens dar.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [DOWN_DIRECTORY](#DOWN-DIRECTORY) | Gibt an, dass die Quellarbeitsmappe in einem Unterverzeichnis des aktuellen Verzeichnisses liegt. |
| [SAME_VOLUME](#SAME-VOLUME) | Gibt an, dass die Quellarbeitsmappe auf demselben Laufwerk wie die abhängige Arbeitsmappe liegt (der Laufwerksbuchstabe wird weggelassen). |
| [UP_DIRECTORY](#UP-DIRECTORY) | Gibt an, dass die Quellarbeitsmappe im übergeordneten Verzeichnis des aktuellen Verzeichnisses liegt. |
| [VOLUME](#VOLUME) | Stellt einen MS-DOS-Laufwerksbuchstaben dar. |
