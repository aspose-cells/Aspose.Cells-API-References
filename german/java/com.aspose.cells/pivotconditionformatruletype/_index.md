Stellt den Typ der PivotTable‑Bedingten Formatierungsregel dar.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [ALL](#ALL) | Gibt an, dass Top N bedingte Formatierung über den gesamten Geltungsbereich hinweg ausgewertet wird. |
| [COLUMN](#COLUMN) | Gibt an, dass Top N bedingte Formatierung für jede Spalte ausgewertet wird. |
| [NONE](#NONE) | Gibt an, dass Top N bedingte Formatierung nicht ausgewertet wird. |
| [ROW](#ROW) | Gibt an, dass Top N bedingte Formatierung für jede Zeile ausgewertet wird. |
