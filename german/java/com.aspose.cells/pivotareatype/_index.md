public final class PivotAreaType

Gibt den Typ der Regel an, die verwendet wird, um einen Bereich oder Aspekt der Pivot-Tabelle zu beschreiben.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [ALL](#ALL) | Stellt die gesamte PivotTable dar. |
| [BUTTON](#BUTTON) | Stellt eine Feldschaltfläche dar. |
| [DATA](#DATA) | Stellt etwas im Datenbereich dar. |
| [NONE](#NONE) | Kein Pivot-Bereich. |
| [NORMAL](#NORMAL) | Stellt eine Kopfzeile oder ein Element dar. |
| [ORIGIN](#ORIGIN) | Stellt die leeren Zellen oben links der PivotTable dar (oben rechts für RTL-Blätter). |
| [TOP_RIGHT](#TOP-RIGHT) | Stellt die leeren Zellen oben rechts der PivotTable dar (oben links für RTL-Blätter). |
