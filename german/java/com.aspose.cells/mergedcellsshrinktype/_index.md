Stellt die Strategie zum Verkleinern zusammengeführter Zellen für Vorgänge wie das Löschen leerer Zeilen/Spalten dar.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [KEEP_HEADER_ONLY](#KEEP-HEADER-ONLY) | Behält nur die Kopfzeilen/Spalten des zusammengeführten Bereichs, wenn die obere linke Zelle des zusammengeführten Bereichs nicht leer ist. |
| [NONE](#NONE) | Lässt die zusammengeführten Zellen unverändert. |
| [SHRINK_TO_FIT](#SHRINK-TO-FIT) | Verkleinert den zusammengeführten Bereich bei Bedarf, indem Zeilen von unten oder Spalten von rechts entfernt werden, wobei sichergestellt wird, dass der gesamte Inhalt sichtbar bleibt. |
