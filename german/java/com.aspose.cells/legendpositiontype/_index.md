## Felder

| --- | --- |
| [BOTTOM](#BOTTOM) | Zeigt die Legende am unteren Rand des Diagrammbereichs an. |

| [LEFT](#LEFT) | Zeigt die Legende links vom Diagrammbereich an. |

| [RIGHT](#RIGHT) | Zeigt die Legende rechts vom Diagrammbereich an. |
