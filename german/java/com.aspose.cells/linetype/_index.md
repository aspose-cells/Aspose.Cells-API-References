
Enumeriert den Typ des [Picture](../../com.aspose.cells/picture)-Rahmens oder der [Chart](../../com.aspose.cells/chart)-Linie.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [DARK_GRAY](#DARK-GRAY) | Stellt eine dunkelgraue Linie dar. |
| [DASH](#DASH) | Stellt eine Strichlinie dar. |
| [DASH_DOT](#DASH-DOT) | Stellt eine Strich-Punkt-Linie dar. |
| [DASH_DOT_DOT](#DASH-DOT-DOT) | Stellt eine Strich-Punkt-Punkt-Linie dar. |
| [DOT](#DOT) | Stellt eine gepunktete Linie dar. |
| [LIGHT_GRAY](#LIGHT-GRAY) | Stellt eine hellgraue Linie dar. |
| [MEDIUM_GRAY](#MEDIUM-GRAY) | Stellt eine mittelgraue Linie dar. |
| [SOLID](#SOLID) | Stellt eine durchgezogene Linie dar. |
