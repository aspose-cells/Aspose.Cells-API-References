### PERCENT_VALUE {#PERCENT-VALUE}
```

```


Stellt die Datenpunkte dar, die zwischen dem Kreisdiagramm und dem zweiten Diagramm aufgeteilt werden sollen, indem die Punkte mit einem Prozentsatz kleiner als den Split Position Prozent im zweiten Diagramm platziert werden.

### POSITION {#POSITION}
```
public static final int POSITION
```

Stellt die Datenpunkte dar. Die Datenpunkte sollen zwischen dem Kreisdiagramm und dem zweiten Diagramm aufgeteilt werden, indem die letzte Split-Position der Datenpunkte im zweiten Diagramm platziert wird.
