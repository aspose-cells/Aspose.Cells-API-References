### AUTOMATIC {#AUTOMATIC}
```
public static final int AUTOMATIC
```


Zeigt die Achse an einer variablen Position basierend auf dem Verhältnis des kleinsten negativen Werts zum größten positiven Wert im Bereich an. Positive Werte werden von links nach rechts angezeigt. Negative Werte werden von rechts nach links angezeigt. Wenn alle Werte positiv oder alle Werte negativ sind, wird keine Achse angezeigt.

### MIDPOINT {#MIDPOINT}
```
public static final int MIDPOINT
```


Zeigt die Achse in der Mitte der Zelle an, unabhängig von der Menge der Werte im Bereich. Positive Werte werden von links nach rechts angezeigt. Negative Werte werden von rechts nach links angezeigt.

### NONE {#NONE}
```
public static final int NONE
```


Es wird keine Achse angezeigt, und sowohl positive als auch negative Werte werden von links nach rechts angezeigt.
