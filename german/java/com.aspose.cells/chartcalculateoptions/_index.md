### getUpdateAllPoints() {#getUpdateAllPoints--}
```
public boolean getUpdateAllPoints()
```


Ob alle Datenpunkte bei der Diagrammberechnung aktualisiert werden sollen. Standard: False. Wenn Sie den Wert für jeden Datenpunkt im Diagramm speziell erhalten möchten, setzen Sie ihn auf true. Wenn dieser Parameter auf True gesetzt ist, können beim Berechnen des Diagramms neue Datenpunkte erzeugt werden. Dies könnte die Excel‑Datei vergrößern.
