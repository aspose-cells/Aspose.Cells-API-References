### DISPLAY_STRING {#DISPLAY-STRING}
```
public static final int DISPLAY_STRING
```


Liefert die angezeigte Zeichenkette, die in MS Excel angezeigt wird. Der Hauptunterschied zu [DISPLAY\_STYLE](../../com.aspose.cells/cellvalueformatstrategy\#DISPLAY-STYLE) besteht darin, dass diese Option auch die Auswirkung der Spaltenbreite berücksichtigt. Ist die Spaltenbreite zu klein, um die formatierte Zeichenkette vollständig anzuzeigen, kann "\#" angezeigt werden, genau wie MS Excel es tut.
