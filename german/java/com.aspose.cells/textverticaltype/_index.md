## Felder

| Feld | Beschreibung |

| [VERTICAL_LEFT_TO_RIGHT](#VERTICAL-LEFT-TO-RIGHT) | Vertikal angezeigt und der Text fließt von oben nach unten, dann von LINKS nach RECHTS |
