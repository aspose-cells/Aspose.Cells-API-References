### CLIP {#CLIP}
```
public static final int CLIP
```


Beachten Sie die oberen und unteren Barrieren. Geben Sie keinen Hinweis darauf, dass Text nicht sichtbar ist.

### ELLIPSIS {#ELLIPSIS}
```
public static final int ELLIPSIS
```


Beachten Sie die oberen und unteren Barrieren. Verwenden Sie ein Auslassungszeichen, um anzuzeigen, dass Text nicht sichtbar ist. Nur für vertikales Überlaufen.

### OVERFLOW {#OVERFLOW}
```
public static final int OVERFLOW
```


Überlaufen Sie den Text und achten Sie nicht auf die oberen und unteren Barrieren.
