**Inheritance:**
java.lang.Object
```
public final class VisibilityType
```

Stellt die Zustände für die Sichtbarkeit des Blatts dar.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [HIDDEN](#HIDDEN) | Gibt an, dass das Blatt ausgeblendet ist, aber vom Benutzer über die Benutzeroberfläche angezeigt werden kann. |
| [VERY_HIDDEN](#VERY-HIDDEN) | Gibt an, dass das Blatt ausgeblendet ist und in der Benutzeroberfläche (UI) nicht angezeigt werden kann. |
| [VISIBLE](#VISIBLE) | Gibt an, dass das Blatt sichtbar ist. |
