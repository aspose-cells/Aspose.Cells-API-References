### ALLOW_MULTIPLE {#ALLOW-MULTIPLE}
```
public static final int ALLOW_MULTIPLE
```


Alle Hyperlinks in einer Zelle werden zu [Worksheet.getHyperlinks()](../../com.aspose.cells/worksheet\#getHyperlinks--) hinzugefügt. Beachten Sie, dass MS Excel selbst nur einen Hyperlink pro Zelle unterstützt, sodass diese Option Dateien erzeugen kann, die Excel nicht vollständig rendern kann.

### NORMAL {#NORMAL}
```
public static final int NORMAL
```


Nur der erste Hyperlink in einer Zelle wird geladen, nachfolgende werden ignoriert.
