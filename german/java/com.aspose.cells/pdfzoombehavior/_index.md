Gibt den anfänglichen Ansichtsmodus an, wenn das erzeugte PDF-Dokument geöffnet wird.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [FIT_HEIGHT](#FIT-HEIGHT) | Passt die Seitenhöhe im Anzeigefenster an. |
