### DEFAULT {#DEFAULT}
```
public static final int DEFAULT
```


Anzeige wie in MS Excel.

### MERGE_FORCELY {#MERGE-FORCELY}
```
public static final int MERGE_FORCELY
```


Leeres TD-Element wird beim Exportieren der Datei nach HTML zwangsweise zusammengeführt. Die Größe der HTML-Datei wird nach dem Setzen des Wertes auf true deutlich reduziert. Wenn Sie die HTML-Datei nach Excel importieren oder beim Speichern der Datei nach HTML perfekte Gitternetzlinien exportieren möchten, behalten Sie bitte den Standardwert bei.

### NONE {#NONE}
```
public static final int NONE
```


Leere TD-Elemente werden beim Exportieren der Datei nach HTML nicht zusammengeführt. Dies führt zu einer deutlich größeren HTML-Datei.
