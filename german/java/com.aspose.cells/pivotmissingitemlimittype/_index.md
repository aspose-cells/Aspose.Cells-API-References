Stellt die Anzahl der pro Feld zu behaltenden Elemente dar.

**Remarks**

HINWEIS: Diese Eigenschaft ist jetzt veraltet. Verwenden Sie stattdessen die Eigenschaft PivotCache.MissingItemsLimit. Diese Methode wird 12 Monate später, ab September 2026, entfernt. Aspose entschuldigt sich für etwaige Unannehmlichkeiten, die Ihnen entstanden sein könnten.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [AUTOMATIC](#AUTOMATIC) | Die standardmäßige Anzahl eindeutiger Elemente pro PivotField, die erlaubt ist. |
| [MAX](#MAX) | Die maximale Anzahl eindeutiger Elemente pro PivotField, die erlaubt ist (>32,500). |
| [NONE](#NONE) | Keine eindeutigen Elemente pro PivotField erlaubt. |
