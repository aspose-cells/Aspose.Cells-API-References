```
public final class HyperlinkActionType
```

Hyperlink hat zwei Aktionstypen: UrlLink und CellCommand. Der UrlLink‑Typ ist ein Anker in einer Zelle; ein Klick navigiert zu einer anderen Seite oder öffnet ein neues Browserfenster. Der CellCommand‑Typ ist ein Befehls‑Button in einer Zelle; ein Klick erzeugt ein serverseitiges Ereignis.
