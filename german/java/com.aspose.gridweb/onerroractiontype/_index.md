```
public final class OnErrorActionType
```

Wird im CellError-Ereignis von GridWeb verwendet. Der Benutzer setzt OnErrorActionQuery.OnErrorAction, um dem Steuerelement mitzuteilen, die Verarbeitung zu stoppen oder den Fehler zu ignorieren.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [IGNORE](#IGNORE) | Ignoriert den Fehler und setzt die Verarbeitung fort. |
| [STOP](#STOP) | Stoppt die aktuelle Verarbeitung. |
| [THROW](#THROW) | Wirft die aktuelle Ausnahme. |
