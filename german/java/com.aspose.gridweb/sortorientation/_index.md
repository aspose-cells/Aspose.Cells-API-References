Stellt die Sortierrichtung dar

**Remarks**

SortOrientation.SortTopToBottom steht für das Sortieren von Daten von oben nach unten und das Austauschen von Daten Zeile für Zeile. SortOrientation.SortLeftToRight steht für das Sortieren von Daten von links nach rechts und das Austauschen von Daten Spalte für Spalte.
