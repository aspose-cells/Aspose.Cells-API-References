## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ConnectionParameter](./connectionparameter/) | Gibt Eigenschaften für alle Parameter an, die mit externen Datenverbindungen verwendet werden. Parameter sind gültig für ODBC- und Webabfragen. |
| [ConnectionParameterCollection](./connectionparametercollection/) | Gibt die [ConnectionParameter](./connectionparameter/) Sammlung an. |
| [DataModelConnection](./datamodelconnection/) | Gibt eine Datenmodellverbindung an. |
| [DBConnection](./dbconnection/) | Gibt alle Eigenschaften an, die mit einer externen ODBC- oder OLE-DB-Datenverbindung verbunden sind. |
| [ExternalConnection](./externalconnection/) | Gibt eine externe Datenverbindung an. |
| [ExternalConnectionCollection](./externalconnectioncollection/) | Gibt die [ExternalConnection](./externalconnection/) Sammlung an. |
| [WebQueryConnection](./webqueryconnection/) | Gibt die Eigenschaften für eine Webabfragequelle an. Eine Webabfrage ruft Daten aus HTML-Tabellen ab und kann außerdem HTTP \"Get\"-Parameter bereitstellen, die vom Webserver bei der Generierung des HTML verarbeitet werden, indem die Parameter und Parameterelemente eingeschlossen werden. |
