## ShapeCollection.Find method

Buscar forma por texto

```csharp
public int Find(string what, int previous, FindOptions findOptions)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| qué | String | El texto a buscar. |
| anterior | Int32 | El índice de la forma anterior que contiene el mismo texto. -1 si se busca desde el inicio. |
| findOptions | FindOptions | Opciones de búsqueda |

### Valor de retorno

El índice de la forma encontrada, -1 si no se encuentra ninguna forma.
