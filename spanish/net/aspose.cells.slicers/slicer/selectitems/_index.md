## Slicer.SelectItems method

```csharp
public void SelectItems(string[] labels, bool append)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| etiquetas | String[] | Etiquetas seleccionadas. |
| añadir | Booleano | False significa que solo se seleccionan estas etiquetas y se deseleccionan las demás. True significa que se conservan los elementos previamente seleccionados y se seleccionan estas etiquetas. |

### Observaciones

Si desea seleccionar todos los elementos, por favor use el método [`ClearFilter`](../clearfilter/).
