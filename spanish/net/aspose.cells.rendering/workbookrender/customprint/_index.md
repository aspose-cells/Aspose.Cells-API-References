## WorkbookRender.CustomPrint method

El cliente puede controlar la configuración de página de la impresora al imprimir cada página usando esta función.

```csharp
public int CustomPrint(bool nextPageAfterPrint, PrintPageEventArgs printPageEventArgs)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| nextPageAfterPrint | Booleano | Si es verdadero, la impresora pasará a la siguiente página después de imprimir la página actual |
| printPageEventArgs | PrintPageEventArgs | System.Drawing.Printing.PrintPageEventArgs |

### Valor de retorno

Índice indirecto de la siguiente página, basado en cero
