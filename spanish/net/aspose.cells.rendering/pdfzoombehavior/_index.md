## PdfZoomBehavior enumeration

Especifica el modo de vista inicial cuando se abre el documento PDF generado.

```csharp
public enum PdfZoomBehavior
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | `0` | Utiliza el comportamiento predeterminado del visor PDF. |
| ZoomFactor | `1` | Abre el documento a un porcentaje de zoom específico. |
| FitPage | `2` | Ajusta toda la página dentro de la ventana del visor. |
| FitWidth | `3` | Ajusta el ancho de la página dentro de la ventana del visor. |
| FitHeight | `4` | Ajusta la altura de la página dentro de la ventana del visor. |
