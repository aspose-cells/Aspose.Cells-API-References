## ExcelRenderingBehavior enumeration

Especifica los comportamientos de renderizado específicos de Excel que se aplican al renderizar un libro de trabajo.

```csharp
[Flags]
public enum ExcelRenderingBehavior
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | `0` | No aplica comportamientos de renderizado específicos de Excel. |
| CellTextLengthLimit | `1` | Aplica el límite de longitud de salida de texto de celda de Excel. Por ejemplo, Excel solo muestra los primeros 1024 caracteres en una celda sin ajuste. |
| All | `FFFFFFFFFFFFFFFF` | Aplica todos los comportamientos de renderizado específicos de Excel compatibles. |
