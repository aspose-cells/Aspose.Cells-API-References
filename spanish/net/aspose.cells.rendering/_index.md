El **Aspose.Cells.Rendering** espacio de nombres proporciona clases para renderizar imágenes y PDF.

## Clases

| Clase | Descripción |
| --- | --- |
| [CustomRenderSettings](./customrendersettings/) | Representa configuraciones personalizadas durante el renderizado. |
| [DrawObject](./drawobject/) | DrawObject será inicializado y devuelto durante el renderizado. |
| [DrawObjectEventHandler](./drawobjecteventhandler/) | Interfaz para obtener DrawObject y Bound durante el renderizado. |
| [ImageOrPrintOptions](./imageorprintoptions/) | Permite especificar opciones al renderizar la hoja de cálculo a imágenes, imprimir la hoja de cálculo o renderizar un gráfico a imagen. |
| [PageEndSavingArgs](./pageendsavingargs/) | La información de una página finaliza el proceso de guardado. |
| [PageSavingArgs](./pagesavingargs/) | Información para el proceso de guardado de una página. |
| [PageStartSavingArgs](./pagestartsavingargs/) | Información para el proceso de inicio de guardado de una página. |
| [PdfBookmarkEntry](./pdfbookmarkentry/) | PdfBookmarkEntry es una entrada en el marcador PDF. Si la propiedad Text de la instancia actual es nula o "", la instancia actual se ocultará y los hijos se insertarán en el nivel actual. |
| [RenderingFont](./renderingfont/) | Fuente para renderizado. |
| [RenderingWatermark](./renderingwatermark/) | Marca de agua para renderizado. |
| [SheetPrintingPreview](./sheetprintingpreview/) | Vista previa de impresión de la hoja de cálculo. |
| [SheetRender](./sheetrender/) | Representa una renderización de hoja de cálculo que puede renderizar la hoja a varias imágenes como (BMP, PNG, JPEG, TIFF...). El constructor de esta clase debe usarse después de modificar la configuración de página y el estilo de celda. |
| [SheetSet](./sheetset/) | Describe un conjunto de hojas. |
| [SvgImageOptions](./svgimageoptions/) | Opciones para generar una imagen SVG. |
| [WorkbookPrintingPreview](./workbookprintingpreview/) | Vista previa de impresión del libro de trabajo. |
| [WorkbookRender](./workbookrender/) | Representa una renderización de libro de trabajo. El constructor de esta clase debe usarse después de modificar la configuración de página y el estilo de celda. |
