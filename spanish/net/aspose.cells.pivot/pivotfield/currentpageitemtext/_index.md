## PivotField.CurrentPageItemText property

Obtiene el texto de visualización del elemento de página actual para este campo de tabla dinámica (solo campo de página).

```csharp
public string CurrentPageItemText { get; set; }
```

### Observaciones

Devuelve "(All)" cuando [`CurrentPageItem`](../currentpageitem/) es igual a [`AllPageItemsIndex`](../../pivotitem/allpageitemsindex/). Para otros valores, devuelve la representación en cadena del índice del elemento.
