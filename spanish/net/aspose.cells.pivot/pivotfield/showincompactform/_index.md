## PivotField.ShowInCompactForm property

Obtiene o establece un valor que indica si este campo de fila usa un diseño de forma compacta. Solo se aplica a campos de fila.

```csharp
public bool ShowInCompactForm { get; set; }
```

### Observaciones

La forma compacta es un submodo del diseño de esquema. Esta configuración solo tiene efecto cuando [`ShowInOutlineForm`](../showinoutlineform/) es verdadero.
