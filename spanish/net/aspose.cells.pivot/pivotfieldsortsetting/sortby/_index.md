## PivotFieldSortSetting.SortBy property

Representa el índice del campo por el cual se ordena. Un valor de -1 indica ordenación por los propios valores del elemento de pivote. Cuando es mayor o igual a cero, representa el índice del campo de datos en la región de datos.

public int SortBy { get; set; }
