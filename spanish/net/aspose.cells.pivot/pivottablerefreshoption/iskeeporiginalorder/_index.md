## PivotTableRefreshOption.IsKeepOriginalOrder property

Indica si se debe mantener el orden original de los elementos pivot como en la fuente de datos anterior.

```csharp
public bool IsKeepOriginalOrder { get; set; }
```

### Observaciones

Solo aplicable al campo dinámico que no está ordenado. Al actualizar este tipo de campo dinámico, Ms Excel mantiene el orden original de la fuente de datos anterior. El valor predeterminado de esta propiedad es true, lo que representa el mismo comportamiento que Ms Excel. Si el usuario necesita que el campo dinámico se actualice completamente como los datos en la nueva fuente de datos, esta propiedad debe establecerse en false.
