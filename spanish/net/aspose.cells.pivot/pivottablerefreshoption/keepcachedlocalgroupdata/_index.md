## PivotTableRefreshOption.KeepCachedLocalGroupData property

Indica si se deben conservar los datos de grupo local en caché si los valores máximo y mínimo permanecen sin cambios. El valor predeterminado es false, lo que significa actualizar el grupo con la configuración local.

```csharp
public bool KeepCachedLocalGroupData { get; set; }
```

### Observaciones

Esta es una solución temporal, por favor localice las tablas dinámicas implementando [`PivotGlobalizationSettings`](../../../aspose.cells.settings/pivotglobalizationsettings/)
