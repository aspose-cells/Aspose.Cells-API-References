## PivotFieldGroupOptions.NewPivotField property

Obtiene o establece un valor que indica si se deben crear nuevos campos dinámicos después de la agrupación.

```csharp
public bool NewPivotField { get; set; }
```

### Observaciones

Si no se establece explícitamente, el valor predeterminado es false para la agrupación numérica y true para la agrupación de fecha y hora, true para el grupo discreto. Solo funciona para el primer nuevo campo pivote de grupo del campo base.
