## PivotTableCreateOptions.IsXlsClassic property

Obtiene o establece un valor que indica si se debe crear una PivotTable al estilo clásico de Excel 97-2003.

```csharp
public bool IsXlsClassic { get; set; }
```

### Observaciones

La tabla dinámica clásica usa el diseño y formato heredados de Excel 97-2003. Cuando no se establece explícitamente, el valor predeterminado se determina por el formato de archivo del libro de trabajo de destino.
