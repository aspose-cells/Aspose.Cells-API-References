## PivotTableCreateOptions.UseSameSource property

Obtiene o establece un valor que indica si se debe compartir la misma fuente de datos con las tablas dinámicas existentes. El valor predeterminado es true.

```csharp
public bool UseSameSource { get; set; }
```

### Observaciones

Cuando se establece en true, varias tablas dinámicas pueden reutilizar una caché de tabla dinámica para reducir el consumo de memoria.
