## PivotTable.MoveItem method

Mueve un elemento hacia arriba o abajo.

```csharp
public void MoveItem(PivotFieldType region, string[] nodes, bool absolute, int offset)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| región | PivotFieldType | La región. Solo para fila o columna. |
| nodos | String[] | El elemento. |
| absoluto | Booleano | Indica si el desplazamiento es una posición absoluta. |
| desplazamiento | Int32 | Si absolute es true :0 mueve al inicio, -1 mueve al final, otros significan posición absoluta; de lo contrario offset es una posición relativa. |
