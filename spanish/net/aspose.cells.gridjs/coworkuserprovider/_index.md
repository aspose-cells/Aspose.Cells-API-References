## CoWorkUserProvider interface

Representa la interfaz del proveedor de usuarios en modo de colaboración. Solo disponible en la versión Java por ahora, estará disponible en las versiones .net/python en el futuro. La aplicación cliente puede implementar esta interfaz para proporcionar la información del usuario.
