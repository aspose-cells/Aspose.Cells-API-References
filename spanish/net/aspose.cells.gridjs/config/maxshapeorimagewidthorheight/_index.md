## Config.MaxShapeOrImageWidthOrHeight property

Obtiene/Establece el ancho o alto máximo para una forma o una imagen, GridJs ignorará la forma o imagen cuyo ancho o alto sea mayor que este valor, tiene efecto cuando IslimitShapeOrImage=true. El valor predeterminado es 10000.

```csharp
public static int MaxShapeOrImageWidthOrHeight { get; set; }
```
