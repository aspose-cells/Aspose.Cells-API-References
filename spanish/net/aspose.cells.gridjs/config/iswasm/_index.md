## Config.IsWasm property

Obtiene/establece si GridJs se ejecuta dentro de un host WebAssembly del navegador en lugar de un proceso de servidor. Cuando es true, no se utiliza ninguna ruta FileCacheDirectory / disco / hilo de interrupción y la caché de archivos debe provenir de GridJsOptions.CacheImp. GridJsOptions.IsWasm establece esto cuando se construye el servicio GridJs, de modo que un solo Aspose.Cells.GridJs.dll sirve a ambos hosts. El valor predeterminado es false.

public static bool IsWasm { get; set; }
