## Config.EnableChartClientRendering property

Obtiene/establece si habilitar la renderización de gráficos del lado del cliente. Si se establece en false, GridJs recurrirá solo a imágenes/formas de gráficos generados por el servidor. El valor predeterminado es true.

```csharp
public static bool EnableChartClientRendering { get; set; }
```
