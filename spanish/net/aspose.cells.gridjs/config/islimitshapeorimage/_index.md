## Config.IslimitShapeOrImage property

Obtiene/Establece si se limita el recuento total de formas/imágenes mostradas en una hoja de cálculo. Si se establece en verdadero, GridJs limitará el recuento total de formas o imágenes mostradas en una hoja a MaxShapeOrImageCount. El valor predeterminado es verdadero.

```csharp
public static bool IslimitShapeOrImage { get; set; }
```
