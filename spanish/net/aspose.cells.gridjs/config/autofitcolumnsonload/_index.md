## Config.AutoFitColumnsOnLoad property

Indica si se deben ajustar automáticamente los anchos de columna durante la carga del archivo. El valor predeterminado es `false`. Advertencia: Configurar esto a `true` realizará una operación de ajuste automático de todas las columnas después de la carga, lo que puede tener un impacto notable en el rendimiento.

```csharp
public static bool AutoFitColumnsOnLoad { get; set; }
```
