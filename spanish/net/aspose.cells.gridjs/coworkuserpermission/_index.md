## CoWorkUserPermission enumeration

Representa el permiso de usuario en modo de colaboración. Solo disponible en la versión Java por ahora, estará disponible en las versiones .net/python en el futuro.

```csharp
public enum CoWorkUserPermission
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| READ_ONLY | `0` | Permiso de solo lectura,El usuario solo puede ver el contenido pero no puede realizar modificaciones |
| EDITABLE | `1` | Permiso editable,El usuario puede ver y editar el contenido |
| DOWNLOAD | `2` | Permiso de descarga,El usuario puede ver, editar y descargar el contenido al almacenamiento local |
| ADMIN | `3` | Permiso de administrador,El usuario tiene acceso total incluyendo operaciones de gestión |
