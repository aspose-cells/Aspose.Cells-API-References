El **Aspose.Cells.GridJs** espacio de nombres encapsula todas las clases de GridJs, proporcionando API simples para ver o editar archivos de hojas de cálculo mediante operaciones JSON.

## Clases

| Clase | Descripción |
| --- | --- |
| [Config](./config/) | Representa todas las configuraciones estáticas para GridJs |
| [DefaultGridJsJsonCache](./defaultgridjsjsoncache/) | Implementación predeterminada de caché JSON (L1 memoria + L2 disco) |
| [GridAbstractCalculationEngine](./gridabstractcalculationengine/) | Representa el motor de cálculo personalizado del usuario para ampliar el motor de cálculo predeterminado de Aspose.Cells. |
| [GridCacheForStream](./gridcacheforstream/) | Esta clase contiene las operaciones de caché para GridJs. El usuario debe implementar su propia lógica de negocio para el almacenamiento basándose en ella. |
| [GridCalculationData](./gridcalculationdata/) | Representa los datos requeridos al calcular una función, como el nombre de la función, los parámetros, ...etc. |
| [GridCellException](./gridcellexception/) | La excepción que se lanza cuando ocurre un error especificado de GridJs. |
| [GridInterruptMonitor](./gridinterruptmonitor/) | Representa todos los operadores sobre la interrupción del cálculo. |
| [GridJsControllerBase](./gridjscontrollerbase/) |  |
| [GridJsLogger](./gridjslogger/) | Proporciona un sistema de registro ligero para el servidor GridJs. Soporta salida a consola y archivo con niveles de registro configurables. El nivel predeterminado es None. En compilación DEBUG, el nivel predeterminado es Debug (muestra todos los mensajes). Soporta la rotación de archivos de registro por día/semana/mes. |
| [GridJsOptions](./gridjsoptions/) | Representa todas las opciones de carga para GridJs |
| [GridJsPermissionException](./gridjspermissionexception/) | Representa una excepción de permiso en modo de colaboración. Solo disponible en la versión Java por ahora, estará disponible en las versiones .net/python en el futuro. |
| [GridJsService](./gridjsservice/) | Proporciona las API básicas de operación utilizadas en acciones de controlador. |
| [GridJsWorkbook](./gridjsworkbook/) | Representa la clase principal de entrada para GridJs |
| [GridReferredArea](./gridreferredarea/) | Representa un área referida por la fórmula. |
| [GridUpdateMonitor](./gridupdatemonitor/) | Monitor para el usuario que rastrea el cambio de la operación de actualización. |
| [GridWorkbookSettings](./gridworkbooksettings/) | Representa la configuración del libro de trabajo. |
| [JsonCacheOptions](./jsoncacheoptions/) | Opciones de configuración para el almacenamiento en caché JSON en GridJs. Controla el comportamiento de la caché tanto en memoria (L1) como en disco (L2). |
| [OprMessageService](./oprmessageservice/) | Esta clase proporciona todas las operaciones para la sincronización de mensajes en modo colaborativo. |
