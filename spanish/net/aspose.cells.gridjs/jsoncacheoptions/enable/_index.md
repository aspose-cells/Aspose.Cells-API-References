## JsonCacheOptions.Enable property

Obtiene/Establece si habilitar la caché JSON para una respuesta más rápida. Cuando está habilitado, GridJs almacenará en caché el JSON generado y lo reutilizará en solicitudes posteriores. El valor predeterminado es false. Nota: Necesita establecer Implementation para usar un almacenamiento de caché personalizado.

```csharp
public bool Enable { get; set; }
```
