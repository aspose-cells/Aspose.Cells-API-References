## JsonCacheOptions.MaxMemoryEntries property

Obtiene/Establece el número máximo de entradas en la caché de memoria (valor predeterminado: 1000). Tiene efecto cuando Enable = true y se usa la caché predeterminada.

public int MaxMemoryEntries { get; set; }
