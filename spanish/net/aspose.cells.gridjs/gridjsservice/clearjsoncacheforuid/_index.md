## GridJsService.ClearJsonCacheForUid method

Elimina todas las entradas de caché JSON que pertenecen al id único especificado. Llame a esto después de modificar el archivo fuente fuera de banda para que la siguiente solicitud regenere el JSON.

```csharp
public void ClearJsonCacheForUid(string uid)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| uid | String | El identificador único para la caché del archivo. |
