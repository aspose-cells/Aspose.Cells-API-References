## GridJsService.Load method

Obtiene la cadena JSON del archivo desde la caché usando el ID único especificado, establece el nombre de archivo de salida en el JSON.

```csharp
public string Load(string uid, string filename)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| uid | String | El identificador único para la caché del archivo. |
| nombre de archivo | String | Especifica el nombre de archivo en el JSON. Si se establece a null, el nombre de archivo predeterminado es: book1. |
