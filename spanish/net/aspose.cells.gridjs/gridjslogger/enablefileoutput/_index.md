## GridJsLogger.EnableFileOutput property

Obtiene o establece si se deben enviar los mensajes de registro a un archivo. El valor predeterminado es false. Debe llamarse a [`SetLogFile`](../setlogfile/) o [`SetLogDirectory`](../setlogdirectory/) antes de habilitarlo.

```csharp
public static bool EnableFileOutput { get; set; }
```
