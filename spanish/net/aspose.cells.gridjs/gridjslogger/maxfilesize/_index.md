## GridJsLogger.MaxFileSize property

Obtiene o establece el tamaño máximo (en bytes) para un solo archivo de registro antes de rotar. Solo es efectivo cuando la rotación está habilitada. 0 significa sin límite de tamaño. El valor predeterminado es 0.

public static long MaxFileSize { get; set; }
