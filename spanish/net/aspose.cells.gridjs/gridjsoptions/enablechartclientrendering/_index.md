## GridJsOptions.EnableChartClientRendering property

Obtiene/Establece si se debe habilitar el renderizado de gráficos del lado del cliente. Si se establece en false, GridJs solo emitirá imágenes/formas de gráficos y no requerirá renderizado del lado del cliente. El valor predeterminado es true.

```csharp
public bool EnableChartClientRendering { get; set; }
```
