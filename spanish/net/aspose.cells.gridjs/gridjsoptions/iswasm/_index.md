## GridJsOptions.IsWasm property

Obtiene/Establece si GridJs se ejecuta dentro de un host WebAssembly en el navegador en lugar de un proceso de servidor. Cuando es verdadero, no se utiliza FileCacheDirectory / disco / ruta de subproceso de interrupción, y la caché de archivos debe provenir de CacheImp, porque un host de navegador no tiene disco local. Selecciona rutas de código en tiempo de ejecución, por lo que un Aspose.Cells.GridJs.dll sirve a ambos hosts. El valor predeterminado es falso.

```csharp
public bool IsWasm { get; set; }
```
