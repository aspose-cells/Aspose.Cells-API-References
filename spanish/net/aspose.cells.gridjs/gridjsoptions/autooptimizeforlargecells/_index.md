## GridJsOptions.AutoOptimizeForLargeCells property

Obtiene/Establece si se debe optimizar automáticamente el rendimiento de carga para una hoja de cálculo con celdas grandes. Ignorará algunos estilos /bordes para reducir el tiempo de carga. El valor predeterminado es true.

public bool AutoOptimizeForLargeCells { get; set; }
