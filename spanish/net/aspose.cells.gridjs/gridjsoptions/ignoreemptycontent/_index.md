## GridJsOptions.IgnoreEmptyContent property

Obtiene/Establece si se muestra el rango máximo que incluye datos, estilo, celdas combinadas y formas. Si la última fila o columna contiene celdas sin valor ni fórmula pero con estilo personalizado, entonces no mostraremos esa fila/columna cuando este valor sea verdadero. El valor predeterminado es verdadero.

```csharp
public bool IgnoreEmptyContent { get; set; }
```
