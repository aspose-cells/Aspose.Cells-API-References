## GridJsWorkbook.JsonToStreamByUid method

Recupera la cadena JSON del archivo desde la caché usando el id único especificado, establece el nombre de archivo de salida en el JSON y lo escribe en el flujo.

```csharp
public bool JsonToStreamByUid(Stream stream, string uid, string filename)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| stream | Stream | El flujo que se escribirá |
| uid | String | El identificador único para la caché del archivo. |
| nombre de archivo | String | Especifica el nombre de archivo en el JSON. Si se establece a null, el nombre de archivo predeterminado es: book1. |
