## GridJsWorkbook.BurnRedactionFile method

Ejecuta (aplica) todas las operaciones de redacción en el libro de trabajo eliminando las formas de redacción y sus formas objetivo o borrando el contenido del rango de celdas objetivo.

```csharp
public void BurnRedactionFile(string excelFilePath, string uid)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| excelFilePath | String | La ruta del archivo Excel. |
| uid | String | El identificador único para el libro. Si es null o está vacío, se generará un nuevo uid basado en la ruta del archivo. |
