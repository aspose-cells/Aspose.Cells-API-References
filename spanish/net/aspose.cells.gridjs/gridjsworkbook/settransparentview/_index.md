## GridJsWorkbook.SetTransParentView method

Establece la transparencia de las formas de redacción en el libro de trabajo.

```csharp
public void SetTransParentView(string excelFilePath, string uid, bool isTransparent)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| excelFilePath | String | La ruta del archivo Excel. |
| uid | String | El identificador único para el libro. Si es null o está vacío, se generará un nuevo uid basado en la ruta del archivo. |
| isTransparent | Booleano | Si es verdadero, establece la transparencia a 0.89 (semi-transparente); si es falso, establece la transparencia a 1 (totalmente opaco/invisible). |
