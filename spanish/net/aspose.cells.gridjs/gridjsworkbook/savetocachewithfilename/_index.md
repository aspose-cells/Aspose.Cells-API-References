## GridJsWorkbook.SaveToCacheWithFileName method

Guarda los datos en memoria en el archivo de caché con el nombre de archivo especificado y también establece la contraseña de apertura; el formato de guardado se basa en la extensión del nombre de archivo.

```csharp
public void SaveToCacheWithFileName(string uid, string filename, string password)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| uid | String | El identificador único para la caché del archivo. |
| nombre de archivo | String | El nombre de archivo para guardar. |
| contraseña | String | La contraseña de apertura del archivo Excel. El valor puede ser nulo si no se establece ninguna contraseña. |
