El espacio de nombres **Aspose.Cells.DataModels** proporciona clases para acceder y actualizar los modelos de datos del libro de trabajo.

## Clases

| Clase | Descripción |
| --- | --- |
| [DataModel](./datamodel/) | Representa el modelo de datos. |
| [DataModelRelationship](./datamodelrelationship/) | Representa una única relación en el modelo de datos de la hoja de cálculo. |
| [DataModelRelationshipCollection](./datamodelrelationshipcollection/) | Representa las relaciones. |
| [DataModelTable](./datamodeltable/) | Representa las propiedades de una única tabla en el modelo de datos de la hoja de cálculo. |
| [DataModelTableCollection](./datamodeltablecollection/) | Representa la lista de la tabla del modelo de datos. |
