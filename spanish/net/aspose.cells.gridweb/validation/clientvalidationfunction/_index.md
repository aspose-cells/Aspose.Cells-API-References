## Validation.ClientValidationFunction property

Obtiene o establece el nombre de la función JavaScript de validación del cliente.

```csharp
public string ClientValidationFunction { get; set; }
```

### Observaciones

Utilice la propiedad ClientValidationFunction para especificar el nombre de la función de validación del cliente. La función debe declararse de la siguiente forma: function customValicationFunction(source, value) El parámetro "source" es el objeto celda. El parámetro "value" es el valor de cadena de una celda que se va a comprobar. La función debe devolver true si el valor es válido.
