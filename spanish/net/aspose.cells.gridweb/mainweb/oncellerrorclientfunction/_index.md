## MainWeb.OnCellErrorClientFunction property

Obtiene o establece el nombre de la función del lado del cliente que se llamará cuando falle la validación de una celda. La función del cliente debe declararse así: function MyOnCellError(cell) { alert(this.getCellValueByCell(cell)); }Nota: Puede usar el puntero "this" en la función del cliente para referirse al control de la cuadrícula que dispara el evento.

```csharp
public string OnCellErrorClientFunction { get; set; }
```
