## MainWeb.OnCellUpdatedClientFunction property

Obtiene o establece el nombre de la función del lado del cliente que se llamará cuando se actualice el valor de una celda. La función del cliente debe declararse así: function MyOnCellUpdated(cell) { alert(this.getCellValueByCell(cell)); }Nota: Puede usar el puntero "this" en la función del cliente para referirse al control de la cuadrícula que dispara el evento.

```csharp
public string OnCellUpdatedClientFunction { get; set; }
```
