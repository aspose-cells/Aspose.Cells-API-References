## MainWeb.OnDoubleClickRowClientFunction property

Obtiene o establece la función del lado del cliente que se llamará cuando una fila se haga doble clic. La función del cliente debe declararse así: function MyOnRowDoubleClick(row) { alert(row); }Nota: Puede usar el puntero "this" en la función del cliente para referirse al control de cuadrícula que dispara el evento.

```csharp
public string OnDoubleClickRowClientFunction { get; set; }
```
