## MainWeb.ShowCellEditBox property

Indica si Gridweb muestra la barra de herramientas de cuadro de edición como en MS-EXCEL. Si está habilitado, se mostrará un cuadro de edición para la celda actual en Gridweb. Si habilitamos esta función, necesitamos importar la biblioteca jquery js en sus archivos aspx para soportar esta nueva característica. Cualquier versión reciente de jquery está bien, etc.

```csharp
public bool ShowCellEditBox { get; set; }
```
