## MainWeb.ForceValidation property

Obtiene o establece si se fuerza la validación del lado del cliente.

```csharp
public bool ForceValidation { get; set; }
```

### Observaciones

Cuando se establece en true, los datos no se enviarán al servidor hasta que todos los campos de entrada sean válidos.
