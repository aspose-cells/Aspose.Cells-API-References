## MainWeb.EnableDoubleClickEvent property

Obtiene o establece si se habilita el evento de doble clic del lado del cliente.

```csharp
public bool EnableDoubleClickEvent { get; set; }
```

### Observaciones

Cuando se establece en true, el control recibirá eventos de doble clic del lado del cliente y podrá manejar estos eventos en el servidor. De lo contrario, el control ignorará cualquier evento de doble clic.
