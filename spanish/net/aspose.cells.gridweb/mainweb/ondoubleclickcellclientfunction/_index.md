## MainWeb.OnDoubleClickCellClientFunction property

Obtiene o establece la función del lado del cliente que se llamará cuando una celda se haga doble clic. La función del cliente debe declararse así: function MyOnDoubleClickCell(cell) { this.setCellValueByCell(cell, "test"); }Nota: Puede usar el puntero "this" en la función del cliente para referirse al control de cuadrícula que dispara el evento.

```csharp
public string OnDoubleClickCellClientFunction { get; set; }
```
