## MainWeb.EnableClientResizeColumnRow property

Obtiene o establece si se habilita el redimensionamiento de columnas y filas del lado del cliente.

```csharp
public bool EnableClientResizeColumnRow { get; set; }
```

### Observaciones

Cuando se establece en true, el usuario puede redimensionar la columna y la fila del lado del cliente.
