## MainWeb.OnCellUnselectedClientFunction property

Obtiene o establece la función del lado del cliente que se llamará cuando se deseleccione una celda. La función del cliente debe declararse así: function MyOnUnselectCell(cell) { this.setCellValueByCell(cell, "test"); }Nota: Puede usar el puntero "this" en la función del cliente para referirse al control de la cuadrícula que dispara el evento.

```csharp
public string OnCellUnselectedClientFunction { get; set; }
```
