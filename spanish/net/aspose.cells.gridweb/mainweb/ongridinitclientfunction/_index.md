## MainWeb.OnGridInitClientFunction property

Obtiene o establece el nombre de la función del lado del cliente que se llamará cuando la cuadrícula se inicialice. La función del cliente debe declararse así: function MyOnGridInit(grid) { alert("The grid is initialized: " + grid.id); }Nota: Puede usar el puntero "this" en la función del cliente para referirse al control de cuadrícula que dispara el evento.

```csharp
public string OnGridInitClientFunction { get; set; }
```
