## MainWeb.OnAjaxCallFinishedClientFunction property

Obtiene o establece el nombre de la función del lado del cliente que se llamará cuando la llamada ajax haya finalizado. La función del cliente debe declararse así: function GridAjaxcallFinished() { alert(this.id+" ajaxcall finished "); }Nota: Puede usar el puntero "this" en la función del cliente para referirse al control de la cuadrícula que dispara el evento.

```csharp
public string OnAjaxCallFinishedClientFunction { get; set; }
```
