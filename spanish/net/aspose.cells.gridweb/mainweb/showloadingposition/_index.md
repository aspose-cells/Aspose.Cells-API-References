## MainWeb.ShowLoadingPosition property

Especifica la posición izquierda, superior (en px) para mostrar el cuadro de diálogo de carga durante el postback al servidor, etc. 100,200 indica que la posición izquierda y superior del cuadro de diálogo de carga es 100px,200px.

public string ShowLoadingPosition { get; set; }
