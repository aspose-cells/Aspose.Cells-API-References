## MainWeb.OnPageChangeClientFunction property

Obtiene o establece la función del lado del cliente que se llamará después de cambiar el índice de página. Solo tiene efecto cuando EnablePaging es true. La función del cliente debe declararse así: function MyOnPageChange(index) { console.log("current page is:"+index); }Nota: Puede usar el puntero "this" en la función del cliente para referirse al control de cuadrícula que dispara el evento.

```csharp
public string OnPageChangeClientFunction { get; set; }
```
