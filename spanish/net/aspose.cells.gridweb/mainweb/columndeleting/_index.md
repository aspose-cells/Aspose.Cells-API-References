## MainWeb.ColumnDeleting event

Ocurre cuando el usuario intenta eliminar una columna del menú del lado del cliente. Puede manejar este evento y establecer el parámetro cancel en True para cancelar la operación de eliminación.

```csharp
public event RowColumnEventHandler ColumnDeleting;
```
