## MainWeb.EnableClientFreeze property

Obtiene o establece si se habilitan las operaciones de congelación del lado del cliente.

```csharp
public bool EnableClientFreeze { get; set; }
```

### Observaciones

Cuando se establece en true, el usuario puede usar el menú del botón derecho para congelar/descongelar paneles.
