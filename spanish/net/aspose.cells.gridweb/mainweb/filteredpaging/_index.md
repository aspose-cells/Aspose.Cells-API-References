## MainWeb.FilteredPaging property

Obtiene o establece si se habilita la paginación después de filtrar los datos; tendrá efecto cuando EnablePaging sea verdadero.

```csharp
public bool FilteredPaging { get; set; }
```

### Observaciones

Cuando se establece en true, el control paginará basándose en los datos filtrados; el valor predeterminado es false.
