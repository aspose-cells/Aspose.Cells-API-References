## MainWeb.EnableStyleDialogbox property

Obtiene o establece si se habilita el cuadro de diálogo de estilo del lado del cliente.

```csharp
public bool EnableStyleDialogbox { get; set; }
```

### Observaciones

Cuando se establece en true, el usuario puede usar el cuadro de diálogo de estilo para establecer el estilo de una celda seleccionando "Format Cell..." del menú emergente.
