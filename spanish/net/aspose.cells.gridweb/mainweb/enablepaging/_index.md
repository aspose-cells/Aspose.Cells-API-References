## MainWeb.EnablePaging property

Obtiene o establece si se habilita el modo de paginación del control.

```csharp
public bool EnablePaging { get; set; }
```

### Observaciones

Cuando se establece en true, el control mostrará PageSize filas de datos a la vez y mostrará el control de selección de página en la barra de pestañas.
