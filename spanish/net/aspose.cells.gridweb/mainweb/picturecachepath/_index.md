## MainWeb.PictureCachePath property

Obtiene o establece la ruta de almacenamiento de imágenes para el libro de trabajo, todas las formas e imágenes se almacenarán en este directorio, la ruta predeterminada es acwcache bajo el Directorio Base de la aplicación actual; los usuarios deben implementar un servicio programado para limpiar los archivos que estén fuera del tiempo de sesión.

```csharp
public static string PictureCachePath { get; set; }
```
