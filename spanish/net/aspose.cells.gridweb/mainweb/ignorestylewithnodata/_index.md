## MainWeb.IgnoreStyleWithNoData property

Obtiene o establece si GridWeb ignora la visualización de filas o columnas que no contienen valores de celda pero están estilizadas. Si se establece en true, el rendimiento será mejor. El valor predeterminado es false, lo que significa que si la última fila/columna consecutiva no tiene valores de celda pero está estilizada, aún se mostrará. Esta opción solo es válida cuando EnableAsync es false. Esta opción no tiene efecto cuando EnableAsync es true, lo que significa que GridWeb mostrará todas las filas/columnas con estilo.

```csharp
public bool IgnoreStyleWithNoData { get; set; }
```
