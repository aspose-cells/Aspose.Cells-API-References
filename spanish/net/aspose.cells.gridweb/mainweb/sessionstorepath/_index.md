## MainWeb.SessionStorePath property

Obtiene o establece la ruta de almacenamiento de caché de sesión cuando el modo de sesión es File o ViewState, etc.: gridweb.SessionStorePath="c:/mytempdir/session"; entonces almacenará los datos de sesión en c:/mytempdir/session

public string SessionStorePath { get; set; }
