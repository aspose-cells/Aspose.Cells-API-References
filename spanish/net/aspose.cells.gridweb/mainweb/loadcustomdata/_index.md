## MainWeb.LoadCustomData event

Se dispara cuando SessionMode del control está configurado en Custom y necesita cargar los datos de la hoja. Puede manejar este evento en modo Custom Session para cargar los datos de la hoja desde un archivo o base de datos.

```csharp
public event WorkbookEventHandler LoadCustomData;
```
