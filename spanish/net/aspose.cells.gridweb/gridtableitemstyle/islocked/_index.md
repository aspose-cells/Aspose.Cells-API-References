## GridTableItemStyle.IsLocked property

Obtiene o establece un valor que indica si una celda puede modificarse o no cuando su hoja de cálculo está protegida. Cuando la hoja está protegida y IsLocked es verdadero, la celda no puede editarse. Cuando la hoja está protegida y IsLocked es falso, la celda puede editarse.

```csharp
public bool IsLocked { get; set; }
```
