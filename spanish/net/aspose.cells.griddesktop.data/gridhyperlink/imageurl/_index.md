## GridHyperlink.ImageURL property

Obtenga o establezca la URL de la imagen para el enlace, no hay propiedades imageurl en el hipervínculo, así que en realidad se usa TextToDisplay para registrar este valor, TextToDisplay se establecerá a &lt;img src=valor &gt; para cambiar el valor de TextToDisplay

public string ImageURL { get; set; }
