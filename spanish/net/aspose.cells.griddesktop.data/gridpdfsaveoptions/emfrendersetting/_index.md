## GridPdfSaveOptions.EmfRenderSetting property

Configuración para renderizar metarchivo Emf.

```csharp
public GridEmfRenderSetting EmfRenderSetting { get; set; }
```

### Observaciones

Los metaficheros EMF identificados como "EMF+ Dual" pueden contener tanto registros EMF+ como registros EMF. Cualquiera de los tipos de registro puede usarse para renderizar la imagen, solo registros EMF+ o solo registros EMF.
