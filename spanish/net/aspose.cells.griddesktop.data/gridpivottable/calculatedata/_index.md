## GridPivotTable.CalculateData method

Calcula los datos de la tabla dinámica en celdas.

```csharp
public void CalculateData()
```

### Observaciones

Cell.Value en el rango pivote no pudo devolver el resultado correcto si el método no ha sido llamado. Este método calcula los datos con una caché interna de pivote, no con la fuente de datos original. Por lo tanto, si la fuente de datos se cambia, por favor llame al método RefreshData() primero.
