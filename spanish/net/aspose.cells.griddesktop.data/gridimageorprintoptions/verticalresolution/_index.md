## GridImageOrPrintOptions.VerticalResolution property

Obtiene o establece la resolución vertical para las imágenes generadas, en puntos por pulgada. Se aplica al método de generación de imágenes, excepto a imágenes en formato Emf.

```csharp
public int VerticalResolution { get; set; }
```

### Observaciones

El valor predeterminado es 96.
