## GridCellValueFormatStrategy enumeration

Especifica cómo aplicar el estilo al valor de la celda.

```csharp
public enum GridCellValueFormatStrategy
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | `0` | No formateado. |
| CellStyle | `1` | Solo formateado con el estilo original de la celda. |
| DisplayStyle | `2` | Formateado con el estilo mostrado de la celda. |
| DisplayString | `3` | Obtiene la cadena mostrada en ms excel. La principal diferencia con DisplayStyle es que esta opción también considera el efecto del ancho de columna. Si el ancho de columna es demasiado pequeño para mostrar la cadena formateada completamente, se puede mostrar "#", al igual que hace ms excel. |
