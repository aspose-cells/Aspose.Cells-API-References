## OnErrorActionType enumeration

Se utiliza en el evento CellError de GridWeb. El usuario establece OnErrorActionQuery.OnErrorAction para indicar al control que Detenga el procesamiento o Ignore el error.

```csharp
public enum OnErrorActionType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Throw | `0` | Lanza la excepción actual. |
| Stop | `1` | Detiene el procesamiento actual. |
| Ignore | `2` | Ignora el error y continúa el procesamiento. |
