## GridComment.Width property

Obtener o establecer el ancho del comentario. El valor predeterminado es 140. El valor de entrada debe estar entre 20 y 1000. Se establecerá en 20 si se ingresa un valor menor que 20. Se establecerá en 1000 si se ingresa un valor mayor que 1000.

public int Width { get; set; }
