## GridCell.Protected property

Indica si la celda está protegida. Si el valor es "true", el usuario no puede modificar la celda a través de la interfaz de usuario. Este atributo no tiene relación con la propiedad Style.CellLocked y no se guardará en el archivo cuando se exporten los datos de la cuadrícula. El valor predeterminado es "false".

```csharp
public bool Protected { get; set; }
```
