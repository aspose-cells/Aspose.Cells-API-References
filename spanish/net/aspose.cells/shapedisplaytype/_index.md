## ShapeDisplayType enumeration

Representa cómo la aplicación muestra las formas en este libro. Las formas pueden incluir gráficos, imágenes y otros datos de objetos que la aplicación admite.

```csharp
public enum ShapeDisplayType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| All | `0` | Indica que todas las formas se muestren en el libro de trabajo. |
| Placeholders | `1` | Indica que la aplicación muestre marcadores de posición para las formas en el libro de trabajo. |
| None | `2` | Indica que todas las formas estén ocultas en el libro de trabajo. |
