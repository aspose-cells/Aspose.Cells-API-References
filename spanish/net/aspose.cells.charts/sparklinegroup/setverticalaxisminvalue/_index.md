## SparklineGroup.SetVerticalAxisMinValue method

Establece el valor mínimo personalizado para el eje vertical del sparkline con el tipo de valor de eje especificado.

```csharp
public void SetVerticalAxisMinValue(SparklineAxisMinMaxType type, double value)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| type | SparklineAxisMinMaxType | Tipo que especifica cómo se aplica el valor mínimo del eje. |
| valor | Double | Valor mínimo personalizado del eje vertical. Se ignora si el tipo no es Custom. |
