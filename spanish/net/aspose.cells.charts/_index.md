El espacio de nombres **Aspose.Cells.Charts** proporciona clases que permiten el acceso y la creación de gráficos y sparklines en hojas de cálculo de Microsoft Excel.

| Clase | Descripción |

| [Trendline](./trendline/) | Representa una línea de tendencia en un gráfico. |
| [TrendlineCollection](./trendlinecollection/) | Representa una colección de todos los objetos [`Trendline`](../aspose.cells.charts/trendline/) para la serie de datos especificada. |
