## ThemeColor.Tint property

Obtiene y establece el valor de tono. El valor de tono se almacena como un double de -1.0 .. 1.0, donde -1.0 significa 100 % oscurecer y 1.0 significa 100 % aclarar. Además, 0.0 significa sin cambios.

public double Tint { get; set; }
