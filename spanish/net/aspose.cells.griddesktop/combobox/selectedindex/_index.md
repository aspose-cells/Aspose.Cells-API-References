## ComboBox.SelectedIndex property

Obtiene o establece el índice que especifica el elemento seleccionado actualmente. Establecer el índice llamará al método GridDesktop.RunAllFormulas automáticamente si la propiedad GridDesktop.RecalculateFormulas es verdadera.

public int SelectedIndex { get; set; }
