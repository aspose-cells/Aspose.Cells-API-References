## GridDesktop.EnableClipboardCopyPaste property

Indica si se debe copiar/pegar basándose en el portapapeles, de modo que pueda copiar/pegar con MS-EXCEL. Solo copia/pega el valor de la celda; no copia ninguna otra configuración de la celda como formato, estilo de borde, etc. El valor predeterminado es false.

```csharp
public bool EnableClipboardCopyPaste { get; set; }
```
