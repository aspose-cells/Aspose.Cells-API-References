## GridDesktop.StartFormatPainter method

Notifica a GridDesktop para iniciar el Pintor de Formato.

```csharp
public void StartFormatPainter(bool formatOnce)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| formatOnce | Booleano | si formatOnce es true, FormatPainter puede usarse una vez, si formatOnce es false, FormatPainter puede usarse múltiples veces, hasta que se invoque EndFormatPainter(). |

### Ejemplos

```csharp
[C#]
gridDesktop1.StartFormatPainter(true);

[Visual Basic]
gridDesktop1.StartFormatPainter(True)

```
