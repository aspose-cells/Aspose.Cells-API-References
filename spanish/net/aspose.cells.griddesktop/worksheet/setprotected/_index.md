## Worksheet.SetProtected method

Establece si el rango de celdas está protegido. Este es un método extendido usado solo en Grid. Este método no tiene relación con la propiedad cell.Style.CellLocked. No tendrá efecto después de guardar en el archivo Excel.

```csharp
public void SetProtected(CellRange range, bool isProtected)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| rango | CellRange | Objeto CellRange. |
| isProtected | Booleano | Valor booleano a establecer. |
