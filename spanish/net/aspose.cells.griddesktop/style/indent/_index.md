## Style.Indent property

Representa el nivel m_IndentLevel para la celda o rango. Solo puede ser un entero de 0 a 15.

```csharp
public int Indent { get; set; }
```

### Observaciones

Si el tipo de alineación horizontal del texto se establece en un valor distinto de izquierda o derecha, el nivel m_IndentLevel se restablecerá a cero.
