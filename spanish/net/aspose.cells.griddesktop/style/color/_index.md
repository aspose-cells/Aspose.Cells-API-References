## Style.Color property

Obtiene o establece el color de sombreado de la celda. Cuando el patrón es ninguno, devuelve Color.Empty; cuando el patrón es BackgroundType.Solid, devuelve ForegroundColor; en otros casos devuelve BackgroundColor.

```csharp
public Color Color { get; set; }
```
