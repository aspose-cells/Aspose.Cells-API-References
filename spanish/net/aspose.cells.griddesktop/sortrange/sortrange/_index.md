## SortRange constructor

Inicializa una nueva instancia de la clase [`SortRange`](../) especificando un rango de hoja de cálculo y la orientación de ordenación.

```csharp
public SortRange(Worksheet worksheet, int startRow, int startColumn, int rows, int columns, 
    SortOrientation orientation, bool isCaseSensitive)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| worksheet | Hoja de cálculo | La hoja de cálculo que contiene el rango. |
| startRow | Int32 | La fila inicial del rango. |
| startColumn | Int32 | La columna inicial del rango. |
| filas | Int32 | El número de filas. |
| columnas | Int32 | El número de columnas |
| orientación | SortOrientation | La orientación del ordenamiento: de arriba a abajo o de izquierda a derecha. |
| isCaseSensitive | Booleano | Determina si la ordenación de los datos distingue entre mayúsculas y minúsculas cuando los datos son cadenas |
