El espacio de nombres **Aspose.Cells.Properties** proporciona clases para trabajar con propiedades de hoja de cálculo personalizadas y predeterminadas, como título, palabras clave, empresa, etc.

## Clases

| Clase | Descripción |
| --- | --- |
| [BuiltInDocumentPropertyCollection](./builtindocumentpropertycollection/) | Una colección de propiedades de documento predefinidas. |
| [ContentTypeProperty](./contenttypeproperty/) | Representa información de identificador. |
| [ContentTypePropertyCollection](./contenttypepropertycollection/) | Una colección de objetos [`ContentTypeProperty`](../aspose.cells.properties/contenttypeproperty/) que representan información adicional. |
| [CustomDocumentPropertyCollection](./customdocumentpropertycollection/) | Una colección de propiedades de documento personalizadas. |
| [CustomProperty](./customproperty/) | Representa una propiedad personalizada que almacena pares de nombre y valor de datos arbitrarios definidos por el usuario para la hoja de cálculo. |
| [CustomPropertyCollection](./custompropertycollection/) | Una colección de objetos [`CustomProperty`](../aspose.cells.properties/customproperty/) que representan información adicional. |
| [DocumentProperty](./documentproperty/) | Representa una propiedad de documento personalizada o predefinida. |
| [DocumentPropertyCollection](./documentpropertycollection/) | Clase base para las colecciones [`BuiltInDocumentPropertyCollection`](../aspose.cells.properties/builtindocumentpropertycollection/) y [`CustomDocumentPropertyCollection`](../aspose.cells.properties/customdocumentpropertycollection/). |
