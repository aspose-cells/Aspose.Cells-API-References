## GridReferredArea.GetValues method

Obtiene los valores de las celdas en esta área.

```csharp
public object GetValues()
```

### Valor de retorno

Si esta área es inválida, "#REF!" será devuelto; si esta área es una sola celda, entonces devuelve el objeto de valor de celda; de lo contrario devuelve una matriz con todos los valores en esta área.
