## WebCells.SetRowReadonly method

Establece una fila como de solo lectura para que el usuario no pueda eliminarla desde el lado del cliente. este es un método extendido de GridWeb específicamente, no se conservará ni tendrá efecto en el archivo Excel real

```csharp
public void SetRowReadonly(int rowIndex, bool isReadonly)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| rowIndex | Int32 | índice de fila. |
| isReadonly | Booleano | verdadero o falso. |
