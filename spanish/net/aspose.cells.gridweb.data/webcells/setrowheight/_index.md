## WebCells.SetRowHeight method

Establece la altura de la fila especificada. El tipo de ancho aceptado es Point, Pixel o Inch.

```csharp
public void SetRowHeight(int row, Unit height)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| fila | Int32 | Índice de fila. |
| altura | Unidad | Altura de la fila. En unidades de punto. Debe estar entre 0 y 409.5. |

### Observaciones

Para ocultar una fila, establece la altura de la fila a cero.
