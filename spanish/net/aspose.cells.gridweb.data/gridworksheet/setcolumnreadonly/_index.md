## GridWorksheet.SetColumnReadonly method

Establece una columna como de solo lectura para que el usuario no pueda eliminarla desde el lado del cliente. este es un método extendido de GridWeb específicamente, no se conservará ni tendrá efecto en el archivo Excel real

```csharp
public void SetColumnReadonly(int columnIndex, bool isReadonly)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| columnIndex | Int32 | índice de columna. |
| isReadonly | Booleano | verdadero o falso. |
