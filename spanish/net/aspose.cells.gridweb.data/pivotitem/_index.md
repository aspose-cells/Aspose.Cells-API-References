## PivotItem class

Representa un elemento en un campo PivotTable. Los elementos son las entradas de datos individuales en una categoría de campo. El objeto PivotItem es un miembro de la colección PivotItems. La colección PivotItems contiene todos los elementos del objeto PivotField.
