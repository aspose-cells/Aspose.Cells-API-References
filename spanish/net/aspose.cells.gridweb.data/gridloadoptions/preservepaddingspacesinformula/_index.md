## GridLoadOptions.PreservePaddingSpacesInFormula property

Indica si se conservan los espacios y saltos de línea que se insertan entre los tokens de la fórmula al obtener y establecer fórmulas. El valor predeterminado es false.

```csharp
public bool PreservePaddingSpacesInFormula { get; set; }
```

### Observaciones

Después de cargar el libro de trabajo desde un archivo de plantilla con esta opción, [`PreservePaddingSpaces`](../../gridworkbooksettings/preservepaddingspaces/) se establecerá al mismo valor que esta propiedad.
