## GridTxtLoadOptions.ExtendToNextSheet property

Indica si se extienden los datos a la hoja siguiente cuando las filas o columnas de datos superan el límite. Si esta propiedad es verdadera, los datos adicionales se extenderán a la hoja siguiente detrás de la actual (si la hoja actual es la última, se añadirá una nueva hoja al libro de trabajo). Si la propiedad es falsa, los datos que superen el límite se ignorarán. El valor predeterminado es false;

```csharp
public bool ExtendToNextSheet { get; set; }
```
