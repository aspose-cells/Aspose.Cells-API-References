## GridTxtLoadOptions.TreatQuotePrefixAsValue property

Indica si el signo de comilla simple inicial debe tomarse como parte del valor de una celda. El valor predeterminado es verdadero. Si es falso, la comilla simple inicial se eliminará del valor de la celda correspondiente y [`QuotePrefix`](../../../aspose.cells.gridweb/gridtableitemstyle/quoteprefix/) se establecerá como verdadero para la celda.

```csharp
public bool TreatQuotePrefixAsValue { get; set; }
```
