## GridValidation.LoadValueList method

Carga la lista de valores desde un objeto DataView. Puede especificar el campo de valor y el campo de texto del DataView. Cada par de valor y texto se combinará en una cadena, con una coma entre ellos.

```csharp
public void LoadValueList(DataView view, string valueField, string textField, bool valuePrefixText)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| vista | DataView | El objeto DataView. |
| valueField | String | El nombre del campo de valor. |
| textField | String | El nombre del campo de texto. |
| valuePrefixText | Booleano | Indica si se debe agregar un prefijo de valor a cada texto mostrado. |
