## WebWorksheet.IsProtected property

Obtiene o establece si la hoja de cálculo está protegida. Cuando una hoja de cálculo está protegida, todas las celdas no pueden editarse excepto la celda cuya propiedad IsLocked es false.

public bool IsProtected { get; set; }
