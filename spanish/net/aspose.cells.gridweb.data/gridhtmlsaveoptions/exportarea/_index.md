## GridHtmlSaveOptions.ExportArea property

Obtiene o establece el área de celdas que se exporta de la hoja de cálculo activa actual. Si establece este atributo, el área de impresión de la hoja activa se omitirá. Solo el área especificada se exportará al guardar el archivo en html.

```csharp
public GridCellArea ExportArea { get; set; }
```
