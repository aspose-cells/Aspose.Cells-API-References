## Hyperlink.ActionType property

Obtiene o establece el tipo de acción del hipervínculo. Puede ser ActionTpye.UrlLink o ActionType.CellCommand. El tipo UrlLink significa que el hipervínculo es un enlace a una página web o a un correo electrónico. Por ejemplo: "http://www.aspose.com" o "mailto:admin@aspose.com". El tipo CellCommand significa que el hipervínculo disparará un evento CellCommand, y usted puede manejar este evento.

```csharp
public virtual HyperlinkActionType ActionType { get; set; }
```
