## GetBaseItemPositionType function

Representa el tipo del elemento pivot base en el campo base cuando el cálculo ShowDataAs está en uso. Válido solo para campos de datos. Debido a que PivotItemPosition.Custom es solo de lectura, si necesita establecer PivotItemPosition.Custom, por favor establezca el atributo PivotField.BaseItemIndex.
