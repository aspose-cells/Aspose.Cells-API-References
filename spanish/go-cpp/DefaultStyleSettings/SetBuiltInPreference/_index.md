## SetBuiltInPreference function

Indica si la propiedad para el formato de número es preferible cuando el estilo define tanto un número incorporado como un patrón personalizado. El valor predeterminado es false, lo que significa que por defecto se utilizará el patrón personalizado para formatear valores siempre que no esté vacío para un estilo.
