## SetJustification function

Esto especifica la justificación del párrafo matemático (una serie de ecuaciones adyacentes dentro del mismo párrafo). Un párrafo matemático puede estar Alineado a la Izquierda, Alineado a la Derecha, Centrado, o Centrado como Grupo. Por defecto, el párrafo matemático está Centrado como Grupo. Esto significa que las ecuaciones pueden alinearse entre sí, pero todo el grupo de ecuaciones se centra como un todo.

```go

func (instance *EquationNodeParagraph) SetJustification(value EquationHorizontalJustificationType)  error

```
