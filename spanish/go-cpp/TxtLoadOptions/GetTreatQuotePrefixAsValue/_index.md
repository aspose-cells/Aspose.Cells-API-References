## GetTreatQuotePrefixAsValue function

Indica si el signo de comilla simple inicial debe tomarse como parte del valor de una celda. El valor predeterminado es true. Si es false, la comilla simple inicial se eliminará del valor de la celda correspondiente y Style.QuotePrefix se establecerá como true para la celda.
