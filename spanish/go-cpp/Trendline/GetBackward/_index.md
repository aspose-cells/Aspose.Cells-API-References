## GetBackward function

Obtiene o establece el número de períodos (o unidades en un gráfico de dispersión) que la línea de tendencia se extiende hacia atrás. El número de períodos debe ser mayor o igual a cero. Si el tipo de gráfico es columna, el número de períodos debe estar entre 0 y 0.5.
