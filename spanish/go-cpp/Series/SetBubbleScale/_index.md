## SetBubbleScale function

Obtiene o establece el factor de escala para las burbujas en el grupo de gráficos especificado. Puede ser un valor entero de 0 (cero) a 300, correspondiente a un porcentaje del tamaño predeterminado. Se aplica solo a gráficos de burbujas.

```go

func (instance *Series) SetBubbleScale(value int32)  error

```
