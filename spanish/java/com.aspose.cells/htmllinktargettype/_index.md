Representa el tipo del atributo target en la etiqueta HTML.
## Campos

| Campo | Descripción |
| --- | --- |
| [BLANK](#BLANK) | Abre el documento vinculado en una nueva ventana o pestaña |
| [PARENT](#PARENT) | Abre el documento vinculado en el marco padre |
| [SELF](#SELF) | Abre el documento vinculado en el mismo marco en el que se hizo clic (este es el valor predeterminado) |
| [TOP](#TOP) | Abre el documento vinculado en todo el cuerpo de la ventana |
