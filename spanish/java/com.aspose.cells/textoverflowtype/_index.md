Representa la forma en que el desbordamiento vertical u horizontal del texto.
## Campos

| Campo | Descripción |
| --- | --- |
| [CLIP](#CLIP) | Presta atención a las barreras superior e inferior. |
| [ELLIPSIS](#ELLIPSIS) | Presta atención a las barreras superior e inferior. |
| [OVERFLOW](#OVERFLOW) | Desborda el texto y no prestes atención a las barreras superior e inferior. |

### CLIP {#CLIP}
```
public static final int CLIP
```


Presta atención a las barreras superior e inferior. No proporciones indicación de que hay texto que no es visible.

### ELLIPSIS {#ELLIPSIS}
```
public static final int ELLIPSIS
```


Presta atención a las barreras superior e inferior. Usa una elipsis para indicar que hay texto que no es visible. Solo para desbordamiento vertical.

### OVERFLOW {#OVERFLOW}
```
public static final int OVERFLOW
```


Desborda el texto y no prestes atención a las barreras superior e inferior.
