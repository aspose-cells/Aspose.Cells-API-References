### getHeightRatioToChart() {#getHeightRatioToChart--}
```
public double getHeightRatioToChart()
```


Obtiene la altura del cuadro delimitador del área de trazado en unidades de la proporción del área del gráfico.

**Remarks**

El cuadro delimitador del área de trazado incluye el área de trazado, marcas de graduación (etiquetas de graduación) y un pequeño borde alrededor de las marcas de graduación. Si el valor no es creado por MS Excel, por favor llame al método Chart.Calculate() antes de llamar a este método.

Los **XRatioToChart**, **YRatioToChart**, **WidthRatioToChart** y **HeightRatioToChart** de **PlotArea** representan el cuadro delimitador del área del gráfico que incluye el área del gráfico, las marcas de graduación (etiquetas de marcas) y un pequeño borde alrededor de las marcas de graduación. Si desea obtener el tamaño real del área del gráfico, debe llamar a las propiedades **InnerXRatioToChart**, **InnerYRatioToChart**, **InnerWidthRatioToChart** y **InnerHeightRatioToChart**.

Para Excel 2007 o posterior, el valor predeterminado es cero. Debe obtener el valor después de llamar a Chart.Calculate().

HeightPixel = HeightRatioToChart \* chart.ChartObject.Width. Nota: Cuando HeightRatioToChart está configurado, la propiedad IsInnerMode se establecerá automáticamente en false.

**Returns:**
double
