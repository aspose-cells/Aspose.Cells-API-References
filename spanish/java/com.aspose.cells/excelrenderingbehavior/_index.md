Especifica comportamientos de renderizado específicos de Excel que se aplican al renderizar un libro de trabajo.
## Campos

| --- | --- |
| [ALL](#ALL) | Aplica todos los comportamientos de renderizado específicos de Excel compatibles. |

| [NONE](#NONE) | No aplica los comportamientos de renderizado específicos de Excel. |

### ALL {#ALL}

### CELL_TEXT_LENGTH_LIMIT {#CELL-TEXT-LENGTH-LIMIT}
```
public static final int CELL_TEXT_LENGTH_LIMIT
```


Aplica el límite de longitud de salida de texto de celda de Excel. Por ejemplo, Excel solo muestra los primeros 1024 caracteres en una celda sin ajuste de texto.

### NONE {#NONE}
