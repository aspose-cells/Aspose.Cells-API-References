java.lang.Object
```
public final class TextCrossType
```

Enumera el tipo de visualización de texto cuando el ancho del texto es mayor que el ancho de la celda.
## Campos

| Campo | Descripción |
| --- | --- |
| [CROSS_KEEP](#CROSS-KEEP) | Muestra todo el texto cruzando otras celdas y conserva el texto de las celdas cruzadas. |
| [CROSS_OVERRIDE](#CROSS-OVERRIDE) | Muestra todo el texto cruzando otras celdas y sobrescribe el texto de las celdas cruzadas. |
| [DEFAULT](#DEFAULT) | Muestra el texto como en Microsoft Excel. |
| [STRICT_IN_CELL](#STRICT-IN-CELL) | Solo muestra el texto dentro del ancho de la celda. |
