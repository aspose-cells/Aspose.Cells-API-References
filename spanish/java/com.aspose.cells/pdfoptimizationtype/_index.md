### MINIMUM_SIZE {#MINIMUM-SIZE}
```
public static final int MINIMUM_SIZE
```


El tamaño del archivo es más importante que la calidad de impresión

**Remarks**

Las fuentes Arial y Times New Roman con caracteres 32-127 no se incrustarán en el pdf. Las líneas de borde están optimizadas para un tamaño de archivo menor.
