Indica el tipo de regla que se usa para describir un área o aspecto de la tabla dinámica.
## Campos

| Campo | Descripción |
| --- | --- |
| [ALL](#ALL) | Representa toda la tabla dinámica. |
| [BUTTON](#BUTTON) | Representa un botón de campo. |
| [DATA](#DATA) | Representa algo en el área de datos. |
| [NONE](#NONE) | Sin área de tabla dinámica. |
| [NORMAL](#NORMAL) | Representa un encabezado o elemento. |
| [ORIGIN](#ORIGIN) | Representa las celdas en blanco en la esquina superior izquierda de la tabla dinámica (superior derecha para hojas RTL). |
| [TOP_RIGHT](#TOP-RIGHT) | Representa las celdas en blanco en la esquina superior derecha de la tabla dinámica (superior izquierda para hojas RTL). |
