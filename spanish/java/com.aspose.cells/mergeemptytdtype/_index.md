### DEFAULT {#DEFAULT}
```
public static final int DEFAULT
```


Mostrar como MS Excel.

### MERGE_FORCELY {#MERGE-FORCELY}
```
public static final int MERGE_FORCELY
```


Fusionar forzadamente elementos TD vacíos al exportar el archivo a html. El tamaño del archivo html se reducirá significativamente después de establecer el valor en true. Si desea importar el archivo html a excel o exportar líneas de cuadrícula perfectas al guardar el archivo en html, mantenga el valor predeterminado.

### NONE {#NONE}
```
public static final int NONE
```


Los elementos TD vacíos no se fusionarán al exportar el archivo a html. Esto generará un archivo html significativamente más grande.
