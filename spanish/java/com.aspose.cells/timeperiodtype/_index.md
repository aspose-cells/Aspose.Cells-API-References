java.lang.Object
```
public final class TimePeriodType
```

Se utiliza en una regla de formato condicional FormatConditionType.TimePeriod. Estos son períodos de tiempo dinámicos, que cambian según la fecha en que el formato condicional se actualiza o se aplica.
## Campos

| [LAST_MONTH](#LAST-MONTH) | Una fecha que ocurre en el último mes calendario. |
| [LAST_WEEK](#LAST-WEEK) | Una fecha que ocurre la semana pasada. |
| [LAST_YEAR](#LAST-YEAR) | Una fecha que ocurre el año pasado. |
