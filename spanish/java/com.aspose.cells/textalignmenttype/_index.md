## Campos

| Campo | Descripción |
| --- | --- |
| [BOTTOM](#BOTTOM) | Representa la alineación de texto inferior. |
| [CENTER](#CENTER) | Representa la alineación de texto centrada. |
| [CENTER_ACROSS](#CENTER-ACROSS) | Representa la alineación de texto centrada a través. |
| [DISTRIBUTED](#DISTRIBUTED) | Representa la alineación de texto distribuida. |
| [FILL](#FILL) | Representa la alineación de texto de relleno. |
| [GENERAL](#GENERAL) | Representa la alineación de texto general. |
| [JUSTIFIED_LOW](#JUSTIFIED-LOW) | Alinea el texto con una longitud de kashida ajustada para texto árabe. |
| [JUSTIFY](#JUSTIFY) | Representa la alineación de texto justificada. |
| [LEFT](#LEFT) | Representa la alineación de texto izquierda. |
| [RIGHT](#RIGHT) | Representa la alineación de texto derecha. |
| [THAI_DISTRIBUTED](#THAI-DISTRIBUTED) | Distribuye el texto tailandés de forma especial, porque cada carácter se trata como una palabra. |
| [TOP](#TOP) | Representa la alineación superior del texto. |
