Representa la estrategia para reducir celdas combinadas en operaciones como eliminar filas/columnas en blanco.
## Campos

| Campo | Descripción |
| --- | --- |
| [KEEP_HEADER_ONLY](#KEEP-HEADER-ONLY) | Solo conserva las filas/columnas de encabezado del área combinada cuando la celda superior izquierda del área combinada no está vacía. |
| [NONE](#NONE) | Deja las celdas combinadas tal como están sin ninguna modificación. |
| [SHRINK_TO_FIT](#SHRINK-TO-FIT) | Reduce el área combinada si es necesario, eliminando filas desde la parte inferior o columnas desde la derecha, mientras se asegura de que todo el contenido permanezca visible. |
