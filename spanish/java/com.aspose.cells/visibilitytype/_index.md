```
public final class VisibilityType
```

Representa los estados de visibilidad de la hoja.
## Campos

| Campo | Descripción |
| --- | --- |
| [HIDDEN](#HIDDEN) | Indica que la hoja está oculta, pero puede ser mostrada por el usuario a través de la interfaz de usuario. |
| [VERY_HIDDEN](#VERY-HIDDEN) | Indica que la hoja está oculta y no puede mostrarse en la interfaz de usuario (UI). |
| [VISIBLE](#VISIBLE) | Indica que la hoja está visible. |
