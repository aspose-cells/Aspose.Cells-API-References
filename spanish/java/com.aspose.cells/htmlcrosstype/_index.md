Representa cinco tipos de cadena cruzada html.
## Campos

| Campo | Descripción |
| --- | --- |
| [CROSS](#CROSS) | Mostrar cadena cruzada HTML, este rendimiento para crear archivos HTML grandes será más de diez veces más rápido que establecer el valor a Default o FitToCell. |
| [CROSS_HIDE_RIGHT](#CROSS-HIDE-RIGHT) | Mostrar cadena cruzada HTML y ocultar la cadena derecha cuando los textos se superponen. |
| [DEFAULT](#DEFAULT) | Mostrar como MS Excel, depende de la siguiente celda. |
| [FIT_TO_CELL](#FIT-TO-CELL) | Solo mostrando la cadena dentro del ancho de la celda. |
| [MS_EXPORT](#MS-EXPORT) | Mostrar la cadena como MS Excel al exportar html. |
