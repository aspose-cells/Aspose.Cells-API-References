Esto especifica el estilo de visualización de la barra de fracción.
## Campos

| Campo | Descripción |
| --- | --- |
| [BAR](#BAR) | Esto especifica que el numerador está arriba y el denominador abajo, separados por una barra en el medio. |
| [LINEAR](#LINEAR) | Esto especifica que el numerador está a la izquierda y el denominador a la derecha, separados por una '/' entre ellos. |
| [NO_BAR](#NO-BAR) | Esto especifica que el numerador está arriba y el denominador abajo, sin estar separados por una barra en el medio. |
| [SKEWED](#SKEWED) | Esto especifica que el numerador está en la esquina superior izquierda y el denominador en la esquina inferior derecha, separados por una \"/\". |
