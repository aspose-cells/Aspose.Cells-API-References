### ALLOW_MULTIPLE {#ALLOW-MULTIPLE}
```
public static final int ALLOW_MULTIPLE
```


Todos los hipervínculos en una celda se añaden a [Worksheet.getHyperlinks()](../../com.aspose.cells/worksheet\#getHyperlinks--). Tenga en cuenta que MS Excel solo admite un hipervínculo por celda, por lo que esta opción puede generar archivos que Excel no pueda renderizar completamente.

### NORMAL {#NORMAL}
```
public static final int NORMAL
```


Solo se carga el primer hipervínculo en una celda, los siguientes se ignoran.
