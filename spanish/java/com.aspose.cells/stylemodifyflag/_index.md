Las banderas de estilo modificado.

**Remarks**

Se definen combinaciones de múltiples propiedades para la conveniencia del usuario. Al comprobar si están modificadas para un estilo, el valor devuelto indica si una o más propiedades de la combinación han sido modificadas.
