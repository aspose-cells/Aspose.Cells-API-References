Representa cómo la aplicación muestra las formas en este libro. Las formas pueden incluir gráficos, imágenes y otros datos de objetos que la aplicación admite.
## Campos

| Campo | Descripción |
| --- | --- |
| [ALL](#ALL) | Indica que todas las formas se muestren en el libro. |
| [NONE](#NONE) | Indica que todas las formas se oculten en el libro. |
| [PLACEHOLDERS](#PLACEHOLDERS) | Indica que la aplicación muestre marcadores de posición para las formas en el libro. |
