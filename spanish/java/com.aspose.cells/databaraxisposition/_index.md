Especifica la posición del eje para un rango de celdas con formato condicional como barras de datos.
## Campos

| Campo | Descripción |
| --- | --- |
| [AUTOMATIC](#AUTOMATIC) | Muestra el eje en una posición variable basada en la proporción del valor negativo mínimo al valor positivo máximo en el rango. |
| [MIDPOINT](#MIDPOINT) | Muestra el eje en el punto medio de la celda sin importar el conjunto de valores en el rango. |
| [NONE](#NONE) | No se muestra ningún eje, y tanto los valores positivos como los negativos se muestran en dirección de izquierda a derecha. |

### AUTOMATIC {#AUTOMATIC}
```
public static final int AUTOMATIC
```


Mostrar el eje en una posición variable basada en la proporción del valor negativo mínimo al valor positivo máximo en el rango. Los valores positivos se muestran en dirección de izquierda a derecha. Los valores negativos se muestran en dirección de derecha a izquierda. Cuando todos los valores son positivos o todos son negativos, no se muestra ningún eje.

### MIDPOINT {#MIDPOINT}
```
public static final int MIDPOINT
```


Mostrar el eje en el punto medio de la celda sin importar el conjunto de valores en el rango. Los valores positivos se muestran en dirección de izquierda a derecha. Los valores negativos se muestran en dirección de derecha a izquierda.

### NONE {#NONE}
```
public static final int NONE
```


No se muestra ningún eje, y tanto los valores positivos como los negativos se muestran en dirección de izquierda a derecha.
