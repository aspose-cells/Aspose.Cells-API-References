Especifica el modo de vista inicial cuando se abre el documento PDF generado.
## Campos

| Campo | Descripción |
| --- | --- |
| [FIT_HEIGHT](#FIT-HEIGHT) | Ajusta la altura de la página dentro de la ventana del visor. |
| [FIT_PAGE](#FIT-PAGE) | Ajusta la página completa dentro de la ventana del visor. |
| [FIT_WIDTH](#FIT-WIDTH) | Ajusta el ancho de la página dentro de la ventana del visor. |
| [NONE](#NONE) | Utiliza el comportamiento predeterminado del visor de PDF. |
| [ZOOM_FACTOR](#ZOOM-FACTOR) | Abre el documento con un porcentaje de zoom específico. |
