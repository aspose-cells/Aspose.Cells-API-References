Representa el tipo de directorio del nombre de archivo.
## Campos

| Campo | Descripción |
| --- | --- |
| [DOWN_DIRECTORY](#DOWN-DIRECTORY) | Indica que el libro de origen está en un subdirectorio del directorio actual. |
| [SAME_VOLUME](#SAME-VOLUME) | Indica que el libro de origen está en la misma unidad que el libro dependiente (se omite la letra de unidad). |
| [UP_DIRECTORY](#UP-DIRECTORY) | Indica que el libro de origen está en el directorio padre del directorio actual. |
| [VOLUME](#VOLUME) | Representa una letra de unidad MS-DOS. |
