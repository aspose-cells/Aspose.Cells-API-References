Especifica cómo manejar el formato del origen HTML.
## Campos

| Campo | Descripción |
| --- | --- |
| [ALL](#ALL) | Transferir todo el formato HTML a la hoja de cálculo junto con los datos. |
| [NONE](#NONE) | Introducir los datos como texto sin formato (la configuración de tipos de datos sigue ocurriendo). |
| [RTF](#RTF) | Traducir el formato HTML a formato de texto enriquecido en los datos introducidos en la hoja de cálculo. |
