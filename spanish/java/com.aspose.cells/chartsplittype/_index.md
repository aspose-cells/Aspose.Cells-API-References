java.lang.Object
```
public final class ChartSplitType
```

Representa la forma en que se dividen las dos secciones de un gráfico de pastel dentro de pastel o de barra dentro de pastel.
## Campos

| Campo | Descripción |
| --- | --- |
| [AUTO](#AUTO) | Representa los puntos de datos que se dividirán usando el mecanismo predeterminado para este tipo de gráfico. |
| [CUSTOM](#CUSTOM) | Representa los puntos de datos que se dividirán entre el pastel y el segundo gráfico de acuerdo con los valores de división personalizada. |
| [PERCENT_VALUE](#PERCENT-VALUE) | Representa los puntos de datos que se dividirán entre el pastel y el segundo gráfico colocando los puntos con un porcentaje inferior al porcentaje de Posición de División en el segundo gráfico. |
| [POSITION](#POSITION) | Representa los puntos de datos. |
| [VALUE](#VALUE) | Representa los puntos de datos que se dividirán entre el pastel y el segundo gráfico colocando los puntos de datos con un valor inferior a la Posición de División en el segundo gráfico. |
