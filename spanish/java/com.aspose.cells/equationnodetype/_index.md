**Inheritance:**
java.lang.Object
```
public final class EquationNodeType
```

Tipo de nodo de ecuación. Aviso: (1)[1-99] Actualmente solo hay un nodo en el alcance, y su valor de enumeración es 1. El nodo que especifica se usa para almacenar texto matemático. (2)[100-199] Indica que el nodo es un componente de algunos nodos de funciones especiales. (3)[200-] Indica que el nodo tiene algunas funciones especiales.
