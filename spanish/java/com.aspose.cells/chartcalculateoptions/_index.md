### getUpdateAllPoints() {#getUpdateAllPoints--}
```
public boolean getUpdateAllPoints()
```


Si se actualizan todos los puntos de datos al realizar el cálculo del gráfico. Predeterminado: False. Cuando desea obtener el valor de cada punto de datos en el gráfico específicamente, configúrelo en true. Si este parámetro se establece en True, pueden generarse nuevos puntos de datos cuando se calcula el gráfico. Esto podría hacer que el archivo de Excel sea más grande.
