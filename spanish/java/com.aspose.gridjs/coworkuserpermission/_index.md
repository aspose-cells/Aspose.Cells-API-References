Representa el permiso de usuario en modo de colaboración. Solo disponible en la versión Java ahora, estará disponible en la versión .net/python en el futuro.
## Campos

| Campo | Descripción |
| --- | --- |
| [ADMIN](#ADMIN) | Permiso de administrador, el usuario tiene acceso completo incluyendo operaciones de gestión |
| [DOWNLOAD](#DOWNLOAD) | Permiso de descarga, el usuario puede ver, editar y descargar el contenido al almacenamiento local |
| [EDITABLE](#EDITABLE) | Permiso editable, el usuario puede ver y editar el contenido |
| [READ_ONLY](#READ-ONLY) | Permiso de solo lectura, el usuario solo puede ver el contenido pero no puede realizar modificaciones |
