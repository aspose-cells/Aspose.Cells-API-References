Representa la orientación de ordenación

**Remarks**

SortOrientation.SortTopToBottom representa la ordenación de datos de arriba a abajo e intercambia los datos fila por fila. SortOrientation.SortLeftToRight representa la ordenación de datos de izquierda a derecha e intercambia los datos columna por columna.
