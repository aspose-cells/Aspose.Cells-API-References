**Inheritance:**
java.lang.Object
```
public final class HyperlinkActionType
```

Hyperlink tiene dos tipos de acción: UrlLink y CellCommand. El hipervínculo de tipo UrlLink es un ancla en una celda; al hacer clic, navegará a otra página o abrirá una nueva ventana del navegador. El hipervínculo de tipo CellCommand es un botón de comando en una celda; al hacer clic, generará un evento del lado del servidor.

**Remarks**

NOTA: Esta clase está ahora obsoleta. Por favor, use GridHyperlink en su lugar. Esta clase será eliminada después de 6 meses a partir de agosto de 2014. Aspose se disculpa por cualquier inconveniente que haya experimentado.
