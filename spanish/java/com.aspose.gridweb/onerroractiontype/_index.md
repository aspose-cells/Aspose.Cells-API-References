java.lang.Object
```
public final class OnErrorActionType
```

Se usa en el evento CellError de GridWeb. El usuario establece OnErrorActionQuery.OnErrorAction para indicar al control que Detenga el procesamiento o Ignore el error.
## Campos

| Campo | Descripción |
| --- | --- |
| [IGNORE](#IGNORE) | Ignora el error y continúa el procesamiento. |
| [STOP](#STOP) | Detiene el procesamiento actual. |
| [THROW](#THROW) | Lanza la excepción actual. |
