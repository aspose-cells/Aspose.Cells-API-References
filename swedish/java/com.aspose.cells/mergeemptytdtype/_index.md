### DEFAULT {#DEFAULT}

### MERGE_FORCELY {#MERGE-FORCELY}
```
public static final int MERGE_FORCELY
```


Tvingande sammanslagning av tomma TD‑element vid export av fil till HTML. Storleken på HTML‑filen kommer att minskas avsevärt när värdet sätts till true. Om du vill importera HTML‑filen till Excel eller exportera perfekta rutnät när du sparar filen till HTML, behåll standardvärdet.

### NONE {#NONE}
```
public static final int NONE
```


Tomma TD‑element kommer inte att slås ihop vid export av fil till HTML. Detta kommer att generera en avsevärt större HTML‑fil.
