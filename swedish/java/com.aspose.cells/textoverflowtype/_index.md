### CLIP {#CLIP}
```
public static final int CLIP
```


Observera övre och nedre begränsningar. Ge ingen indikation på att det finns text som inte är synlig.

### ELLIPSIS {#ELLIPSIS}
```
public static final int ELLIPSIS
```


Observera övre och nedre begränsningar. Använd en ellips för att ange att det finns text som inte är synlig. Endast för vertikal överspill.
