Enumererar visningstyp för text när textbredden är större än cellbredden.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [CROSS_KEEP](#CROSS-KEEP) | Visa all text genom att korsa andra celler och behålla texten i de korsade cellerna. |
| [CROSS_OVERRIDE](#CROSS-OVERRIDE) | Visa all text genom att korsa andra celler och skriva över texten i de korsade cellerna. |
| [DEFAULT](#DEFAULT) | Visa text som i Microsoft Excel. |
| [STRICT_IN_CELL](#STRICT-IN-CELL) | Visa endast texten inom cellens bredd. |
