## Fält

| Fält | Beskrivning |
| --- | --- |
| [AUTOMATIC](#AUTOMATIC) | När textflödet är horisontellt eller enkelt vertikalt samma som fontBaseline men för andra vertikala lägen samma som fontCenter. |
| [BASELINE](#BASELINE) | Bokstäverna är förankrade vid den nedre baslinjen för en enda rad. |
| [BOTTOM](#BOTTOM) | Bokstäverna är förankrade vid den allra nedersta delen av en enda rad. |
| [CENTER](#CENTER) | Bokstäverna är förankrade mellan de två baslinjerna för en enda rad. |
| [TOP](#TOP) | Bokstäverna är förankrade vid den övre baslinjen för en enda rad. |
