### ALLOW_MULTIPLE {#ALLOW-MULTIPLE}
```
public static final int ALLOW_MULTIPLE
```


Alla hyperlänkar i en cell läggs till i [Worksheet.getHyperlinks()](../../com.aspose.cells/worksheet\#getHyperlinks--). Observera att MS Excel endast stöder en hyperlänk per cell, så detta alternativ kan skapa filer som Excel inte kan rendera fullt ut.

### NORMAL {#NORMAL}
```
public static final int NORMAL
```
