### add(String url) {#add-java.lang.String-}
```
public int add(String url)
```


Lägg till en [XmlMap](../../com.aspose.cells/xmlmap) via URL/sökväg till en xml/xsd-fil.

**Example**

Följande kod lägger till två XmlMaps med en xsd-fil och en xml-fil.

```
         Workbook wb = new Workbook();
 
         XmlMapCollection xmlMapCollection = wb.getWorksheets().getXmlMaps();
 
         //Add a XmlMap by a xsd file.
         xmlMapCollection.add("schema.xsd");
 
         //Add a XmlMap by a xml file.
         xmlMapCollection.add("xml.xml");
 
         wb.save("twoXmlMaps.xlsx");
```

| --- | --- | --- |
