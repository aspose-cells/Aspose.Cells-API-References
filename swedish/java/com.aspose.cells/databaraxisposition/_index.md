### AUTOMATIC {#AUTOMATIC}
```
public static final int AUTOMATIC
```


Visa axeln på en variabel position baserat på förhållandet mellan det minsta negativa värdet och det största positiva värdet i intervallet. Positiva värden visas från vänster till höger. Negativa värden visas från höger till vänster. När alla värden är positiva eller alla värden är negativa visas ingen axel.

### MIDPOINT {#MIDPOINT}
```
public static final int MIDPOINT
```


Visa axeln i cellens mittpunkt oavsett vilka värden som finns i intervallet. Positiva värden visas från vänster till höger. Negativa värden visas från höger till vänster.

### NONE {#NONE}
```
public static final int NONE
```


Ingen axel visas, och både positiva och negativa värden visas från vänster till höger.
