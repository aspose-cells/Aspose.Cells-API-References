public final class OnErrorActionType

Används i CellError‑händelsen för GridWeb. Användaren sätter OnErrorActionQuery.OnErrorAction för att instruera kontrollen att Stoppa bearbetning eller Ignorera fel.
## Fält

| Fält | Beskrivning |
| --- | --- |
| [IGNORE](#IGNORE) | Ignorerar felet och fortsätter bearbetningen. |
| [STOP](#STOP) | Stoppar den aktuella bearbetningen. |
| [THROW](#THROW) | Kastar det aktuella undantaget. |
