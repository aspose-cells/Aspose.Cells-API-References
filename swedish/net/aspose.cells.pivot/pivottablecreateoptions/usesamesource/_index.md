## PivotTableCreateOptions.UseSameSource property

Hämtar eller anger ett värde som indikerar om samma datakälla ska delas med befintliga pivottabeller. Standardvärdet är sant.

```csharp
public bool UseSameSource { get; set; }
```

### Anmärkningar

När den är satt till true kan flera pivottabeller återanvända en pivotcache för att minska minnesförbrukningen.
