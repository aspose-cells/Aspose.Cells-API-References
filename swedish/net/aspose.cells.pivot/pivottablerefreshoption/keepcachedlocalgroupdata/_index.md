## PivotTableRefreshOption.KeepCachedLocalGroupData property

Anger om cachad lokal gruppdata ska behållas om de maximala och minimala värdena förblir oförändrade. Standardvärdet är false, vilket betyder att gruppen uppdateras med lokala inställningar.

```csharp
public bool KeepCachedLocalGroupData { get; set; }
```

### Anmärkningar

Detta är en tillfällig lösning, vänligen lokalisera pivottabeller genom att implementera [`PivotGlobalizationSettings`](../../../aspose.cells.settings/pivotglobalizationsettings/)
