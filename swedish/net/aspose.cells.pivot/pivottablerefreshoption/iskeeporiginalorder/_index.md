## PivotTableRefreshOption.IsKeepOriginalOrder property

Anger om pivotobjektens ursprungliga ordning ska behållas som i den gamla datakällan.

```csharp
public bool IsKeepOriginalOrder { get; set; }
```

### Anmärkningar

Gäller endast för pivottfältet som inte är sorterat. När ett sådant pivottfält uppdateras behåller Ms Excel den ursprungliga ordningen från den gamla datakällan. Standardvärdet för denna egenskap är true, vilket motsvarar samma beteende som i Ms Excel. Om användaren vill att pivottfältet ska uppdateras helt enligt data i den nya datakällan, bör denna egenskap sättas till false.
