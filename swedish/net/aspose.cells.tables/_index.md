Namnrummet **Aspose.Cells.Tables** innehåller klasser som representerar tabeller, rader, celler och deras formatering för Excel‑kalkylbladsfiler.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [ListColumn](./listcolumn/) | Representerar en kolumn i en tabell. |
| [ListColumnCollection](./listcolumncollection/) | Representerar en lista över alla [`ListColumn`](../aspose.cells.tables/listcolumn/)-objekt i tabellen. |
| [ListObject](./listobject/) | Representerar en tabell i ett arbetsblad. |
| [ListObjectCollection](./listobjectcollection/) | Representerar en samling av [`ListObject`](../aspose.cells.tables/listobject/)-objekt i arbetsbladet. |
| [TableStyle](./tablestyle/) | Representerar tabellens stil. |
| [TableStyleCollection](./tablestylecollection/) | Representerar alla anpassade tabellstilar. |
| [TableStyleElement](./tablestyleelement/) | Representerar elementet i tabellstilen. |
| [TableStyleElementCollection](./tablestyleelementcollection/) | Representerar alla element i tabellstilen. |
| [TableToRangeOptions](./tabletorangeoptions/) | Representerar alternativen när tabell konverteras till ett område. |
