## Config.IsWasm property

Hämtar/Anger om GridJs körs i en webbläsar‑WebAssembly‑värd istället för en serverprocess. När den är `true` används ingen FileCacheDirectory / disk / interrupt‑thread‑sökväg och filcachen måste komma från GridJsOptions.CacheImp. GridJsOptions.IsWasm sätter detta när GridJs‑tjänsten konstrueras, så en Aspose.Cells.GridJs.dll kan betjäna båda värdarna. Standardvärdet är `false`.

public static bool IsWasm { get; set; }
