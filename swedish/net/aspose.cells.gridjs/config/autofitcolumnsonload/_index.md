## Config.AutoFitColumnsOnLoad property

Anger om kolumnbredder ska automatiskt anpassas vid filinläsning. Standardvärdet är `false`. Varning: Om detta sätts till `true` utförs en automatisk anpassning av alla kolumner efter inläsning, vilket kan ha en märkbar inverkan på prestandan.

```csharp
public static bool AutoFitColumnsOnLoad { get; set; }
```
