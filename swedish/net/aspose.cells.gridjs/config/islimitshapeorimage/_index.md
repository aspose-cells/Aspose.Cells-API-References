## Config.IslimitShapeOrImage property

Hämtar/Sätter om det totala antalet visade former/bilder i ett kalkylblad ska begränsas, om satt till sant kommer GridJs att begränsa det totala antalet visade former eller bilder i ett kalkylblad till MaxShapeOrImageCount. Standardvärdet är sant.

public static bool IslimitShapeOrImage { get; set; }
