## Config.AutoFitRowsHeightOnLoad property

Anger om radhöjder ska automatiskt anpassas vid filinläsning. Standardvärdet är `false`. Varning: Om detta sätts till `true` utförs en automatisk anpassning av alla rader efter inläsning, vilket kan ha en märkbar inverkan på prestandan.

```csharp
public static bool AutoFitRowsHeightOnLoad { get; set; }
```
