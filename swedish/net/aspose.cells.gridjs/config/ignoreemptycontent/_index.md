## Config.IgnoreEmptyContent property

Hämtar/Sätter om det maximala intervallet som inkluderar data, stil, sammanslagna celler och former ska visas. Om den sista raden eller kolumnen innehåller celler utan värde och formel men med anpassad stil visas inte den raden/kolumnen när detta värde är sant. Standardvärdet är sant.

public static bool IgnoreEmptyContent { get; set; }
