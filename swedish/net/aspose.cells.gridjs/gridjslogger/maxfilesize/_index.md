## GridJsLogger.MaxFileSize property

Hämtar eller anger den maximala storleken (i byte) för en enskild loggfil innan den rullas. Gäller endast när rullning är aktiverad. 0 betyder ingen storleksgräns. Standard är 0.

public static long MaxFileSize { get; set; }
