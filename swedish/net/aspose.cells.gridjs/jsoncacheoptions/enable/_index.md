## JsonCacheOptions.Enable property

Hämtar/Anger om JSON‑cachning ska aktiveras för snabbare svar. När den är aktiverad kommer GridJs att cacha den genererade JSON‑en och återanvända den för efterföljande begäranden. Standardvärdet är false. Obs: Du måste ange Implementation för att använda anpassad cache‑lagring.

public bool Enable { get; set; }
