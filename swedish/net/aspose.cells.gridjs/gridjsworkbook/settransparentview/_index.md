## GridJsWorkbook.SetTransParentView method

Ställer in transparensen för redigeringsformer i arbetsboken.

```csharp
public void SetTransParentView(string excelFilePath, string uid, bool isTransparent)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| excelFilePath | String | Filvägen för Excel-filen. |
| uid | String | Den unika identifieraren för arbetsboken. Om null eller tom, kommer ett nytt uid att genereras baserat på filvägen. |
| isTransparent | Boolean | Om true, sätts transparensen till 0,89 (halvgenomskinlig); om false, sätts transparensen till 1 (fullt ogenomskinlig/osynlig). |
