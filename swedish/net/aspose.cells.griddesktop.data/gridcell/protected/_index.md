## GridCell.Protected property

Anger om cellen är skyddad. Om värdet är "true" kan användaren inte ändra cellen via användargränssnittet. Detta attribut har ingen koppling till egenskapen Style.CellLocked och sparas inte till fil när rutnätsdata exporteras. Standardvärdet är "false".

public bool Protected { get; set; }
