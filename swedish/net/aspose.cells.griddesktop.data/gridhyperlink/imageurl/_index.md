## GridHyperlink.ImageURL property

Hämta eller ange bild‑URL för länken, det finns ingen imageurl‑egenskap i hyperlänken, så använd i stället TextToDisplay för att lagra detta värde, TextToDisplay kommer att sättas till &lt;img src=value &gt; så att värdet på TextToDisplay ändras.

public string ImageURL { get; set; }
