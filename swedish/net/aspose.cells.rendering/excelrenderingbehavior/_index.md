## ExcelRenderingBehavior enumeration

Specificerar Excel‑specifika renderingsbeteenden som ska tillämpas vid rendering av en arbetsbok.

```csharp
[Flags]
public enum ExcelRenderingBehavior
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | `0` | Tillämpar inte Excel-specifika renderingsbeteenden. |
| CellTextLengthLimit | `1` | Tillämpar Excels begränsning för celltextens utskriftslängd. Till exempel exporterar Excel endast de första 1024 tecknen i en cell som inte är radbruten. |
| All | `FFFFFFFFFFFFFFFF` | Tillämpar alla stödda Excel-specifika renderingsbeteenden. |
