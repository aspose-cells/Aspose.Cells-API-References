Namnområdet **Aspose.Cells.ExternalConnections** tillhandahåller klasser för externa anslutningar för att hämta data från externa källor såsom databaser och webben.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [ConnectionParameter](./connectionparameter/) | Anger egenskaper för alla parametrar som används med externa datakopplingar. Parametrar är giltiga för ODBC- och webbfrågor. |
| [ConnectionParameterCollection](./connectionparametercollection/) | Anger [`ConnectionParameter`](../aspose.cells.externalconnections/connectionparameter/)-samlingen |
| [DataModelConnection](./datamodelconnection/) | Anger en datamodellsanslutning |
| [DBConnection](./dbconnection/) | Anger alla egenskaper som är associerade med en extern ODBC- eller OLE DB-datakoppling. |
| [ExternalConnection](./externalconnection/) | Anger en extern datakoppling |
| [ExternalConnectionCollection](./externalconnectioncollection/) | Anger [`ExternalConnection`](../aspose.cells.externalconnections/externalconnection/)-samlingen |
| [WebQueryConnection](./webqueryconnection/) | Anger egenskaperna för en webbfrågekälla. En webbfråga hämtar data från HTML-tabeller och kan även leverera HTTP \"Get\"-parametrar som behandlas av webbservern vid generering av HTML genom att inkludera parametrarna och parameterelementen. |
## Uppräkning

| Uppräkning | Beskrivning |
| --- | --- |
| [ConnectionDataSourceType](./connectiondatasourcetype/) | Anger typ av extern databaskälla |
| [ConnectionParameterType](./connectionparametertype/) | Anger parametertypen för extern anslutning |
| [CredentialsMethodType](./credentialsmethodtype/) | Anger metod för autentiseringsuppgifter som används för serveråtkomst. |
| [ExternalConnectionClassType](./externalconnectionclasstype/) | Representerar anslutningstypen |
| [HtmlFormatHandlingType](./htmlformathandlingtype/) | Anger hur formatering från HTML-källan ska hanteras |
| [OLEDBCommandType](./oledbcommandtype/) | Anger OLE DB-kommandotypen. |
| [ReConnectionMethodType](./reconnectionmethodtype/) | Anger vad kalkylbladsapplikationen ska göra när en anslutning misslyckas. |
| [SqlDataType](./sqldatatype/) | Anger SQL-datatyp för parametern. Gäller endast för ODBC-källor. |
