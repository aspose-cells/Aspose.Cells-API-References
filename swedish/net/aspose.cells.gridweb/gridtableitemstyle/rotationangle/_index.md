Hämtar eller anger rotationsattributet.

```csharp
public short RotationAngle { get; set; }
```

### Anmärkningar

0: Inte roterad.

255: Uppifrån och ner.

-90: Downward.

90: Uppåt.

Du kan ange 255 eller ett värde mellan -90 och 90.
