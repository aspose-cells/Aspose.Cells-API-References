## GridTableItemStyle.IsLocked property

Hämtar eller anger ett värde som indikerar om en cell kan ändras eller inte när dess kalkylblad är skyddat. När kalkylbladet är skyddat och IsLocked är true, kan cellen inte redigeras. När kalkylbladet är skyddat och IsLocked är false, kan cellen redigeras.

```csharp
public bool IsLocked { get; set; }
```
