## Validation.ClientValidationFunction property

Hämtar eller anger klientvalideringens JavaScript-funktionsnamn.

```csharp
public string ClientValidationFunction { get; set; }
```

### Anmärkningar

Använd egenskapen ClientValidationFunction för att ange namn på klientvalideringsfunktionen. Funktionen bör deklareras enligt följande: function customValicationFunction(source, value) Parametern "source" är cellobjektet. Parametern "value" är strängvärdet för en cell som ska kontrolleras. Funktionen bör returnera true om värdet är giltigt.
