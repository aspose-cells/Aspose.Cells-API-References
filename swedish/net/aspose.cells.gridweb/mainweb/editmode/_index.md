## MainWeb.EditMode property

Hämtar eller anger kontrollens redigeringsläge.

```csharp
public bool EditMode { get; set; }
```

### Anmärkningar

När den sätts till true är kontrollens celler redigerbara, och ikonerna "save" och "undo" visas. När den sätts till false är kontrollens celler skrivskyddade, och ikonerna "save" och "undo" visas inte.
