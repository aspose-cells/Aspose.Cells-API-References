## MainWeb.EnableDoubleClickEvent property

Hämtar eller anger om dubbelklickshändelse på kundsidan ska aktiveras.

```csharp
public bool EnableDoubleClickEvent { get; set; }
```

### Anmärkningar

När den sätts till true kommer kontrollen att ta emot dubbelklick‑händelser på kundsidan och du kan hantera dessa händelser på serversidan. Annars kommer kontrollen att ignorera alla dubbelklick‑händelser.
