## MainWeb.MinRow property

Hämtar eller anger det minsta visningsradindexet (nollbaserat) för webblarket. Kontrollen använder det mindre värdet av MinRow och bladdata's minsta rad.

```csharp
public int MinRow { get; set; }
```

[C#]
