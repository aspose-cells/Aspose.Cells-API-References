## MainWeb.MaxColumn property

Hämtar eller anger det maximala visningskolumnindexet (nollbaserat) för webblarket. Kontrollen använder det större värdet av MaxColumn och bladdata's maximala kolumn.

```csharp
public int MaxColumn { get; set; }
```

[C#]
