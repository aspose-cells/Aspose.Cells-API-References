## MainWeb.OnCellUnselectedClientFunction property

Hämtar eller anger den klientsidiga funktionen som ska anropas när en cell avmarkerats. Klientfunktionen bör deklareras så här: function MyOnUnselectCell(cell) { this.setCellValueByCell(cell, "test"); }Obs: Du kan använda "this"-pekaren i klientfunktionen för att peka på gridkontrollen som utlöser händelsen.
