## MainWeb.OnCellSelectedClientFunction property

Hämtar eller anger den klientsidiga funktionen som ska anropas när en cell är markerad. Klientfunktionen bör deklareras så här: function MyOnSelectCell(cell) { GridWeb1.setCellValueByCell(cell, "test"); }Obs: Du kan använda "this"-pekaren i klientfunktionen för att peka på gridkontrollen som utlöser händelsen.
