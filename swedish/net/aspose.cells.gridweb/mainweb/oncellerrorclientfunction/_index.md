## MainWeb.OnCellErrorClientFunction property

Hämtar eller anger namnet på klientsidans funktion som ska anropas när en cells validering misslyckas. Klientfunktionen bör deklareras så här: function MyOnCellError(cell) { alert(this.getCellValueByCell(cell)); } Obs: Du kan använda "this"‑pekaren i klientfunktionen för att referera till rutnätskontrollen som utlöser händelsen.
