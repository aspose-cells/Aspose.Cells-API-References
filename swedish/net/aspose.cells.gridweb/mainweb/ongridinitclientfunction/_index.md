## MainWeb.OnGridInitClientFunction property

Hämtar eller anger namnet på den klientsidiga funktionen som ska anropas när griden initieras. Klientfunktionen bör deklareras så här: function MyOnGridInit(grid) { alert("The grid is initialized: " + grid.id); }Obs: Du kan använda "this"-pekaren i klientfunktionen för att peka på gridkontrollen som utlöser händelsen.
