## MainWeb.OnPageChangeClientFunction property

Hämtar eller anger den klientsidiga funktionen som ska anropas efter sidindexändring. Gäller endast när EnablePaging är true. Klientfunktionen bör deklareras så här: function MyOnPageChange(index) { console.log("current page is:"+index); }Obs: Du kan använda "this"-pekaren i klientfunktionen för att peka på gridkontrollen som utlöser händelsen.
