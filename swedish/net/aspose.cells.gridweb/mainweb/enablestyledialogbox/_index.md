## MainWeb.EnableStyleDialogbox property

Hämtar eller anger om stil‑dialogrutan på klientsidan ska aktiveras.

```csharp
public bool EnableStyleDialogbox { get; set; }
```

### Anmärkningar

När den sätts till true kan användaren använda stil‑dialogrutan för att sätta en cells stil genom att välja \"Format Cell...\" i popup‑menyn.
