## MainWeb.MinColumn property

Hämtar eller anger det minsta visningskolumnindexet (nollbaserat) för webblarket. Kontrollen använder det mindre värdet av MinColumn och bladdata's minsta kolumn.

```csharp
public int MinColumn { get; set; }
```
