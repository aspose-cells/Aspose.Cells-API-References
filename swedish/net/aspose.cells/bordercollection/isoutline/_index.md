## BorderCollection.IsOutline property

Anger om vänster, höger, övre och nedre kanter ska tillämpas endast på yttre kanter av ett cellområde. Standardvärdet är true.

```csharp
public bool IsOutline { get; set; }
```

### Anmärkningar

Fungerar endast när den tillämpas på ett område för villkorsformatering eller pivottabeller. Om false, vänster, höger, topp och botten appliceras på varje cell, annars endast på yttre kanter av ett cellområde. Om true, ange horisontella och vertikala kanter för de inre kanterna i området för villkorsformatering eller pivottabeller.
