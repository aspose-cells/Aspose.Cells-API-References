## GridTxtLoadOptions.ExtendToNextSheet property

Om data ska utökas till nästa blad när rader eller kolumner överskrider gränsen. Om denna egenskap är sann, kommer extra data att utökas till nästa blad bakom det aktuella (om det aktuella bladet är det sista, kommer ett nytt blad att läggas till i den aktuella arbetsboken). Om egenskapen är falsk, kommer data som överskrider gränsen att ignoreras. Standardvärdet är falskt;

```csharp
public bool ExtendToNextSheet { get; set; }
```
