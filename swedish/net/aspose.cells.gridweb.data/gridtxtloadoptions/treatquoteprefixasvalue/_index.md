## GridTxtLoadOptions.TreatQuotePrefixAsValue property

Anger om det inledande enkelfnuttstecknet ska tas med som en del av värdet i en cell. Standard är true. Om det är false kommer det inledande enkelfnuttstecknet att tas bort från motsvarande cells värde och [`QuotePrefix`](../../../aspose.cells.gridweb/gridtableitemstyle/quoteprefix/) kommer att sättas till true för cellen.

public bool TreatQuotePrefixAsValue { get; set; }
