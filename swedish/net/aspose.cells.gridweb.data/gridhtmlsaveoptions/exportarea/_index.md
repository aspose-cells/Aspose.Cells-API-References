## GridHtmlSaveOptions.ExportArea property

Hämtar eller anger det exporterande CellArea för det aktuella aktiva kalkylbladet. Om du anger detta attribut kommer utskriftsområdet för det aktuella aktiva kalkylbladet att utelämnas. Endast det angivna området kommer att exporteras när filen sparas till html.
