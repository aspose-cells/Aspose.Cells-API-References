## GridCalculationData.CalculatedValue property

Hämtar eller anger det beräknade värdet för denna funktion.

```csharp
public object CalculatedValue { get; set; }
```

### Anmärkningar

Användaren bör sätta denna egenskap i sin anpassade beräkningsmotor för de funktioner som motorn stöder, och det satta värdet kommer att returneras när egenskapen hämtas. Att hämta denna egenskap innan den har satts gör att funktionen beräknas av standardberäkningsmotorn i Aspose.Cells och det beräknade värdet kommer att returneras.
