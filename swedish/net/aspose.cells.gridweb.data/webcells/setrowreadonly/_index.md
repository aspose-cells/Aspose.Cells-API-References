## WebCells.SetRowReadonly method

Ställer in en rad som skrivskyddad så att användaren inte kan ta bort den från klientsidan. Detta är en utökad metod för GridWeb specifikt, den kommer inte att sparas eller ha effekt i den faktiska Excel-filen.

```csharp
public void SetRowReadonly(int rowIndex, bool isReadonly)
```

| Parameter | Typ | Beskrivning |

| rowIndex | Int32 | radindex. |
| isReadonly | Boolean | sant eller falskt. |
