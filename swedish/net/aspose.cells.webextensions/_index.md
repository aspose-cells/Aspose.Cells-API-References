Namnrummet **Aspose.Cells.WebExtensions** innehåller klasser för att komma åt Office‑tillägg i Excel‑filer.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [WebExtension](./webextension/) | Representerar en Office-tilläggsinstans. |
| [WebExtensionBinding](./webextensionbinding/) | Representerar ett bindningsförhållande mellan ett Office-tillägg och data i dokumentet. |
| [WebExtensionBindingCollection](./webextensionbindingcollection/) | Representerar listan över bindningsförhållanden mellan ett Office-tillägg och data i dokumentet. |
| [WebExtensionCollection](./webextensioncollection/) | Representerar listan över webbutökning. |
| [WebExtensionProperty](./webextensionproperty/) | Representerar en anpassad egenskap för ett Office-tillägg. |
| [WebExtensionPropertyCollection](./webextensionpropertycollection/) | Representerar listan över egenskaper för webbutökning. |
| [WebExtensionReference](./webextensionreference/) | Representerar identifiering av leverantörens plats och version av tillägget. |
| [WebExtensionReferenceCollection](./webextensionreferencecollection/) | Representerar listan över referenser för webbutökning. |
| [WebExtensionTaskPane](./webextensiontaskpane/) | Representerar ett beständigt taskpane-objekt. |
| [WebExtensionTaskPaneCollection](./webextensiontaskpanecollection/) | Representerar listan över taskpane. |
