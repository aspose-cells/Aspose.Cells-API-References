## GridDesktop.EnableClipboardCopyPaste property

Anger om kopiering/klistring ska baseras på urklipp, så att det kan kopiera/klistra med MS-EXCEL. Det kopierar/endast klistrar cellvärdet, det kopierar inte några andra inställningar för cellen som format, kantstil osv. Standardvärdet är falskt.

public bool EnableClipboardCopyPaste { get; set; }
