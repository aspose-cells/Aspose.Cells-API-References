## GridDesktop.AlwasysRecalculateAllFormulas property

Hämtar eller anger ett värde som indikerar om vi behöver köra alla formler, som när vi kör alla formler, när en cellvärde uppdateras, och det påverkar andra, och andra påverkar andra, mer och mer, vilket får att hela cellerna måste omberäknas, precis som fjärilseffekten, det kräver många stackoperationer, det ger mycket låg prestanda, som i CELLSNET-41921, detta problem innehåller den fil som kan visa detta scenario, vi bör hellre bara köra alla formler, eftersom när vi kör alla formler kan vi ha viss optimering.

public bool AlwasysRecalculateAllFormulas { get; set; }
