## GridDesktop.StartFormatPainter method

Meddelar GridDesktop att starta FormatPainter.

```csharp
public void StartFormatPainter(bool formatOnce)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| formatOnce | Boolean | Om formatOnce är true kan FormatPainter användas en gång, om formatOnce är false kan FormatPainter användas flera gånger, tills EndFormatPainter() anropas. |

### Exempel

```csharp
[C#]
gridDesktop1.StartFormatPainter(true);

[Visual Basic]
gridDesktop1.StartFormatPainter(True)

```
