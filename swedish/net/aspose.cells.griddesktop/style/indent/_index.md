## Style.Indent property

Representerar m_IndentLevel‑nivån för cellen eller området. Kan endast vara ett heltal mellan 0 och 15.

```csharp
public int Indent { get; set; }
```

### Anmärkningar

Om textens horisontella justeringstyp är satt till ett värde annat än vänster eller höger, återställs m_IndentLevel‑nivån till noll.
