## ExcelRenderingBehavior Enum

Anger Excel-specifika renderingsbeteenden att tillämpa vid rendering av en arbetsbok.

```go

type ExcelRenderingBehavior int32


```

## Fält

| Fält | Beskrivning |
| --- | --- |
| [None](./none/) | Tillämpar inte Excel-specifika renderingsbeteenden. |
| [CellTextLengthLimit](./celltextlengthlimit/) | Tillämpar Excels begränsning för celltextens utskriftslängd. Till exempel skriver Excel endast ut de första 1024 tecknen i en icke‑radbruten cell. |
| [All](./all/) | Tillämpar alla stödjade Excel-specifika renderingsbeteenden. |
