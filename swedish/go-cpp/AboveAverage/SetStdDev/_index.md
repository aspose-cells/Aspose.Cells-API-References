## SetStdDev function

Hämta eller ange antalet standardavvikelser som ska inkluderas över eller under medelvärdet i det villkorsformatregeln.Inmatningsvärdet måste vara mellan 0 och 3 (inkludera 0 och 3).Att sätta detta värde till 0 betyder att stdDev inte är angivet.Standardvärdet är 0.

```go

func (instance *AboveAverage) SetStdDev(value int32)  error

```
