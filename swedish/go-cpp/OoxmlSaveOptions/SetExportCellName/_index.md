## SetExportCellName function

Anger om cellnamn ska exporteras till Excel2007 .xlsx (.xlsm, .xltx, .xltm)-fil. Om utdatafilen kan nås av SQL Server DTS måste detta värde vara sant. Att sätta värdet till falskt kommer kraftigt öka prestandan och minska filstorleken vid skapande av stora filer. Standardvärdet är sant.
