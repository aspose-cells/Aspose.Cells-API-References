## SetDefaultFont function

När tecken i Excel är Unicode och inte har rätt teckensnitt inställt i cellstilen, kan de visas som block i pdf eller bild. Ställ in DefaultFont, till exempel MingLiu eller MS Gothic, för att visa dessa tecken. Om denna egenskap inte är inställd kommer Aspose.Cells att använda systemets standardteckensnitt för att visa dessa Unicode-tecken.
