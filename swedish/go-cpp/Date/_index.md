## Date Struct

Representerar ett datum och en tid.

```go

type Date int32


```

## Fält

| Fält | Beskrivning |
| --- | --- |
| [year](./year/) | Årkomponent (1-9999). |
| [month](./month/) | Månadskomponent (1-12). |
| [day](./day/) | Dagkomponent (1-31). |
| [hour](./hour/) | Timkomponent (0-23). |
| [minute](./minute/) | Minutkomponent (0-59). |
| [second](./second/) | Sekundkomponent (0-59). |
| [millisecond](./millisecond/) | Millisekundkomponent (0-999). |
| [dateKind](./datekind/) | Anger om tiden är lokal, UTC eller ospecificerad. Standardvärdet är Ospecificerad. |
