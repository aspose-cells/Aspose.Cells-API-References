## HtmlFormatHandlingType Enum

Anger hur formatering från HTML-källan ska hanteras

```go

type HtmlFormatHandlingType int32


```

## Fält

| Fält | Beskrivning |
| --- | --- |
| [All](./all/) | Överför all HTML-formatering till kalkylbladet tillsammans med data. |
| [None](./none/) | Ta in data som oformaterad text (inställning av datatyper sker fortfarande). |
| [Rtf](./rtf/) | Översätt HTML-formatering till rik textformatering på data som har tagits in i kalkylbladet. |
