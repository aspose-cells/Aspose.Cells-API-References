## SetEmbedStandardWindowsFonts function

True för att bädda in TrueType-teckensnitt. Påverkar endast ASCII-tecken 32-127. Teckensnitt för teckenkoder över 127 bäddas alltid in. Teckensnitt bäddas alltid in för PDF/A-1a, PDF/A-1b-standarden. Standard är true.
