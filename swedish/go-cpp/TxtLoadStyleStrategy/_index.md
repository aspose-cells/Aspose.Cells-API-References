## TxtLoadStyleStrategy Enum

Specificerar hur stil ska tillämpas för analyserade värden när en strängvärde konverteras till nummer eller datum/tid.

```go

type TxtLoadStyleStrategy int32


```

## Fält

| Fält | Beskrivning |
| --- | --- |
| [None](./none/) | Ställer inte in stil för det analyserade värdet. |
| [BuiltIn](./builtin/) | Ställ in stilen som inbyggd nummer/datumtid när det analyserade värdet är enkla numeriska/datumtidvärden. |
| [ExactFormat](./exactformat/) | Ange det exakta anpassade formatet för det analyserade värdet så att det formaterade värdet blir detsamma som det ursprungliga inmatade. |
