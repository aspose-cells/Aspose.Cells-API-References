## VisibilityType Enum

Representerar tillstånden för bladets synlighet.

```go

type VisibilityType int32


```

## Fält

| Fält | Beskrivning |
| --- | --- |
| [Visible](./visible/) | Indikerar att bladet är synligt. |
| [Hidden](./hidden/) | Indikerar att bladet är dolt, men kan visas av användaren via användargränssnittet. |
| [VeryHidden](./veryhidden/) | Indikerar att bladet är dolt och inte kan visas i användargränssnittet (UI).Detta tillstånd är endast tillgängligt programatiskt. |
