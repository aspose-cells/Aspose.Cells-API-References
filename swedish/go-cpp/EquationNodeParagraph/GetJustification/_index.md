## GetJustification function

Detta specificerar justeringen av matematikstycket (en serie intilliggande ekvationer inom samma stycke). Ett matematikstycke kan vara vänsterjusterat, högerjusterat, centrerat eller centrerat som grupp. Som standard är matematikstycket centrerat som grupp. Detta innebär att ekvationerna kan justeras i förhållande till varandra, men hela gruppen av ekvationer är centrerad som helhet.
