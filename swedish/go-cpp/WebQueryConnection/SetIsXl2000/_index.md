## SetIsXl2000 function

Denna flagga finns för bakåtkompatibilitet med äldre befintliga kalkylbladsfiler, och sätts till true om denna webbförfrågan uppdaterades i ett kalkylbladsprogram nyare än eller lika med Microsoft Excel 2000. Detta är ett valfritt attribut som kan ignoreras.
