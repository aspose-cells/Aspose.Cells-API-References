## SetHtmlCrossStringType function

Anger om en sträng som sträcker sig över flera celler visas på samma sätt som i MS Excel när en Excel‑fil sparas i html‑format. Som standard är värdet Default, så för strängar som sträcker sig över celler är skillnaden mellan html‑filer skapade av Aspose.Cells och MS Excel liten. Men prestandan för att skapa stora html‑filer blir flera gånger snabbare om värdet sätts till Cross jämfört med Default eller Fit2Cell.
