## SetAlignColumnPadding function

Anger om kolumnjustering är aktiverad för genererade Markdown-tabeller. När den är aktiverad justeras kolumnerna genom att fylla cellinnehållet med det angivna tecknet (vanligtvis ' ' för mellanslag). Sätt till '\\0' för att inaktivera kolumnjustering (standard).
