## DateKind Enum

Anger om ett Date-objekt representerar lokal tid, koordinerad UTC-tid (UTC) eller inte är specificerad som vare sig lokal tid eller UTC.

```go

type DateKind int32


```

## Fält

| Fält | Beskrivning |
| --- | --- |
| [Unspecified](./unspecified/) | Den tid som representeras är inte specificerad som varken lokal tid eller koordinerad universell tid (UTC). |
| [Utc](./utc/) | Den tid som representeras är UTC. |
