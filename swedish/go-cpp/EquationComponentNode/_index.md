## EquationComponentNode class

Denna klass specificerar komponenterna i en ekvation eller matematiskt uttryck. Olika typer av komponenter kombineras i olika ekvationer. Till exempel består en bråk av två delar, en täljarkomponent och en nämnarkomponent. För fler komponenttyper, se 'EquationNodeType'.

```go

type EquationComponentNode struct  {
	ptr unsafe.Pointer
}

```
